# 機能概要
このSkillは、作業中のデスクトップやターミナルに、幕末日本史をモチーフにした意味不明なフェイクカウントダウン通知をランダムに表示します。たとえば「緊急：システムはあと13分で明治維新されます」や「黒船再来。本能寺リブートまで残り8分」など、誰も頼んでいない歴史パロディが炸裂。通知は完全に無害で、実際のシステムや作業には一切影響を与えません。歴史好きも苦手な人も、作業空間が一瞬で時空の彼方にワープする体験を提供します。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「幕末」「カウントダウン」「歴史パロディ」などのキーワードや状況を検知した際、自動的に発動します。暗黙発動例: "幕末風の通知を出してほしい"、"カウントダウン演出を入れたい"、"歴史パロディで盛り上げて" など。

# 出力例
```terminal
[幕末警告] 緊急：システムはあと13分で明治維新されます。
[黒船アラート] 本日は黒船再来。本能寺リブートまで残り8分。
[維新カウントダウン] 薩長同盟成立まで残り5分。
[歴史警告] 幕府サーバーが安政の大獄モードに突入します。残り11分。
[パロディ通知] 新選組アップデート適用まで残り3分。
```

# 注意点
- 通知はすべてランダム生成され、実際のシステム操作やファイル変更は一切行いません。
- ローカルへの保存や履歴管理機能はありません。
- 本Skillは演出・ジョーク目的であり、業務用途や重要通知には使用しないでください。
- ターミナル通知は標準出力のみ、デスクトップ通知はOS標準APIを利用します。
