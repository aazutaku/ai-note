# 概要
本Skillは、作業中の静寂や緊張感を和らげるため、架空の“OS公式サウンドトラック”通知を自動生成・表示するジョーク系演出Skillです。通知内容は毎回ユニークで、開発現場ならではのネタや無意味な曲名が特徴です。

# 公式ドキュメント抜粋
- macOS: `osascript` による通知表示
- Linux: `notify-send` コマンド
- Windows: `win10toast` ライブラリ（なければ標準出力）

# 利用例
- 長時間のコーディングや会議中の気分転換
- チーム開発の話題作りやアイスブレイク
- OSジョーク演出によるコミュニケーション促進

# 注意点
- 実際のBGMや音は流れません。
- 通知頻度はスクリプト実行時に調整可能です。
- 通知内容はローカルに保存されません。

# 設計方針
- OSごとに実在するAPI/コマンドのみ使用
- 通知内容は毎回ランダム生成
- 作業の妨げにならない頻度・出力形式
- シンプルなCLIサブコマンド構成
