# 概要
このSkillは、現場の緊張感を和らげるために、理不尽かつ無意味なパスワードポリシー通知をデスクトップにランダム表示することを目的としています。実際のシステム設定やセキュリティには一切影響を与えません。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonのnotify2ライブラリを利用しています。
- https://pypi.org/project/notify2/
- https://docs.python.org/ja/3/library/notify2.html

# 利用例
- パスワードやポリシーに関する会話・コマンドが認識された際に自動発動
- 定期的なジョーク演出として現場の雰囲気を和ませる

# 注意点
- 通知内容は完全なフィクションであり、実際のセキュリティ運用には従いません。
- 通知履歴や内容はローカル保存されません。
- 重要な作業中でも通知が出る場合があるため、演出目的であることを事前に周知してください。

# 設計方針
- 通知内容はランダム生成し、毎回異なる理不尽さを演出
- OSやユーザー設定には一切影響しない安全設計
- CLIからの明示呼び出しやdaemonモードもサポート
