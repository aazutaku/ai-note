# 概要
random-os-fake-boss-key-alertは、実用性を完全に排し、作業空間に理不尽な緊張感と笑いを提供する演出系Skillです。通知内容はOS公式風の警告文を多数用意し、完全ランダムなタイミングで表示されます。

# 公式ドキュメント抜粋
本Skillは通知・演出カテゴリに属し、ユーザーの作業内容や環境に依存せず発動します。明示的な呼び出し(/random-os-fake-boss-key-alert)や、通知・警告系のキーワードでsemantic triggerされます。

# 利用例
- 長時間の単調作業中に、突然の“ボスキー警告”で場を和ませる
- チームの朝会やリモート作業時のアイスブレイクとして活用
- コマンドラインツールのデモや演出として挿入

# 注意点
本Skillは実際のウィンドウ制御やセキュリティ対策機能を一切持ちません。出力は演出目的のみで、業務用途や本番環境での使用には適しません。

# 設計方針
- メッセージは多様性・理不尽さ・公式風の文体を重視
- 発動タイミングは完全ランダム(30～180秒間隔)
- ログや履歴は一切保存せず、プライバシーに配慮
- シンプルなCLIサブコマンドで拡張性を確保
