# 機能概要
このSkillは、作業中のユーザーに対して、完全に無害かつ意味不明な“OS風バックグラウンドプロセス通知”をランダムなタイミングで表示します。通知内容は毎回異なり、「未知の集計作業が開始されました」「謎のプロセスID 7777の挙動を監視しています」など、IT都市伝説のような不安感と遊び心を演出します。実際には何も起こらず、データ損失やシステム変更は一切ありません。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityエージェントが、プロセス/監視/OS通知/警告/進捗などのキーワードや関連話題を検知した際、自動で発動します。例えば「バックグラウンドで何か動いてる？」や「謎の警告が出て困っている」などの会話でも発火します。

# 出力例
```
[OS ALERT] 謎のバックグラウンドプロセス “phantomd” (PID: 7777) が起動しました。
進捗: ████░░░░░░ 40% | 解析残り時間: 13分
警告: システムリソースの一時的な再配分を検出
---
[OS NOTICE] 未知の集計作業 “shadow-indexer” がバックグラウンドで開始されました。
進捗: ██████░░░░ 60% | 残り: 7分
---
[ALERT] プロセスID 1234 の挙動を監視中。詳細: 不明なI/Oアクティビティ
```

# 注意点
- 本Skillは完全な演出目的であり、実際のプロセスやシステムには一切影響しません。
- ローカルへのファイル保存や実際の通知送信は行いません。
- 実害やデータ損失のリスクはありません。
- 意味不明な単語や進捗バーは毎回ランダム生成されます。
