# 概要
このSkillは、OSの標準通知APIを利用して、完全にフェイクなメモリリーク警告をランダムに表示することで、作業中のユーザーに遊び心と注意喚起を提供します。実際のシステムやファイルには一切影響を与えません。

# 公式ドキュメント抜粋
- notify2 (Linux): https://github.com/caronc/apprise
- win10toast (Windows): https://github.com/jithurjacob/Windows-10-Toast-Notifications
- pync (macOS): https://github.com/SeTeM/pync

# 利用例
- 長時間のコーディングや集中作業中に、息抜きとしてフェイク警告を表示
- チーム内での話題作りや、仮想的な障害訓練の演出に

# 注意点
- 通知内容は完全なジョークです。実害や副作用はありません。
- OSの通知機能が無効な環境では表示されません。
- 重要な作業中に驚かせたくない場合はSkillを一時的に無効化してください。

# 設計方針
- 実在APIのみを使用し、外部に危険な処理やファイル操作を行わない
- 導入・削除が容易で、通常作業への影響がない
- 通知メッセージは毎回ランダムで、遊び心を重視
