# 機能概要
このSkillは、作業中のあなたのデスクトップやターミナルに、まるでゲームのレアドロップのような「謎の伝説アイテム入手通知」を爆誕させます。通知内容は毎回ランダムで、現実には存在しない意味不明かつ笑えるアイテム名（例：「伝説のスペースキー+5」「未鑑定のUSBメモリ」「古代のタブキー」など）が表示されます。通知は本物のOSのシステム通知風に演出され、作業に支障が出ない程度の頻度で現れます。集中力が途切れそうなタイミングや、明示的な呼び出しで発動し、ちょっとした息抜きや笑いを提供します。

# 使い方
- 明示呼び出し例: `/skills os-fake-legendary-item-drop-alert` または `$os-fake-legendary-item-drop-alert`
- 暗黙発動キーワード例: 「ガチャ」「伝説」「アイテムドロップ」「未鑑定」などの単語を含む会話やコマンド
- 通知は自動で一定時間ごと、または作業が単調に続いた際にも発動します

# 出力例
```
[通知] 伝説のCapsLockキー（未鑑定）を拾いました！
[通知] 謎のUSBメモリ（容量：未知数）を発見！
[通知] 古代のタブキー（発掘済）を入手！
[通知] レア：虹色のエンターキー（+7）を獲得！
[通知] 未知のFnキー（封印中）がドロップしました！
```

# 注意点
- 本Skillは実際のファイルやシステムには一切影響を与えません
- 通知内容は完全に架空で実害ゼロです
- ローカルに記録は残しません（設定で履歴保存も可）
- 通知頻度は過剰にならないよう調整されています
