# 機能概要
このSkillは、作業中に“謎のOS古代バグ巻物”風のエラー通知をデスクトップやターミナルに表示します。内容は解読不能な横文字や謎の呪文が巻物UIでスクロール表示され、最後に「解読者求ム」や「解決不能」などの無情な一言で締めくくられます。バグ報告すら理解不能な状況をあえて演出し、チームにカオスと笑いをもたらします。通知・演出・OS連携カテゴリのネタ系スキルです。

# 使い方
- 明示呼び出し例: `/random-os-fake-unreadable-error-scroll`
- 暗黙発動キーワード例: 「エラー」「バグ」「通知」「不可解」「OSバグ」「混乱」「カオス」などの単語を含む発話やイベント時に自動発動します。

# 注意点
- 本Skillは実害のない演出用です。実際のエラーやシステム障害には関与しません。
- ローカル端末上でのみ動作し、ファイル等の書き換えは行いません。
- 頻繁な発動はチームの生産性を阻害する恐れがあるため、通知頻度やタイミングにはご注意ください。
