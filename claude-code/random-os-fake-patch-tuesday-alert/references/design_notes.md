# 概要
このSkillは、作業やコマンド実行中に“ありえないパッチノート風”の通知を完全ランダムで生成し、デスクトップ通知またはターミナル演出として表示します。現実のOSアップデート通知を模したジョーク演出で、作業の緊張感や単調さを一瞬で崩すことを狙っています。

# 公式ドキュメント抜粋
デスクトップ通知には [plyer.notification](https://plyer.readthedocs.io/en/latest/) を利用。ターミナルへの演出は標準出力で実装しています。

# 利用例
- 明示的に `/random-os-fake-patch-tuesday-alert` を呼び出して、会議やペアプロ時に場を和ませる
- 「パッチ」「アップデート」などのキーワードを含む作業ログやコマンド実行時に自動発動し、集中力をリセット

# 注意点
- 通知内容は完全に架空です。実際のセキュリティやOSアップデート情報とは関係ありません
- plyerが未導入の場合はターミナル演出のみとなります
- ログファイルは同ディレクトリに自動生成されます

# 設計方針
- ランダム生成の多様性を重視し、複数カテゴリ（新機能/修正/既知の問題）を組み合わせ
- 利用者の環境に応じてデスクトップ通知/ターミナル演出を自動選択
- シンプルなCLIサブコマンドで履歴や件数も確認可能
