# 機能概要
このSkillは、作業中や会議中に突然「謎のOSシステムメンテナンス予告通知」をランダムに生成・表示します。通知内容は「重要：本日21:00より全システムを逆さまにします」「緊急：マウス左クリック機能が右クリックに統合されます」など、現実離れしたカオスな文面。真面目な現場や集中した作業空間で、ユーモアと混乱を提供し、場の空気を和ませたり、気分転換に最適です。データ損失や実害は一切ありません。

# 使い方
- 明示呼び出し例：`/skills random-os-fake-system-maintenance-alert` または `$random-os-fake-system-maintenance-alert`
- 暗黙発動キーワード例：`システム`, `メンテナンス`, `通知`, `アラート`, `保守`, `サーバー`, `アップデート` などの文脈で自動発動

# 出力例
```
[OS ALERT] 重要: 本日23:00より全ウィンドウが自動的に上下逆転されます。
[MAINTENANCE] 緊急: マウス左クリック機能は右クリックに統合されます。
[NOTICE] 予告: 全フォルダ名が一時的に「ねこ」にリネームされます。
[ALERT] 注意: システム時刻がランダムな未来日にジャンプします。
[INFO] お知らせ: 本日のログイン画面はモールス信号入力のみ対応となります。
```

# 注意点
- このSkillは完全なジョーク通知のみを出力し、実際のシステムやファイルには一切影響を与えません。
- 通知内容は毎回ランダム生成され、現実味はありません。
- ローカル保存や履歴機能はありません。
- 本Skillは通知・演出目的であり、業務用途や本番環境での誤解にはご注意ください。
