# 概要
このスキルは、ユーザーの作業中に突発的な“謎のOS公式・ペット命名通知”を発動することで、作業空間にユーモアとカオスを提供します。実用性をあえて排除し、集中力を削ぐことを目的としています。

# 公式ドキュメント抜粋
通知には Python の plyer パッケージを利用しています。plyer はクロスプラットフォームで OS のネイティブ通知を呼び出すことができます。
- plyer: https://github.com/kivy/plyer

# 利用例
- 明示呼び出し: `python pet_name_notifier.py once` で即時通知
- バッチ: `python pet_name_notifier.py batch --count 10 --interval 1`
- ランダム自動発動: `python pet_name_notifier.py loop --min 30 --max 300`

# 注意点
- plyer が未インストールの場合は標準出力のみとなります。
- 通知履歴や命名履歴はローカル保存されません。
- OSや環境によっては通知が表示されない場合があります。

# 設計方針
- 実在APIのみを利用し、CLIサブコマンドで柔軟に動作。
- 通知文・デバイス・二つ名のバリエーションを十分に確保し、毎回違う体験を演出。
- Skill本体は副作用を持たず、作業やデータに影響を与えません。
