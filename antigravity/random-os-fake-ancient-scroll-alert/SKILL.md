# 機能概要
このSkillは、現代の作業現場に突如として“謎のOS公式・古文書巻物通知”をランダムに表示することで、日常に非日常と笑いをもたらします。通知内容は「西のコードベースにバグの兆し」「東のモジュールに伝説の関数現る」など、古代預言者のような意味深なテキストが毎回異なり、作業の合間に混乱と遊び心を提供します。実際のシステムには影響せず、ユーザー体験の演出・リフレッシュを目的としています。

# 使い方
本Skillは明示的な呼び出しは不要です。Antigravityが「長時間の作業」「CLI操作の合間」「バグや警告に関する会話」など、特定のキーワードや状況を検知した際に自動で発動します。暗黙発動キーワード例: バグ、伝説、警告、異変、預言、巻物、OS通知。

# 出力例
```
[古文書巻物通知] 西のコードベースにバグの兆し。
[古文書巻物通知] 東のモジュールに伝説の関数現る。
[古文書巻物通知] 南の依存関係に静かな異変。
[古文書巻物通知] 北のテストケースに謎の預言。
[古文書巻物通知] すべてのログに沈黙の影。
```

# 注意点
- 実際のシステムやファイルには一切影響を与えません。
- 通知内容は毎回ランダム生成され、同じものはほぼ出ません。
- ローカル保存や履歴機能はありません。
- 通知はターミナル/コンソール上にのみ表示されます。
- ユーザー環境に依存せず、追加の環境構築は不要です。
