# 機能概要
このSkillは、ポモドーロタイマーや集中タイマーの開始・終了・中断などのアクションに連動して、謎のOS風“ポモドーロ失敗通知”を毎回ランダムな内容で発生させます。通知文は「失敗：トマトが爆発しました」「警告：集中力が鍋底にこびりつきました」など、実用性ゼロのふざけた演出が中心。まじめに集中したいのに、なぜかトマトやピザなどのネタで邪魔される、完全エンタメ志向のSkillです。集中作業の合間に笑いを提供し、気分転換やチームの雰囲気作りにも役立ちます。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「ポモドーロ」「集中タイマー」「タイマー開始」「タイマー終了」「休憩」「失敗」などのキーワードや、セマンティックな文脈から自動的に発動します。ユーザーがタイマーを起動・停止・リセットなどしたタイミングで、毎回異なるジョーク通知がターミナルやデスクトップ通知として出力されます。

# 出力例
```
[FakeOS Notification] 失敗：トマトが爆発しました。机上に赤い液体注意！
[FakeOS Notification] 警告：集中力が鍋底にこびりつきました。洗剤推奨。
[FakeOS Notification] 注意：タイマーがピザに変身したため無効です。
[FakeOS Notification] 失敗：ポモドーロが月面に着陸しました。
[FakeOS Notification] エラー：トマトの種が暴走しています。
```

# 注意点
- 本Skillは完全なジョーク通知です。実際のタイマー進行や作業管理には影響しません。
- 通知内容は毎回ランダム生成され、実用性はありません。
- ローカルファイルや個人情報を保存・送信しません。
- 10分程度で環境構築・動作確認が可能です。
- 通知はターミナル出力とデスクトップ通知（OS対応時）両方に対応します。
