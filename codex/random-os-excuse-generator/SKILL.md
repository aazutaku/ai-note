# 機能概要
random-os-excuse-generatorは、開発現場の緊張感や深刻なエラー発生時に、全く根拠のないユーモラスな『OS言い訳』をデスクトップ通知またはターミナルにランダム表示するジョーク系Skillです。作業が止まった理由やバグの原因を、天体現象や不可解な現象のせいにすることで、場の空気を和ませます。深刻なバグや進捗遅延時にも、笑いでリフレッシュできる演出を提供します。

# 使い方
- 明示呼び出し例: `/skills menu` から random-os-excuse-generator を選択、または `$random-os-excuse-generator` とメンション
- 暗黙発動キーワード例: 「バグ」「エラー」「進捗遅延」「止まった」「動かない」「なぜ」などの文脈を検知し自動発動

# 出力例
```
[OS Excuse] 今バグが出たのは水星逆行のせいです。
[OS Excuse] コードが今日は恥ずかしがっているようです。
[OS Excuse] 太陽フレアが強すぎて動作が不安定です。
[OS Excuse] 量子もつれの影響で一時的に停止しました。
[OS Excuse] 今日はOSの気分が乗らないみたいです。
[OS Excuse] 近所のWi-Fiが共鳴してエラーが発生しました。
[OS Excuse] サーバーが月齢を気にしています。
[OS Excuse] バグは宇宙線のせいかもしれません。
```

# 注意点
- 本Skillは通知・表示のみで、ファイルやシステムに一切変更を加えません。
- 本番データや業務フローへの影響はありません。
- OSの通知APIを利用しますが、通知が非対応の環境ではターミナル出力のみとなります。
- ジョーク用途のため、実際の障害対応やバグ修正には使えません。
