# 機能概要
このSkillは、作業中に突如として“謎のOS省エネモード突入通知”をデスクトップやターミナルに表示する演出を提供します。通知内容は毎回ランダムで、「全ウィンドウの明るさ自動調整(嘘)」「キーボード省入力モード発動(意味不明)」「OSが独断でパフォーマンスを自己最適化中」など、実害ゼロのフェイク演出です。実際のOSや作業環境には一切影響を与えず、作業者の集中力や現実感覚を微妙に揺さぶることで、リフレッシュやユーモアを提供します。

# 使い方
- 明示呼び出し例: `/random-os-fake-power-saving-mode`
- 暗黙発動キーワード例: 「省エネモード」「パフォーマンス低下」「OS通知」「作業遅い」「バッテリー節約」などを含む会話やコマンドで自動発動

# 出力例
```
[OS通知] システムは自動的に「全アプリ低消費電力モード」に移行しました。
[OS通知] キーボード省入力モード発動。タイプ速度を自動的に最適化します。
[OS通知] OSが独断でパフォーマンス調整中。全てが遅く感じるかもしれません。
[OS通知] 画面の明るさを自動で最小に設定しました（実際には変更されません）。
[OS通知] バッテリー節約のため、全プロセスを仮想的にスローダウン中。
```

# 注意点
- 通知は完全なフェイクで、実際のOS設定やアプリには影響しません
- ローカルファイルや設定の変更、保存は一切行いません
- 出力はターミナルやコンソール限定です（デスクトップ通知機能は含みません）
- ジョーク用途のため、業務用途や自動化には使用しないでください
