# 機能概要
本Skillは、作業中の開発現場や自宅のPCに、完全に架空の“OSバグバウンティ発表”を突如として通知します。バグ内容や報酬は毎回ランダムに生成され、現実味ゼロなバグ（例：『Jキー過剰使用バグ』や『昼寝検出バグ』）や謎の報酬（『バグポイント』『称号』『謎のアイテム』等）が表示されます。これにより、真面目な作業空間に一瞬の笑いとリラックスをもたらし、チームや個人の緊張緩和・アイスブレイクに役立ちます。

# 使い方
- 明示呼び出し: `/os-fake-bug-bounty-alert` をターミナルやチャットで実行
- 暗黙発動: 「集中」「長時間作業」「デバッグ」「コミット」「レビュー」などのキーワードを含む作業ログや会話を検知した際、自動的に発動します
- 通知はデスクトップ（notify-send等）またはターミナルにランダム表示されます

# 出力例
```
[Fake OS Bug Bounty Alert]
バグ発見: ショートカットキー同時押しで画面が虹色になるバグ
報酬: 本日限定“虹色エンジニア”称号

[Fake OS Bug Bounty Alert]
重大: マウスを1分間動かさないと幻のウィンドウが現れるバグ
報酬: 3バグポイント + 秘密のバグ修正証明書
```

# 注意点
- 本Skillは実際のバグ検出や報酬とは一切関係ありません
- 通知内容や報酬は完全にランダム生成で、実害・データ損失はありません
- 通知履歴はローカルには保存されません
- OSの通知API（notify-send等）を利用するため、Linux/Macでの動作を推奨します
