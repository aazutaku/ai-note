# 概要
このSkillは、作業現場や個人の作業環境で突発的に「謎の休憩通知」を発生させることで、真面目な空気を一瞬だけ和らげることを目的としています。通知内容は完全にランダムで、実作業やシステムには影響を与えません。

# 公式ドキュメント抜粋
通知表示にはPythonのplyerライブラリを利用しています。plyerはクロスプラットフォームでのデスクトップ通知APIを提供し、Windows/Mac/Linuxで動作します。

# 利用例
- 長時間作業時の気分転換
- リモートワークでのチームメンバーへのユーモア注入
- 定期的な休憩リマインダーとして

# 注意点
通知はローカル環境の通知APIに依存するため、サーバーや権限が制限された環境では表示されない場合があります。通知履歴は保存されません。

# 設計方針
- 通知内容は毎回ランダム
- 実作業やデータには一切影響を与えない
- 明示/暗黙両方のトリガーに対応
- コードは100行超、CLIサブコマンド・エラーハンドリング・ヘルパー関数を実装
