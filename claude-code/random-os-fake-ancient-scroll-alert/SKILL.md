# 機能概要
このSkillは、現代の開発現場に突如として“謎のOS公式・古文書巻物通知”を出現させる演出系ツールです。通知内容は「西のコードベースにバグの兆し」や「東のモジュールに伝説の関数現る」など、古代預言者風の意味深なテキストが毎回ランダム生成されます。真面目な作業風景に非日常の混乱と笑いをもたらし、チームや個人の気分転換・コミュニケーションのきっかけとして機能します。実際のシステムには影響せず、純粋な演出のみを提供します。

# 使い方
- 明示呼び出し例: `/random-os-fake-ancient-scroll-alert` をコマンドラインやClaude CodeのSkill呼び出しで実行
- 暗黙発動: 「巻物」「預言」「古文書」「公式通知」などのキーワードを含む会話や、コマンド実行の合間に自動発動

# 出力例
```
[OS Ancient Scroll Alert]
紀元前の預言者より伝言：
「西方のコードベースにバグの兆しあり。夜明け前に修正せよ」
---
[OS Ancient Scroll Alert]
伝説の関数、東のモジュールに現る。
「その名は 'dragon_breath()'、使い手に繁栄をもたらす」
---
```

# 注意点
- 通知は純粋な演出であり、実際のシステムやファイルには影響を与えません
- ローカル保存や履歴機能はありません
- 出力内容は毎回異なり、完全ランダムです
- OSや環境依存の機能は使わず、Python標準APIのみで動作します
