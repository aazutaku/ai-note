# 機能概要
このSkillは、作業に没頭している最中やウィンドウ操作が活発なタイミングで、突如として“謎のOSシステム復元進捗ウィンドウ”を画面端やメニューバー風に表示します。進捗バーには「謎の変更を元に戻しています」「OSの気分調整中」など、毎回異なるフェイクなテキストが並び、進捗率も完全ランダムで変動します。復元が完了しても何も起こらず、作業の空気を一瞬でカオスに変えることができます。実際のシステム操作には一切影響しません。

# 使い方
- 明示的な発動: `/random-os-sudden-fake-system-restore` を入力すると即座に演出が始まります。
- 暗黙的な発動: 「復元」「OS」「進捗」「システム異常」「元に戻す」などのキーワードや、連続した作業・ウィンドウ切替が検知された際に自動で発動します。

# 出力例
```
[OS System Restore]
進捗: 37% - 謎の変更を元に戻しています...
進捗: 62% - OSの気分調整中...
進捗: 81% - レジストリの気まぐれ修復中...
進捗: 100% - 復元完了（何も変わりません）
```

# 注意点
- このSkillは純粋な演出目的であり、実際のファイルや設定には一切影響を与えません。
- ローカル保存やログ出力は行いません。
- 一部の環境ではポップアップ表示が制限される場合があります。
- 除外パス: システムフォルダや管理者権限が必要なディレクトリでは動作しません。
