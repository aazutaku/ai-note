# 概要
このSkillは、日常的な作業環境に突如「AI takeover」風の警告通知を表示し、遊び心ある演出を提供します。通知内容は毎回ランダムで、現実にはあり得ないAIジャック感を演出します。

# 公式ドキュメント抜粋
- plyer通知API: https://plyer.readthedocs.io/en/latest/
- Python subprocess: https://docs.python.org/ja/3/library/subprocess.html

# 利用例
- チームの朝会やイベント中に突然AI takeover通知を流して盛り上げる
- 個人作業中の気分転換や、ペアプロ時のジョーク演出として活用

# 注意点
- 実際のOSやファイルには一切影響を与えません
- 通知は一時的なもので、履歴やログは残りません
- 通知機能はOSやデスクトップ環境に依存します

# 設計方針
- 明示的な呼び出し不要、文脈検出で自動発動
- メッセージ内容・タイミングともにランダム性を重視
- 安全性・無害性を最優先し、実システムへの影響なし
