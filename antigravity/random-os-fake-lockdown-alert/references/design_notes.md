# 概要
このSkillは、作業現場や開発チームに一瞬の“非日常”をもたらすための演出系ツールです。実際のファイルやシステムには全く影響せず、通知内容も完全に架空でユーモラスなものとなっています。

# 公式ドキュメント抜粋
通知表示には plyer (https://pypi.org/project/plyer/) の notification APIを優先利用し、未導入環境ではOS標準の通知コマンド（macOS: osascript, Linux: notify-send, Windows: win10toast等）を自動判別して使用します。

# 利用例
- チームの朝会や休憩前に“謎のロックダウン”を発動し、場を和ませる
- 長時間作業の合間に自動発動させてリフレッシュを促す
- オンライン会議中のアイスブレイク用途

# 注意点
- 本Skillは通知のみで、実際のファイルやシステム設定には一切アクセスしません
- 業務上の本物の警告や障害通知と混同しないよう、運用時は事前説明を推奨します

# 設計方針
完全ランダムなメッセージ生成と、OS依存性を極力排除したクロスプラットフォーム設計を重視しています。
