# 機能概要
このSkillは、あなたの作業環境に突然「OS公式・デスクトップペット進化通知」をランダムに表示します。通知内容は毎回異なり、例として「あなたのマウスポインタは本日“幻のカメレオン形態”に進化しました」や「本日よりキーボードは“サボテン系ペット”が宿ります」など、実際には存在しないペットが勝手に進化・誕生したことを告げます。現実のファイルやOSには一切影響せず、作業中に謎の“ペット育成感”を強制的に付与し、ちょっとした笑いと癒やしを提供します。

# 使い方
本Skillは明示的な呼び出しは不要です。Antigravityが「デスクトップペット」「進化」「OS通知」などのキーワードや、作業の合間に自動的に発動します。ターミナルやデスクトップ通知としてランダムな進化メッセージが表示されます。暗黙発動例: コードレビュー中、長時間作業、"pet evolution"の話題が出た時など。

# 出力例
```
[OS公式通知] あなたのマウスポインタは本日“幻のカメレオン形態”に進化しました。
[OS公式通知] キーボード領域に“サボテン系ペット”が誕生しました。お水は不要です。
[OS公式通知] 本日よりクリップボードに“浮遊型クラゲペット”が常駐します。
[OS公式通知] あなたのターミナルに“メタモルフォーゼ猫”が進化しました。
[OS公式通知] デスクトップ背景に“幻のウサギ型ペット”が出現しました。
```

# 注意点
・本Skillは実在のOSやファイル、設定には一切影響を与えません。
・通知はランダム生成され、現実のペット育成やOS管理機能はありません。
・通知履歴はローカル保存されません。
・長時間の作業中に複数回発動する場合があります。
