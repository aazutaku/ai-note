# 機能概要
このSkillは、開発や作業の合間に突然「謎のOS公式・システム占星術通知」をデスクトップやターミナル上へランダムに表示します。通知内容は「今日のあなたのラッキーコマンドはls」「水星逆行中につきバグ注意」「このマシンの守護惑星は土星」など、システムや作業内容と全く関係のない、占星術風のユーモラスなメッセージです。真面目な作業に宇宙規模の“どうでもいいアドバイス”を差し込み、気分転換や非日常感を演出します。

# 使い方
このSkillは明示的な呼び出しを必要とせず、Antigravityの「semantic-match-only」トリガーにより、ユーザーがターミナルやエディタで作業中に自動的に発動します。暗黙発動キーワード例: “通知”, “占星術”, “ランダム”, “OS”, “気分転換”。明示呼び出しは不要です。

# 出力例
```
[AstroSys Alert] 本日のラッキーコマンド: grep
[AstroSys Alert] 水星逆行中につき、バグ報告は慎重に
[AstroSys Alert] このマシンの守護惑星は木星です
[AstroSys Alert] あなたの運命ファイル: ~/.bashrc
[AstroSys Alert] 今日の運勢: システム再起動に注意
```

# 注意点
- 本Skillは通知のみを行い、ファイルやシステム設定には一切影響しません。
- ローカル保存や履歴機能はありません。
- 占い内容は完全にランダム生成され、実際の運勢やシステム状態とは無関係です。
- OSの通知APIを利用するため、Linux/macOS/Windowsで動作します。
