# 概要
本Skillは、開発者の日常作業に「非日常感」を与えるため、OSの公式通知風に“占星術ジョーク”をランダムに表示します。通知はシステムや作業内容に一切依存せず、完全にランダムな内容を生成します。

# 公式ドキュメント抜粋
- Linux: `notify2` (https://pypi.org/project/notify2/) または `notify-send`
- macOS: `osascript` による通知 (https://ss64.com/osx/osascript.html)

# 利用例
- 開発作業中のリフレッシュや雑談ネタに最適
- チームの朝会やペアプロ時のアイスブレイクとして
- CLIから `python astrology_alert.py --once` で即時通知、`--daemon` で定期的な演出

# 注意点
- 通知内容は完全なジョークであり、実際の占星術やOSの公式アドバイスではありません。
- システムやファイルへの変更は一切行いません。

# 設計方針
- ランダム性と安全性を重視し、通知以外の副作用は排除
- クロスプラットフォーム対応（Linux/macOS/Windows）
- ユーザーがいつでも停止・一時停止できる設計
