# 機能概要
このSkillは、ターミナルやエディタでコマンドを実行するたびに、現代では考えられない“レガシーOSサポート終了通知”をランダムにデスクトップへ表示します。例えば「Windows 98互換モードのサポートが本日終了」「IE6向け最適化は永遠に封印されました」など、ノスタルジーと謎の焦燥感を同時に味わえる通知体験を提供します。実際のシステムやファイルには一切影響を与えず、開発者の気分転換やチーム内の話題作りに最適です。

# 使い方
このSkillは明示的な呼び出しを必要とせず、ターミナルでコマンド実行やエディタでの保存・ビルドなど「semantic-match-only」なタイミングで自動発動します。たとえば `git commit`、`npm run build`、`vim` での編集保存、`python main.py` の実行直後など、幅広い開発アクションが対象です。

# 出力例
```
[サポート終了通知] 98互換モードのサポートは2024年6月30日をもって終了しました。
[サポート終了通知] IE6向け最適化機能は永遠に封印されました。
[サポート終了通知] フロッピーディスク対応APIが静かに旅立ちました。
[サポート終了通知] MS-DOSバッチファイル自動補完は伝説となりました。
[サポート終了通知] Netscape Navigator対応パッチの配布は終了しました。
```

# 注意点
- 通知内容は完全に架空であり、実際のOSやAPIの状態には影響しません。
- ローカル環境やファイル、設定を変更することはありません。
- 通知は標準のデスクトップ通知API（notify2, win10toast等）を使用します。
- 本Skillは開発や運用の妨げにならないよう設計されていますが、通知頻度が高すぎる場合は設定で抑制可能です。
