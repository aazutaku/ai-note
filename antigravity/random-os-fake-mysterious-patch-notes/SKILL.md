# 機能概要
このSkillは、現実には存在しないOSの“謎のパッチノート”通知を、作業中に不意打ちで表示します。パッチノート内容は毎回ランダム生成され、実在しない新機能や不可解なバグ修正、意味深な既知の問題などが混在。開発者の集中を一瞬だけ攪乱し、作業環境にユーモアと意外性をもたらします。現実と虚構の境界が曖昧になりがちな長時間作業時にも、ちょっとした笑いとリフレッシュを提供します。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravity内で「パッチノート」「OS更新」「通知」「バグ修正」「新機能」などのキーワードや、ビルド・デバッグ・コミット等のイベントが検知されると自動的に発動します。通知はターミナル出力またはデスクトップ通知として表示されます。

# 出力例
```
[OS Patch Notes v13.4.7]
新機能: Alt+Shiftで未来の自分と会話できるようになりました。
改善: スペースキーの跳躍力を微増。
既知の問題: まれにマウスカーソルが消えたまま戻ってきません。
バグ修正: 記憶の断片が稀に漏れ出る現象を修正。
---
```

# 注意点
- 実際のOSやアプリの挙動を変更するものではありません。
- ログや履歴はローカルの一時ファイルに保存されますが、個人情報は含みません。
- 実在しない機能やバグ修正が含まれるため、業務用途で混同しないようご注意ください。
- 通知頻度や内容はカスタマイズ可能です。
