# 機能概要
このSkillは、デスクトップ環境に「OS再起動までのカウントダウン」風のフェイク通知ウィンドウを表示します。通知には毎回異なる“謎の理由”が添えられ、0秒になると「ジョークです」と明示されます。実際の再起動やシステム変更は一切行われません。職場や友人との軽いドッキリ、緊張感を和らげる演出、または自分への気分転換など、攻めたフェイク通知体験を提供します。

# 使い方
明示的な呼び出し例:
- `/skills os-fake-reboot-countdown-prank`
- `$os-fake-reboot-countdown-prank`

暗黙発動キーワード例:
- 「再起動」「OSアップデート」「謎の通知」「カウントダウン」「フェイク再起動」などの文脈で自動発動します。

# 出力例
```
[OS通知]
理由: RAMの気分転換を実施中
再起動まで: 00:19
...
再起動まで: 00:00
[ジョークです。実際の再起動は行われません]
```

# 注意点
- 本Skillは実際の再起動やシャットダウン、OS操作は一切行いません。
- 通知ウィンドウはローカルでのみ表示され、ネットワーク送信や記録はありません。
- Linux/macOS/Windowsの主要な通知APIに対応していますが、仮想環境やリモートデスクトップでは正常動作しない場合があります。
- 業務端末や公共PCでの使用は十分ご注意ください。
