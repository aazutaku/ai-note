# 機能概要
このSkillは、作業中のユーザーに対し、突如として「OS画面ズームイン警告」風のフェイク通知を表示します。通知内容は毎回ランダム生成され、「重大：ズームインモード突入まで残り5秒」「画面拡大率が謎の力で上昇中」など、現実には何も起こらないのに焦らせる演出を実現します。実害は一切なく、作業の緊張感を一瞬で崩壊させる“謎演出”として、会議やリラックスタイム、イベントなどで盛り上げたい時に最適です。

# 使い方
このSkillは明示的な呼び出しコマンドは不要で、Antigravityエージェントが「os」「zoom」「警告」「通知」「拡大」「演出」などのキーワードを検知した際や、長時間作業・集中状態が続いた場合に自動発動します。設定により、通知の頻度や表示方法（デスクトップ/ターミナル）をカスタマイズ可能です。

# 出力例
```
[ALERT] 重大：ズームインモード突入まで残り5秒
[WARNING] 画面拡大率が謎の力で上昇中！
[NOTICE] OSが自動的にズームインを試行中です
[ALERT] 不明なプロセスが画面を拡大しようとしています
[INFO] ズームイン解除方法：不明
```

# 注意点
本Skillは実際のズーム処理や画面操作は一切行いません。通知は全てランダム生成のフェイクであり、実害やシステム変更はありません。通知の内容が紛らわしい場合があるため、重要な作業中や誤解を招く環境ではご注意ください。通知履歴はローカルに保存されません。
