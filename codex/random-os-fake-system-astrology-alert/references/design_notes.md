# 概要
本Skillは、開発者の作業環境に“OS公式占星術通知”という架空の非日常体験を提供し、作業の合間にランダムなユーモアやリフレッシュをもたらすことを目的としています。

# 公式ドキュメント抜粋
- Python標準のrandom, argparse, datetime, subprocess, platformモジュールを利用し、クロスプラットフォームで動作します。
- 通知APIはmacOS (osascript)、Linux (notify-send)、Windows (win10toast)に対応。

# 利用例
- 明示的に`python random_os_astrology_alert.py once`で即時通知
- `loop`サブコマンドで作業中にランダムなタイミングで自動通知
- テスト用に複数回出力も可能

# 注意点
- 通知内容は完全なフィクションで、実際の運勢やシステム状態とは無関係です。
- システムやファイルに変更を加えない安全設計です。

# 設計方針
- 占星術風の表現とOSコマンド・システム用語を組み合わせ、現実と非現実のギャップを楽しめるよう設計。
- ローカル保存や履歴管理は行わず、気軽に使える演出系Skillとしています。
