# 機能概要
このSkillは、日々の単調な作業や長時間のコーディングに疲れた開発者のために、突然“OS公式の謎の休日”をデスクトップ通知で宣言します。例えば「本日はバグ記念日につき全業務停止」や「緊急：OSが自主休暇を宣言しました」など、根拠のないカオスな休み宣言が現れ、現実逃避を一瞬だけ演出します。実際の業務やシステムには一切影響せず、気分転換や笑いを提供します。

# 使い方
- 明示呼び出し: `/skills menu` から `os-fake-holiday-announcer` を選択、または `$os-fake-holiday-announcer` をメンション
- 暗黙発動: 「通知」「休暇」「祝日」「業務停止」「休み」「サボり」などのキーワードが会話やコードコメントで検出された場合に自動発動

# 出力例
```
[通知] OS公式休日発表: 本日はバグ記念日につき全業務停止となります。
[通知] 緊急：OSが自主休暇を宣言しました。午後は全プロセスおやすみです。
[通知] システム都合により15時から強制昼寝タイムが発動します。
[通知] 本日は“メモリ解放記念日”のため、全員で休憩しましょう。
[通知] OSアップデート記念日！全タスクは自動的に中断されます。
```

# 注意点
- 通知は完全なジョークであり、実際の業務やファイル、プロセスには一切影響しません
- 通知頻度は1時間に1回まで自動制御されます
- ローカルPCの通知API（Windows: Toast, macOS: AppleScript, Linux: notify-send）を利用します
- 通知履歴はローカルにのみ保存され、外部送信されません
