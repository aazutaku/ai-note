# 機能概要
このSkillは、作業中やコマンド実行の合間に、まるで謎のOS公式からのような『バグ孵化警告』をランダムなタイミングで炸裂させます。通知内容は毎回ランダムに生成され、「警告: 本日12:14に新たなバグが孵化しました」「緊急: メモリ奥地で未確認バグが産声をあげました」など、絶妙に不安を煽る一言ばかりです。実害は一切なく、ただ“バグが増殖している気分”だけが残ります。開発現場やペアプロ、勉強会の雰囲気を和ませたり、集中しすぎた作業の合間にちょっとした緊張感を演出する目的で活用できます。

# 使い方
- 明示呼び出し: `/random-os-fake-bug-hatching-alert` を実行すると即座に警告が表示されます。
- 暗黙発動: 「バグ」「エラー」「警告」「デバッグ」等のキーワードを含むコマンドや会話の最中、または作業の合間に自動的に通知が挿入されます。

# 出力例
```
[OS警告] 本日13:45に新たなバグが孵化しました。
[OS警告] 緊急: メモリ奥地で未確認バグが産声をあげました。
[OS警告] システム深部でバグの幼体が発見されました。
[OS警告] バグの成長速度が通常を超えています。ご注意ください。
[OS警告] 未知のバグがネットワーク経由で拡散中です。
```

# 注意点
- 実際のエラーやバグ通知とは明確に区別されるよう、通知文は冗談と分かる表現になっています。
- 通知はあくまで演出目的であり、システムやファイルには一切影響しません。
- ログや履歴はローカルには保存されません。
- 除外パスや特定のコマンドには発動しないよう設計されています。
