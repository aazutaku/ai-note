# 機能概要
このSkillは、作業中やコマンド実行の合間に、まるでOS公式から発せられるかのような“古代皇帝の勅令”をランダムな文面で通知します。内容は「皇帝より勅令：本日よりCapsLockの使用を禁ず」や「御前会議：スペースキーの叛逆を鎮圧せよ」など、威厳と理不尽さを兼ね備えた一文です。真面目な作業環境に突如としてカオスな演出を加え、ユーザーの気分転換やユーモアの演出に役立ちます。

# 使い方
このSkillは明示的な呼び出しは不要で、Antigravityが「通知」「演出」「気分転換」「冗談」「古代皇帝」「ランダム」「作業中断」などのキーワードや状況を検知した際、自動的に発動します。ユーザーは特定のコマンドや設定を行う必要はありません。

# 出力例
```
皇帝より勅令：本日よりCapsLockの使用を禁ず。
御前会議：スペースキーの叛逆を鎮圧せよ。
大勅令：全てのファイル名に母音を含めよ。
禁令：Altキーの乱用を厳しく取り締まる。
御触書：本日、ターミナルは沈黙を守るべし。
皇帝の思し召し：スクリーンショットは一日一回に限る。
```

# 注意点
- 本Skillは通知表示のみを行い、実際のOS・ファイル・キーボード等の設定には一切影響を与えません。
- ローカルに出力履歴や勅令内容を保存することはありません。
- 実在の皇帝や歴史的勅令とは無関係のフィクションです。
- 明示呼び出しやカスタマイズは未対応です。
