# 機能概要
このSkillは、ターミナルやエディタでコマンドを実行した瞬間、画面端に「謎のOS進捗バー祭り」を発生させます。進捗バーは「バグ撲滅進捗」「コーヒー摂取量」「脳内会議進行度」など完全に意味不明なテーマで、進捗値も毎回ランダム。複数バーが同時に重なって現れるカオスな演出で、作業中の緊張感を一瞬で崩壊させ、周囲の注目を集めます。通知・演出・OS連携カテゴリの新感覚Skillです。

# 使い方
- 明示呼び出し: `/skills random-os-mysterious-progressbar-festival` または Skillメニューから選択
- 暗黙発動: 「進捗」「バー」「謎」「祭り」「祭」などの単語を含むコマンド実行や会話文脈、またはビルド/保存/実行などの操作時に自動発動

# 出力例
```
[バグ撲滅進捗]     [██████████────]  54%
[コーヒー摂取量]   [█████─────────]  27%
[脳内会議進行度]   [█████████████──]  82%
[OS再起動欲求]     [███────────────]  13%
[デバッグ迷子度]   [████████──────]  60%
```

# 注意点
- 進捗バーのテーマ・値は毎回ランダム生成されます
- 実際のOSや作業進捗とは一切関係ありません
- ローカルファイル保存や履歴記録は行いません
- 端末やエディタによっては描画が崩れる場合があります
