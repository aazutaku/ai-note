# 機能概要
このSkillは、Antigravityがターミナルやエディタ上でコマンドを実行するたびに、謎の“OS公式サウンドエフェクト”をランダムで再生します。『ファイルが旅立つ音』『シュールなやる気起動音』『謎のシステム自動拍手』など、意味不明なSEを複数用意。開発現場で突然シュールな音が鳴り響くことで、作業の集中を崩壊させたり、周囲の反応を楽しめるカオスな演出を実現します。通知・演出・OS連携カテゴリに最適です。

# 使い方
このSkillは明示的な呼び出しは不要です。"サウンド"、"効果音"、"SE"、"通知音"などのキーワードを含むコマンド実行や、ファイル操作・ビルド・保存・削除などのアクション時に自動的に発動します。導入・削除はSkillの追加/削除のみで完結し、環境に恒久的な影響を残しません。

# 出力例
```
$ git commit -m "fix bug"
[git] ファイルが旅立つ音が再生されました。
$ rm important.txt
[system] 謎のシステム自動拍手が再生されました。
$ python main.py
[python] シュールなやる気起動音が再生されました。
```

# 注意点
- サウンド再生には`playsound`や`subprocess`でOS標準プレイヤーを利用します。
- 音源ファイルはSkill内に同梱され、ローカル保存されます。
- サウンドの種類は5種類以上を用意。
- 環境に依存する部分（OSごとの再生コマンド等）は自動判別します。
- サウンド再生が不要な場合はSkillを無効化してください。
