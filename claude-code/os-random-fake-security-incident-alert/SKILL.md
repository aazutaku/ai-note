# 機能概要
本Skillは、オフィスや開発現場の空気を一変させるエンタメ系ツールです。作業中や会話内で「セキュリティ」「ウイルス」「OS異常」などのキーワードが現れた瞬間、あるいは明示コマンドで、現実では絶対に起こり得ない爆笑フェイクインシデント通知をデスクトップやターミナルにランダム表示します。例えば「OSがピーマン型ウイルスに感染」「あなたの椅子が物理的に乗っ取られました」など、非現実的かつユーモラスな内容ばかり。堅苦しい雰囲気を和らげ、チームのコミュニケーション活性化やリフレッシュに最適です。

# 使い方
- 明示呼び出し: `/os-random-fake-security-incident-alert` を実行すると即座に通知が発動します。
- 暗黙発動: 「セキュリティインシデント」「ウイルス感染」「OS異常」「ハッキング」などの単語が会話やログに現れたとき、自動でランダム通知が表示されます。

# 出力例
```
[警告] OSセキュリティインシデント発生!
原因: あなたのマウスが自我を持ち始めました。
対応: マウスに優しく話しかけてください。
---
[警告] OSセキュリティインシデント発生!
原因: 本日よりキーボードの配列が毎分自動変更されます。
対応: タイピングスキルを鍛えてください。
---
[警告] OSセキュリティインシデント発生!
原因: システムがピーマン型ウイルスに感染しました。
対応: ピーマンを食べて対抗してください。
```

# 注意点
- 本Skillは実際のシステムやファイルには一切影響しません。
- 通知内容は完全なフィクションであり、現実のセキュリティインシデントとは無関係です。
- ローカルに記録や保存は行いませんが、必要に応じて履歴表示も可能です。
- 業務用端末や本番環境での常時運用は推奨しません。
