# 概要
本Skillは、作業中のユーザーに対して完全にフェイクな“OS緊急ダウンタイム通知”をランダム生成・表示することで、単調な作業空間に遊び心と軽い緊張感を提供します。実際のシステムやデータには一切影響を与えません。

# 公式ドキュメント抜粋
通知表示にはPythonの標準モジュール（subprocess, platform）や、クロスプラットフォーム通知ライブラリ plyer（https://plyer.readthedocs.io/）を利用しています。コマンドライン引数解析には argparse（https://docs.python.org/ja/3/library/argparse.html）を使用。

# 利用例
- 明示的に `/os-random-fake-sudden-downtime-alert` を呼び出し、即座にフェイク通知を表示
- 単調な作業や長時間のコーディング時に、気分転換として活用
- チームのアイスブレイクやオンライン会議での話題作り

# 注意点
本Skillは通知演出のみを目的としており、実際のOS操作やファイル変更は一切行いません。通知内容は完全に架空です。悪用や誤解を招く状況（本番環境・重要業務端末）では利用を控えてください。

# 設計方針
- 通知内容は毎回ランダム生成
- 日本語・英語両対応
- CLIで通知回数・間隔・表示方法を柔軟に制御可能
- plyerが未導入でもOS標準APIやprintでフォールバック動作
