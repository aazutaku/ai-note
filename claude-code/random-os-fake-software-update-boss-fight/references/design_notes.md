# 概要
このSkillは、作業中に突如RPGバトル風のアップデート通知を表示し、開発現場の雰囲気を一瞬で変えることを目的としています。進捗バーや実況風セリフをランダム生成することで、毎回異なる演出を実現します。

# 公式ドキュメント抜粋
- plyer: https://plyer.readthedocs.io/en/latest/
- notifiers: https://notifiers.readthedocs.io/en/latest/

# 利用例
- チームのアイスブレイクや休憩タイムのネタとして
- 長時間の作業や会議中にランダムで発動し、リフレッシュを促す

# 注意点
- 実際のOSやアプリのアップデート機能とは無関係です
- 通知APIが利用できない環境では標準出力のみとなります
- バトル展開や勝敗は完全ランダムです

# 設計方針
- Python標準ライブラリとplyerを活用し、クロスプラットフォームで動作
- イベント/セリフ/勝敗をテンプレート化し、拡張性を確保
- CLIサブコマンドでバトル実行・テンプレート一覧表示を分離
