# 機能概要
このSkillは、開発作業中のターミナルやデスクトップに、架空のOS公式による“古代預言通知”を突如表示します。通知内容は毎回ランダム生成され、神秘的かつ意味深長なメッセージ（例：「北のリポジトリに伝説のレビュアー現る」）があなたの作業空間を彩ります。日々の単調なコーディングやレビューに、遊び心と非日常感をもたらす演出系Skillです。

# 使い方
- 明示呼び出し: `/random-os-fake-ancient-prophecy-alert`
- 暗黙発動: "預言", "通知", "謎", "警告" などのキーワードを含むコマンド実行や作業時に自動で発動します。

# 出力例
```
=== 古代OS預言通知 ===
南のコード砂漠に巨大バグの影動く。
時を超えしレビュアー、北のリポジトリに現る。
西のCI/CDの門、今まさに開かれん。
====================
```

# 注意点
- 本Skillは完全なジョーク機能であり、実用的な警告や通知は一切含みません。
- 通知はローカル環境にのみ表示され、外部送信や保存は行いません。
- 他の通知や作業と干渉しない設計ですが、通知頻度が高すぎる場合は設定で間隔調整が可能です。
