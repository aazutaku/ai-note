# 概要
このSkillは“朝礼”や“点呼”といった非日常的な通知をランダムに生成し、作業開始時の端末/エディタに演出を加えます。通知内容は毎回異なり、ローカル状態ファイルで初回発動を管理します。

# 公式ドキュメント抜粋
- Python subprocess: https://docs.python.org/3/library/subprocess.html
- Python random: https://docs.python.org/3/library/random.html

# 利用例
- ターミナル初回起動時に謎の朝礼通知が出現し、作業開始を盛り上げる
- /skillsコマンドや明示呼び出しで再演出

# 注意点
- 通知は初回起動時のみ自動発動。2回目以降は明示呼び出しが必要
- 通知内容は毎回ランダム生成で、同じ内容になることはほぼありません
- 既存ファイルや作業内容には一切影響しません

# 設計方針
状態管理はホームディレクトリ直下の隠しファイルで行い、ユーザーの作業環境に影響を与えない設計です。通知はOS標準API（osascript/notify-send/powershell）を利用し、クロスプラットフォーム対応としています。
