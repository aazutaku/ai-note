# 機能概要
このSkillは、PC作業中やコマンド実行時に、完全ジョーク仕様の「OSウイルス検出アラート」をデスクトップ通知として表示します。通知内容は毎回ランダム生成され、「怠惰ウイルス」「残業無限増殖型バグウイルス」「コーヒー依存症ウイルス」など、実害ゼロ・緊張ゼロのカオスなネーミングが特徴です。退屈な現場に不条理な刺激と笑いをもたらし、会話や作業のリフレッシュを狙います。

# 使い方
- 明示呼び出し: `/skills random-os-fake-virus-detect-alert` または `$random-os-fake-virus-detect-alert`
- 暗黙発動: 「ウイルス」「アラート」「通知」「セキュリティ」「ジョーク」などのキーワードを含む会話や、一定間隔ごとの自動発動にも対応
- CLIサブコマンド: `python fake_virus_alert.py trigger` で即時通知、`python fake_virus_alert.py run` で定期発動

# 出力例
```
[通知] 謎のウイルス検出: "怠惰ウイルス" がシステムに潜伏中です！
[通知] 検出: "残業無限増殖型バグウイルス" (脅威度: 低) を隔離しました
[通知] "コーヒー依存症ウイルス" がCPU使用率を上昇させています
[通知] "会議無限ループ型ウイルス" の駆除に失敗しました
[通知] "進捗ゼロウイルス" が発見されました。至急ご休憩ください
```

# 注意点
- 本Skillは100%ジョーク通知のみを行い、システムやデータには一切影響しません
- 通知内容は毎回ランダム生成され、実在のウイルス名や脅威とは無関係です
- ローカル保存や履歴記録は行いません
- 通知機能はOS環境依存です（Windows/macOS/Linuxの主要デスクトップ環境で動作）
