# 概要
このSkillは、現実には存在しない“伝説のOSクエスト”を架空の通知として表示し、作業中のユーザーにユーモアと現実逃避の機会を提供します。通知内容は毎回異なり、完全なフェイクでシステムやファイルに影響を与えません。

# 公式ドキュメント抜粋
Pythonのデスクトップ通知には plyer ライブラリ（https://pypi.org/project/plyer/）を利用しています。plyerはクロスプラットフォームで通知APIをラップし、Windows/Mac/Linuxで動作します。

# 利用例
- 長時間のコーディングや単調な作業中に、突如“伝説の任務”が通知されることで気分転換や笑いを誘発。
- チームの朝会やイベントで“今日の伝説クエスト”として活用可能。

# 注意点
- 通知内容はすべて架空であり、実際のファイルやプロセス、システムには一切影響を与えません。
- plyerがインストールされていない場合はターミナル出力のみとなります。

# 設計方針
- ユーザー体験を損なわず、実害ゼロ・安全設計。
- 通知内容のバリエーションを重視し、テンプレートとランダム変数で毎回異なる“伝説”を生成。
- ログ機能を実装し、過去の通知履歴や統計も参照可能。
