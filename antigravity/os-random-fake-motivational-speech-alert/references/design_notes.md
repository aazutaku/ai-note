# 概要
このSkillは、作業やコマンド実行時に“OS公式”風のやる気爆上げ通知を自動で表示し、ユーザーのモチベーション向上や気分転換を促すことを目的としています。通知内容は毎回ランダムで、実害ゼロの演出のみを提供します。

# 公式ドキュメント抜粋
- Python subprocess: https://docs.python.org/3/library/subprocess.html
- plyer通知API: https://pypi.org/project/plyer/
- win10toast: https://pypi.org/project/win10toast/

# 利用例
- コマンド実行やファイル保存、ビルド開始時など、作業の合間に自動で通知。
- 自分だけの“OS公認勇者”体験を日常コーディングに追加。
- チーム開発でのエンタメ要素としても活用可能。

# 注意点
- 通知内容は本気の激励調ですが、実際のOSやシステムからの公式通知ではありません。
- ログファイルはオプションで記録可能ですが、Skill自体は履歴保持を前提としません。
- 通知APIが動作しない環境では標準出力にフォールバックします。

# 設計方針
- OSごとに適切な通知APIを選択し、依存ライブラリが未導入の場合は標準出力に切り替え。
- CLIサブコマンドで通知発火・ログ表示・集計が可能。
- シンプルかつ拡張性のある構成を意識し、他Skillとの干渉や副作用を排除。
