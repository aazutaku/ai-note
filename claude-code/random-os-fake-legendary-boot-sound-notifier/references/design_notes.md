# 概要
本Skillは、作業開始や新規セッション時に架空の伝説的OS起動音の“名前”をテキスト通知として表示し、ユーモアや集中力リセットの演出を提供します。実際に音は鳴らさず、通知内容は毎回ランダム生成されます。

# 公式ドキュメント抜粋
実在しない起動音タイトルを生成し、出力はテキスト通知のみ。履歴はセッション内メモリにのみ保持し、ファイル保存や音声再生は行いません。

# 利用例
- 朝一の作業開始時に「伝説のバグフィックス交響曲」と表示されて気分転換
- 新規ターミナルで毎回違う“起動音”通知が出て、チーム内で話題に

# 注意点
本Skillはジョーク・演出用途です。業務通知やアラートには利用できません。通知履歴はセッション内のみで永続化されません。

# 設計方針
通知内容は、実在しないが“ありそう”な起動音名を30種以上用意し、毎回ランダム選択。CLIサブコマンドで履歴やサマリーも表示可能にしています。
