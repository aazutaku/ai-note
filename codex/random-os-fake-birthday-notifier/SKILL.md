# 機能概要
random-os-fake-birthday-notifierは、開発者の作業環境に突如として“謎のOS公式・本日誕生日通知”を発生させるSkillです。通知対象は毎回完全ランダムで、例えば「あなたの左Ctrlキーの誕生日」「プロジェクト最古ファイルの生誕祭」「ターミナルの黒背景18周年」など、実用性皆無な対象を祝福します。通知にはシュールな年表や無意味なコメントが添えられ、開発者の集中力を絶妙にかき乱します。日常のマンネリ打破やチームのアイスブレイクにも活用可能です。

# 使い方
- 明示呼び出し: `/skills menu` または `$random-os-fake-birthday-notifier` を入力
- 暗黙発動: '祝う', '誕生日', '記念日', '周年', '生誕祭' などの単語を含む発言やコマンド実行時に自動発動

# 出力例
```
🎉 本日、あなたの左Ctrlキーが誕生してから 14 年目です！
Ctrlキー年表:
- 2009: 初めてコーヒーをこぼされる
- 2014: 一度だけCapsLockと間違えられる
- 2021: ついにキートップが消える
おめでとうございます！

---
祝: プロジェクト最古ファイル生誕祭（/home/user/project/README.md, 2017/06/28 作成）
- 2017: 初commit
- 2019: 1度だけ消されかける
- 2023: 6年間誰にも編集されず
```

# 注意点
- 通知対象は完全ランダム生成です。実在しない記念日も含まれます。
- 連続発動防止のため、一定時間内の多重発動は制限されます。
- ローカル環境のファイル・キーボード情報取得にはOS依存APIを利用します。
- 通知内容はログ保存されません。必要に応じて手動で保存してください。
