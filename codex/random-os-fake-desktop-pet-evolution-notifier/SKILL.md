# 機能概要
このSkillは、あなたの作業環境に“謎のデスクトップペット進化通知”をランダムに炸裂させる演出ツールです。実際には存在しないOS公式ペットが、勝手に進化・誕生したと告げてきます。例えば「あなたのマウスポインタは幻のカメレオン形態に進化しました」や「本日よりキーボードにサボテン系ペットが宿ります」など、毎回内容が異なります。現実のOSやファイルには一切影響せず、作業中の気分転換や話題作りに最適です。

# 使い方
明示呼び出し: `/skills menu` から `random-os-fake-desktop-pet-evolution-notifier` を選択、または `$random-os-fake-desktop-pet-evolution-notifier` を直接メンション。
暗黙発動: 「通知」「ペット」「進化」「デスクトップ」「ジョーク」「演出」などのキーワードを含む会話やコマンド実行時に自動発動。

# 出力例
```
[OS公式通知] あなたのマウスポインタは本日“幻のカメレオン形態”に進化しました。
[OS公式通知] 本日よりキーボードに“サボテン系ペット”が宿ります。
[OS公式通知] デスクトップ領域に“浮遊型ペンギン”が誕生しました。お世話不要です。
[OS公式通知] あなたのターミナルには“夜行性リス”が進化して棲みつきました。
[OS公式通知] 本日限定で“回転式クラゲ”がデスクトップを巡回中です。
```

# 注意点
- 実際のOS・ファイル・ユーザー設定には一切影響を与えません。
- 通知内容は全て架空であり、現実世界の動作やペット育成には関与しません。
- ローカル保存や履歴機能はありません（出力は一時的）。
- 業務中の過度な発動や連続通知には注意してください。
