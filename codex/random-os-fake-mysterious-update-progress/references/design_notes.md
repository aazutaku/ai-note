# 概要
このSkillは、作業中に「謎のOSアップデート進行中」風の進捗バーを表示し、非日常感や緊張緩和、ちょっとした笑いを提供するエンタメ系演出を目的としています。

# 設計方針
- 進捗内容は毎回ランダムかつ意味不明なメッセージを生成
- 進捗バーの挙動は理不尽（逆戻り、99%で止まる等）を必ず含む
- 実際のシステムやファイルには一切影響しない安全設計
- CLIサブコマンドで「run」「list」「summary」を提供し、用途に応じて使い分け可能

# 利用例
- チームの雑談や作業の合間に、ターミナルやチャットで実行
- 本番環境や重要な作業の進捗とは無関係な演出用途

# 公式ドキュメント抜粋
- Python random: https://docs.python.org/3/library/random.html
- tqdm（進捗バー演出例）: https://github.com/tqdm/tqdm

# 注意点
- 本Skillはあくまで演出目的であり、実際のアップデートや進捗管理には利用できません。
- ログや進捗履歴の保存機能はありません。
