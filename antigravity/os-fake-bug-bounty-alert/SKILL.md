# 機能概要
このSkillは、あなたの作業環境に突如「偽のバグバウンティ通知」を届けることで、日常の緊張感や単調な雰囲気を一瞬で和ませます。通知内容は完全ランダム生成され、現実離れした“バグ”と“報酬”が毎回異なります。例えば「発見：コーヒー過剰摂取バグ、賞金3バグポイント進呈」や「重大：本日限定“昼寝検出バグ”修正者に謎の称号授与」など、ユーモア溢れる内容で開発現場やリモートワークの空気を一変させます。実害やデータ損失は一切なく、純粋なエンターテインメントとして機能します。

# 使い方
このSkillは明示的な呼び出しを必要とせず、Antigravityのsemantic-match機能により自動発動します。たとえば「バグ」「バウンティ」「報酬」「通知」などのキーワードを含む会話やタスク、あるいは長時間の作業・集中状態が検出された場合に、突如として偽バグバウンティ通知が表示されます。設定により通知頻度や表示方法（デスクトップ通知・ターミナル出力等）をカスタマイズ可能です。

# 出力例
```
[FAKE BUG BOUNTY ALERT]
発見: キーボードのJキー過剰使用バグ
報酬: 1バグポイント進呈

[FAKE BUG BOUNTY ALERT]
重大: 本日限定“昼寝検出バグ”修正者に謎の称号授与

[FAKE BUG BOUNTY ALERT]
警告: マグカップ底なしバグ、修正者に幻のステッカー贈呈

[FAKE BUG BOUNTY ALERT]
発見: 机上の消しゴム消失バグ、賞金: 5バグポイント
```

# 注意点
- 通知内容は完全に架空であり、実際の業務やデータには一切影響しません。
- ログや通知履歴はローカルに保存されません（設定で履歴保存も可能）。
- 本Skillは職場の雰囲気や受け手によっては冗談が通じない場合もあるため、導入時はご注意ください。
- 通知はOSの標準API（notify-send, plyer等）を利用します。
