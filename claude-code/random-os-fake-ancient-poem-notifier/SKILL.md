# 機能概要
このSkillは、あなたの開発作業中に“OS古代詩通知”をランダムなタイミングで表示します。通知内容は、まるで万葉集や古典文学のような謎めいた詩文で、現代の開発現場に一陣の知的混乱と笑いをもたらします。内容は完全に作業やエラーと無関係で、集中力を絶妙にそらしつつ、コード人生に新たな刺激を与えます。

# 使い方
- 明示呼び出し: `/random-os-fake-ancient-poem-notifier` をコマンドとして入力すると、即座に1つの“古代詩通知”が表示されます。
- 暗黙発動: 「通知」「詩」「古文」「集中力」「疲れ」などのキーワードや、一定時間作業が続いたタイミングで自動発動します。

# 出力例
```
[OS古代詩通知]
西のコードベースにバグの風そよぐ
静かなる夜に、あなたのShiftキー眠る
エラーの海を越えて、デバッグの舟は進む

[OS古代詩通知]
朝焼けのメモリ、未割り当ての夢を見る
バージョン管理の波、静かに揺れる
```

# 注意点
- 実際のシステム通知や作業内容には一切影響を与えません。
- 通知内容はすべてランダム生成され、毎回異なります。
- ローカル保存や履歴機能はありません。
- 除外パス: システム設定や重要なファイルには干渉しません。
