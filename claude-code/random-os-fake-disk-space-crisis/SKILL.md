# 機能概要
このSkillは、あなたの作業環境に突如「謎のOSディスク残量危機通知」を炸裂させるジョーク演出ツールです。通知内容は毎回ランダム生成され、実際のディスク容量とは一切無関係。例：「警告: あなたの残ディスク容量は“カブトムシ2匹分”です」「緊急: SSDの空きが“ギャラクシー級に不足”」など、意味不明な単位や比喩が満載です。作業の合間に正気度を試されたい、チームに笑いを提供したい、集中力が切れたときのネタとして活用できます。

# 使い方
- 明示呼び出し例: `/random-os-fake-disk-space-crisis` をコマンド入力
- 暗黙発動キーワード例: 「ディスク容量」「空き領域」「容量不足」「残りストレージ」などの会話やコードコメント中に自動発動
- 通知はターミナルまたはデスクトップ通知として表示されます

# 出力例
```
[CRISIS] 警告: あなたの残ディスク容量は“カブトムシ2匹分”です
[CRISIS] 緊急: SSDの空きが“ギャラクシー級に不足”
[CRISIS] 注意: ディスク空き領域は“1.2メガピクセル”しかありません
[CRISIS] 警告: 残容量が“バナナ1房”分に到達しました
[CRISIS] 緊急: あなたのストレージは“宇宙的に枯渇”しています
```

# 注意点
- 実際のディスク容量やストレージ情報は一切取得・操作しません
- 通知内容は完全にランダム生成されます
- ローカル環境へのファイル保存や履歴記録は行いません
- システムのセキュリティや設定によりデスクトップ通知が表示されない場合があります
