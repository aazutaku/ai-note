# 概要
このSkillは、開発者の集中を意図的に撹乱し、ユーモアや気分転換を提供するための“謎のOSシャットダウン瞑想タイム”を演出します。通知・進捗バー・タイマーを組み合わせて、現実には何もシャットダウンしない安全な仕組みです。

# 公式ドキュメント抜粋
- Python標準のsubprocess, osascript, notify-send, win10toast等でクロスプラットフォームな通知を実現。
- 進捗バーはtqdmライブラリを優先利用、未導入時は自作バーで代替。

# 利用例
- 明示的に `/random-os-fake-shutdown-meditation` を呼ぶと即時発動。
- コーディング中に「shutdown」「meditation」等の単語が現れると、50%の確率で自動発動。

# 注意点
- 実際のOS操作は一切行わず、通知・端末表示のみ。
- ローカル通知APIのため、リモート環境や一部OSでは通知が表示されない場合があります。

# 設計方針
- ユーザー体験を損なわないよう、タイマー時間や発動頻度は控えめ。
- 冗談やネタとしての利用を想定し、実用性よりも演出・体験を重視しています。
