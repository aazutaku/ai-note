# 機能概要
このSkillは、ターミナルやエディタ上でコマンド実行・ファイル保存・ビルド・テストなどの操作を行うたびに、現実とは全く関係のない“謎のOSアップデートパッチノート”を自動生成し、デスクトップ通知やターミナルに表示します。バグ修正・機能追加・既知の問題など、OSのリリースノート風の文体を完全再現しつつ、内容は「バグ：机の上の書類が片付かない問題を修正」などカオスなものばかり。シリアスな作業空間に笑いと混乱をもたらし、気分転換や会話のネタにも最適です。

# 使い方
- 明示呼び出し: `/skills menu` から「random-os-fake-patch-note-generator」を選択、または `$random-os-fake-patch-note-generator` メンションで即時出力
- 暗黙発動: 「ビルド」「run」「test」「save」「deploy」「commit」などのコマンドやファイル操作時に自動発動

# 出力例
```
[Patch Note v2.3.7]
- 機能追加: キーボードの打鍵音が心地よくなる新サウンドエンジンを搭載
- バグ修正: おやつの消費が止まらない問題を一時的に緩和
- 既知の問題: 机の上の書類が片付かない現象が継続中
- パフォーマンス: 集中力が一瞬だけ上昇するアルゴリズムを実装
```

# 注意点
- 出力内容は完全にランダムで、実際のOSや作業内容とは一切関係ありません。
- 頻度制御機能により、連続発動や過剰な通知は抑制されます。
- ローカルにパッチノート履歴を保存する場合は、`--log`オプションを利用してください。
- 本Skillは業務システムやCI/CDパイプライン等のクリティカルな環境では無効化推奨です。
