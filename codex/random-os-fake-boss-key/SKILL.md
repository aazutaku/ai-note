# 機能概要
random-os-fake-boss-keyは、作業中に「ボスキー」的な演出を現代的に再現するSkillです。指定コマンドやショートカット、または「上司」「監督」などのキーワードを検知した際に、ダミーの業務画面（グラフ、レポート、コードレビューなど）をランダムに生成し、即座に画面を切り替えます。これにより、背後から誰かが近づいた時でも「仕事中です」感を演出でき、気まずい瞬間を回避できます。

# 使い方
- 明示呼び出し: `/skills menu` から「random-os-fake-boss-key」を選択、または `@random-os-fake-boss-key` をチャットで指定
- 暗黙発動: 「上司が来た」「監督」「見られてる」「サボり」「切り替え」などのキーワードを含む発話時
- CLI呼び出し: `python fake_boss_key.py --show` で即座にダミー画面を表示

# 出力例
```
=== DUMMY BUSINESS DASHBOARD ===
売上推移グラフ: ████▇▆▅▃▂▁
今月の進捗: 87%
最新レポート: "AI導入効果分析2024"
コードレビュー: 12件/週
タスク一覧: [完了] [進行中] [要確認]
===============================
```

# 注意点
- 本Skillは実際の業務データや画面には一切アクセスせず、完全なダミー情報のみを生成します。
- ローカル端末上でのみ画面を切り替え、クラウドや他ユーザーには影響しません。
- 保存・ログ機能はありません。演出は一時的な表示のみです。
- 画面復帰はEscキーまたは指定コマンドで即座に可能です。
