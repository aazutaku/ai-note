# 機能概要
このSkillは、作業の合間や明示的な呼び出し時に、まるでOSが謎のアップデートを始めたかのような進捗バーをターミナル上に突然表示します。進捗内容は毎回「未知の言語パーサ更新中」「秘密のAPIを最適化中」など完全に謎で、進捗バーも時に止まったり逆流したりする理不尽な演出が特徴です。実際には何も更新されず、現実感をじわじわ侵食するだけの無意味な演出を提供します。

# 使い方
- 明示呼び出し例:
  - `/skills menu` から本Skillを選択
  - `$ os-fake-mystery-update-progress` コマンドを直接実行
- 暗黙発動キーワード例:
  - 「アップデート」「進捗」「謎」「OS」「fake」「バー」などの単語を含む会話やコマンド時

# 出力例
```
[=====>         ] 28%  未知の言語パーサ更新中...
[=======>      ] 43%  伝説のバグを発掘中...
[======        ] 37%  秘密のAPIを最適化中...(逆流!)
[=========>    ] 59%  謎のドライバを再構築中...
[============= ] 95%  世界線の同期を試行中...
```

# 注意点
- 実際のファイルやシステムには一切影響を与えません。
- 出力はターミナル上のみ。ローカル保存や履歴記録は行いません。
- 進捗バーや内容文言は毎回ランダム生成です。
- 一部端末では進捗バーの描画が崩れる場合があります。
