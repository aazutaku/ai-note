# 機能概要
このSkillは、作業中のデスクトップに「謎のOS風・強制休憩通知」をランダムなタイミングで表示します。通知内容も毎回ランダムで、「肩回しタイム発動」「OS推奨：5分間ぼーっとするべし」「緊急！脳内メモリ休息モード」など、意味不明かつカオスなメッセージが炸裂。真面目な現場に唐突なユーモアを注入し、張り詰めた空気を一瞬だけほぐすことができます。実作業やデータには一切影響を与えず、あくまで演出と気分転換を目的としています。

# 使い方
- 明示呼び出し例: `/random-os-fake-breaktime-alert`
- 暗黙発動キーワード例: 「休憩したい」「集中力が切れた」「通知で遊びたい」「OSアラート」「リラックスしたい」などを含む会話や指示

# 出力例
```terminal
[OS通知] 肩回しタイム発動！今すぐ両腕を回転せよ。
[OS通知] 緊急！脳内メモリ休息モード。5分間ぼーっと推奨。
[OS通知] システム推奨：窓の外を眺めて深呼吸するべし。
[OS通知] 休憩プロトコル：好きな飲み物を用意してください。
[OS通知] 謎のアップデート中。作業を一時中断してください。
```

# 注意点
- 本Skillは実際の作業やファイルには一切干渉しません。
- 通知はローカル環境のデスクトップ通知機能を利用します（Linux/macOS/Windows対応）。
- 一部環境では通知が表示されない場合があります。
- ログや履歴はローカルに保存されません。
