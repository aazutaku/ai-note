# 機能概要
本Skillは、OSのパスワードポリシーが突然意味不明な内容に変更されたかのような通知をデスクトップに表示します。通知内容は「季節の俳句＋円周率12桁＋好きな給食メニュー必須」や「新ルール：母音だけのパスワード不可」など、現実にはありえない理不尽なものばかり。実際のパスワード設定やシステムには一切影響を与えず、開発現場の緊張感やマンネリを一瞬で和らげる混沌系ジョーク演出を実現します。

# 使い方
このSkillは明示的な呼び出しは不要です。「パスワード」「password」「ポリシー」「セキュリティ」「認証」などのキーワードを含む会話やコマンド、ドキュメント編集がトリガーとなり、Antigravityが自動で実行します。通知は完全ランダムまたは一定間隔で出現し、内容も毎回異なります。

# 出力例
```
【重要】OSパスワードポリシー変更のお知らせ
本日よりパスワードは「季節の俳句＋円周率12桁＋好きな給食メニュー」を含める必要があります。

【新ルール】
母音だけのパスワードは使用禁止となりました。

【推奨】
毎日ランダムなパスワードに変更し、記憶しないでください。

【参考】
詳細は社内Wiki「謎のポリシー集」参照。
```

# 注意点
- 実際のパスワードやOS設定には一切影響を与えません。
- 通知内容は完全にジョークであり、現実のセキュリティ運用には従いません。
- 通知履歴や内容はローカルには保存されません。
- 重要な作業中に表示される場合がありますので、演出目的であることをご理解ください。
