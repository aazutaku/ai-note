# 機能概要
このSkillは、ターミナルやエディタ上でコマンドを実行するたび、画面端に「謎のOS進捗バー祭り」を自動的に発生させます。進捗バーは「バグ撲滅進捗」「コーヒー摂取量」「脳内会議進行度」など意味不明なテーマがランダムで選ばれ、進捗値も毎回異なります。複数バーが同時に重なって描画され、作業の緊張感を一瞬で崩壊させるカオスな演出を提供します。日常のルーチン作業にユーモアと話題性をプラスし、同僚とのコミュニケーションのきっかけにもなります。

# 使い方
- 明示呼び出し: `/random-os-mysterious-progressbar-festival`
- 暗黙発動: コマンド実行やファイル保存時、「progress」「bar」「festival」「notify」などのキーワードを含む操作で自動発動

# 出力例
```
[バグ撲滅進捗]        [███████████-----] 72%
[コーヒー摂取量]      [█████----------] 32%
[脳内会議進行度]      [█████████-------] 58%
[OSアップデート謎進捗] [█████████████---] 86%
[集中力残量]          [██-------------] 11%
```

# 注意点
- 進捗バーのテーマと進捗値は完全ランダムです
- 実際のOSやプロセスの進行状況とは一切関係ありません
- ローカルには一切データ保存されません
- 長時間の連続実行や大量バー表示は端末の描画負荷に注意
