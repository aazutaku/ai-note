# 機能概要
このSkillは、作業中に突如「謎のOSアップデート進行中」風の進捗バーをターミナルやチャットに表示し、非日常感や脱力感を演出します。進捗内容は「未知の言語パッチ適用中」「レガシーキーボード最適化中」など毎回意味不明で、進捗バーも理不尽に逆戻りしたり99%で止まったりします。作業の緊張感を和らげ、エンタメ要素を加える用途に最適です。

# 使い方
- 明示呼び出し例:
  - `/skills menu` から選択
  - `$random-os-fake-mysterious-update-progress` をメンション
- 暗黙発動キーワード例:
  - 「アップデート」「進捗バー」「OS更新」「謎のパッチ」などの単語を含む会話中

# 出力例
```
[  7%] 未知の言語パッチ適用中...
[ 25%] レガシーキーボード最適化中...
[ 12%] ファイルシステムの逆最適化中...
[ 42%] メモリの謎領域を拡張中...
[ 99%] 進捗状況を再計算中...
[ 88%] 進捗が巻き戻りました...
[ 99%] 未知のプロトコルを初期化中...
```

# 注意点
- 実際のシステムやファイルには影響を与えません
- 本Skillは演出目的のため、実作業や本番環境の進行状況とは無関係です
- ローカル保存や通知機能はありません
