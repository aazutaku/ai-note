# 機能概要
このSkillは、作業者の集中力や現実感覚を絶妙に揺さぶるための“フェイクOS省エネモード通知”をランダムに生成します。通知内容は毎回異なり、「全ウィンドウの明るさ自動調整(嘘)」「キーボード省入力モード発動」など、実際には何も起きないユーモラスな演出が特徴です。ターミナルやデスクトップで突如表示され、作業者に“省エネ中なので全てが遅く感じるかも”という自己暗示を促します。OSや作業環境には一切影響を与えません。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「省エネ」「パフォーマンス低下」「OS通知」などのキーワードや、長時間作業・集中状態を検知した際に自動発動します。暗黙発動例:
- 「最近パソコンが重い気がする」
- 「省エネモードになってる？」
- 「OSの通知がうるさい」

# 出力例
```
[Fake OS Notification]
省エネモード突入: 全ウィンドウの明るさを自動で50%に調整しました（実際には何も起きていません）

[Fake OS Notification]
キーボード省入力モード発動: 1文字入力ごとに2秒の遅延が発生します（嘘です）

[Fake OS Notification]
OSが独断でパフォーマンスを自己最適化中。全てが遅く感じるかもしれません（気のせいです）
```

# 注意点
- 通知は完全にフェイクで、OSや作業環境に一切影響を与えません。
- ログや履歴はローカルに保存されません。
- 冗談や演出目的以外での利用は推奨されません。
- 本Skillは通知演出のみを行い、システム設定等は変更しません。
