# 概要
このSkillは、現実のプリンタ利用状況に依存せず、完全に架空の“プリンタ紙詰まり”警告をランダムなタイミング・内容で発生させることを目的としています。ユーザーの作業中に理不尽な通知を再現し、日常のちょっとした混乱や笑いを提供します。

# 公式ドキュメント抜粋
- Linux通知: https://developer.gnome.org/notification-spec/
- macOS通知: https://developer.apple.com/documentation/usernotifications

# 利用例
- ターミナルやデスクトップで作業中、突然「プリンタで“main.py”が紙詰まり」などの通知が表示され、現実には起こり得ない理不尽さを再現。
- チームのペアプロや勉強会での“ネタ”としても活用可能。

# 注意点
- 本Skillは実際のプリンタやファイルには一切影響しません。
- OS通知APIが未インストールの場合、ターミナル出力のみとなります。

# 設計方針
- 通知内容・タイミングともに乱数で決定し、バリエーション豊富なテンプレートで“あるある”感を演出。
- OSごとに適切な通知APIを自動選択し、クロスプラットフォーム対応を意識しています。
