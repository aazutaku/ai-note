# 概要
このSkillは、現場の緊張感やマンネリを打破するためのジョーク通知を目的に設計されています。OSのネイティブ通知APIを利用し、実際には何も保存しない点が特徴です。

# 公式ドキュメント抜粋
- Linux: notify-send (freedesktop.org)
- macOS: osascript (AppleScript)
- Windows: win10toast (PyPI)

# 利用例
- ビルドやテストの自動化スクリプトに組み込む
- チームの朝会やペアプロ時のアイスブレイク
- コマンドライン作業の合間に

# 注意点
- 通知APIはOSごとに挙動が異なります。Linux/macOSでは標準搭載ですが、Windowsはwin10toastのインストールが必要です。
- 実際のファイル保存や画像生成は一切行いません。

# 設計方針
- シンプルな構成で、導入・削除が容易
- ユーモアと混沌を重視しつつ、迷惑にならない頻度設計
- コマンドライン/標準入力監視の両対応
