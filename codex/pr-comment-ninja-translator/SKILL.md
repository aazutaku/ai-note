# 機能概要
このSkillは、Pull Request（PR）のコメントやレビュー文を“忍者口調”に自動変換し、GitHub等のPRコメントとして投稿できるエンタメ系ツールです。普段は堅苦しくなりがちな開発現場のやり取りを、忍者の世界観で一気に和ませます。例えば「この変数名は分かりづらいです」を「拙者思うに、この変数名、影の如く分かりづらいでござる…」と変換。真剣な議論も、伊賀甲賀の忍法合戦に早変わり。

# 使い方
- 明示呼び出し: `/skills pr-comment-ninja-translator` または `@codex pr-comment-ninja-translator 変換して` のように記述。
- 暗黙発動: 「忍者語」「忍者口調」「ジョーク」「和ませたい」「忍法」などのキーワードがPRコメントに含まれる場合、自動で発動します。
- 変換対象のテキストを直接指定するか、既存PRコメントのID/URLを指定して変換可能です。

# 出力例
```
原文: この関数はバグがあります。修正してください。
忍者口調: 拙者が見たところ、この術式にはバグの気配…修正の術、お願い申す！

原文: テストケースが不足しています。
忍者口調: ござる…テストの術が足りぬと見受けられる！

原文: 変数名をもっと明確にしましょう。
忍者口調: 拙者思うに、この変数名、もっと明快にするのが良きでござろう！
```

# 注意点
- 忍者口調への変換は日本語限定です。英語や他言語には未対応。
- 元文の意味が大きく損なわれる場合があります。正式なレビュー用途には注意。
- ローカルに変換履歴は保存されません。必要なら別途ログ出力を有効化してください。
- GitHub API等でPRコメント投稿時は認証情報が必要です。
