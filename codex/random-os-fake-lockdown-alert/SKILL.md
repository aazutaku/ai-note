# 機能概要
このSkillは、あなたの作業環境に突然『謎のOSロックダウン発令通知』を出現させます。通知内容は完全ランダムで「本日より全ファイル凍結」「理由：カフェイン過剰摂取検知」「解除方法：深呼吸5回」など、現実にはあり得ないユーモア溢れるものばかり。真面目な雰囲気の中に突如“非日常”を演出し、職場やチームの空気を一瞬で和ませます。実際のファイルや環境には一切影響を与えず、安心してご利用いただけます。

# 使い方
- 明示呼び出し: `/skills menu` から「random-os-fake-lockdown-alert」を選択、または `$random-os-fake-lockdown-alert` と発話
- 暗黙発動: 「ロック」「凍結」「緊急」「OS」「通知」などの単語が会話やコマンドに含まれると自動発動

# 出力例
```
=== 緊急OSロックダウン通知 ===
発令時刻: 2024-06-30 14:23:11
対象: 全ユーザーディレクトリ
理由: キーボード過熱検知
解除方法: 画面を3回タップしてください
備考: この通知は実際の操作には影響しません
```
```
=== 謎のシステム凍結警告 ===
発令時刻: 2024-06-30 15:01:08
対象: 本日作成された全ファイル
理由: カフェイン摂取量が閾値を超過
解除方法: 深呼吸を5回行ってください
備考: ご安心ください、ファイルは安全です
```

# 注意点
- 通知は完全にジョークであり、実ファイルやシステムには一切作用しません
- ローカル保存や実際の通知ポップアップは行いません（標準出力のみ）
- 業務上の重要な場面や混乱を招く場では控えめにご利用ください
