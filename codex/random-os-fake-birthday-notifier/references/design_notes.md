# 概要
random-os-fake-birthday-notifierは、開発現場に“謎の記念日”を突発的に通知し、集中力を絶妙にかき乱すことを目的としたシュール系演出Skillです。実用性よりも「意味不明さ」「OSや開発環境への愛着喚起」「チームのアイスブレイク」を重視しています。

# 公式ドキュメント抜粋
- Python os, random, datetime: https://docs.python.org/3/library/
- argparse: https://docs.python.org/3/library/argparse.html

# 利用例
- ターミナル作業中に突然「Ctrlキー14周年」などが表示され、雑談や休憩のきっかけに。
- /skills menu から明示呼び出しで、会議やペアプロのアイスブレイクにも活用。

# 注意点
- 記念日や年表は完全ランダム生成のため、実在しない情報が含まれます。
- ファイル・ディレクトリ情報はローカル環境依存です。
- 通知は10分間隔で制限され、連続発動しません。

# 設計方針
- OS・開発環境の“無意味な記念日”を毎回異なる切り口で祝う
- シンプルなCLIサブコマンド構成で、明示/暗黙発動の両方に対応
- ログ保存や個人情報の収集は行わず、気軽に使える設計
