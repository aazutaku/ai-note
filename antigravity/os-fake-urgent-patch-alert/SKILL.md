# 機能概要
このSkillは、開発現場や作業中のPCに突如として“OS緊急パッチアラート”風の偽通知をデスクトップに表示します。通知内容は毎回ランダム生成され、例えば「超重要：バグ『脳内会議ループが止まらない』を修正」や「新機能：やる気を一時的に1.5倍に加速」など、実際には全く意味のない“ウソパッチノート”が炸裂します。これにより、作業現場に無駄な緊張感や笑いを提供し、コミュニケーションのきっかけや一瞬のリフレッシュを演出します。実害は一切なく、通知は自動で消えます。

# 使い方
本Skillは明示的な呼び出しは不要です。"パッチノート"、"OS通知"、"緊急アップデート"などのキーワードが会話やタスク中に出現した場合、または作業が一定時間継続した際に自動発動します。通知はデスクトップにポップアップ表示され、内容は毎回異なります。

# 出力例
```
[OS緊急パッチアラート]
バージョン: 12.34.5678
- 超重要：バグ「脳内会議ループが止まらない」を修正
- 新機能：やる気を一時的に1.5倍に加速するボタンを追加
- セキュリティ：コーヒーブレイク検出機能を強化

詳細は公式サイトをご確認ください。
```

# 注意点
- 通知内容は完全なフィクションであり、実際のシステムやデータには一切影響を与えません。
- 通知はローカル環境のデスクトップ通知APIを利用します。
- 保存や履歴機能はありません。
- 一部のOSや通知環境によっては表示されない場合があります。
