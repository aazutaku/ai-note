# 概要
このSkillは、ターミナルやエディタ上で作業中に「意味不明な進捗バー」を複数同時に描画し、作業空間をカオスに演出するために設計されました。進捗テーマ・値ともに完全ランダムで、実際の進行状況とは無関係です。

# 公式ドキュメント抜粋
- Python標準ライブラリのみで構築
- argparseによるCLIサブコマンド対応
- 画面クリアやバー描画はANSIエスケープシーケンスで実現

# 利用例
- `/random-os-mysterious-progressbar-festival` で即座に発動
- `python mysterious_progressbar_festival.py run --bars 4 --cycles 7` などコマンドラインからも利用可能

# 注意点
- 実際のOSやプロセス進行度とは一切関係ありません
- 長時間連続実行や大量バー表示は端末の描画負荷に注意してください

# 設計方針
- テーマ・進捗値ともに毎回ランダム生成
- 1回の発動で3～6本のバーを同時描画
- CLIからの明示呼び出し・サブコマンドで柔軟に制御可能
