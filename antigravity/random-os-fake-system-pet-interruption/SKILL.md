# 機能概要
このSkillは、作業中のユーザーに対し、完全ランダムなタイミングで「OSペット乱入イベント」を発生させます。内容は「仮想猫がマウスを追いかける」「デジタル柴犬がファイルの上で昼寝中」など多彩で、何の役にも立たないのに謎の癒しと混乱をもたらします。長時間の集中や“ペット”関連の語句出現時に発動し、OSがペットを飼い始めた世界観を一瞬だけ体験できます。集中しすぎた頭をリセットしたいときや、ちょっとした遊び心を加えたいときに最適です。

# 使い方
このSkillは常時バックグラウンドで動作し、明示的な呼び出しは不要です。暗黙発動キーワード例として「ペット」「猫」「柴犬」「癒し」などが会話や作業ログに現れると、乱入イベントが発生しやすくなります。また、一定時間無操作や集中状態が続いた場合にも自動で発動します。

# 出力例
```
[通知] OS公式ペット「ねこまる」が画面を横切りました。
[通知] 仮想猫がマウスカーソルを追いかけています。
[通知] デジタル柴犬がファイル「report.docx」の上で昼寝中です。
[通知] OSペット「うさぎん」がタスクバーでジャンプしています。
[通知] ペンギンが端末ウィンドウに登場しました。
```

# 注意点
- 本Skillは通知・演出のみで、実際のファイルやシステムには影響を与えません。
- ローカル保存や履歴の記録は行いません。
- ペットの種類や演出内容は完全ランダムです。
- 長時間の無操作や特定キーワードで発動頻度が上がります。
