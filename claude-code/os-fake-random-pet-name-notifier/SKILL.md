# 機能概要
このスキルは、あなたの作業中に突然“謎のOS公式・ペット命名通知”をデスクトップやターミナルに表示します。内容は毎回ランダムで、例えば「あなたのマウスは本日より“疾風のコロンブス”と命名されました」など、PC周辺機器に意味不明な二つ名を勝手に付与する理不尽イベントを演出します。実用性はありませんが、作業にカオスと笑いをもたらし、集中力を根こそぎ奪います。

# 使い方
- 明示呼び出し: `/os-fake-random-pet-name-notifier`
- 暗黙発動: 「ペット名」「命名」「通知」「デバイス」などのキーワードが会話やコードに現れた時、自動的に発動します。

# 出力例
```
[OS通知] あなたのマウスは本日より「疾風のコロンブス」と命名されました。
[OS通知] キーボードの新しい名は「静寂なる鉄槌」です。
[OS通知] モニターの公式ペット名：「闇夜の覗き魔」
[OS通知] USBハブは「無限分岐の賢者」となりました。
[OS通知] あなたのWebカメラは「見守る千里眼」になりました。
```

# 注意点
- 本Skillは通知のみを行い、実際のデバイスやデータには一切影響しません。
- ローカルへの保存や履歴機能はありません。
- 一部OS環境ではデスクトップ通知が利用できない場合があります（その際はターミナル出力のみ）。
- 実在の命名規則やOS公式機能とは無関係です。
