# 機能概要
このSkillは、OSやシステム運用現場でよくある「パスワードポリシー変更通知」を、完全に架空かつ理不尽な内容でランダムにデスクトップ通知として表示します。たとえば「本日よりパスワードは季節の俳句＋円周率12桁＋好きな給食メニュー必須」など、現実にはあり得ないポリシーが突然現れ、作業中の緊張感やマンネリを一瞬で和ませます。実際のパスワードやOS設定には一切影響せず、ジョークやチームのアイスブレイクに最適です。

# 使い方
- 明示呼び出し例: `/os-random-fake-password-policy-alert` または `/skill-name`
- 暗黙発動キーワード例: 「パスワード」「認証」「セキュリティ」「ログイン」「ポリシー」「OS設定」などが会話やコマンド履歴に現れた際に自動発動します。

# 出力例
```
[ALERT] 重要：本日よりパスワードは季節の俳句＋円周率12桁＋好きな給食メニュー必須です。
[NOTICE] 新ルール：母音だけのパスワードは禁止されました。ご注意ください。
[INFO] 推奨：毎日ランダムにパスワードを変えましょう（記憶は禁止です）。
[ALERT] パスワードには最低1つの元素記号を含めてください。
[NOTICE] 本日よりパスワード変更時は「好きな動物の鳴き声」を3回入力してください。
```

# 注意点
- 本Skillは通知の表示のみを行い、実際のパスワードやセキュリティ設定には一切影響しません。
- 通知内容は完全なジョークであり、実務上の参考にはなりません。
- 通知はローカル環境にのみ表示され、ログやファイル保存は行いません。
- 定期的またはランダムなタイミングで自動発動する場合があります。
