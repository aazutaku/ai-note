# 機能概要
このSkillは、作業中のターミナルやデスクトップに「謎のOSアップデート進行中」風の進捗バーを突如表示し、非日常感や脱力感を演出します。進捗内容は毎回ランダムで、「未知の言語パッチ適用中」「レガシーキーボード最適化中」など意味不明なものばかり。進捗バーは理不尽に逆戻りしたり、99%から一向に終わらなかったりと、現実のアップデートの理不尽さを再現します。緊張感ある作業に、適度なユーモアと休息をもたらします。

# 使い方
このSkillは明示的なコマンド呼び出しは不要で、semantic-match-onlyトリガーによって自動発動します。たとえば「update」「progress」「mysterious」「fake」「OS」「notification」などのキーワードを含む文脈で自動的に演出が始まります。ターミナル上での実行や、Pythonスクリプトとして直接呼び出すことも可能です。

# 出力例
```
[=====        ]  35%  未知の言語パッチ適用中...
[=======      ]  60%  レガシーキーボード最適化中...
[======       ]  55%  逆位相メモリ同期中...
[==========   ]  80%  仮想ペンギンモード有効化中...
[===========  ]  99%  進捗待機中...
[======       ]  57%  モジュール逆流抑制中...
```

# 注意点
本Skillはエンターテインメント目的であり、実際のOSやシステムには一切影響を与えません。進捗バーや出力内容は完全に架空で、ローカル環境やファイルシステムへの書き込みも行いません。演出が不要な場合はSkillの無効化を推奨します。
