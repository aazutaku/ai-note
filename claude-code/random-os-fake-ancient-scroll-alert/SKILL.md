# 機能概要
このSkillは、作業中やコマンド実行の合間に、突如として“謎のOS公式・古文書巻物通知”をデスクトップやターミナル画面端に表示します。通知は「西のコードベースにバグの気運漂う」「レビュアーの機嫌は末吉」など、古文書風の無意味なテキストが毎回ランダム生成され、巻物風UIで表示されます。実用性は皆無ですが、集中力をブレイクしたい時や、作業に一息入れたい時のエンタメ演出として活用できます。

# 使い方
- 明示呼び出し：`/random-os-fake-ancient-scroll-alert` をコマンドとして実行
- 暗黙発動：コマンド実行後や一定時間ごと（例: 15分毎）、または「集中」「疲れ」などのキーワードを含む会話文脈で自動発動

# 出力例
```
┌────────────────────────────┐
│  西のコードベースにバグの気運漂う  │
│  本日、レビュアーの機嫌は末吉      │
│  東の山より新たな仕様書が届く      │
│  朝霧の中、ビルドは静かに失敗す    │
└────────────────────────────┘
```

# 注意点
- 実用性はありません。通知内容は完全に無意味で、そのまま業務に使わないでください。
- 通知はローカル画面端に一時的に表示され、履歴保存やOS通知センター連携はありません。
- 他の通知や作業の邪魔になる場合があります（それが目的です）。
