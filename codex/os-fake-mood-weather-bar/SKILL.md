# 機能概要
os-fake-mood-weather-barは、あなたの作業環境に“謎の気分天気バー”を出現させる演出系Skillです。実用性は一切ありませんが、画面端やメニューバーに「絶好調・晴れ」「やる気霧雨」「集中力台風接近中」「仕様雪崩」など、完全ランダムな“気分天気”ワードを表示し、職場や自宅の空気をカオスに彩ります。日々のコーディングや作業に、ちょっとした謎のユーモアと脱力感を提供します。

# 使い方
- 明示呼び出し: `/skills menu` でスキル一覧から選択、または `$ os-fake-mood-weather-bar` を直接メンション
- 暗黙発動キーワード例: 「気分」「天気」「通知」「バー」「演出」「今日の調子」などが会話やコードに含まれると自動発動します。

# 出力例
```
[OS風・謎の気分天気バー]
現在の気分天気: 仕様雪崩
（次回更新まで: 3分）

[OS風・謎の気分天気バー]
現在の気分天気: バグの嵐
（次回更新まで: 5分）

[OS風・謎の気分天気バー]
現在の気分天気: やる気霧雨
（次回更新まで: 2分）
```

# 注意点
- 実際の天気や気分とは一切関係ありません。
- 他の通知・演出系Skillと同時利用時は重複表示に注意。
- ローカル保存や履歴機能はありません。
- Mac/Linux: tkinterでポップアップ表示、Windows: タスクバー通知で演出します。
