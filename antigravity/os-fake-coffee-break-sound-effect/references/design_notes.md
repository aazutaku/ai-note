# 概要
このSkillは、作業の合間に強制的に“コーヒーブレイク”を演出することで、ユーザーのリズムを意図的に撹乱し、開発現場に遊び心を持ち込むことを目的としています。

# 公式ドキュメント抜粋
- plyer: クロスプラットフォームなデスクトップ通知API ([公式](https://plyer.readthedocs.io/en/latest/))
- playsound: シンプルなサウンド再生API ([公式](https://github.com/TaylorSMarks/playsound))

# 利用例
- 長時間作業時に自動で休憩を促す
- チーム開発現場で“謎の休憩”を演出し会話のきっかけを作る
- カフェ風BGMや効果音でオフィスの雰囲気を変化させる

# 注意点
- サウンドファイルはローカルに配置が必要
- 通知APIは一部Linux環境で追加依存が必要
- 過剰な発動は逆効果なので間隔調整推奨

# 設計方針
- 実在APIのみを使用し、環境依存性を最小化
- ログ/サマリー機能で発動履歴も可視化
- 通知文言・サウンドは完全ランダムで毎回異なる体験を提供
