# 機能概要
このSkillは、OS風の“バグ孵化警告”を完全ランダムなタイミングでデスクトップ通知またはターミナル出力として表示します。通知内容は毎回異なり、「警告: 本日13:14に新たなバグが孵化しました」や「緊急: メモリ奥地で未確認バグが産声をあげました」など、明らかに冗談と分かる表現で、実害はありません。作業の合間に不安を煽ることで、気分転換やチーム内の話題作りに役立ちます。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「ビルド」「テスト」「デバッグ」「長時間のターミナル操作」などのキーワードや状況を検知した際、自動的に発動します。ユーザー操作や特定のコマンド実行時に、数分〜数十分の間隔でランダムに通知が表示されます。

# 出力例
```
[OS警告] 2024-06-18 13:14:02
警告: 本日13:14に新たなバグが孵化しました

[OS警告] 2024-06-18 13:47:59
緊急: メモリ奥地で未確認バグが産声をあげました

[OS警告] 2024-06-18 14:03:10
注意: システム深部でバグの卵が発見されました
```

# 注意点
- 実際のバグやエラーとは無関係で、すべて演出です。
- 通知は完全にランダムなタイミングで表示されます。
- ローカルのログやシステムには一切影響しません。
- 本物のエラー通知と混同しないよう、文面は冗談と分かるものに限定しています。
