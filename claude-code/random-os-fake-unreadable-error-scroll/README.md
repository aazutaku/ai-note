# random-os-fake-unreadable-error-scroll

> このSkillは、エラーやバグ、通知、混乱、カオス、OSバグ、不可解な現象などのキーワードや、/random-os-fake-unreadable-error-scroll 明示呼び出し時に発動します。巻物風UIで意味不明なエラーをスクロール表示し、チームに笑いと混乱を提供します。

このSkillは [ai-note.tech](https://ai-note.tech) の Skill 提案媒体で設計され、**Claude Code** 向けに最適化したものです。

## ファイル構成

- `SKILL.md` - Skill本体 (frontmatter + 指示)
- `scripts/fake_unreadable_error_scroll.py` - 謎のOS古代バグ巻物エラー演出スクリプト
- `references/design_notes.md` - 概要 をまとめた参考資料

## 配置方法

degit で一発:

```bash
npx degit aazutaku/ai-note/claude-code/random-os-fake-unreadable-error-scroll .claude/skills/random-os-fake-unreadable-error-scroll
```

または git clone してコピー:

```bash
git clone --depth 1 https://github.com/aazutaku/ai-note.git
cp -r ai-note/claude-code/random-os-fake-unreadable-error-scroll .claude/skills/random-os-fake-unreadable-error-scroll
```

配置後、Claude Code を再起動するか自動検出を待つと利用できるようになります。
