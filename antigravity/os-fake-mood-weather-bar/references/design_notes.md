# 概要
本Skillは、作業環境に遊び心を加えるための演出系ツールです。気分や作業状況を天気になぞらえ、完全ランダムなワードで“OS風バー”を表示します。Tkinterを用いクロスプラットフォームで動作します。

# 公式ドキュメント抜粋
- [Tkinter 公式リファレンス](https://docs.python.org/ja/3/library/tkinter.html)
- [Antigravity Skill開発ガイド](https://ai-note.tech/docs/antigravity-skill-guide)

# 利用例
- 仕事や勉強の合間に気分転換として表示
- オンライン会議やペアプロ時の話題作り
- コード実行時の演出や、休憩提案のきっかけ

# 注意点
- 実用的な通知や進捗管理は行いません
- 他の通知系Skillと同時利用時は競合に注意
- 表示内容の意味や精度は保証されません

# 設計方針
- 完全ランダム生成でカオス感を演出
- ローカル実行のみ、外部通信なし
- シンプルなUIと最小限の依存関係
