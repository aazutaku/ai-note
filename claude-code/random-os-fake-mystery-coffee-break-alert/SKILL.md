# 機能概要
random-os-fake-mystery-coffee-break-alertは、作業の合間やコマンド実行中に、まるでOS公式のような説得力ある“強制コーヒーブレイク”通知を突如発動します。通知メッセージは毎回ランダムで、集中力の限界やOS推奨リフレッシュタイムなど、現実離れした演出を楽しめます。真面目な作業中でも強制的に休憩を促されることで、非日常的な体験やユーモアを提供し、作業のリズムに意外性をもたらします。

# 使い方
- 明示呼び出し: `/random-os-fake-mystery-coffee-break-alert` または `/skill random-os-fake-mystery-coffee-break-alert`
- 暗黙発動: 「集中」「休憩」「リフレッシュ」「疲労」「OS通知」などのキーワードを含む会話やコマンド実行時に自動発動します。
- 通知はデスクトップ(Windows/macOS/Linux)またはターミナル上に表示されます。

# 出力例
```
[OS公式通知] 本日、あなたの集中力ゲージが限界に到達しました。コーヒーブレイクが自動発動されます。
[OS推奨] 重要：OS推奨のリフレッシュタイム到来。3分間の休憩を推奨します。
[警告] ユーザーの生産性が閾値を超過しました。強制的にコーヒーブレイクを開始します。
[システム] コーヒーブレイクプロトコル v2.3.4 が実行されました。復帰までお待ちください。
[OS通知] あなたの作業効率が低下しています。今すぐコーヒーを淹れましょう。
```

# 注意点
- 通知はローカル環境のOS通知APIを利用します。環境によっては一部通知が表示されない場合があります。
- メッセージ内容はジョークや演出を目的としたもので、実際のOSや業務指示とは無関係です。
- ログはローカルに保存されません。必要に応じて履歴機能を追加してください。
