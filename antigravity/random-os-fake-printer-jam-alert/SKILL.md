# 機能概要
このSkillは、現実には全くプリンタを使っていない状況でも、OSの公式風通知として「プリンタ紙詰まり警告」や「印刷ジョブ渋滞」などのアラートを完全ランダムなタイミング・内容で発生させます。通知文は毎回異なり、「重要：プリンタで“main.py”が詰まりました」「警告：印刷待ちジョブが渋滞中」など、理不尽かつ意味不明な内容が特徴です。作業中のユーザーに小さな混乱や笑いを提供し、日常の単調な作業に“紙詰まりあるある”のスパイスを加えます。

# 使い方
このSkillは明示的な呼び出しを必要とせず、Antigravityエージェントが自動的に発動します。トリガーはsemantic-match-onlyで、ユーザーの作業内容やコマンド履歴に関係なく、完全にランダムなタイミングで通知が表示されます。暗黙発動キーワード例：「印刷」「プリンタ」「紙」「ファイル保存」などが含まれる場合は発生頻度が上がりますが、原則としてどんな状況でも発生します。

# 出力例
```
[OS通知] 重要：プリンタで“report_2024.txt”が詰まりました。紙を手で給紙してください。
[OS通知] 警告：印刷待ちジョブが渋滞中。謎のトナーを補充してください。
[OS通知] エラー：main.pyの印刷中に紙詰まりが発生しました。プリンタカバーを開けてください。
[OS通知] 注意：プリンタが応答しません。紙を裏返して再度セットしてください。
[OS通知] 重大：印刷キューに未知の障害が発生しました。管理者に連絡してください。
```

# 注意点
- 実際のプリンタや印刷機能とは一切連携しません。
- ローカル環境でのみ動作し、通知履歴やログは自動的に削除されます。
- 通知内容は完全にフィクションです。
- OSの通知API（Windows: win10toast, macOS: pync, Linux: notify2等）を使用しています。
