# 機能概要
このSkillは、作業やコマンド実行の合間に、まるでOS公式のような“偽404エラー通知”をデスクトップまたはターミナルにランダム表示します。通知内容は「404: 今日の集中力が迷子です」「あなたのやる気が見つかりません」など、完全に役に立たないが妙に心に刺さるメッセージばかり。実用性はゼロですが、作業の合間に気分転換や笑いを提供し、単調な作業を和らげます。通知タイミング・内容は毎回ランダムで、非日常的な体験を演出します。

# 使い方
このSkillは明示的な呼び出し操作は不要です。Antigravityが「進捗」「やる気」「404」「エラー」「集中」などのキーワードを検知した際や、作業の合間に自動で発動します。ターミナル/デスクトップ通知として表示されます。

# 出力例
```
[通知] 404: 今日の集中力が迷子です
[通知] 404 Not Found: 予定されていた進捗が行方不明です
[通知] 404: あなたのやる気が見つかりません
[通知] 404 Error: コーヒーブレイクが必要です
[通知] 404: 残業回避モードが見つかりません
[通知] 404: 週末の気配が検出できません
```

# 注意点
本Skillは実際のエラーやシステム障害を通知するものではありません。誤解を避けるため、通知文言には「冗談」であることを示唆する要素を含めています。通知頻度はデフォルトで1時間に1回程度に抑制されていますが、環境や設定によっては異なる場合があります。ローカルにメッセージ履歴等は保存しません。

# 参考資料
本SkillはPythonの`random`と`time`、デスクトップ通知には`plyer`ライブラリを利用しています。詳細は`references/design_notes.md`および[plyer公式ドキュメント](https://plyer.readthedocs.io/en/latest/)を参照してください。
