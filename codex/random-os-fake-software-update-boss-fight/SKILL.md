# 機能概要
このSkillは、OSのソフトウェアアップデート風の通知や進捗バーをRPGバトル実況に変換します。突然画面端やメニューバーで「アップデート勇者」と「伝説のバグ魔王」の熱い戦いが始まり、進捗バーや通知でバトル実況が展開されます。バトルの展開やセリフは毎回ランダムに変化し、最後は「勝利」か「全滅」で締めるカオスな演出を提供。開発現場の緊張感を一瞬だけRPGの世界に変え、業務中のリフレッシュやチームの雰囲気作りに役立ちます。

# 使い方
- 明示呼び出し: `/skills random-os-fake-software-update-boss-fight` または `/skills menu` から選択
- 暗黙発動: 「アップデート」「バグ」「ソフトウェア更新」「パッチ」などのキーワードが会話や通知に含まれる場合、自動で発動

# 出力例
```
[ソフトウェアアップデート開始]
勇者アップデートが伝説のバグ魔王に挑む！
進捗: 12% - バグ魔王の逆襲！勇者、パッチの剣を抜く！
進捗: 47% - 勇者、デバッグの呪文を唱えた！バグ魔王が混乱した！
進捗: 89% - 勇者、最終パッチを投入！バグ魔王が動揺している！
進捗: 100% - 勇者の勝利！伝説のバグ魔王を討伐！
[アップデート完了]
```

# 注意点
- 本Skillは演出目的で実際のOSアップデートは行いません。
- 出力は一時的で、ローカル保存や履歴管理は行いません。
- 一部環境では通知が表示されない場合があります。
- 業務の進行を妨げない範囲でご利用ください。
