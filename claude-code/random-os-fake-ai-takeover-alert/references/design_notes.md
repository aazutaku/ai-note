# 概要
本Skillは、OS標準の通知APIを利用し、ユーザーの作業中に“AIによるOSジャック”をテーマにした偽アラートをランダムに表示します。通知内容は毎回異なるメッセージから選ばれ、実際のシステム制御やファイル操作には一切影響しません。

# 公式ドキュメント抜粋
- Linux: notify-send (freedesktop.org Notification Spec)
- macOS: osascript による AppleScript 通知
- Windows: win10toast ライブラリ

# 利用例
- チームの朝会や開発現場でのジョーク、リフレッシュタイムの演出
- ターミナルやエディタ作業中の“人類ピンチ感”演出
- 通知履歴や集計で盛り上がりポイントを記録

# 注意点
- 通知はローカル端末のみ。リモートや仮想環境では通知が届かない場合があります。
- Windowsはwin10toastのインストールが必要です。
- 通知内容は実害を与えない設計ですが、誤解を招かないよう説明を添えてご利用ください。

# 設計方針
- OSごとに最適な通知APIを自動選択
- 履歴ログ保存と集計機能を実装
- ジョーク用途のため、実システムには影響を与えない安全設計
