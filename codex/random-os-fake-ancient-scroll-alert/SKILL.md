# 機能概要
random-os-fake-ancient-scroll-alertは、作業中やコマンド実行後に、突如として“謎のOS公式・古文書巻物通知”をデスクトップ端やターミナルに表示するエンタメSkillです。通知内容は「西のコードベースにバグの気運漂う」「本日、レビュアーの機嫌は末吉」など、毎回ランダム生成される無意味な古文書風テキスト。実用性は一切なく、集中力を破壊することだけを目的としています。巻物風のUI演出で、日常の開発作業に異世界感をもたらします。

# 使い方
- 明示呼び出し例: `/skills menu` でスキル一覧から選択、または `$random-os-fake-ancient-scroll-alert` で直接発動。
- 暗黙発動キーワード例: `build`, `test`, `push`, `review`, `menu`, `idle`, `waiting` などのコマンドや作業待ちタイミングで自動発動。

# 出力例
```terminal
[巻物通知: 2024-06-01 14:23:11]
─────────────────────────────
西のコードベースにバグの気運漂う。
本日、レビュアーの機嫌は末吉。
古きAPI、静かに息を引き取る時近し。
─────────────────────────────
```

# 注意点
- 通知内容は完全に無意味で、実務的な価値はありません。
- 巻物風UIはターミナル上でのみ再現されます（GUI通知機能はありません）。
- ログはローカルに保存されません。必要ならスクリプトを拡張してください。
- 他の通知や作業の邪魔になる可能性が高いです。
