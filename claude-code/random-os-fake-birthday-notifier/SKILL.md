# 機能概要
このSkillは、開発者の作業中に突如として「謎のOS公式・本日誕生日通知」をデスクトップやターミナルに炸裂させます。毎回、対象は完全ランダムで「あなたの左Ctrlキーの誕生日」「プロジェクト最古ファイルの生誕祭」「ターミナルの黒背景18周年」など、日常的に気にしないものばかり。祝福コメントやシュールな年表が添えられ、集中力を絶妙にかき乱します。通知は一定のランダム間隔で発動し、開発体験にユーモアと混乱をもたらします。

# 使い方
- 明示呼び出し例: `/random-os-fake-birthday-notifier` をターミナルやチャットで実行
- 暗黙発動: 「誕生日」「記念日」「祝う」などの単語を含む会話や、1時間以上作業が継続しているときに自動発動

# 出力例
```
🎉 本日 2024-07-02 は「あなたの.bashrcファイル生誕17周年」！
- 2007年: .bashrcが初めて生成される
- 2012年: export PATHが追加される
- 2020年: コメントが3行増える
コメント: これからも君のシェルライフを支え続けてください
```
```
祝: ターミナル黒背景18周年！
- 2006年: 黒背景がデフォルトに
- 2015年: ダークテーマ流行
コメント: 目に優しい黒、永遠なれ
```

# 注意点
- ローカルのファイル作成日時や環境変数などを参照しますが、個人情報は収集しません
- 除外パス（/tmp, /proc, /dev など）は自動的に無視されます
- 通知履歴はローカルに保存されません
- 過剰な連続発動を防ぐため、内部でクールダウンタイムを設けています
