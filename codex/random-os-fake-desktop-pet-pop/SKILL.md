# 機能概要
このSkillは、日々の作業やコーディング中に突然“謎のOS公式デスクトップペット”がターミナルや通知領域に乱入する演出を提供します。ペットは毎回ランダムで登場し、「OS公式ペンギン」「バグを拾う犬」「やる気を吸い取る猫」など、意味不明な自己紹介やアクションを披露します。実際の作業には何の役にも立ちませんが、単調な作業に一瞬の非日常体験をもたらし、癒しや笑いを提供します。

# 使い方
- 明示呼び出し: `/skills menu` から `random-os-fake-desktop-pet-pop` を選択、または `$random-os-fake-desktop-pet-pop` を直接メンション。
- 暗黙発動: 'ペット', '癒し', '通知', '集中妨害', '遊び心' などのキーワードを含む会話やコマンド実行時に自動発動。

# 出力例
```
[🐧 OS公式ペンギン] こんにちは！今日もバグを凍らせに来ました。
[🐶 バグを拾う犬] 進捗バーの下に何か落ちてない？ワン！
[🐱 やる気を吸い取る猫] ふぁ〜…やる気、いただきます。
[🐦 謎の鳥] ピヨピヨ…（通知ウィンドウを横切る）
[🐢 ゆっくりカメ] 進捗は急がなくてもいいんだよ…
```

# 注意点
- 本Skillは実用性ゼロのエンタメ用途です。実際の作業やファイルには影響しません。
- 出現頻度は自動制御され、過度な妨害は行いません。
- ローカルに画像や履歴は保存しません。
- 一部端末や通知環境によっては演出が表示されない場合があります。
