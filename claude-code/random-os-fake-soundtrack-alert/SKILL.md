# 機能概要
このSkillは、作業中やコマンド実行時に“謎のOS公式サウンドトラック通知”をデスクトップに表示します。通知内容は毎回異なり、「本日のテーマソング：『バグ修羅場行進曲』」「今こそ流せ！『納期デッドヒート』」など、完全オリジナルの曲名や開発現場ネタがランダムで生成されます。実際に音楽は流れませんが、作業の緊張感や沈黙をシュールに打ち破る、カオスなジョーク通知を提供します。

# 使い方
- 明示呼び出し: `/random-os-fake-soundtrack-alert` を実行すると即座に通知が表示されます。
- 暗黙発動: 「作業開始」「ビルド」「テスト」「コミット」などのキーワードや、コマンド実行時に自動で発動します。

# 出力例
```
[通知] 本日のテーマソング：『バグ修羅場行進曲』
[通知] 今こそ流せ！『納期デッドヒート』
[通知] 推奨BGM：『仕様書迷宮のワルツ』
[通知] 公式サウンド：『デバッグ無限ループ』
[通知] システム推奨BGM：『コミット前夜のバラード』
```

# 注意点
- 通知内容は毎回異なりますが、同じセッション内で重複する場合があります。
- 本Skillは実際に音楽やBGMを再生しません。通知のみが表示されます。
- 通知の頻度は自動制御され、作業の邪魔になりすぎない設計です。
- ローカルに通知履歴や曲名リストは保存されません。
