# 概要
このSkillは、ユーザーの作業中に完全なフェイク警告を理不尽なタイミングで表示し、作業空間にユーモアと意図的なカオスをもたらすために設計されています。通知内容は毎回ランダムで、実際の健康状態やシステム状態とは一切関係ありません。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonの`plyer`ライブラリを利用しています（https://pypi.org/project/plyer/）。ターミナル出力は標準出力を使用し、OS依存の演出はありません。

# 利用例
- 長時間のコーディングや集中作業時に、突然フェイクな警告で場を和ませる。
- チームのリモートワーク中に、SlackやTeamsのbot連携でジョーク通知として利用。

# 注意点
本Skillはジョーク目的であり、通知内容の信憑性はゼロです。ログはユーザーのホームディレクトリにのみ保存され、他のシステム設定やファイルには一切影響を与えません。

# 設計方針
- OSやターミナル環境に依存しない安全な演出のみを採用
- 通知内容は完全に架空で、健康やシステムに害を与えない
- ログ出力/集計機能でユーザーの反応を振り返ることも可能
