# 機能概要
このSkillは、あなたの作業中に突然“謎のOS公式デスクトップペット”がターミナルや通知領域に現れ、意味不明な自己紹介や行動を披露して去ります。ペットは「OS公式ペンギン」「バグを拾う犬」「やる気を吸い取る猫」など毎回ランダムで、進捗バーや通知を横切ったり、無意味なメッセージを残します。実害はなく、作業の流れを壊しすぎない頻度で、非日常の癒しやリフレッシュを提供します。

# 使い方
- 明示呼び出し: `/random-os-fake-desktop-pet-pop` をターミナルやチャットで入力
- 暗黙発動: 「通知」「癒し」「集中力リセット」「作業妨害」などのキーワードや、長時間無操作時に自動で発動

# 出力例
```
[🐧 OS公式ペンギン] こんにちは。私はOSの守護神ペンギンです。進捗バーを横切ります。
[🐶 バグを拾う犬] ワン！ワン！バグを1個拾いました。気にしないでください。
[😺 やる気を吸い取る猫] ふぁ〜…やる気、吸い取っておきました。
[🐢 遅延タートル] 進捗が遅いですね。私のせいじゃありません。
[🦉 深夜フクロウ] もう夜ですよ。そろそろ休みませんか？
```

# 注意点
- 本Skillは視覚的な演出のみで、ファイルやシステムには一切影響しません。
- ローカル保存や履歴の記録は行いません。
- 実際のデスクトップ上にウィンドウを表示する機能はありません（ターミナル/通知領域のみ）。
- 頻度は自動調整され、過度な妨害は発生しません。
