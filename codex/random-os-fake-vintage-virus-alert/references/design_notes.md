# 概要
このSkillは、実際のウイルス検知や駆除を行うものではなく、完全なジョーク・演出目的で設計されています。作業中の気分転換やチーム内のちょっとした話題作りに最適です。

# 公式ドキュメント抜粋
- Python標準ライブラリ `random` により毎回異なる警告文を生成。
- 通知にはOS標準の `notify-send` (Linux), `osascript` (macOS), `win10toast` (Windows) を利用。

# 利用例
- チームの朝会やペアプロ時に `/skills random-os-fake-vintage-virus-alert` で発動し、場を和ませる
- 「ウイルス」「警告」などの単語が会話に登場した際の自動発火

# 注意点
- 実際のファイルやシステムには一切影響を与えません
- 通知内容は完全にフィクションです
- Windowsでデスクトップ通知を利用する場合は `win10toast` パッケージが必要です（未インストール時はターミナル出力のみ）

# 設計方針
- 依存を最小限に抑え、環境構築不要・即動作を重視
- 通知頻度・内容ともに作業を妨げすぎないバランス設計
- 拡張性を考慮し、通知テンプレートやウイルス名リストを随時追加可能
