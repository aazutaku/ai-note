# 機能概要
このSkillは、作業中のPCやターミナルに「低重力モード突入」などの架空OS通知をランダムに表示します。通知内容は毎回異なり、「本日このPCは低重力環境に切り替わりました」「ファイルのドラッグ操作が普段の3倍遠く飛びます」など、ユーモラスかつ非日常的な演出を提供。仕事や学習の緊張感を一瞬でリセットし、思考をリフレッシュする効果があります。OSやファイル等の実データには一切影響しません。

# 使い方
このSkillは明示的なコマンド呼び出しは不要です。'gravity', 'low', 'alert', 'notification', '宇宙', '浮遊', '重力'などの単語や、一定時間無操作が続いた際などに自動で発動します。ターミナルまたはデスクトップ通知として表示されます。

# 出力例
```
[Low Gravity Alert]
警告：本日このPCは低重力環境に切り替わりました。
ファイルのドラッグ操作が普段の3倍遠く飛びます。
コードのバグがふわふわ浮遊中。
重力センサー異常を検知しました。
宇宙遊泳モードを有効化します。
```

# 注意点
- 本Skillは通知の演出のみで、システムやファイル操作には一切影響しません。
- 通知頻度は自動制御され、作業の妨げにならないよう配慮されています。
- ローカルに通知履歴を残すことはありません。
- 一部環境ではデスクトップ通知が表示されない場合があります。
