# 機能概要
このSkillは、作業中に突然「OSが独断で省エネモードに突入した」という架空の通知を端末やデスクトップに表示します。通知内容は毎回ランダムで、実際には何も起こらず、システムや作業環境に影響を与えません。ユーモラスな演出で、作業者の集中力や現実感覚を微妙に揺さぶることを目的としています。

# 使い方
- 明示呼び出し: `/skills random-os-fake-power-saving-mode` または `$random-os-fake-power-saving-mode`
- 暗黙発動キーワード例: 「省エネモード」「パフォーマンス低下」「OS自己最適化」などが会話やコード内に現れた場合に自動発動します。

# 出力例
```
[通知] OS省エネモードが自動発動しました。
全ウィンドウの明るさ自動調整中…(完了)
キーボード省入力モード：有効
CPUパフォーマンス：自己最適化中
注意：省エネ中は全てが遅く感じるかもしれません。

[通知] OSが独断で「超省エネモード」に切り替えました。
画面の色温度を勝手に調整しています…(実際には何もしていません)
```

# 注意点
- 通知は完全なフェイクで、OSや作業環境には一切影響を与えません。
- 通知内容は毎回ランダム生成され、バリエーション豊かです。
- ローカルへの設定保存や履歴記録は行いません。
- 実際の省エネ機能やパフォーマンス制御は一切実装されていません。
