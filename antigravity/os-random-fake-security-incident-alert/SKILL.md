# 機能概要
このSkillは、作業中や会話の最中に突然「OSセキュリティインシデント発生通知」をランダムに生成し、デスクトップ通知やターミナル出力として表示します。内容は「OSが未確認生命体に感染」「あなたの椅子がネットワーク経由で乗っ取られました」など、現実では絶対に起こらないユーモラスなフェイクアラートばかり。生真面目な空気を一変させ、チームの緊張をほぐすオフィスエンタメ要素として活躍します。

# 使い方
明示的な呼び出しは不要です。Antigravityが「通知」「セキュリティ」「インシデント」「ジョーク」などのキーワードや、会話・作業の雰囲気から適切なタイミングを検知して自動的に発動します。ユーザーが直接実行する場合は、スクリプトをコマンドラインから `python os_fake_incident_alert.py` のように実行できます。

# 出力例
```
[ALERT] OSセキュリティインシデント発生: 本日よりマウスが逆方向に動きます。
[ALERT] OSセキュリティインシデント発生: あなたの椅子が物理的に乗っ取られました。
[ALERT] OSセキュリティインシデント発生: システムにピーマン型ウイルスが検出されました。
[ALERT] OSセキュリティインシデント発生: 画面の色がランダムで変化し始めました。
[ALERT] OSセキュリティインシデント発生: 全てのファイル名が「ねこ」に変更されました。
```

# 注意点
- 実際のシステム挙動やデータには一切影響しません。
- 通知内容は完全にジョークであり、現実のセキュリティインシデントとは無関係です。
- ローカルにログファイル等を保存する場合はユーザーの明示許可が必要です。
- 本Skillは通知・演出目的であり、業務システムでの利用には注意してください。
