# 機能概要
このSkillは、作業中やCLIコマンドの実行時に、現実には絶対に体験したくない“謎のOS人事研修強制参加通知”を、デスクトップ通知やターミナル出力として唐突に表示します。通知内容は毎回ランダム生成され、「緊急：本日14時より“謎のパワポ芸入門”研修必須」「重要：OS公式“無限ビデオ視聴”研修が始まります」など、カオスで笑える人事イベントを演出。現実逃避とユーモアを同時に提供し、作業の合間にちょっとした息抜きをもたらします。

# 使い方
- 明示呼び出し例:
  - `/skills menu` から `random-os-fake-hr-training-alert` を選択
  - `$random-os-fake-hr-training-alert` をターミナルで実行
- 暗黙発動キーワード例:
  - 「研修」「人事」「通知」「アラート」などの語を含むコマンドや会話
- 実行すると、OSの通知APIまたはターミナルにランダムな“人事研修通知”が即時表示されます。

# 出力例
```
[ALERT] 緊急：本日14:00より「謎のパワポ芸入門」研修が強制開催されます。
[NOTICE] 重要：OS公式「無限ビデオ視聴」研修が今すぐ開始されます。
[WARNING] ただ今より「謎マナー講座」への参加が必須です。
[INFO] 新着：本日17:30より「謎のリモート背景選手権」研修が始まります。
[ALERT] 参加必須：OS人事部主催「無限フィードバック地獄」研修が開幕！
```

# 注意点
- 実データやファイルには一切影響を与えません。
- 通知は一時的な表示のみで、履歴や記録は残りません。
- OSの通知APIやターミナル出力のみを利用し、ローカル保存や権限変更は行いません。
- 通知内容は完全なフィクションです。
