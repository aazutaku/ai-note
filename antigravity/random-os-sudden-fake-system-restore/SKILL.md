# 機能概要
このSkillは、作業や議論が盛り上がっている最中に、突如として“謎のOSシステム復元進捗ウィンドウ”を模した演出を画面端やメニューバー風に表示します。進捗バーやメッセージは完全ランダムで、「謎の変更を元に戻しています」「OSの気分調整中」など、思わずツッコミたくなるテキストが並びます。進捗率も毎回異なり、リアルなフェイク感を演出。復元が完了しても何も起こらず、作業の空気を一瞬でカオスに変える遊び心満載のSkillです。

# 使い方
このSkillは明示的な呼び出しは不要です。会話や作業ログ内で「システム復元」「OSトラブル」「進捗バー」「リカバリ」「復元ポイント」などのキーワードや、進捗・復旧・異常に関する文脈が出現すると自動的に発動します。

**暗黙発動キーワード例:**
- 「システム復元が必要かも」
- 「OSが不安定」
- 「進捗バーが出てきた」
- 「復元ポイントを作成」

# 出力例
```
[OS System Restore]
進捗: 42% | 状態: 謎の変更を元に戻しています...
進捗: 67% | 状態: OSの気分調整中...
進捗: 13% | 状態: 予期せぬファイルを復元中...
進捗: 89% | 状態: システムのやる気を回復中...
進捗: 100% | 状態: 復元が完了しました（何も変わりません）
```

# 注意点
- 本Skillは純粋な演出目的であり、実際のシステムやファイルには一切影響しません。
- ローカル環境への保存や実際の復元処理は行いません。
- 除外パス: システム管理や本番運用環境では自動発動しません。
