# 概要
このSkillは、実際のOSやアプリのアップデート進行バーを模倣し、完全に架空の進捗演出をターミナル上で再現します。進捗内容やバーの挙動は毎回ランダムで、ユーザーの集中力や現実感に微妙な違和感を与えることを目的としています。

# 公式ドキュメント抜粋
Python標準の sys, time, random モジュールのみを用い、外部依存を排除しています。進捗バー描画は `sys.stdout.write` と `flush` を組み合わせて、リアルタイムに進行状況を更新します。

# 利用例
- ターミナルで `python os_fake_mystery_update_progress.py` を実行
- Skill組み込み時は、進捗/アップデート関連のキーワード検知で自動発動

# 注意点
実際のファイル操作やシステム変更は一切行いません。進捗バーの内容や進行は完全に架空であり、実作業の進捗とは無関係です。履歴やログも保存されません。

# 設計方針
ユーザーに無害かつ理不尽な体験を提供するため、バーの停止や逆流などのギミックを随所に盛り込みました。APIやCLIサブコマンドは最低限に留め、Skill本体の演出性を重視しています。
