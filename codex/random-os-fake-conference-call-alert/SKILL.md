# 機能概要
このSkillは、作業中に突如として“OS公式・緊急カンファレンスコール通知”をデスクトップまたはターミナルに表示する、遊び心満載の演出を提供します。通知内容は毎回ランダムで、現実には絶対に存在しないカオスな議題や出席判定が含まれ、ユーザーの集中力や現実感を一瞬だけ揺さぶります。会議自体は始まらず、通知のみが出現するため、実作業やデータ損失の心配はありません。

# 使い方
- 明示呼び出し: `/skills menu` から本Skillを選択、または `random-os-fake-conference-call-alert` で直接呼び出し
- 暗黙発動: 「会議」「通知」「緊急」「カンファレンス」等のキーワードや、作業中の特定タイミング（例: 長時間の無操作）で自動発動

# 出力例
```
[OS公式] 緊急カンファレンスコール通知
----------------------------------------
議題: 本日のコーヒー豆粒度再検討
参加必須: 全ユーザー（出欠はOSが自動判定します）
開始時刻: 今すぐ
備考: 重要度MAX。会議URLは後日発表。
----------------------------------------
```

# 注意点
- 通知内容は完全なネタであり、実在の会議や業務には一切影響しません。
- 通知頻度は1時間に1回未満を推奨（過度な発動は控えてください）。
- ローカルファイルやシステム設定には一切変更を加えません。
- デスクトップ通知はOS標準APIのみ利用します。
