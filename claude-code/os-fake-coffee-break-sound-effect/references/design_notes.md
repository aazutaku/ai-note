# 概要
このSkillは、開発現場に“謎のコーヒーブレイク”演出を強制的に挿入することで、作業リズムにユーモアとリフレッシュ効果をもたらすことを目的としています。通知文もサウンドも完全ランダムで、毎回異なる演出を楽しめます。

# 公式ドキュメント抜粋
- [playsound](https://github.com/TaylorSMarks/playsound): クロスプラットフォームな音声再生API。
- [plyer.notification](https://plyer.readthedocs.io/en/latest/): PythonからOSネイティブ通知を送信可能。

# 利用例
- 長時間のコーディング時に、定期的に強制休憩を促す。
- チームでのペアプロやハッカソンの雰囲気作り。
- テスト・ビルド完了後の演出として自動発動。

# 注意点
- サウンドファイルは `sounds/` ディレクトリに配置が必要。
- 通知機能は一部Linux環境やWSLでは動作しない場合があります。
- 音量調整や通知のカスタマイズは現状未対応です。

# 設計方針
- サウンド・通知ともにPython標準APIで最大限クロスプラットフォーム化。
- 拡張性を重視し、サウンドや通知文の追加が容易な構成。
- 明示/暗黙発動の両対応で、柔軟な組み込みが可能。
