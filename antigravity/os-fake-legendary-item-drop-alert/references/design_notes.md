# 概要
このSkillは、作業中のユーザーに「伝説のアイテムドロップ通知」をランダムに表示し、遊び心と気分転換を提供します。通知内容は完全に架空で、実用性はありませんが、集中力の維持やリラックス効果を狙っています。

# 公式ドキュメント抜粋
- Python random: https://docs.python.org/ja/3/library/random.html
- plyer通知API: https://plyer.readthedocs.io/en/latest/

# 利用例
長時間コーディングや単調な作業中に、突如「謎のUSBメモリ（未鑑定）」などの通知が表示され、ユーザーの気分転換や会話のネタになります。通知はコマンドラインまたはデスクトップで表示されます。

# 注意点
- 実際のファイルやOS設定には一切影響を与えません。
- 通知履歴はメモリ上のみで、永続保存は行いません。
- 頻度が高すぎると逆効果なので、20〜50秒のランダム間隔を推奨。

# 設計方針
実在APIのみを利用し、追加権限や外部サービス不要。通知内容は毎回カオスで笑えるものになるよう工夫しています。
