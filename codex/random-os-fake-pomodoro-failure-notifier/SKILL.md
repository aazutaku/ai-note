# 機能概要
このSkillは、あなたがポモドーロタイマーを開始・終了した際に、実用性ゼロの“フェイク失敗通知”をデスクトップやターミナルに表示します。通知内容は毎回ランダムで、トマトやピザ、鍋などのネタを交えた意味不明なメッセージばかり。まじめな作業の合間にエンタメ要素を加え、集中しすぎて疲れることを防ぐ狙いも。OSの通知APIを利用し、クロスプラットフォームで動作します。

# 使い方
- 明示呼び出し例: `/skills menu` から本Skillを選択、または `$random-os-fake-pomodoro-failure-notifier` をmention。
- 暗黙発動キーワード例: 「ポモドーロ開始」「集中タイマー」「作業を始める」「25分セット」「休憩タイム」などの会話に反応。

# 出力例
```
[通知] 失敗：トマトが爆発しました。作業時間は跡形もありません。
[通知] 警告：集中力が鍋底にこびりつきました。スクレーパー推奨。
[通知] 注意：タイマーがピザに変身したため無効です。
[通知] エラー：ポモドーロがケチャップになりました。再起動してください。
[通知] 失敗：休憩時間がトマトソースに吸収されました。
```

# 注意点
- 実際のタイマー管理や進捗記録機能はありません。
- 通知はローカル端末のOS通知APIまたはターミナル出力でのみ表示され、データ保存や外部送信はありません。
- 10分程度で環境構築・動作可能。Python3とnotify-send(macOSはosascript)が必要です。
- ふざけた通知のみで、実用的なリマインダーや記録には使えません。
