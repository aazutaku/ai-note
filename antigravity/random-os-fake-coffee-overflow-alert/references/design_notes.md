# 概要
このSkillは、作業中のユーザーに対して架空の“コーヒーあふれ”警告をデスクトップ通知として発火し、作業空間にユーモアをもたらすことを目的としています。通知内容は毎回ランダム生成され、実用的な警告と見せかけて完全なネタである点が特徴です。

# 公式ドキュメント抜粋
通知にはPython用クロスプラットフォーム通知ライブラリ plyer (https://pypi.org/project/plyer/) を利用しています。plyerはWindows, macOS, Linuxで動作し、追加ソフト不要でシンプルなAPIを提供します。

# 利用例
- 深夜の集中作業時に突然通知が表示され、気分転換やチーム内の話題作りに活用できます。
- コーヒーやカフェインに関するジョークが好きな開発者向けの遊び心ある演出としても有用です。

# 注意点
- 通知は実際のシステムや健康状態とは無関係です。
- plyerの通知機能はOS環境やデスクトップ環境によって挙動が異なる場合があります。

# 設計方針
Skill本体は単一スクリプトで完結し、履歴管理やサマリー表示などのCLIサブコマンドも提供しています。AIエージェントからの自動発火を前提に、ユーザー操作なしで自然にジョーク通知が届く体験を重視しています。
