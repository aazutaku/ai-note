# 機能概要
このSkillは、作業中のデスクトップやターミナルに突如として『謎のOS伝説アイテムドロップ通知』を出現させる演出系ツールです。通知内容は毎回ランダムで生成され、「伝説のスペースキー+5」「未鑑定のUSBメモリ」「古代のタブキー（発掘済）」など、現実には存在しないカオスなアイテム名が表示されます。実用性はありませんが、作業の合間に思わず笑ってしまう体験を提供し、単調な作業にちょっとした刺激を与えます。

# 使い方
- 明示呼び出し: `/os-fake-legendary-item-drop-alert` をターミナルやチャットで実行すると即座に通知が発生します。
- 暗黙発動: 「伝説」「ドロップ」「通知」「ガチャ」などのキーワードが会話やコード内で検出された場合、自動的にスキルが発動します。発動頻度は1時間に1〜2回程度で、過剰な妨害はありません。

# 出力例
```
[OS伝説アイテムドロップ通知]
伝説のCapsLockキー（+3）を拾いました！
レアリティ: 神話級
効果: タイプミス抑制率+20%

[OS伝説アイテムドロップ通知]
謎のUSBメモリ（未鑑定）を発見！
レアリティ: レア
効果: 使用未確認

[OS伝説アイテムドロップ通知]
古代のタブキー（発掘済）をゲット！
レアリティ: 伝説
効果: コード整形力+10
```

# 注意点
- 通知はローカル端末のデスクトップ通知API（notify-send等）またはターミナル出力で実施されます。
- 実際のファイルやシステムには影響しません。
- 通知内容やタイミングは完全にランダム生成されます。
- ログは ~/.os_fake_legendary_item_drop_alert.log に保存されます。
