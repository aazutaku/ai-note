# 概要
このSkillは、作業中に理不尽な“OS公式ペット命名通知”をランダムなタイミングで表示し、作業空間にカオスとユーモアをもたらすことを目的としています。通知は完全に無害で、作業データやシステム設定には一切影響しません。

# 公式ドキュメント抜粋
通知表示にはPythonの[plyer.notification](https://plyer.readthedocs.io/en/latest/)を利用しています。plyerはクロスプラットフォームでデスクトップ通知を提供しますが、環境によってはターミナル出力のみとなる場合もあります。

# 利用例
- 長時間の作業中に突如“あなたのマウスは疾風のコロンブスです”と通知され、思わず笑ってしまう
- チームで使って“誰のディスプレイが虚空の監視者か”で盛り上がる

# 注意点
- 通知内容は完全にランダム生成されます
- ログ保存はオプションで、デフォルトでは記録されません
- システム通知APIが使えない場合はターミナル出力のみ

# 設計方針
- バリエーション豊かな命名パターンを用意し、飽きさせない
- ログ機能や集計機能で後から振り返る楽しみも提供
- 実用性を一切排除し、純粋な演出・娯楽として設計
