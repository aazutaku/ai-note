# 機能概要
random-os-fake-horoscope-notifierは、開発作業を始めるタイミングで“謎のOS星占い”通知を自動表示するSkillです。内容は完全ランダムで「今日のラッキーコマンドはls」「運勢：バグ回避率上昇」「注意：仕様変更星が逆行中」など、根拠のない占い風アドバイスを提供します。作業開始時の緊張やマンネリを和らげ、ユーモアある開発スタートを演出します。通知は1日1回のみ表示されるため、頻繁な邪魔にはなりません。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「start」「begin」「open project」「code」「新規作業」などの作業開始キーワードを検出した際、自動的に発動します。ターミナル・デスクトップ通知の両方に対応しており、どちらの環境でも分かりやすく表示されます。

# 出力例
```
[OS Horoscope] 今日の運勢: コードレビュー運が最高潮！
ラッキーコマンド: git diff
注意: 仕様変更星が逆行中。設計書の再確認を忘れずに。
---
[OS Horoscope] 幸運の兆し: バグ回避率が20%上昇中。
ラッキーエディタ: vim
アドバイス: コミット前に深呼吸。
```

# 注意点
- 1日1回のみ通知されます（~/.os_horoscope_notifiedで管理）
- 通知内容は完全にランダムで、実際の運勢や作業内容とは無関係です
- ローカル環境の通知API（notify-send, osascript, Windows toast）を利用します
- 通知が失敗した場合はターミナル出力のみ行われます
- 設定や履歴保存はありません
