# 概要
本Skillは、現実には絶対起きないフェイクOSインシデント通知をランダムに生成し、オフィスやオンライン会議の雰囲気を和らげるエンタメ用途に特化しています。通知はターミナル出力・デスクトップ通知の両方に対応。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonのplyerライブラリを利用。plyerはクロスプラットフォームでOS標準の通知APIを呼び出します。

# 利用例
- チームの朝会や雑談タイムに自動発火させて笑いを誘う
- コマンドラインから `python os_fake_incident_alert.py --interval 300 --desktop` で5分ごとにジョーク通知
- ログ・集計機能で「どんなインシデントが多かったか」を振り返る

# 注意点
- 実際のシステムやファイルには影響しません
- plyer未インストール時はターミナル通知のみ
- ログはユーザーディレクトリ直下に保存

# 設計方針
実在APIのみを用い、CLIからも手軽に試せる設計。通知内容は現実離れしたジョークのみとし、誤解や混乱を避ける工夫を徹底しています。
