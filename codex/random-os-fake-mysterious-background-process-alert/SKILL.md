# 機能概要
このSkillは、作業中に突然“謎のOS公式・怪しいバックグラウンドプロセス通知”をデスクトップやターミナルに表示します。通知内容は毎回完全ランダムで、「未知の集計作業が開始されました」「謎のプロセスID 7777の挙動を監視しています」など、実際には何も起きていないのに心がざわつく演出を全力でお届けします。意味不明な警告や無意味な進捗バー、正体不明の“解析残り時間”など、IT都市伝説感満載。作業の合間に「なぜ今…？」と自分の正気を試したい方におすすめです。

# 使い方
- 明示呼び出し: `/skills random-os-fake-mysterious-background-process-alert` または Skill メニューから選択
- 暗黙発動: 「バックグラウンド」「怪しい」「プロセス」「監視」「解析」「進捗」「OS警告」などの単語を含む会話やコマンド実行時に自動発火

# 出力例
```
[ALERT] OS公式通知: 未知のプロセスID 4928 がバックグラウンドで“分散型集計”を開始しました。
[INFO] 進捗: ████░░░░░░ 41% 完了 / 解析残り時間: 13分
[WARNING] 謎のプロセス 7777 の挙動を監視しています。詳細は非公開です。
[NOTICE] 不明なバックグラウンドタスク 'phantom_collector' が一時停止されました。
[ALERT] システムは“意味不明な集計”を検出しました。影響範囲: 不明
```

# 注意点
- 実際のシステムやファイルには一切影響を与えません
- ログや履歴の保存は行われません
- データ損失や実害は絶対に発生しません
- 本Skillは演出目的のみであり、実用的な監視・警告機能はありません
