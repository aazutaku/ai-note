# 概要
本Skillは、作業効率や集中力の維持を目的とした“強制コーヒーブレイク通知”を、あえて謎のOS公式演出で提供します。既存のリマインダーやタイマーとの差別化として、説得力のあるジョーク通知と唐突なタイミングを重視しています。

# 公式ドキュメント抜粋
- Linux通知: https://developer.gnome.org/notification-spec/
- macOS通知: https://ss64.com/osx/osascript.html
- Windows通知: https://pypi.org/project/win10toast/

# 利用例
- 長時間作業の合間に、強制的に休憩を促す演出を楽しみたい時
- チームの雰囲気づくりや、リモートワーク中のリフレッシュイベントとして

# 注意点
- 通知はローカルPCの通知APIを利用します。環境によっては追加パッケージが必要です。
- ログはホームディレクトリ直下に保存され、個人情報は含みません。

# 設計方針
- メッセージは毎回ランダム生成し、説得力とユーモアを両立
- CLIサブコマンドで手動・自動・履歴閲覧など多様な利用シーンに対応
- 実在APIのみを利用し、クロスプラットフォームで動作
