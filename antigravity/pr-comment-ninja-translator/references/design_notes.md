# 概要
このSkillは、Pull Requestのコメントを忍者口調に自動変換し、開発現場にユーモアとエンターテイメント性を加えることを目的としています。単純な単語置換だけでなく、prefixやsuffix、表現の工夫により自然な忍者風の文章を生成します。

# 公式ドキュメント抜粋
本SkillはAntigravityのsemantic-match-onlyトリガーにより、PRコメント投稿・編集時に自動発動します。明示的な呼び出しや追加設定は不要です。

# 利用例
- チームのアイスブレイクや、レビューの雰囲気を和らげたい場面
- PRコメントの自動変換で、開発者同士のコミュニケーションを活性化

# 注意点
- 技術的な正確さや公式な議論には不向きです
- 原文の意味が大きく損なわれないよう設計していますが、100%保証はできません
- 除外パスや特定ワードの検知で適用を制限する場合があります

# 設計方針
- 単語変換・prefix/suffix追加・文末調整の3段階で自然な忍者口調に変換
- スクリプトはPythonで実装し、CLIからもテスト可能
- ローカル保存や履歴管理は行わず、PRコメント変換のみに特化
