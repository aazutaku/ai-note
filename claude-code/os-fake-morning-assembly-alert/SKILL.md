# 機能概要
このSkillは、ターミナルやエディタを朝イチで開いた瞬間や「朝礼」「スローガン」などの関連ワードを検知した際、OS風の“謎朝礼通知”をデスクトップや画面端に表示します。通知内容は「本日のスローガン」「点呼開始」「OS公式体操」など毎回ランダムで、作業開始時に非日常感を演出。通知後は「本日の作業目標」も自動で宣言され、開発者の集中力を一瞬でリセットします。既存ファイルや作業内容には一切影響しません。

# 使い方
- 明示呼び出し: `/os-fake-morning-assembly-alert` を実行
- 暗黙発動: 「朝礼」「点呼」「スローガン」「体操」などのキーワードを含む発話や初回起動時
- スクリプトは自動で一度だけ通知を表示します（再実行で再度通知）

# 出力例
```
[OS朝礼通知] 2024-07-01 09:01
本日のスローガン: 「エラーは友達、焦らず冷静に！」
点呼開始: 1番から順に返事してください。
OS公式体操のご案内: 5分間ストレッチ推奨
本日の作業目標: 「バグゼロでリリース！」
```

# 注意点
- 通知は初回起動時のみ自動表示されます（明示呼び出しで再表示可）
- ファイルや作業内容には影響しません
- 通知はローカル環境のみに表示され、履歴は保存されません
- Windows/macOS/Linuxで動作（Python標準＋通知API使用）
