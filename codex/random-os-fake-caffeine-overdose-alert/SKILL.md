# 機能概要
このSkillは、作業に没頭しているユーザーのデスクトップやターミナルに、完全に架空の「OSカフェイン過剰摂取警告」を突然表示します。通知内容は毎回ランダムで、例えば「重大：あなたのカフェイン血中濃度が“徹夜エンジニア”レベルに到達」「警告：コーヒーカップが自動でリフィルされました」「OSより：今すぐ水分を摂取してください」など、全く根拠のないフェイク警告が炸裂します。真面目に集中している人ほど不意を突かれ、作業空間に一瞬のカオスと笑いを生みます。

# 使い方
明示的な呼び出しは `/skills menu` から「random-os-fake-caffeine-overdose-alert」を選択、または `$random-os-fake-caffeine-overdose-alert` と入力してください。暗黙的には「徹夜」「集中」「カフェイン」「眠気」「コーヒー」などのキーワードが会話や作業ログに現れた際、自動でランダムなタイミングで発動します。

# 出力例
```
[ALERT] OSより警告: あなたのカフェイン血中濃度が“徹夜エンジニア”レベルに到達しました。
[WARNING] コーヒーカップが自動でリフィルされました。OSはあなたの健康を心配しています。
[CRITICAL] 今すぐ水分を摂取してください。カフェイン摂取量が推奨上限を超えています。
[INFO] システム: あなたのマグカップが空になることはありません。
[NOTICE] OS診断: 睡眠推奨。カフェイン依存度: 99.9%
```

# 注意点
本Skillは完全なジョーク機能であり、実際の健康状態やシステム状態とは一切関係ありません。通知は一時的に表示され、ファイルやログへの保存は行いません。どのOSやターミナル環境でも害のない演出のみを行いますが、通知ポップアップは環境によって表示方法が異なる場合があります。
