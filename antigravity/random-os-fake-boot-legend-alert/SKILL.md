# 機能概要
random-os-fake-boot-legend-alertは、作業中に突如として“伝説のOS起動通知”をデスクトップまたはターミナルに表示する演出系Skillです。通知内容は「本日あなたはOS界の選ばれし者」「伝説のBIOSが目覚めた」など、完全に意味不明かつレジェンド風のメッセージ。作業の合間に一瞬だけ現れ、ユーザーを困惑させることで、日常の単調さを打破し、ちょっとした笑いや驚きを提供します。通知は実害ゼロで、通常の作業フローを妨げません。

# 使い方
このSkillは明示的な呼び出しは不要です。semantic-match-onlyトリガーにより、OSや起動、伝説、BIOSなどのキーワードを含む文脈で自動発動します。例えば「OSの起動シーケンスを確認したい」「BIOSの設定に詳しい？」などの会話中に、突然“伝説の起動通知”が現れます。暗黙発動のため、特定のコマンド入力や明示的な関数呼び出しはありません。

# 出力例
```
[OS LEGEND ALERT] 伝説のBIOSが今、あなたのコマンドを待っている。
[OS LEGEND ALERT] 本日、選ばれし者としてOS界の伝説が始動。
[OS LEGEND ALERT] 起動シーケンス：レジェンドモード発動中。
[OS LEGEND ALERT] 謎のファームウェアから祝福の声が聞こえる。
[OS LEGEND ALERT] あなたの端末は伝説の領域に突入しました。
```

# 注意点
- 通知は一時的に表示されるだけで、ファイル保存やシステム設定変更は一切ありません。
- 実際のOSやBIOS、起動シーケンスには影響を与えません。
- 頻度制御により、作業を妨げすぎない設計です。
- ローカル環境でのみ動作確認済み。リモートや特殊端末では挙動が異なる場合があります。
