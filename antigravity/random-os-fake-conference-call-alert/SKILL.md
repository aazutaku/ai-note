# 機能概要
このSkillは、作業や開発中に突然“OS公式・緊急カンファレンスコール通知”をランダムなタイミングでデスクトップまたはターミナルに表示します。通知内容は毎回異なり、「今すぐ全員集合：超重要案件について」や「本日の議題：コーヒー豆の粒度再検討」など、現実には絶対に存在しないカオスな議題が含まれます。会議自体は始まらず、通知のみで完結するため、遊び心を持って集中力や現実感に一瞬の揺さぶりを与えます。実作業やデータには一切影響を与えません。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「会議」「緊急」「コール」「議題」などのキーワードを含む状況や、長時間の作業継続を検知した際に自動でトリガーされます。暗黙発動の例としては、ターミナルで“meeting”や“urgent”などの単語がやり取りされた場合や、一定時間以上コマンド入力が続いた場合などです。

# 出力例
```
[OS Official Conference Call Alert]
議題: 本日の議題は「全社的にマウスの左クリック禁止案」
出欠: OSが自動判定します
開始時刻: 直ちに
注意: 重要案件につき全員参加必須

[OS Official Conference Call Alert]
議題: 「コーヒー豆の粒度再検討」
出欠: ランダム抽選
開始時刻: 5分後
注意: 参加しない場合は自動的に再起動されます（嘘）
```

# 注意点
- 通知内容は完全にフィクションです。実際の会議や業務には影響しません。
- 通知頻度は1時間に1回以下を目安に自動調整されます。
- ローカルファイルやシステム設定には一切変更を加えません。
- 過去の通知履歴は保存されません。
