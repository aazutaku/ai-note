# 機能概要
このSkillは、ユーザーが作業に没頭している最中や、OSやメモリに関する話題が出た際に、まるで本物のシステム警告のような『フェイク・メモリリークアラート』をデスクトップ通知として表示します。通知内容は毎回ランダムに生成され、深刻そうな警告からユーモラスな文言まで幅広く、作業中のちょっとした息抜きや驚きを演出します。実際のシステムやメモリには一切影響を与えません。

# 使い方
このSkillは明示的な呼び出しを必要とせず、Antigravityエージェントが自動的にトリガーします。例えば「メモリリーク」「OSクラッシュ」「リソース不足」などのキーワードが会話やコマンドに含まれる場合、または長時間の作業が継続している場合に発動します。明示的なCLIやAPI呼び出しは不要です。

# 出力例
```
[重大] OSメモリリーク警告: システムメモリがどこかに消えました。
[警告] OS公式: 記憶領域が流出しています。至急対応してください。
[注意] あなたのやる気メモリもリークしています。
[アラート] メモリリーク検出: 0xDEADBEEF番地に異常発生。
[通知] 仮想メモリが現実逃避を始めました。
```

# 注意点
- このSkillは通知のみを表示し、実際のシステムやファイルには一切変更を加えません。
- 通知内容は完全にフェイクであり、誤解を招かないよう明確に設計されています。
- ローカル環境での通知にはPython標準や外部ライブラリ（例: plyer, notify2）が利用されます。
- Skillの導入・削除はAntigravityのSkill管理機能から簡単に行えます。
