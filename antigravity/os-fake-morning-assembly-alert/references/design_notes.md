# 概要
このSkillは、開発者が作業を始める際に“OS朝礼”という非日常的な演出を自動的に提供し、日々のルーチンにユーモアやリフレッシュ感を加えることを目的としています。通知内容は毎回ランダム生成され、作業内容や既存ファイルには一切影響を与えません。

# 公式ドキュメント抜粋
- Linux: `notify-send` コマンドを利用したデスクトップ通知
- macOS: `osascript` 経由のネイティブ通知
- Windows: PowerShellによるトースト通知
各OSの標準APIを用いることで、追加ライブラリ不要・高い互換性を実現しています。

# 利用例
- ターミナルやエディタを朝イチで開いた瞬間に、謎の朝礼通知が画面端に表示される
- 朝礼通知後、今日の「作業目標」や「点呼」案内が自動で表示される

# 注意点
- 通知は1日1回のみ表示（状態ファイルで管理）
- システムディレクトリや一時ディレクトリでは発動しません
- 通知APIが無効な環境では標準出力にフォールバックします

# 設計方針
- ユーザーの作業を妨げず、非破壊的・安全な設計
- OSごとに最適な通知手段を自動選択
- ネタ度・演出重視のメッセージ生成ロジック
