# 概要
このSkillは、作業中にユーザーへ意味不明な“伝説級OS起動通知”を表示し、日常にユーモアと驚きを提供することを目的としています。通知は実害ゼロで、作業の妨げにならない頻度制御と、ログ保存機能を備えています。

# 公式ドキュメント抜粋
通知表示にはPythonのplyerパッケージを利用しています。
- plyer: https://pypi.org/project/plyer/

# 利用例
- ターミナルで `python legend_alert.py test` を実行すると、ランダムな伝説通知が1回表示されます。
- `loop` サブコマンドでバックグラウンド通知を自動化できます。
- `semantic` サブコマンドで任意テキストに対し発動判定が可能です。

# 注意点
- plyer未インストール時は標準出力のみ。
- 通知内容は完全なジョークであり、実際のOSやシステムには影響しません。
- ログファイルはユーザーのホームディレクトリ直下に保存されます。

# 設計方針
意味不明かつ伝説風な通知文を厳選し、頻度・発動条件を調整。ユーザー体験を損なわず、ちょっとした話題や驚きを演出できるよう設計しています。
