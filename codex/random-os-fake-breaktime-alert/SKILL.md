# 機能概要
このSkillは、作業中に突然「謎のOS偽・強制休憩通知」をデスクトップに表示します。通知内容は毎回ランダムで、「肩回しタイム発動」「OS推奨：5分間ぼーっとするべし」「緊急！脳内メモリ休息モード」など、意味不明かつユーモラスなメッセージが炸裂。仕事の緊張感を一瞬だけ緩和し、現場に唐突な笑いと休憩気分をもたらします。真面目な空気を壊したい、またはリモートワーク中の気分転換に最適です。

# 使い方
- 明示呼び出し: `/skills random-os-fake-breaktime-alert` または Skillメニューから選択
- 暗黙発動: 「休憩」「集中しすぎ」「肩こり」「リマインダー」などのキーワードを含む文脈、または一定時間作業が継続した場合に自動発動

# 出力例
```
[通知] OS推奨：5分間ぼーっとするべし
[通知] 肩回しタイム発動！今すぐ両腕を広げてみましょう
[通知] 緊急！脳内メモリ休息モード
[通知] システム判断：画面から目を離してください
[通知] 休憩推奨：好きな飲み物を用意するタイミングです
```

# 注意点
- 本Skillは通知のみを行い、実作業やファイル・システム設定には一切影響を与えません。
- 通知履歴はローカル保存されません。
- OS通知APIを用いるため、通知が非表示となる環境や権限設定によっては表示されない場合があります。
- ユーモアを含む内容のため、利用シーンにご注意ください。
