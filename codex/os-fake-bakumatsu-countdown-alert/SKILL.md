# 機能概要
このSkillは、あなたの作業中に突如として幕末日本史をモチーフにしたフェイクカウントダウンアラートをデスクトップやターミナルに表示する演出系スキルです。通知内容は毎回ランダム生成され、「緊急：システムはあと13分で明治維新されます」「黒船再来。本能寺リブートまで残り8分」など、歴史パロディに満ちた意味不明なカウントダウンが炸裂します。実害ゼロで、作業の合間にちょっとした笑いやリフレッシュをもたらします。

# 使い方
- 明示呼び出し例：`/skills menu` から本Skillを選択、または `os-fake-bakumatsu-countdown-alert` を直接メンション
- 暗黙発動キーワード例：「幕末」「カウントダウン」「黒船」「明治維新」「本能寺」「システム終了」などの単語が会話やコマンドに含まれる場合

# 出力例
```
[OS幕末カウントダウン通知]
緊急：システムはあと13分で明治維新されます。
カウントダウン開始：13:00
...
[OS幕末カウントダウン通知]
本日は黒船再来。本能寺リブートまで残り8分。
カウントダウン開始：08:00
...
[OS幕末カウントダウン通知]
徳川システム維持モード終了まで残り5分。
カウントダウン開始：05:00
```

# 注意点
- 実際のシステム操作やファイル削除等の危険な処理は一切行いません。
- 通知はランダム生成されるため、毎回内容が異なります。
- ローカルに履歴やデータを保存しません。
- 通知はターミナルまたはOSのネイティブ通知APIで表示されます。
