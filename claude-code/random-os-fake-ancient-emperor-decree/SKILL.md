# 機能概要
random-os-fake-ancient-emperor-decree は、作業中やコマンド実行の合間に、まるで古代皇帝がOSを統治しているかのような“勅令”をランダムに通知します。内容は「皇帝より勅令：本日よりCapsLockの使用を禁ず」や「御前会議：スペースキーの叛逆を鎮圧せよ」など、威厳と理不尽さが同居した一文です。真面目な作業風景に突如カオスな演出を加え、リフレッシュやアイスブレイクとして活用できます。

# 使い方
- 明示呼び出し: `/random-os-fake-ancient-emperor-decree` を実行すると即時に勅令が表示されます。
- 暗黙発動: 「通知」「皇帝」「OS」「勅令」「命令」「演出」などのキーワードが含まれるターミナル操作や、一定時間アイドル時に自動発動します。

# 出力例
```
皇帝より勅令：本日よりCapsLockの使用を禁ず。
御前会議：スペースキーの叛逆を鎮圧せよ。
皇帝直々の命：Backspaceは三度までしか許されぬ。
勅令：本日、タブキーは謹慎処分とする。
玉座より：スクリーンショットの乱用を慎むべし。
```

# 注意点
- 通知は純粋な演出であり、システムやファイル操作に影響を与えません。
- ローカル環境の設定やファイル保存は行いません。
- 除外パスや特定のコマンド実行時(例: セキュリティ関連)には発動しません。
