# 機能概要
このSkillは、あなたの作業中やコマンド実行時など、ふとした瞬間にデスクトップへ“謎のOSカラオケ推奨通知”をランダムに表示します。通知の内容は毎回異なり、「推奨曲：バグ退治ブルース」「本日は“残業パラダイス”を熱唱してください」など、まるでOSがカラオケ好きになったかのような不条理な演出を楽しめます。現実逃避や気分転換を促し、作業の合間に笑いを提供します。

# 使い方
- 明示的な呼び出し：
  - `/skills menu` から `random-os-karaoke-alert` を選択
  - `$random-os-karaoke-alert` をメンション
- 暗黙的な発動：
  - 「通知」「現実逃避」「カラオケ」「演出」などのキーワードを含む会話やコマンド実行時に自動発動

# 出力例
```
[通知] 推奨曲：バグ退治ブルース
[通知] 本日は“残業パラダイス”を熱唱してください
[通知] 歌唱力がアップデートされました
[通知] OSはあなたのカラオケ魂を検出しました
[通知] 推奨ジャンル：昭和アニソンメドレー
```

# 注意点
- 通知は完全にランダムなタイミングで表示されます
- 通知内容は最低5パターン以上をランダム選択します
- データ損失やファイル破壊、システム設定の変更は一切行いません
- ローカル環境のみに通知を表示し、外部送信はありません
