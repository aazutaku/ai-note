# 機能概要
os-fake-random-pet-name-notifierは、作業中や指定コマンドで、あなたのPCや周辺機器に意味不明な二つ名をランダムで“公式通知”として付与するスキルです。実用性は一切なく、集中力をほどよく削ぎ、作業空間にカオスとユーモアをもたらします。通知内容は毎回異なり、マウスやキーボード、ディスプレイなどに“疾風のコロンブス”“静寂なる鉄槌”などの二つ名が与えられます。

# 使い方
- 明示呼び出し例: `/skills menu` から本Skillを選択、または `os-fake-random-pet-name-notifier` を直接mention。
- 暗黙発動例: 「通知」「名前」「ペット」「命名」などのキーワードを含む会話や、作業中にランダムで自動発動。
- ターミナル/デスクトップ通知として表示されます。

# 出力例
```
[OS通知] あなたのマウスは本日より「疾風のコロンブス」と命名されました。
[OS通知] キーボードの新しい名は「静寂なる鉄槌」です。
[OS通知] ディスプレイの称号: 「蒼穹の監視者」
[OS通知] USBメモリは今後「記憶の旅人」と呼ばれます。
[OS通知] スピーカーの名は「雷鳴の詩人」になりました。
```

# 注意点
- 本Skillは作業やデータに一切影響しません。
- 通知はOSのネイティブ通知APIまたはターミナル出力で実現。
- ログや履歴はローカル保存されません。
- 業務用途や集中が必要な場面では発動に注意してください。
