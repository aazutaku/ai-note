# 機能概要
本Skillは、作業の合間やコマンド実行時に、まるで1990年代のOS公式警告風の“レトロウイルス発見通知”をランダム生成し、ターミナルやデスクトップ通知として表示します。通知内容は完全なジョークで、実害ゼロの意味不明なウイルス名や警告文が毎回変わります。真面目な作業空間に一瞬の緊張感や笑いを提供し、チームや個人の気分転換・ネタとして活用できます。

# 使い方
- 明示呼び出し例：`/skills random-os-fake-vintage-virus-alert` または `$random-os-fake-vintage-virus-alert`
- 暗黙発動例：ターミナルで「ウイルス」「警告」「セキュリティ」などの単語を含むコマンドや会話が検出された際に自動発火
- 追加オプション：`--now` で即時通知、`--count N` でN回連続発生

# 出力例
```
[1998年製] OS公式警告: 伝説のワーム“メロンパン”を検出しました。
駆除ツール: C:\Tools\melonpan_cleaner.exe
影響範囲: Dドライブ全域
詳細: 本ウイルスは1998年に発見され、未だに正体不明です。

[2002年製] OS公式警告: “さすらいのポリオミノ”が潜伏中です。
駆除方法: 再起動推奨
影響範囲: C:\WINDOWS\System32
```

# 注意点
- 本Skillは実害のあるウイルスやマルウェアを検出・駆除するものではありません
- 通知内容はすべてフィクションであり、実際のファイル操作やシステム変更は行いません
- ローカル保存やログ出力はありません（必要に応じて拡張可）
- 作業を妨げすぎない頻度・タイミングで発動します
