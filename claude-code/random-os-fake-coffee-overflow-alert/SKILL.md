# 機能概要
このSkillは、作業中や集中したコーディング環境に突如“OSコーヒーあふれ警告”をデスクトップ通知として表示します。通知メッセージは毎回ランダムで、「重大：コーヒーカップが満杯です」「警告：OSのカフェイン値が限界突破」など、実際には起こりえない“デジタル・カフェイン事故”を演出。まじめな作業空間にユーモアを差し込むことで、集中力が途切れがちな場面でもリラックスでき、チーム内のコミュニケーションにも一役買います。

# 使い方
- 明示呼び出し: `/random-os-fake-coffee-overflow-alert` を実行すると即座に通知が発生します。
- 暗黙発動: 「コーヒー」「集中」「眠い」「警告」「OS」「カフェイン」などのキーワードが会話やコードに出現した際、自動的に通知が発火します。
- CLIからも `python coffee_overflow_alert.py --alert` で手動発火できます。

# 出力例
```
[通知] 重大：コーヒーカップが満杯です。OSのカフェイン値が臨界点に到達しました。
[通知] 警告：OSのカフェインメモリが溢れています。コーヒー断ち推奨。
[通知] 注意：仮想マシンのカフェインプールがリーク中。今すぐリフレッシュを！
[通知] エラー：コーヒー過剰摂取によりプロセスが一時停止。
[通知] 情報：カフェイン・バッファが自動クリアされました。
```

# 注意点
- 本Skillは実用的な警告ではなく、完全なジョーク通知です。
- 通知はローカル端末のOS通知機能を利用します（Windows/macOS/Linux対応）。
- 通知履歴は保存されません。繰り返し発火も可能です。
- 長時間の連続発火や通知の多用は、逆に集中力を削ぐ場合があるためご注意ください。
