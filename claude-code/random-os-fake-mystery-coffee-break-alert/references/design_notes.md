# 概要
random-os-fake-mystery-coffee-break-alertは、作業の流れに“謎のOS公式通知”を挿入することで、ユーザーに意外性とユーモアを提供するスキルです。通常のリマインダーやタイマーと異なり、通知内容やタイミングが完全にランダムで、説得力のある演出メッセージが特徴です。

# 公式ドキュメント抜粋
- Python通知API: https://pypi.org/project/plyer/
- OSコマンド: macOS (osascript), Linux (notify-send), Windows (print出力)

# 利用例
- 長時間のコーディングや集中作業時に、強制的に休憩を促すジョークツールとして利用
- チーム内の雑談やハッカソンでのアイスブレイク演出

# 注意点
- 通知APIの動作は環境依存です。Linux/macOSでは追加パッケージが必要な場合があります。
- 実際の業務指示やOSの公式通知とは無関係です。

# 設計方針
- メッセージ内容・発動タイミングの“謎感”を重視
- ローカル保存や履歴管理は最小限とし、シンプルな実装を優先
- CLIから明示/暗黙どちらでも発動できる柔軟性を持たせています。
