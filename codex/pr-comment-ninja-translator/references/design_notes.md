# 概要
このSkillは、PRコメントやレビュー文を忍者口調に変換し、開発現場の雰囲気を和ませるためのジョーク系ツールです。GitHub APIを用いて既存コメントの取得・投稿にも対応しています。

# 公式ドキュメント抜粋
- [GitHub REST API v3](https://docs.github.com/ja/rest) の `/pulls/comments/{comment_id}` および `/issues/{issue_number}/comments` を利用。

# 利用例
- PRで「この関数はバグがあります」と書かれたコメントを忍者口調に変換し、再投稿。
- チームの雰囲気を和ませたい時に/skillsコマンドで明示呼び出し。

# 注意点
- 日本語以外の文には未対応。
- 意味が大きく変わる場合や、正式なレビューには利用を控えること。
- GitHub API利用時はアクセストークン管理に注意。

# 設計方針
- 変換は単純な置換＋忍者語テンプレートで構成。
- コマンドラインからの柔軟な利用を想定し、ファイル入出力やAPI連携も可能とした。
