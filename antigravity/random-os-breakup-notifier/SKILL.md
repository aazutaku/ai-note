# 機能概要
random-os-breakup-notifierは、作業中のユーザーに対して突如“デジタル失恋”をテーマにしたランダムな通知を表示するスキルです。通知内容は毎回異なり、例として「あなたのマウスが新しいパートナーを見つけました」や「CtrlキーがAltキーと付き合い始めました」など、意味不明かつシュールな文面で構成されます。真面目な作業空間に非日常をもたらし、ユーザーの気分転換や場の雰囲気を和らげることを目的としています。

# 使い方
このスキルは明示的な呼び出しは不要で、semantic-match-onlyトリガーにより自動発動します。たとえば「集中力が切れた」「気分転換したい」「ジョーク通知が欲しい」などのキーワードやコンテキストを検知した際に、システム通知またはターミナル出力として発動します。明示的なCLIコマンドはありません。

# 出力例
```
[通知] 重要: あなたのマウスが新しいパートナーに乗り換えました。
[通知] 悲報: エディタがそっとあなたのもとを去りました。
[通知] ごめん、今日からCtrlキーはAltキーと付き合うことに。
[通知] ディスプレイがあなたの視線を避けています。
[通知] あなたのUSBメモリは新しいPCに夢中です。
```

# 注意点
- システムや他の作業への干渉は一切ありません。
- 通知内容は完全にランダム生成されるため、同じメッセージが繰り返される場合があります。
- ローカルに通知履歴や個人情報は保存しません。
- 一部のOS環境では通知APIが制限される場合があります。
