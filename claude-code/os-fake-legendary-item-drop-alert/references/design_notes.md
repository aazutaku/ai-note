# 概要
このSkillは、作業中のユーザーに「意味不明な伝説アイテムドロップ通知」を演出することで、日常の単調な作業やコーディングにユーモアとちょっとした刺激を与えることを目的としています。現実世界のガチャ的なワクワク感を、デスクトップやターミナルに再現します。

# 公式ドキュメント抜粋
- Python random: https://docs.python.org/3/library/random.html
- plyer通知API: https://plyer.readthedocs.io/en/latest/

# 利用例
- 長時間のコーディングやドキュメント作成時の気分転換
- チームでのリモートワーク雑談ネタ
- 明示的に `/os-fake-legendary-item-drop-alert` で即時発動も可能

# 注意点
- 通知内容は完全に架空で、実際のシステムやファイルには一切影響しません。
- ログはユーザーのホームディレクトリ直下に保存されます。
- plyerがインストールされていない場合はターミナル出力のみ対応します。

# 設計方針
- 実在APIのみ使用し、外部依存は最小限（plyerのみ）
- 通知頻度はデフォルトで作業妨害にならない程度（1時間1-2回）
- ログ・サマリー機能も備え、ユーザーが過去の「ドロップ」を振り返ることができます。
