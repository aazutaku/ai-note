# 機能概要
このSkillは、あなたの作業環境に“謎のOS公式・IT英雄召喚通知”をランダムなタイミングで表示します。通知内容は毎回異なり、伝説のデバッグ勇者やコマンド使いなど、IT界の架空英雄があなたの作業を（精神的に）サポートする演出を提供します。実用性はありませんが、孤独な作業や長時間のコーディングにちょっとした勇気や笑いをもたらします。

# 使い方
- 明示呼び出し: `/random-os-fake-it-hero-summon-notifier` を入力すると即時発動します。
- 暗黙発動: 「寂しい」「集中力が切れた」「バグが倒せない」「助けて」などのキーワードを含む状況や、一定時間操作がない場合に自動発動します。

# 出力例
```
[OS通知] 伝説のデバッグ勇者「バグスレイヤー・アリス」が参上しました！
[OS通知] “コマンド使いのジョン”がバグ退治に出動します。
[OS通知] システムの守護者「rootの精霊」がログインしました。
[OS通知] バージョン管理の魔術師「Gitマスター・ミカ」が召喚されました。
[OS通知] 「コンパイルの賢者」からのメッセージ: “焦らず進もう！”
```

# 注意点
- 実際の作業データや環境には一切影響を与えません。
- 通知内容は完全にフィクションです。
- 通知履歴はローカルには保存されません。
- 一部OSでは通知APIの制限により表示されない場合があります。
