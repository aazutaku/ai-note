# 概要
本Skillは、作業中に意図的な“偽エラー通知”をランダム表示することで、ユーザーの気分転換やリフレッシュを促すユーモア系ツールです。通知内容は実際のエラーと誤解されないよう設計されています。

# 公式ドキュメント抜粋
通知表示には plyer (https://pypi.org/project/plyer/) を優先利用し、未導入環境では macOSのosascript, Linuxのnotify-send, Windowsのwin10toast等を自動選択します。

# 利用例
- 長時間作業時のリフレッシュ
- チーム内でのジョークやアイスブレイク
- ターミナルで /random-os-fake-404-notification once

# 注意点
- 本Skillは実用性よりも遊び心を重視しています。
- 通知は1時間に1～3回程度の頻度で発火し、過剰な邪魔を避けます。
- ログはホームディレクトリに保存されますが、個人情報や機密情報は記録しません。

# 設計方針
- 本物のエラーと誤解されない文言のみを厳選
- OSごとに最適な通知APIを自動選択
- ログ出力・履歴閲覧・集計機能を備え、Skillの利用状況を可視化
