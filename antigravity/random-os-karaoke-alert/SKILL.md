# 機能概要
このSkillは、作業中のあなたのデスクトップに、まるでOSが突然カラオケ好きになったかのようなユーモラスな通知をランダムで表示します。通知内容は完全ランダムで「本日は“残業パラダイス”を熱唱してください」「推奨曲：バグ退治ブルース」など、現実逃避や息抜きを推奨するカオスな演出を楽しめます。集中しすぎて疲れた時や、単調な作業の合間に、思わずクスリと笑える不条理な“OS演出”を体験したい方に最適です。

# 使い方
本Skillは明示的な呼び出しコマンドは不要です。Antigravityエージェントが「カラオケ」「休憩」「疲れた」「歌」「現実逃避」などのキーワードや、長時間作業・アイドル状態を検知した際に自動的に発動します。手動で通知をテストしたい場合は、スクリプトの `--test` オプションを利用できます。

# 出力例
```
[通知] 本日は“残業パラダイス”を熱唱してください
[通知] 推奨曲：バグ退治ブルース
[通知] 歌唱力がアップデートされました。再起動は不要です
[通知] OSよりお知らせ：本日のカラオケ推奨タイムが始まりました
[通知] 現実逃避モードON！カラオケでリフレッシュしましょう
```

# 注意点
- 通知はデスクトップ通知API（Windows: Toast, macOS: terminal-notifier, Linux: notify-send）を利用します
- 通知内容は毎回ランダム生成されますが、データ損失やシステム設定には一切影響しません
- ログや履歴はローカル保存されません
- 明示的な呼び出しコマンドはありません
