# 機能概要
このSkillは、あなたの作業環境に突如として“OSがカラオケ好きになった”かのような通知を炸裂させる演出系ツールです。通知内容は完全ランダムで「本日は“残業パラダイス”を熱唱してください」「推奨曲：バグ退治ブルース」など、現実逃避やユーモアをOSが推奨してくるカオスな体験を提供します。作業の合間の気分転換や、チームの雰囲気を和ませたいときに最適です。

# 使い方
- 明示呼び出し例: `/random-os-karaoke-alert` を実行すると即座に通知が表示されます。
- 暗黙発動: 「カラオケ」「休憩」「現実逃避」「歌いたい」などのキーワードが会話やログに現れると自動的に発動します。
- 常時監視型: スキルを有効化しておくと、30分～2時間のランダムな間隔で自動的に通知します。

# 出力例
```
[通知] OSカラオケ推奨: 本日は“残業パラダイス”を熱唱してください。
[通知] 推奨曲: バグ退治ブルース
[通知] 歌唱力がアップデートされました。今すぐ一曲いかがですか？
[通知] OSより: カラオケ休憩の時刻です。
[通知] システム: “仕様書ブルース”を歌うとバグが減るかもしれません。
```

# 注意点
- 通知はローカル環境でのみ表示され、外部サーバー等には一切情報を送信しません。
- データ損失やシステム破壊を引き起こすことはありません。
- 通知内容は5パターン以上からランダム生成されます。
- 通知履歴はローカルに保存されます（`~/.random_os_karaoke_alert.log`）。
- Linux/macOS: `notify-send`/`osascript`を利用。Windows: `win10toast`を利用。
