# 機能概要
random-os-fake-boss-keyは、作業中に「サボりがバレそう」「急に上司が来た」などの状況で発動し、即座に本物の業務画面風のダミーウィンドウ（例：グラフやレポート、ダッシュボード）をランダム生成して表示します。伝説の“ボスキー”を現代風に再現し、背後からの視線対策や気まずい瞬間の“業務中オーラ”演出を自動化。実際の業務データではなく、その場限りのフェイク画面なので、プライバシーや情報漏洩の心配もありません。

# 使い方
- 明示呼び出し例: `python boss_key.py --show` で即時ダミー画面を表示。
- 暗黙発動: 「サボり」「上司」「バレそう」「画面切替」「ボスキー」などのキーワードを含む発話や指示で自動発動。
- ダミー画面は毎回ランダム生成。`--restore`で元の作業画面に即時復帰。

# 出力例
```
[Fake Report Dashboard]
- Sales Growth: 12.4% (Q2)
- Customer Churn: 2.1%
- Active Users: 1,234
[Graph: Revenue vs. Time]
██████████ 2023Q1
█████████████ 2023Q2
███████████████ 2023Q3
[End of Report]
```

# 注意点
- 本Skillはローカル環境でのみ動作し、実際の業務システムやデータには一切アクセスしません。
- 生成される画面はあくまでフェイクであり、実業務には利用できません。
- 保存機能はありません。画面復帰後は内容が消えます。
