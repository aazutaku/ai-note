# 概要
このSkillは、現実離れしたディスク残量危機通知をランダム生成し、デスクトップやターミナルに表示することで、作業中にユーモアや意外性を提供します。実際のストレージ情報は一切参照せず、完全にフェイクな通知のみを目的としています。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonの `plyer` ライブラリを使用。詳細: https://github.com/kivy/plyer

# 利用例
- チームの朝会やペアプロ中に突然流して場を和ませる
- コーディング中の気分転換や集中力回復のきっかけに
- ジョークBotや演出用スクリプトの一部として

# 注意点
- 通知内容は完全なランダム生成であり、実際のディスク状態とは無関係
- plyerが未インストールの場合はターミナル出力のみ
- システム設定により通知がブロックされる場合あり

# 設計方針
- 実在APIのみ使用し、架空のCLIや関数は排除
- ランダム性を重視し、毎回異なる通知文を生成
- スクリプトはCLIサブコマンド形式で柔軟に利用可能
