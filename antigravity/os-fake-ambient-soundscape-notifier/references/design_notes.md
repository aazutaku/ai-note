# 概要
このSkillは、実際に音を鳴らさずに“OS風の環境音通知”だけを表示することで、作業空間にユーモアや非日常感を与える演出ツールです。通知内容は完全ランダムで、ユーザーの集中力や気分転換を妨げない頻度で自動表示されます。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonの`plyer`ライブラリを利用。クロスプラットフォーム対応で、Windows/Mac/Linuxで動作します。plyer公式: https://github.com/kivy/plyer

# 利用例
- 長時間のコーディングやリモートワーク中に、突然“謎の環境音通知”が現れ、笑いや驚きを提供
- チームメンバー間で「今日はどんな通知が来た？」と話題になる

# 注意点
- 実際の音声再生機能は一切ありません
- 通知頻度は10分〜1時間程度で自動調整
- 履歴やサマリーはメモリのみで永続化されません

# 設計方針
ユーザーの作業リズムを乱さず、あくまで“フェイク感”を楽しむことを重視。明示的な呼び出しや設定項目は極力省略し、手軽に非日常演出を体験できるよう設計しています。
