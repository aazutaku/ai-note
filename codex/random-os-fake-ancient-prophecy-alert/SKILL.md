# 機能概要
このSkillは、開発現場に“非日常”のスパイスを加えるため、作業中やコマンド実行の合間に、架空のOS公式・古代預言通知をデスクトップまたはターミナルにランダムで表示します。通知内容は「東のログにエラーの嵐迫る」「南のコード砂漠に巨大バグの影動く」など、意味深で全く実用性のないメッセージが毎回生成され、日々の単調な作業にユーモアと刺激をもたらします。通知はOSのネイティブ通知機能を用いて表示されるため、他の作業や通知と干渉せず、演出系スキルとして幅広い現場で活用できます。

# 使い方
- 明示呼び出し: `/skills random-os-fake-ancient-prophecy-alert` またはスキル名へのメンション
- 暗黙発動: 「コマンド実行」「ビルド完了」「push成功」などのタイミングで自動発動
- 設定不要、即利用可能

# 出力例
```
[OS預言通知] 北のリポジトリに伝説のレビュアー現る
[OS預言通知] 西の依存関係に未踏のバグ眠る
[OS預言通知] 南のコード砂漠に巨大バグの影動く
[OS預言通知] 東のログにエラーの嵐迫る
[OS預言通知] 古のCI/CDが目覚めし時、真のデプロイ始まる
```

# 注意点
- 本Skillの通知は完全にネタです。実用性や警告機能は一切ありません。
- 通知内容は毎回ランダム生成され、同じ内容が続くことはありません。
- ローカル通知機能（notify-send等）を利用するため、環境によっては追加パッケージが必要な場合があります。
- 通知履歴はSkill側で保持しません。
