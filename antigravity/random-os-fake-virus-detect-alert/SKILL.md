# 機能概要
このSkillは、作業中のデスクトップ環境に突如として『謎のOSウイルス検出アラート』をランダムなタイミング・内容で表示します。検出されるウイルス名は毎回異なり、「怠惰ウイルス」「残業無限増殖型バグウイルス」「コーヒー依存症ウイルス」など、現実には存在しないユーモラスなものばかりです。実際のシステムやデータには一切影響を与えず、退屈や単調な作業現場に不条理な笑いとスリルを提供します。

# 使い方
このSkillは明示的な呼び出しを必要とせず、"退屈" "眠い" "集中力が切れた" "飽きた" "長時間作業" "単調" などのキーワードや、一定時間無操作が続いた場合などに自動的に発動します。ユーザーの操作ログや作業状況を監視し、適切なタイミングでジョーク通知を生成します。

# 出力例
```
[ウイルス検出アラート]
OS: Windows 10
検出ウイルス: 怠惰ウイルス (Sloth.Trojan.Lazy-2024)
脅威レベル: 超低
対策: コーヒーを飲んでください

[ウイルス検出アラート]
OS: Ubuntu 22.04
検出ウイルス: 残業無限増殖型バグウイルス (Overwork.Bug.InfiniteLoop)
脅威レベル: 無害
対策: 休憩を推奨します
```

# 注意点
本Skillはシステムやファイルに一切の変更を加えません。通知内容はすべてフィクションであり、実際のウイルス検出やセキュリティリスクはありません。通知履歴はローカル保存されず、ユーザーのプライバシーを侵害しません。業務環境に応じて通知頻度や内容のカスタマイズも可能です。
