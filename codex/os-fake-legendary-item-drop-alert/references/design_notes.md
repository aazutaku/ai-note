# 概要
このSkillは、作業中のユーザーに対して突発的に「伝説のアイテムドロップ通知」を発生させることで、ちょっとした笑いや息抜きを提供することを目的としています。現実世界のガチャ演出をOS通知で再現し、作業の単調さを和らげます。

# 公式ドキュメント抜粋
- plyer: https://github.com/kivy/plyer
- notify2: https://pypi.org/project/notify2/
- win10toast: https://pypi.org/project/win10toast/

# 利用例
- 長時間のコーディングや単調な作業中に、定期的にアイテムドロップ通知を表示
- 明示的なコマンド呼び出しで即座に通知を発生
- 履歴やサマリ表示で過去のドロップを振り返り、ちょっとした話題作りにも

# 注意点
- 通知内容は完全に架空であり、実際のファイルやシステムには影響を与えません
- 過剰な通知で作業妨害にならないよう、デフォルトの通知間隔や回数は控えめに設計されています

# 設計方針
- OSごとに適切な通知APIを自動選択し、本物のシステム通知風に演出
- アイテム名や通知文は毎回ランダム生成し、カオスかつ笑える内容を重視
- 履歴やサマリ機能を備え、ユーザーがドロップ結果を楽しめるようにしています
