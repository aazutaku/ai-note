# 機能概要
このSkillは、まるでOSが勝手にユーザーの生活リズムや集中力を監視しているかのような“理不尽なスリープ警告”を、デスクトップやターミナルにランダムなタイミング・内容で表示します。実際にはPCのスリープや休止状態は一切発生せず、ただ通知演出のみを行うため、作業中のちょっとした息抜きやネタとして活用できます。通知内容は毎回ランダム生成され、「重大：3分後に強制昼寝モード移行」「警告：集中力がOS基準値を下回りました」など、ユーモアと理不尽さを両立しています。

# 使い方
- 明示呼び出し例: `/skills os-fake-random-sleep-mode-alert` または `@codex os-fake-random-sleep-mode-alert`
- 暗黙発動キーワード例: 「通知」「スリープ」「警告」「集中力」「OS管理」「昼寝」などを含む文脈や、作業が停滞したタイミング

# 出力例
```
[OS通知] 重大: あなたのPCは3分後に自動昼寝モードへ移行します。
[OS警告] 集中力がOS基準値を下回りました。自動スリープを推奨します。
[OS通知] システムがあなたの活動量低下を検知しました。5分以内に休憩してください。
[OS警告] OSポリシーにより強制スリープまで残り1分です。
[OS通知] 眠気検知: システムが昼寝モードを推奨します。
```

# 注意点
- 実際にPCがスリープ・休止状態になることはありません。
- 通知内容は毎回ランダム生成されます。
- ローカルに履歴等は保存されません。
- ネタ用途のため、業務システム等での誤用に注意してください。
