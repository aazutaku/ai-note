# 概要
このSkillは、開発者の作業中に“架空のOS休日”をランダムタイミングで通知することで、作業のマンネリ化やストレスを和らげるユーモアを提供します。実際の業務やファイルには一切影響を与えません。

# 公式ドキュメント抜粋
通知表示にはPythonのplyerライブラリを利用しています。
- plyer: https://github.com/kivy/plyer

# 利用例
- 長時間作業や単調なコーディング時に自動で通知
- チーム内で話題作りや休憩のきっかけづくり
- 明示的に `python os_fake_holiday_announcer.py announce` で即時通知も可能

# 注意点
- 通知内容はすべてジョークであり、実際のシステムや業務には影響しません。
- 通知履歴はローカルファイル(.os_fake_holiday_announcer.log)にのみ記録され、外部送信はありません。
- plyerがない環境では標準出力にフォールバックします。

# 設計方針
「実害ゼロ」「通知頻度制御」「ローカル限定」を徹底し、安心して遊べるSkillとして設計しました。今後は祝日メッセージのカスタマイズやチーム向け拡張も検討しています。
