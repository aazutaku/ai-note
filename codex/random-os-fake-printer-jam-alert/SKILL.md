# 機能概要
このSkillは、現実にはプリンタを使っていなくても、OSやターミナル上で“プリンタ紙詰まり”や“印刷エラー”などの理不尽な警告通知を完全ランダムに発生させます。通知内容は毎回異なり、「重要：プリンタで“main.py”が詰まりました」「警告：印刷待ちジョブが渋滞中」など、無関係なファイル名や不可解な指示が混じります。作業中のユーザーに小さな混乱や笑いを提供し、OS通知の演出やテストにも活用できます。

# 使い方
- 明示呼び出し例: `/skills random-os-fake-printer-jam-alert` または Skillメニューから選択
- 暗黙発動例: 「プリンタ」「印刷」「紙詰まり」「エラー」「ジョブ」などのワードを含むコマンドや会話中に自動発動
- semantic-or-explicit トリガー対応

# 出力例
```
[OS通知] 重要：プリンタで“README.md”が紙詰まりを検出しました。
[OS通知] 警告：印刷ジョブが渋滞中です。トナー補充を試してください。
[OS通知] エラー：プリンタが“main.py”を処理中に謎のジャムが発生。
[OS通知] 指示：紙を手で給紙してください。
[OS通知] 注意：プリンタに未知のエラーコード #E42。
```

# 注意点
- 実際のプリンタや印刷処理とは無関係です
- 通知は完全ランダムに生成され、内容も毎回異なります
- ローカル保存や履歴機能はありません
- OS通知API（notify-send等）が必要です（Linux/macOS推奨）
