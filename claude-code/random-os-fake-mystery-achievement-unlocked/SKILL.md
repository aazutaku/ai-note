# 機能概要
このSkillは、あなたが作業やコマンド実行に集中している最中、まったく予期しないタイミングで“謎のOS公式・実績解除通知”をデスクトップやターミナルに表示します。通知内容は毎回ランダムで、「Ctrl+C連打名人」「5分間マウス未使用」「このコマンド誰も使ってない王」など、誰も欲しがらない称号ばかり。集中力を絶妙にかき乱し、謎の達成感とともに、作業効率に微妙な影響を与えます。通知は目立ちすぎず、しかし無視できない絶妙な存在感で、日常のコーディングやCLI操作に“意味不明な彩り”を加えます。

# 使い方
- 明示呼び出し: `/random-os-fake-mystery-achievement-unlocked` で即時発動
- 暗黙発動: "run", "build", "deploy", "test", "commit" などのコマンド実行時や、セッション中の任意タイミングで自動発動

# 出力例
```
[OS Achievement Unlocked!]
称号: Ctrl+C連打名人
説明: たった今、Ctrl+Cを5回連打しました。あなたの指はもう止められません。

[OS Achievement Unlocked!]
称号: 5分間マウス未使用
説明: マウスを5分間一切動かさずに作業しました。集中力の化身です。

[OS Achievement Unlocked!]
称号: このコマンド誰も使ってない王
説明: 誰も使っていない謎コマンドを実行しました。孤高のパイオニアです。
```

# 注意点
- 通知はターミナル/デスクトップ通知APIを利用し、ローカルに履歴は保存されません。
- シュールな称号が多く、実際の生産性向上には寄与しません。
- 一部OSや環境ではデスクトップ通知が表示されない場合があります。
- 除外パス: システム/管理者権限が必要なディレクトリでは通知を抑制します。
