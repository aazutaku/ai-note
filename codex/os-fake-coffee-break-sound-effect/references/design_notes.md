# 概要
本Skillは、開発現場や個人作業中に強制的な休憩ムードを演出するため、OSの通知APIとローカルサウンド再生機能を組み合わせて設計されています。

# 公式ドキュメント抜粋
- Linux: notify-send (freedesktop.org)
- macOS: osascript (AppleScript)
- Windows: win10toast, playsound (PyPI)

# 利用例
- 長時間作業の合間に自動発動し、ユーザーの集中をリセット。
- チーム開発のリラックス演出や、イベント時の“謎演出”として活用。

# 注意点
- サウンドファイルは各自で`sounds/`配下に配置が必要。
- サーバーやリモート環境では通知・音声がユーザーに届きません。
- 通知APIやサウンド再生コマンドはOS依存性が高いため、クロスプラットフォーム検証が重要です。

# 設計方針
- OS自動判定による最適な通知・再生手段を選択。
- 通知文言・サウンドともに完全ランダム性を担保。
- CLIサブコマンドで柔軟な操作性を提供。
