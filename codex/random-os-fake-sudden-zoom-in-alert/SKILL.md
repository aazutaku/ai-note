# 機能概要
このSkillは、作業や開発中に突然「重大：ズームインモード突入まで残り5秒」など、現実には何も起こらない“謎のOSズームイン警告”をデスクトップやターミナルにランダム表示します。通知内容は毎回変化し、ユーザーや周囲の空気を一瞬で混乱させることができます。実際のズームやシステム操作は一切発生せず、純粋なフェイク通知として盛り上げや場の和ませ、リフレッシュ効果を狙う演出用途に最適です。

# 使い方
- 明示呼び出し例:
  - `/skills random-os-fake-sudden-zoom-in-alert`
  - `$random-os-fake-sudden-zoom-in-alert`
- 暗黙発動キーワード例:
  - 「通知」「ズームイン」「警告」「演出」「フェイク」などを含むチャットやコマンド実行時

# 出力例
```
[ALERT] 重大：ズームインモード突入まで残り5秒
[ALERT] 謎の力により画面拡大率が上昇中…
[ALERT] システム：ズームイン警告！解除方法は不明です
[ALERT] 画面拡大率が制御不能になりました
[ALERT] 5秒後にズームインが始まるかもしれません
```

# 注意点
- 実際の画面ズームやOS設定変更は一切行いません
- 通知は一時的に表示され、履歴やファイル保存はありません
- 一部の環境では通知がポップアップせずターミナル表示のみとなる場合があります
- 本Skillはジョーク・演出目的専用です。業務用途や障害通知には絶対に使わないでください
