# 概要
このSkillは、作業やコマンド実行中に“謎の人事研修通知”をランダムに表示し、現実逃避や笑いを提供する演出系ツールです。通知内容は毎回異なり、実際の業務やデータには一切影響を与えません。

# 公式ドキュメント抜粋
- Python subprocess: https://docs.python.org/3/library/subprocess.html
- plyer通知: https://pypi.org/project/plyer/
- win10toast: https://pypi.org/project/win10toast/

# 利用例
- ターミナル作業中に突然“謎のパワポ芸入門”研修通知が表示され、場の空気を和ませる
- チームの朝会やイベントで、ジョークとして活用

# 注意点
- 通知は一時的なもので、ファイルやデータベースへの保存は行いません
- 実在する会社や団体・個人名は一切出力されません
- OS通知は環境によって動作しない場合があり、その場合はターミナル表示のみとなります

# 設計方針
- ランダム性とバリエーションを重視し、毎回異なる通知を生成
- OS/ターミナル両対応で、違和感なく“人事研修系”通知を演出
- 安全性を最優先し、実データやシステム設定には一切影響しない設計
