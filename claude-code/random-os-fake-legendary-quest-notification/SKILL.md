# 機能概要
このSkillは、日常の作業やコーディングの最中に、まるでOS公式から届いたかのような“伝説のクエスト通知”をランダムに生成し、ターミナルやデスクトップに表示します。内容は毎回異なり、「禁断のレジストリ迷宮から脱出せよ」「Cドライブの最奥に眠る古のバグを討伐せよ」など、現実には絶対に存在しないファンタジックな無茶ぶりクエストばかり。真面目な通知に飽きた人や、作業の合間に笑いと妄想力を刺激したい方に最適な“OS通知ファンタジー”体験を提供します。

# 使い方
- 明示呼び出し: `/random-os-fake-legendary-quest-notification` を実行すると即座に通知が発生します。
- 暗黙発動: 「通知」「演出」「OS連携」「現実逃避」「クエスト」などのキーワードを含む会話や作業中に、Skillが自動的に発動します。
- 通知はターミナル出力またはOS通知として表示されます。

# 出力例
```
[OS Quest Notification]
緊急任務: Cドライブ深奥に眠る古のバグ退治
報酬: システム安定度+100
---
[OS Quest Notification]
伝説のUSBメモリ捜索開始
場所: デスク下の未確認領域
---
[OS Quest Notification]
極秘: レジストリ迷宮からの脱出指令
期限: 24時間以内
```

# 注意点
- 本Skillは完全なフェイク通知のみを生成し、実際のファイル操作やシステム変更は一切行いません。
- 通知内容は毎回ランダムで、実害やデータ損失はありません。
- ローカルに通知履歴を保存する場合は、明示的な同意が必要です。
- 実在するOSや業務通知と混同しないようご注意ください。
