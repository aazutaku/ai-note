# 機能概要
このSkillは、作業やコマンド実行の合間に、デスクトップやターミナル上へ“OS公式風”の404エラー通知をランダムなタイミングで表示します。通知内容は毎回異なり、「404: あなたのやる気が見つかりません」「404: 今日の集中力が迷子です」など、実用性ゼロでありながらクスっと笑えるメッセージが特徴です。作業の合間にちょっとした気分転換やリフレッシュを提供し、日常の単調さを打破します。

# 使い方
- 明示呼び出し: `/skills random-os-fake-404-notification` またはスキルメニューから選択
- 暗黙発動キーワード例: 「やる気」「進捗」「集中」「エラー」「404」などの出現時や、長時間操作がない場合に自動発火

# 出力例
```
[通知] 404: あなたのやる気が見つかりません
[通知] 404: 今日の集中力が迷子です
[通知] 404: 予定されていた進捗が行方不明です
[通知] 404: コーヒーブレイクが検出されませんでした
[通知] 404: 午後の生産性が応答しません
[通知] 404: Motivation Not Found
[通知] 404: 重要なアイデアが行方不明です
```

# 注意点
- 本Skillは冗談目的であり、実際のエラーやシステム障害ではありません。
- 通知の頻度は過度にならないよう調整されていますが、必要に応じて停止・間引きが可能です。
- ローカル環境でのみ通知が表示され、外部サーバーやクラウドには何も送信しません。
- 一部OSでは通知表示に追加パッケージが必要な場合があります。
