# 概要
このSkillは、作業中の緊張感や沈黙をジョーク通知で和らげるために設計されました。通知内容は完全オリジナルで、OSが勝手に“今日のBGM”を推奨してくるような演出を再現します。

# 公式ドキュメント抜粋
通知にはPythonのplyer.notificationを利用しています。plyerはクロスプラットフォーム対応で、Windows/macOS/Linuxで同じコードで通知が可能です。

# 利用例
- 明示的に `python random_os_fake_soundtrack_alert.py once` で即座に通知
- `loop` サブコマンドで一定間隔ごとに通知
- `sample` サブコマンドで通知例を確認

# 注意点
- plyerがインストールされていない場合やサーバ環境では、print出力にフォールバックします。
- 実際に音楽やBGMは再生されません。

# 設計方針
通知内容は毎回異なるよう、複数のプレフィックス・曲名・副題をランダム合成。通知頻度は15分ごとをデフォルトとし、作業の邪魔になりすぎない設計です。履歴保存やログ機能はあえて実装していません。
