# 機能概要
このSkillは、作業やコーディング中に唐突に“謎のOSライセンス期限切れ”風の警告を表示します。警告は毎回異なり、「あなたのCaps Lockキーのライセンスが失効しました」「Ctrlキーの利用は本日で終了です」など、実在しないデバイスや機能の期限切れを本格的な警告文で通知します。実害は一切なく、緊張感や理不尽なスパイスを加え、退屈な現場や深夜作業の気分転換に最適です。

# 使い方
- 明示呼び出し例: `/random-os-fake-mystery-license-alert`
- 暗黙発動キーワード例: 「ライセンス」「期限」「OS」「警告」「認証」「有効期限」「失効」「アラート」などの単語が会話や作業ログに現れると自動発動します。発動間隔や回数はスクリプト内でランダム制御されます。

# 出力例
```
[ALERT] OSライセンス警告: あなたのCaps Lockキーのライセンスは本日をもって失効しました。再認証が必要です。
[ALERT] システム通知: Num Lock機能の試用期間が終了しました。今後は一部機能が制限されます。
[ALERT] OSライセンス警告: スクロールバーの利用権が期限切れとなりました。管理者にお問い合わせください。
[ALERT] システム通知: Shiftキーの年間ライセンスが失効しました。継続利用には更新手続きが必要です。
[ALERT] OSライセンス警告: ターミナルウィンドウの最大化機能の認証が切れています。
```

# 注意点
- 実際のデータやシステム設定には一切影響しません。
- 通知は標準出力(ターミナル)またはOSの通知API経由で表示されます。
- ログや履歴はローカル保存されません。
- 本Skillは冗談や演出目的であり、業務システム等への導入はご注意ください。
