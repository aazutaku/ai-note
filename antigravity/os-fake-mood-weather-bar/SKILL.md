# 機能概要
本Skillは、ユーザーの作業環境に“OS風・謎の気分天気バー”を突如出現させる演出系ツールです。気分や作業状況を天気に見立てたカオスなワード（例：絶好調・晴れ、やる気霧雨、集中力台風接近中、バグの嵐、仕様雪崩など）を完全ランダムに生成し、画面端やメニューバーに表示します。実用性はありませんが、職場や自宅での作業中に唐突な“気分天気”演出で場の空気を和ませたり、話題のきっかけを生み出します。

# 使い方
このSkillは明示的な呼び出しを必要とせず、Antigravityが「気分」「天気」「やる気」「集中力」「バグ」などのキーワードや、進捗・休憩・雑談を検知した際に自動発動します。設定やトリガーのカスタマイズは不要です。他の通知・演出系Skillと同時利用する場合は、競合しないように注意してください。

# 出力例
```
[OS風・気分天気バー]
本日の気分: 仕様雪崩
集中力: 台風接近中
やる気: 霧雨
バグ状況: 嵐

[OS風・気分天気バー]
本日の気分: 絶好調・晴れ
集中力: 快晴
やる気: そよ風
バグ状況: なし
```

# 注意点
- 本Skillは実用的な通知や進捗管理を目的としません。
- ローカル環境でのみ動作し、外部サーバーへのデータ送信等は行いません。
- 他の通知・演出系Skillと同時に使用する場合、表示位置の競合に注意してください。
- 表示内容は完全ランダムで、意味や精度は保証されません。
