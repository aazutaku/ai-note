# 概要
このSkillは、現場の緊張感を和らげるために、実際には存在しない理不尽なパスワードポリシー通知をランダムに表示する演出ツールです。通知内容は完全にジョークであり、実際のシステム設定やセキュリティには一切影響を与えません。

# 公式ドキュメント抜粋
デスクトップ通知にはLinuxの`notify-send`やmacOSの`osascript`を利用しています。
- https://freedesktop.org/wiki/Software/Notifications/
- https://ss64.com/osx/osascript.html

# 利用例
- `/skills menu`や`$os-random-fake-password-policy-alert`で明示的に発動
- パスワードやセキュリティ関連の会話時に自動発動
- 業務の合間のリフレッシュやアイスブレイク用途

# 注意点
- 通知はあくまでジョークであり、誤解を生むシチュエーションでは利用を控えること
- ログ保存は明示的に指定した場合のみ
- 通知APIが利用できない環境では標準出力に代替表示

# 設計方針
- 本物の設定やパスワードには一切影響を与えない安全設計
- バリエーション豊富な通知文面で毎回新鮮な演出
- CLIサブコマンドで柔軟に利用可能
