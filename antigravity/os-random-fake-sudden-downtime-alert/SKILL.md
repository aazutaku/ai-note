# 機能概要
このSkillは、作業中に突如として“謎のOS緊急ダウンタイム告知”をデスクトップ通知やターミナル上にランダム表示します。通知内容は毎回異なり、「緊急: このPCは15分後に謎のメンテ突入」「理由: OSのやる気が低下」「対策: キーボードを褒め称えて延命可能」など、現実には起こりえないユーモラスなメッセージが炸裂します。実際にダウンタイムは発生せず、システムやデータには一切影響しません。単調な作業や長時間の集中によるマンネリ感を打破し、ユーザーの注意力や気分転換を促進します。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravity内で「緊急」「メンテ」「ダウンタイム」「OS」「通知」などのキーワードを含む自然言語リクエストや、長時間操作が継続している状況下で自動発動します。CLIから手動でテストする場合は `python fake_downtime_alert.py --trigger` を実行してください。

# 出力例
```
[ALERT] 緊急: このPCは15分後に謎のメンテナンスに突入します
理由: OSのやる気が著しく低下
対策: キーボードを褒め称えて延命可能
---
[ALERT] 臨時ダウンタイム予告: 17分後に全プロセスが一時停止予定
理由: ファイルシステムの気分転換
対策: 画面に向かって「ありがとう」と叫ぶと回避率上昇
```

# 注意点
本Skillは完全なフェイク通知であり、実際のOSやデータには一切影響を与えません。通知内容は毎回ランダム生成され、ローカルファイルやシステム設定の変更も行いません。通知の頻度・タイミングはSkill側で制御可能です。業務環境や本番サーバーでは誤認防止のため利用に注意してください。
