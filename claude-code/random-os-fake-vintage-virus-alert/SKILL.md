# 機能概要
このSkillは、作業やコマンド実行の合間に、レトロOS時代を彷彿とさせる“謎のウイルス警告”をランダム生成・表示します。通知内容は完全なジョークで、実際のウイルスや損害は一切発生しません。真面目な作業空間に、意味不明かつ懐かしい緊張感と笑いを提供します。通知は毎回異なり、90年代・2000年代風の警告文や架空ウイルス名が登場します。

# 使い方
- 明示呼び出し例: `/random-os-fake-vintage-virus-alert` をターミナルやコマンドパレットで実行
- 暗黙発動: 「警告」「ウイルス」「感染」「セキュリティ」などのキーワードを含む会話やスクリプト実行時に自動発火

# 出力例
```
[警告] 1998年製ワーム“メロンパン”を検出。C:\WINDOWS\SUSPECT\melonpan.dll に潜伏中。
[OS公式通知] “さすらいのポリオミノ”がDドライブを徘徊しています。
[ウイルス警告] 伝説の“バナナシールド.EXE”がメモリに常駐しました。
[注意] あなたのPCに“カセットテープ型ウイルス”の痕跡が見つかりました。
[警告] “フロッピーゴースト”がAドライブを監視しています。
```

# 注意点
- 本Skillは完全なジョークであり、実際のウイルス検出やシステム操作は一切行いません
- 通知は一時的に表示され、ローカルファイルやシステムに保存されません
- 作業の妨げにならないよう、通知頻度やタイミングは制御されています
- 実在のウイルス名や特定の個人・団体を揶揄する内容は生成しません
