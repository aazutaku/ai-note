# 概要
このSkillは、実在しないデバイスやOS機能の“ライセンス期限切れ”を本格的な警告文で通知し、作業中の緊張感や遊び心を演出します。通知内容は毎回ランダム生成され、実害や副作用は一切ありません。

# 公式ドキュメント抜粋
- Python subprocess: https://docs.python.org/ja/3/library/subprocess.html
- OS通知API例: https://pypi.org/project/notifiers/

# 利用例
- 深夜のコーディングで気分転換したいとき
- チームメンバーへのちょっとしたドッキリ
- 長時間作業の合間に理不尽なスパイスを加えたい場合

# 注意点
- 本Skillは冗談・演出目的です。業務システムや本番環境での利用は推奨しません。
- 実際のシステム設定やファイルには一切影響しません。
- OSの通知APIが利用できない場合は標準出力のみとなります。

# 設計方針
- ランダム性と多様な警告文で飽きさせない設計
- 実害ゼロを徹底（ファイル書き込みや設定変更禁止）
- CLIサブコマンドで明示的な発火・例文表示・Skill概要確認が可能
