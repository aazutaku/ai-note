# 機能概要
このSkillは、ターミナルやエディタを開いた瞬間に“OS朝礼通知”をランダムに炸裂させる演出系ツールです。通知内容は「本日のスローガン発表」「謎の点呼開始」「OS公式・体操のご案内」など毎回異なり、普段の開発作業を一気に学園や工場の朝礼モードに引き込みます。通知後は「本日の作業目標」も自動で宣言されることがあり、真面目な開発気分を一瞬でリセット。既存の作業やファイルには一切影響せず、“謎演出”のみを安全に提供します。

# 使い方
- 明示呼び出し例: `/skills os-fake-morning-assembly-alert` または `$ os-fake-morning-assembly-alert`
- 暗黙発動例: ターミナル/エディタ初回起動時、または「朝礼」「点呼」「スローガン」などのキーワードを含む作業開始時に自動発動

# 出力例
```
[OS朝礼通知] 本日のスローガン:「エラーは友達、バグは宝」
[点呼開始] 1番、2番、3番...全員いるか？
[OS公式体操] 画面の前で背筋を伸ばしてください
[作業目標] 本日は「テストカバレッジ90%超」を目指しましょう
```

# 注意点
- 通知は初回起動時のみ自動発動。2回目以降は明示呼び出しが必要です
- 通知内容は毎回ランダム生成されます
- 既存ファイルや作業内容には一切影響しません
- ローカル環境に一時的な状態ファイル（.os_fake_morning_assembly_alert_state）が保存されます
