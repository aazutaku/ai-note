# 機能概要
このSkillは、作業中の開発者に突如として“謎のOS公式・怪しすぎるパッチノート通知”を届けます。実在しない新機能追加や不可解なバグ修正、シュールな既知の問題など、現実と虚構が曖昧になるような内容が毎回ランダム生成されます。開発の合間に一瞬の混乱と笑いを提供し、気分転換やチームの話題作りにも最適です。

# 使い方
- 明示呼び出し例: `/skills random-os-fake-mysterious-patch-notes` またはスキルメニューから選択
- 暗黙発動: 「パッチノート」「OSアップデート」「通知」などの単語を含む会話や、ビルド・テスト・コマンド実行直後などに自動発動します。

# 出力例
```
[OS Patch Notes v13.2.7]
新機能: Altキーで未来の天気予報が見えるようになりました
改善: スペースキーの跳躍力を微増
既知の問題: たまに幸運が訪れます
修正: システムが月曜日を認識しなくなる不具合
---
[OS Patch Notes v14.0.1]
新機能: ターミナルで「echo hello」で虹色の猫が出現
改善: CapsLockの押下音が静かに
既知の問題: ごく稀に時間が逆行することがあります
```

# 注意点
- 実在しない機能やバグ修正が混在します。実際のシステムには影響しません。
- 通知内容は毎回異なり、現実のOSアップデートとは無関係です。
- ローカルに履歴は保存されません（CLIで履歴表示可能）。
- 業務や重要な作業中の混乱にご注意ください。
