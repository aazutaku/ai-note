# 機能概要
このSkillは、Pull Requestのコメント文を自動で“忍者口調”に変換し、開発現場にユーモアをもたらします。通常のレビューコメントが「拙者思うにこの変数、影のように消してもよろしいか」「ござる…バグの術か…？」といった忍者ワールドの言い回しに変換され、堅苦しい雰囲気を一瞬で和ませます。真剣な議論の中にエンタメ要素を加え、チームのコミュニケーションを活性化します。

# 使い方
このSkillはAntigravityのsemantic-match-onlyトリガーで自動発動します。明示的な呼び出しは不要です。PRコメントの投稿・編集時に「忍者」「ござる」「拙者」「術」などのキーワードが含まれる、または忍者口調への変換リクエストが暗黙的に検知された場合に適用されます。

# 出力例
```
原文: この関数、もう少し整理できますか？
変換後: 拙者思うに、この関数、もう少し影のように整理してもよろしいかと存じまする。

原文: バグが残っているようです。
変換後: ござる…バグの術が未だ残っているように見受けられ申す。

原文: 変数名を修正してください。
変換後: 拙者より申し上げ候、変数名を修正していただければ幸いにござる。
```

# 注意点
- 原文の意味を極端に損なわないよう工夫していますが、完全な意図伝達を保証するものではありません。
- 重要な技術的議論や公式なやりとりには適しません。
- ローカルに変換履歴を保存しません。
- 除外パスや特定のコメントには適用しない場合があります。
