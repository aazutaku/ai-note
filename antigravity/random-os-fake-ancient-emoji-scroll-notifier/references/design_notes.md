# 概要
このSkillは、作業の合間やコマンド実行後に、古文調と現代顔文字・記号が混在した巻物風の通知を自動生成・表示します。エンタメや気分転換、余白の演出を目的としています。

# 公式ドキュメント抜粋
- Linux: `notify-send`はデスクトップ通知標準APIです。
- macOS: `osascript`で通知を表示できます。

# 利用例
- ターミナル作業の合間に自動でシュールな通知を挿入
- チームの雰囲気を和らげる演出
- 開発イベントやLTでの余興用途

# 注意点
- 通知内容は完全ランダム生成のため、意味不明な場合があります。
- デスクトップ通知はOS依存です。未対応環境ではターミナル出力のみ。
- ログ保存は任意指定です。

# 設計方針
- 実在APIのみ利用し、CLIから柔軟に出力先・回数・間隔・ログ保存を選択可能にしました。
- 古文調/現代顔文字/記号の混成テキストを複数パターンで生成し、毎回異なる巻物体験を保証します。
