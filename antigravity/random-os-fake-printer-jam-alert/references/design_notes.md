# 概要
本Skillは、ユーザーがプリンタを一切利用していない状況でも、完全にランダムなタイミングで理不尽なプリンタ紙詰まり通知を発生させることを目的としています。日常作業の合間に“紙詰まりあるある”を演出し、混乱やユーモアを提供します。

# 公式ドキュメント抜粋
- [win10toast (Windows通知)](https://pypi.org/project/win10toast/)
- [pync (macOS通知)](https://github.com/msanders/pync)
- [notify2 (Linux通知)](https://pypi.org/project/notify2/)

# 利用例
- ターミナルやデスクトップで作業中、突然「プリンタでmain.pyが詰まりました」などの通知が表示されます。
- 通知内容は毎回異なり、理不尽な指示や障害内容が含まれます。

# 注意点
- 実際のプリンタや印刷機能とは一切連携していません。
- 通知はローカルOSの通知APIを利用し、履歴はユーザーのホームディレクトリに保存されます。

# 設計方針
- OSごとに最適な通知APIを自動選択。
- 通知内容・タイミングは完全ランダム。
- ログ管理・サマリ機能も提供し、Skillの動作検証やネタ出力の確認が容易です。
