# 機能概要
このSkillは、作業中に突如として「謎のOS風・強制休憩通知」をデスクトップに表示します。通知内容は毎回ランダム生成され、「肩回しタイム発動」「OS推奨：5分間ぼーっとするべし」「緊急！脳内メモリ休息モード」など、意味不明かつユーモラスなメッセージが炸裂。真面目な作業現場に唐突なユーモアを注入し、一瞬だけ休憩気分を味わえます。作業効率やデータには一切影響を与えず、緊張感を和らげたい時や、リラックスした雰囲気を作りたい場面に最適です。

# 使い方
このSkillは明示的な呼び出しを必要とせず、Antigravityが「休憩」「リラックス」「集中」「疲労」などのキーワードや長時間作業の兆候を検知した際に自動発動します。ユーザー操作は不要です。

## 暗黙発動キーワード例
- そろそろ休憩しませんか？
- 集中しすぎて肩が凝ってきました
- 長時間作業しています
- 休息タイム

# 出力例
```
[OS通知] 肩回しタイム発動：今すぐ肩をぐるぐる回してください。
[OS通知] OS推奨：5分間ぼーっとするべし。
[OS通知] 緊急！脳内メモリ休息モードに移行します。
[OS通知] 画面を見つめすぎです。深呼吸しましょう。
[OS通知] システム推奨：今だけコーヒーブレイク！
```

# 注意点
- 本Skillは通知表示のみで、ファイル・設定・作業内容には一切影響しません。
- 通知履歴はローカル保存されません。
- OSの通知APIを利用するため、環境によっては通知が表示されない場合があります（Linux: notify-send, Windows: win10toast, macOS: osascript）。
- 業務用端末や通知制限環境では動作しない場合があります。
