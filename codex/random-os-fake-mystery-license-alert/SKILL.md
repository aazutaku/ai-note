# 機能概要
このSkillは、日常の作業や開発現場に突如として現れる“謎のOSライセンス期限切れ通知”を模倣します。通知内容は実在しないデバイスや機能（例：Ctrlキー、Caps Lock、NumPad、仮想RAM、システム時刻同期機能など）のライセンス失効や試用期間終了を、妙に本格的な警告文体で表示。実害やシステム変更は一切ありませんが、退屈な作業や深夜の集中タイムに、理不尽なスパイスや笑いを提供します。

# 使い方
- 明示呼び出し例: `/skills random-os-fake-mystery-license-alert` またはスキルメニューから選択。
- 暗黙発動: 「通知」「演出」「集中妨害」「OS」「ライセンス」「期限切れ」などのキーワードを含む会話やコマンド実行時に自動発動。
- バックグラウンドでランダムな間隔（5～30分程度）でも自動的に通知が表示されます。

# 出力例
```
[ALERT] OSライセンス警告: あなたのCtrlキーのライセンスは本日24:00をもって失効します。再認証を行ってください。
[WARNING] Caps Lock機能は試用期間を超過しました。継続利用には管理者権限が必要です。
[NOTICE] 仮想RAM拡張モジュールのライセンスが期限切れです。パフォーマンス低下の可能性があります。
[ALERT] システム時刻同期サービスの利用権が失効しました。手動同期を推奨します。
[WARNING] NumPadエミュレータのライセンスが本日失効しました。
```

# 注意点
- 実際のシステム設定やファイルには一切影響しません。
- 通知内容は完全に架空であり、ユーザーの作業やデータを妨害・削除することはありません。
- ローカル保存や外部送信は行いません。
- 長時間セッションでは通知頻度が高まる場合があります。
