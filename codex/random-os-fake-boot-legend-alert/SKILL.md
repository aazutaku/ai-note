# 機能概要
このSkillは、作業中に突如として「伝説のOS起動通知」をデスクトップやターミナルに表示します。通知内容は完全に意味不明かつレジェンド感満載で、「あなたはOS界の選ばれし者」や「幻のBIOSからのメッセージ」など、現実にはあり得ない謎のメッセージが炸裂します。実害はゼロですが、作業の合間に「何だこれ!?」と一瞬正気を疑わせる演出で、チームの雰囲気を和ませたり、気分転換の小ネタとして利用できます。

# 使い方
- 明示呼び出し: `/skills random-os-fake-boot-legend-alert` またはスキルメニューから選択
- 暗黙発動: 「OS」「起動」「伝説」「BIOS」「通知」などのキーワードを含む会話や、作業の合間（自動タイミング）

# 出力例
```
[伝説のOS起動通知]
本日、あなたの端末は選ばれし者として認定されました。
幻のBIOSがあなたに囁きかけています…
-- LEGENDARY BOOT SEQUENCE INITIATED --

[伝説のOS起動通知]
OS界の伝説が今、ここに蘇る。
あなたの作業環境に“神託”が降り注ぎます。
```

# 注意点
- 通知は完全に無害で、作業やファイルには影響しません。
- 通知頻度は控えめに設計されていますが、連続発動にはご注意ください。
- ローカルに通知履歴は保存されません。
- 本Skillはジョーク用途専用です。実際のシステム通知やセキュリティとは無関係です。
