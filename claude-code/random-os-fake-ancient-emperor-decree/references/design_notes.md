# 概要
このSkillは、作業環境に遊び心を加えることを目的とし、威厳と理不尽さを持つ古代皇帝風の勅令をランダムに通知します。通知は純粋な演出で、システムやファイルへの影響はありません。

# 公式ドキュメント抜粋
通知にはPythonのnotify2ライブラリを利用しています。notify2はLinuxデスクトップ環境で標準的な通知APIを提供し、クロスプラットフォーム性と安全性が高いです。

# 利用例
- ターミナル作業の合間に明示呼び出し(`/random-os-fake-ancient-emperor-decree notify`)
- 一定時間アイドル時や「通知」「皇帝」などのキーワード検出時に自動発動

# 注意点
- 通知は履歴としてローカルに保存できますが、ユーザーの操作やファイルには一切影響しません。
- セキュリティや重要なコマンド実行時は発動しない設計です。

# 設計方針
- 威厳と理不尽さを両立した文体テンプレートを複数用意し、毎回ランダム生成
- notify2が利用できない環境でも標準出力で動作
- 履歴保存・サマリ機能を提供し、ユーザーが過去の勅令を振り返れるよう設計
