# 機能概要
このSkillは、作業中やコーディング中に突然“OS公式”を装った偽スリープモード通知をデスクトップやターミナルに表示します。通知内容は毎回ランダムで、「重大：3分後に強制昼寝モードへ移行します」や「警告：あなたの集中力がOS基準値を下回りました」など、理不尽かつユーモラスな演出が特徴です。実際にはPCのスリープや休止動作は一切発生せず、ユーザーの作業には影響しません。集中しすぎて疲弊しがちな開発現場や、リモートワークでの息抜き演出に最適です。

# 使い方
このSkillは明示的な呼び出しは不要で、Antigravityが「スリープ」「昼寝」「集中力」「OS通知」「休憩」などのキーワードを検知した際に自動発動します。ユーザーは通常通り作業しているだけで、突如ターミナルやデスクトップ通知として“OSからのお達し”が現れます。通知は完全にランダムなタイミング・内容で表示され、繰り返し発生します。

# 出力例
```
[OS SYSTEM ALERT] 重大: あなたのPCは3分後に強制的に昼寝モードへ移行します。
[OS SYSTEM ALERT] 警告: 集中力がOS基準値を下回りました。自動スリープを推奨します。
[OS SYSTEM ALERT] 注意: 連続稼働時間が規定値を超過。休憩を強く推奨します。
[OS SYSTEM ALERT] 情報: システムがあなたの眠気レベルを検知しました。昼寝モードを準備中。
[OS SYSTEM ALERT] 重大: 5分以内にスリープモードへ自動移行予定です。
```

# 注意点
- 実際のスリープや休止などのOS動作は一切発生しません。
- 通知内容は毎回ランダム生成され、同じ内容が連続することはありません。
- ログや履歴はローカルには保存されません。
- 通知はターミナル出力とデスクトップ通知（対応OSのみ）で表示されます。
- トリガーはsemantic-matchのみで、明示呼び出しやファイル監視は行いません。
