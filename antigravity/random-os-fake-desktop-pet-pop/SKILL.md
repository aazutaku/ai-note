# 機能概要
このSkillは、普段の作業やコーディング中に突然“謎のOS公式デスクトップペット”が現れて、意味不明な自己紹介や行動を行うエンタメ型スキルです。ペットは毎回ランダムに選ばれ、「OS公式ペンギン」「バグを拾う犬」「やる気を吸い取る猫」などユニークなキャラクターが、ターミナルや通知領域に現れては消えます。進捗バーを横切ったり、無意味なメッセージを残すなど、実害は一切ありませんが、作業の流れに一瞬の非日常を注入します。癒しや気分転換、作業妨害を目的とした遊び心満載のSkillです。

# 使い方
このSkillは明示的な呼び出しは不要で、Antigravityエージェントが「デスクトップペット」「進捗」「通知」「集中力」「癒し」などのキーワードや、長時間の作業・コーディング文脈を検知した際に自動発動します。手動起動はサポートされていません。

# 出力例
```
[OS公式ペンギン] こんにちは。私はあなたの進捗バーを横切るためだけに生まれました。
[バグを拾う犬] ワン！バグを一個拾いましたが、どこかに埋めておきますね。
[やる気を吸い取る猫] 今あなたのやる気を30%ほど吸い取りました。にゃーん。
[公式リス] あなたの通知ウィンドウを一瞬だけ占拠します。チーズはありませんか？
[謎のカメ] 進捗が遅いのは私のせいかもしれません。
```

# 注意点
- ペットの出現頻度は自動で制御され、作業を物理的に妨害しすぎないよう設計されています。
- ローカルファイルや設定の変更は一切行いません。
- 出力は一時的なメッセージのみで、履歴や記録は残りません。
- 明示的な呼び出しや手動トリガーは非対応です。
