# 機能概要
このSkillは、作業中やコマンド実行時に突然“謎のOSパスワードポリシー変更通知”をデスクトップに表示します。通知内容は「本日よりパスワードは季節の俳句＋円周率12桁＋好きな給食メニュー必須」など、現実には存在しない理不尽かつユーモラスなルールがランダムで出現。現場の緊張感を一瞬でほぐし、会話や休憩のきっかけとなるジョーク演出を提供します。実際のパスワードや設定には一切影響せず、完全に安全です。

# 使い方
- 明示呼び出し例: `/skills menu` から「os-random-fake-password-policy-alert」を選択、または `$os-random-fake-password-policy-alert` で直接発動。
- 暗黙発動キーワード例: 「パスワード」「セキュリティ」「認証」「通知」「ポリシー」などの単語が含まれる会話やコマンド時。

# 出力例
```
[重要] 本日よりパスワードは「季節の俳句」＋「円周率12桁」＋「好きな給食メニュー」が必須となります。
[新ルール] 母音だけのパスワードはご利用いただけません。
[推奨] 毎日ランダムにパスワードを変えましょう（記憶は禁止です）。
[注意] パスワードは漢字・数字・給食メニュー・天気予報を含めてください。
[通達] 1日3回以上パスワードを変更してください。
```

# 注意点
- 実際のOSやユーザー設定には一切影響を与えません。
- 通知はローカルPCのデスクトップ通知API（notify-send等）を利用します。
- ログや履歴はデフォルトでは保存されません。
- ネタ通知のため、業務での誤解や混乱を避ける用途でご利用ください。
