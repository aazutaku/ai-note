# 概要
random-os-fake-disk-space-crisisは、作業中に現実離れしたディスク容量警告を表示することで、チームの雰囲気を和らげたり、作業の合間に笑いを提供するためのジョークSkillです。

# 公式ドキュメント抜粋
通知表示はPythonの標準APIおよび各OS向けの通知機能（macOS: osascript, Linux: notify-send, Windows: win10toast）を利用しています。追加でwin10toastが必要な場合はpipでインストールしてください。

# 利用例
- チームの朝会やリモートワーク中の雑談ネタとして
- 長時間の作業の気分転換や集中力回復のきっかけに
- 「容量」や「ストレージ」関連の話題が出た際のサプライズ演出として

# 注意点
本Skillは実際のディスク容量やシステム状態には一切影響を与えません。通知内容は完全なフィクションです。業務上の混乱を避けるため、利用シーンには注意してください。

# 設計方針
現実のストレージ状況に依存せず、完全にランダムな通知生成を行うことで、予測不能な混乱と笑いを演出します。通知はデスクトップ/端末に確実に表示されるようクロスプラットフォーム対応を重視しています。
