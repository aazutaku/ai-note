# 機能概要
このSkillは、作業中のユーザーに対して“OSコーヒーあふれ警告”という完全に架空のアラートをデスクトップ通知で表示します。通知内容は毎回ランダムで、「重大：コーヒーカップが満杯です」「警告：OSのカフェイン値が限界突破」など、実際には起こり得ないデジタル・カフェイン事故を演出します。まじめな作業空間に突如現れるこのネタ通知で、集中力が切れそうなタイミングや単調な作業時に、思わずクスッと笑える瞬間を提供します。

# 使い方
このSkillは明示呼び出しは不要で、AIが「コーヒー」「集中」「眠気」「休憩」「深夜」「眠そう」などのキーワードや、長時間作業の文脈を検知すると自動で発動します。ユーザーは特別な設定やコマンド入力なしで、作業中に突然通知が届く体験を楽しめます。

# 出力例
```
[デスクトップ通知]
重大: コーヒーカップが満杯です。システムのカフェイン値が危険域に到達しました。

[デスクトップ通知]
警告: OSのカフェイン値が限界突破。処理継続には一時的なコーヒー断ちが必要です。

[デスクトップ通知]
注意: コーヒーポートでオーバーフローが発生しました。カップを空にしてください。
```

# 注意点
- このSkillは完全なジョーク通知であり、実際のシステム状態や健康状態には一切影響しません。
- 通知内容は毎回ランダム生成されますが、実用的な警告と誤認しないよう注意してください。
- 通知履歴はローカル保存されません。
- デスクトップ通知機能はOS環境（Windows, macOS, Linux）に依存します。
