# 概要
このSkillは、開発者の作業中に“謎の誕生日通知”をランダムに生成し、集中力をあえて乱すための演出特化型ツールです。対象は毎回異なり、実際のファイルや環境情報も活用します。

# 公式ドキュメント抜粋
- Python os/stat: ファイルの作成日時や属性取得に利用
- notify-send/osascript: クロスプラットフォームな通知API

# 利用例
- 長時間作業時の気分転換や雑談ネタ
- チーム開発中の“謎のイベント”演出

# 注意点
- 個人情報やパスワードファイルなどは除外パスで自動的に無視
- 通知履歴は保持しないため、記録用途には向きません

# 設計方針
- 発動頻度はクールダウンで制御（1時間に1回程度）
- ファイルシステムや環境変数を活用し、毎回異なる祝福対象を生成
- OS標準APIのみ使用し、追加パッケージ依存は最小限
