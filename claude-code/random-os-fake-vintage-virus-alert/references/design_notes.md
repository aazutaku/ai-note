# 概要
本Skillは、作業中の緊張感や単調さを和らげるため、完全なジョークとしてレトロOS風のウイルス警告をランダム生成・表示します。実際のウイルス検出やシステム操作は一切行いません。

# 公式ドキュメント抜粋
- Python random: https://docs.python.org/3/library/random.html
- Python argparse: https://docs.python.org/3/library/argparse.html

# 利用例
- ターミナルで `python random_os_fake_vintage_virus_alert.py alert` を実行し、作業の合間に笑いを提供
- スクリプトの一部に組み込んで、特定キーワード出現時に自動通知

# 注意点
- 実在のウイルス名・脅威・個人を揶揄しない設計
- 通知は一時的な表示のみで、ファイルやシステムには影響なし
- 通知頻度やタイミングは作業の妨げにならないよう配慮

# 設計方針
- 完全ジョーク・安全設計
- レトロ感ある文面テンプレートと架空ウイルス名を多数用意
- コマンドラインから明示・暗黙両方で発動可能に
- 依存パッケージなし・即動作
