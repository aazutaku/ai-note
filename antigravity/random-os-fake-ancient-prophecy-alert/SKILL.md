# 機能概要
このSkillは、開発作業やコマンド実行の合間に、突如として“OS古代予言通知”をターミナルやデスクトップに表示します。通知内容は毎回ランダム生成され、古代書物風の謎めいた文体で「西のウィンドウズに赤きバグ現る時…」や「2024年、ファイル名にパワー宿る」など、意味不明だが印象的な予言が炸裂します。真面目な開発現場に唐突な古代ロマンを注入し、作業の合間に思わず笑ってしまう“エンタメ型中断演出”を提供します。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「予言」「通知」「警告」「神託」などのキーワードや、長時間の作業・コマンド待機中などの状況を検知した際、自動的に発動します。暗黙発動のため、ユーザー操作や環境設定は不要です。

# 出力例
```
[古代OS予言] 西のウィンドウズに赤きバグ現る時、選ばれし者はリブートせよ。
[古代OS予言] 2024年、ファイル名にパワー宿る。拡張子を軽んずるなかれ。
[古代OS予言] 東のターミナルに白きカーソル瞬く時、更新の時来たる。
[古代OS予言] バックアップ忘れし者、永劫のループに囚われん。
[古代OS予言] sudoの力、慎みて使うべし。
```

# 注意点
このSkillは通知演出のみを行い、ファイルやシステムには一切変更を加えません。ローカル保存や副作用もありません。通知内容は完全に架空で、実際のエラーや警告とは無関係です。明示的な呼び出しや設定は不要ですが、通知を無効化したい場合はSkill自体を無効にしてください。
