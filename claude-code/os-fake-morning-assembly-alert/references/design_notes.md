# 概要
このSkillは、開発者がターミナルやエディタを初回起動した際に、OS風の朝礼通知をランダム表示することで、日常作業に遊び心や非日常感を加えることを目的としています。通知内容は毎回異なり、作業開始時の気分転換やチーム内の話題作りにも活用できます。

# 公式ドキュメント抜粋
- Python subprocess: https://docs.python.org/3/library/subprocess.html
- plyer通知API: https://plyer.readthedocs.io/en/latest/

# 利用例
- 朝イチでエディタを開いた瞬間、謎のスローガンや点呼通知が画面端に表示され、職場やリモート環境で話題に。
- `/os-fake-morning-assembly-alert --force` で任意タイミングに再通知。

# 注意点
- 通知履歴はユーザーディレクトリの隠しファイルに日付単位で記録されます。
- plyerが未インストールの場合でも、OS標準の通知APIやprint出力で必ず通知内容が確認できます。
- ファイルや作業内容には一切影響を与えません。

# 設計方針
- 再現性の高いランダム通知生成と、マルチプラットフォーム動作（Windows/macOS/Linux）を重視。
- 通知内容は日本語・ユーモア重視で、毎回異なる構成となるよう工夫しています。
- 既存作業への影響を完全排除し、手軽に導入・削除できる設計です。
