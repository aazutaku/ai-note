# 機能概要
`random-os-fake-hr-training-alert`は、作業中やコマンド実行時に、現実には絶対に体験したくない“謎の人事研修”強制参加通知をOSやターミナルにランダム表示する演出系Skillです。通知内容は毎回ランダム生成され、「本日14時より“謎のパワポ芸入門”研修必須」「OS公式“無限ビデオ視聴”研修が始まります」など、カオスな人事イベントが次々降ってきます。現実逃避と笑いを同時に提供し、作業の合間にユーモアをもたらします。

# 使い方
- 明示呼び出し: `/random-os-fake-hr-training-alert` をターミナルやSkillコマンドとして実行
- 暗黙発動: 「通知」「研修」「人事」「アラート」などのキーワードを含むコマンドや会話を検出時、自動でランダム通知が表示されます

# 出力例
```
[ALERT] 緊急：本日15:00より“謎のパワポ芸入門”人事研修に強制参加してください。
[NOTICE] 重要：OS公式“無限ビデオ視聴”研修が30分後に開始されます。
[WARNING] 今すぐ“謎マナー講座”を受講してください。
[MANDATORY] 本日中に“仮想空間での正しい座り方”研修を完了せよ。
[REMINDER] “OS人事主催：謎のチームビルディング”研修が間もなく始まります。
```

# 注意点
- 実データやファイル、システムには一切影響しません（完全な演出専用）
- 通知内容はすべて架空であり、現実の人事制度・研修とは無関係です
- ローカル保存や履歴記録は行いません
- 一部OSの通知API制約により、ターミナル上のみの表示となる場合があります
