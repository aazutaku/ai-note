# 機能概要
このSkillは、作業中のユーザーに対し「謎のOSディスク残量危機通知」をランダムに炸裂させるジョーク演出ツールです。現実離れした比喩や意味不明な単位（例：「カブトムシ2匹分」「ギャラクシー級に不足」）で、実際のディスク容量とは無関係なアラートを生成し、端末やデスクトップに通知します。ユーザーの正気度を試す“混乱と笑い”のためのSkillであり、実害やシステム操作は一切行いません。

# 使い方
- 明示呼び出し例:
  - `/skills menu` から選択
  - `$random-os-fake-disk-space-crisis` メンション
- 暗黙発動キーワード例:
  - 「ディスク」「disk」「容量」「空き」「警告」「残量」「危機」「alert disk」などを含む発話時

# 出力例
```
警告: あなたのディスク残量は“カブトムシ2匹分”です。至急ご確認ください。
緊急: SSDの空きが“ギャラクシー級に不足”しています。宇宙的対策が必要です。
注意: 残り容量は“ラーメンどんぶり0.5杯”分です。お腹が空きます。
警告: ディスクスペースが“時空間のひずみ”レベルで不足中。
アラート: 空きディスク容量が“18世紀の蒸気機関車1両分”です。
```

# 注意点
- 本Skillは実際のディスク容量取得やシステム操作を一切行いません。
- 通知内容は完全にランダム生成され、現実のストレージ状況とは無関係です。
- ローカルに情報を保存したり、履歴を残すことはありません。
- 一部環境ではデスクトップ通知が表示されない場合があります。
