# 概要
random-os-breakup-notifierは、ユーザーの作業中にシュールな“デジタル失恋”通知を発生させることで、気分転換やリフレッシュを促すジョーク系スキルです。通知内容は固定リストからランダム選択され、各OSの標準通知APIを使用して実際にポップアップ表示されます。

# 公式ドキュメント抜粋
- macOS: osascript (AppleScript) による通知表示
- Linux: notify-send コマンド
- Windows: win10toast ライブラリ、または PowerShell の MessageBox

# 利用例
- 長時間のコーディングや単調作業の合間に、突発的な通知で場を和ませる
- チームのSlackや画面共有時に話題作りとして

# 注意点
- 通知履歴はホームディレクトリ直下の .random_os_breakup_history.log に保存されますが、個人情報や他のファイルには一切影響しません
- 一部のLinux環境やWSLではnotify-sendが利用できない場合があります
- Windowsではwin10toastのインストールが推奨されます

# 設計方針
- シンプルな構成でOS依存性を最小限に
- ユーザー体験を損なわず、作業の妨げにならない通知頻度をデフォルト設定
- ジョーク通知の内容は随時追加・編集可能な設計
