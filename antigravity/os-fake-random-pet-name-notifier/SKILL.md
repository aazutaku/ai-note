# 機能概要
このSkillは、あなたの作業中に突如“謎のOS公式・ペット命名通知”をデスクトップやターミナルに表示します。通知内容は毎回ランダムで、マウスやキーボードなどの周辺機器に意味不明な二つ名や称号が付与される理不尽なイベントを演出します。実用性は皆無ですが、作業空間にカオスとユーモアをもたらし、集中力を根こそぎ奪うことが目的です。

# 使い方
このSkillは明示的な呼び出しを必要とせず、「通知」「OS」「ペット」「命名」などのキーワードや、作業が一定時間アイドル状態になるなどのセマンティック条件で自動発動します。手動でのCLI呼び出し例:

```
python notifier.py --notify-now
```

暗黙発動キーワード例: 「OS通知」「ペット名」「作業中」「ランダム演出」

# 出力例
```
[OS通知] あなたのマウスは本日より“疾風のコロンブス”と命名されました。
[OS通知] キーボードの新しい名は“静寂なる鉄槌”です。
[OS通知] ディスプレイは“虚空の監視者”と呼ばれることになりました。
[OS通知] あなたのUSBメモリは“迷宮の案内人”です。
[OS通知] スピーカーの名は“響鳴の咆哮”です。
```

# 注意点
- 本Skillは実用性が一切なく、作業やデータには影響しません。
- 通知内容は完全にランダムで、ローカルには保存されません。
- 一部OSではデスクトップ通知が表示されない場合があります。
- 除外パス: システム設定や重要な作業中のアプリケーションでは発動しません。
