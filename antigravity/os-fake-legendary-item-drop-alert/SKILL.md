# 機能概要
このSkillは、作業中に突如「伝説のOSアイテムドロップ通知」をデスクトップやターミナルに表示します。通知内容は毎回ランダム生成され、「伝説のスペースキー+5」「謎のUSBメモリ（未鑑定）」「古代のタブキー（発掘済）」など完全に意味不明なアイテム名が出現。実用性はゼロですが、思わず笑ってしまう謎演出で作業の合間にちょっとした気分転換やリフレッシュを提供します。現実世界の『ガチャ運』をデスクトップに召喚し、作業の集中力を微妙に乱す唯一無二のスキルです。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「長時間作業」「集中力低下」「気分転換」などのキーワードや状況を検知した際に自動発動します。トリガー例としては「集中している」「疲れてきた」「ちょっと休憩したい」など。通知はデスクトップ通知（Windows/macOS/Linux）やターミナル出力として表示されます。

# 出力例
```
[伝説アイテムドロップ通知]
アイテム: 謎のUSBメモリ（未鑑定）
レア度: ★★★★☆
効果: 使うと何かが起こる気がする

[伝説アイテムドロップ通知]
アイテム: 古代のタブキー（発掘済）
レア度: ★★★☆☆
効果: コード整形力+2

[伝説アイテムドロップ通知]
アイテム: 伝説のスペースキー+5
レア度: ★★★★★
効果: 空白挿入速度が超絶UP
```

# 注意点
- 実在するOSやファイルには一切影響を与えません。
- 通知頻度は自動調整され、連続発生や過度な作業妨害はありません。
- ローカルにアイテム履歴などは保存されません。
- デスクトップ通知はOS標準APIのみを利用し、追加権限は不要です。
