# 機能概要
このSkillは、現代の開発現場に突如として“古代文学の風”を吹き込むユニークな通知スキルです。ユーザーの作業中や特定のキーワード（例：通知、詩、古文、息抜き）を検知した際に、完全ランダムな古文調・詩体の謎ポエムをデスクトップやターミナルに通知します。内容は作業内容やエラーとは一切無関係で、集中力を絶妙にそらしつつ、知的混乱と笑いを提供します。日常のコーディングに新たな刺激と遊び心をもたらします。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「通知」「詩」「古文」「息抜き」などの発話や、作業中の一定時間経過を検知した際に自動で発動します。暗黙発動キーワード例：
- 「ちょっと息抜きしたい」
- 「通知を表示して」
- 「詩的な一言を」

# 出力例
```
[OS古代詩通知]
西のコードベースにバグの風そよぐ
あなたのShiftキー、今宵は静かに眠るべし
朝霧のメモリ、解放されぬまま
デバッグの道、遠く霞みて

[OS古代詩通知]
コンパイルの鐘、虚空に響く
エラーの渦巻、心を惑わす

[OS古代詩通知]
ファイルの彼方、未保存の夢
```

# 注意点
- 通知内容は完全にランダムであり、実際のシステム状態や作業内容とは一切関係ありません。
- 本Skillは既存のシステム通知や作業ファイルを変更・破壊しません。
- ローカルに通知履歴は保存されません。
- デスクトップ通知はOS標準API（notify-send, osascript, win10toast等）を利用します。
