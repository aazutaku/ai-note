# 機能概要
このSkillは、あなたの作業環境に突如として“謎のOS侍”からの時代錯誤な通知を送り込みます。通知内容は毎回ランダム生成され、「拙者、Altキーの抜刀訓練状況を監視しておる」や「油断大敵、マウスの居合切りに注意せよ」など、現代人には意味不明な侍語録が炸裂。単調なデジタル作業に斬新な刺激とユーモアをもたらし、集中力をリフレッシュします。通知はデスクトップ（OS通知API）とターミナルの両方で表示され、実害ゼロで安全です。

# 使い方
- 明示呼び出し: `/random-os-fake-ancient-samurai-alert`
- 暗黙発動: 「侍」「通知」「集中力」などのキーワードを含む会話やコマンド実行時に自動発動
- OSに応じてデスクトップ通知（Windows/macOS/Linux）またはターミナル出力

# 出力例
```
[OS侍のお達し]
拙者、Altキーの抜刀訓練状況を監視しておる。

[OS侍のお達し]
油断大敵、マウスの居合切りに注意せよ。

[OS侍のお達し]
今宵もCtrl+Cの奥義を磨くべし。

[OS侍のお達し]
タスク切り替え、まるで手裏剣のごとし。
```

# 注意点
- 実害ゼロ（データ損失・システム設定変更なし）
- 通知内容は毎回ランダム生成で飽きさせません
- ローカルファイルや履歴保存は行いません
- 通知API利用のため、環境によっては追加パッケージ（`plyer`等）が必要です
