# 概要
このSkillは、ユーザーのデスクトップ環境に「OS再起動カウントダウン」風のフェイク通知を表示し、実際の再起動やシステム操作は一切行いません。演出のリアリティと安全性を両立させる設計です。

# 公式ドキュメント抜粋
- plyer: https://github.com/kivy/plyer
- tkinter: https://docs.python.org/ja/3/library/tkinter.html

# 利用例
- 職場での軽いドッキリ
- チームのアイスブレイク
- 自分への気分転換や集中リセット

# 注意点
- システム通知APIは環境依存のため、仮想環境やリモートデスクトップではGUI表示が制限される場合があります。
- 本Skillは通知表示のみで、ファイル書き込みやネットワーク送信は行いません。

# 設計方針
- plyerとtkinterの両対応で、環境に応じて最適な通知方法を自動選択
- カウントダウン終了時は必ず「ジョークです」と明示
- CLIオプションで理由や秒数、GUI/非GUIを柔軟に切替可能
- 100%安全なジョーク用途のみ
