# 機能概要
このSkillは、作業中やコマンド実行の合間に、架空の“OS公式サウンドトラック通知”をデスクトップに表示します。通知は「本日のテーマソング：『バグ修羅場行進曲』」や「今こそ流せ！『納期デッドヒート』」など、完全オリジナルかつ開発現場ネタ満載の曲名で構成され、実際に音は流れません。作業の緊張感をシュールに和らげ、静寂を破るジョーク通知として、気分転換やチームの話題作りに最適です。

# 使い方
このSkillは明示的な呼び出しは不要で、Antigravityが「作業開始」「コマンド実行」「長時間無操作」などのタイミングを検知し、自動的に発動します。暗黙発動キーワード例: `通知`, `BGM`, `OS演出`, `サウンドトラック`, `作業中` など。

# 出力例
```terminal
[通知] 本日のテーマソング：『バグ修羅場行進曲』
[通知] 今こそ流せ！『納期デッドヒート』
[通知] 推奨BGM：『コミット地獄ロンド』
[通知] システム推奨本日BGM：『マージ衝突アダージョ』
[通知] 本日のおすすめ：『デバッグ迷宮組曲』
[通知] 今流すべき一曲：『仕様書未読ブルース』
```

# 注意点
- 通知内容は毎回異なりますが、実際に音やBGMは流れません。
- 通知の頻度は自動制御され、作業の妨げにならないよう配慮されています。
- ローカルに通知履歴や曲名リストは保存されません。
- 本Skillは通知・演出用途のみで、業務用途のアラートとは異なります。
