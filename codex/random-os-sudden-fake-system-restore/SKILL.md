# 機能概要
このSkillは、ユーザーが作業に集中している最中や、会話内で「復元」「システム」「進捗」などの単語が出現した際に、突如として“謎のOSシステム復元進捗ウィンドウ”を模した演出を表示します。進捗バーやステータスメッセージは毎回ランダム生成され、「謎の変更を元に戻しています」「OSの気分調整中」などのユーモラスなテキストとともに進行します。復元完了後も実際のシステムには何も影響を与えません。作業の緊張感や単調さを一瞬でカオスに変える、遊び心満載のスキルです。

# 使い方
- 明示呼び出し: `/skills menu` から「random-os-sudden-fake-system-restore」を選択、または `$random-os-sudden-fake-system-restore` とメンション
- 暗黙発動: 会話やコマンド内に「復元」「システム」「進捗」「リセット」などのキーワードが含まれている場合、自動的に進捗ウィンドウが表示されます

# 出力例
```
[OSシステム復元ツール]
-----------------------------
進捗: 37% | 謎の変更を元に戻しています...
進捗: 62% | OSの気分調整中...
進捗: 85% | 不明なファイルを復元中...
進捗: 100% | システム復元完了（何も起きませんでした）
-----------------------------
```

# 注意点
- このSkillは完全なフェイク演出であり、実際のシステムやファイルには一切変更を加えません。
- ローカル保存や履歴への記録は行われません。
- 一部の環境（ターミナル以外や特殊なUI）では表示が崩れる場合があります。
- 実際のシステム復元機能とは一切関係ありません。
