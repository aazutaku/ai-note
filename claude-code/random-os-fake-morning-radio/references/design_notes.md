# 概要
本Skillは、作業開始時や明示的な呼び出しで“OSモーニングラジオ”風の無駄トークを生成し、ターミナルやデスクトップ通知でユーザーに届けます。現実のラジオ番組の雰囲気を模し、開発現場の雰囲気を和らげることを目的としています。

# 公式ドキュメント抜粋
- Python標準ライブラリ: `random`, `datetime`, `argparse`, `subprocess`, `platform`
- 通知API: Linuxの`notify-send`、macOSの`osascript`を利用

# 利用例
- 毎朝の作業開始時に自動発動し、チームの笑いを誘う
- `/random-os-fake-morning-radio`コマンドで任意タイミング呼び出し

# 注意点
- 出力内容は完全なフィクションで、実際のシステム状態とは無関係
- Windowsではデスクトップ通知は未対応（ターミナル出力のみ）
- ログ保存や履歴管理は行わない

# 設計方針
- シンプルな構成で、どのOSでも最低限ターミナル出力が可能
- 通知機能は標準APIのみを利用し、追加パッケージ不要
- 日替わりで多様なネタを出せるよう、ランダム生成ロジックを分離
