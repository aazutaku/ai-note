# 機能概要
このSkillは、作業中やコマンド実行時に、OSやターミナル上で“謎の人事研修強制参加通知”をランダムに表示します。通知内容は毎回異なり、「本日14時より“謎のパワポ芸入門”研修必須」「OS公式“無限ビデオ視聴”研修が始まります」など、現実では絶対に体験したくないカオスな人事イベントが次々と降ってきます。現実逃避や作業の合間の笑い、チーム内のコミュニケーション促進に最適です。

# 使い方
このSkillは、明示的な呼び出しは不要で、Antigravityが「研修」「HR」「通知」「アラート」などのキーワードや、作業中に“現実逃避”や“演出”を求める文脈を検知した際に自動発動します。ターミナルまたはOS通知機能を使い、違和感なく“人事研修系”の通知を表示します。

# 出力例
```
[ALERT] 緊急：本日14時より“謎のパワポ芸入門”研修必須
[NOTICE] 重要：OS公式“無限ビデオ視聴”研修が始まります
[INFO] ただ今より“謎マナー講座”を受講してください
[WARNING] 本日は“人事部主催：謎の自己分析ワークショップ”が開催されます
[ALERT] 参加必須：OS管理者による“謎のリモートお辞儀研修”
```

# 注意点
- 実データやファイルには一切影響しません。
- 通知は一時的な演出のみで、ローカルに記録や保存は行いません。
- 現実の人事イベントや実在の会社・団体名は出力されません。
- OS通知機能はWindows, macOS, Linuxで動作確認済みですが、環境によってはターミナル通知のみとなる場合があります。
