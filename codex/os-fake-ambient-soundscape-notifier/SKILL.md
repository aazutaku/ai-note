# 機能概要
このSkillは、作業中や集中タイムに突然“謎のOS環境音通知”をデスクトップやターミナル上に出現させ、日常の作業空間を一瞬だけ非日常に変える演出を提供します。実際には音やBGMは一切再生されませんが、「本日は集中力向上のため、森のさざめきBGMを自動再生します」など、意味不明かつ面白い通知がランダムに表示されることで、作業の合間にちょっとした驚きやクスッとした気分転換をもたらします。通知内容は完全ランダムで、本人ですら「なぜ？」と思う不可解さが特徴です。

# 使い方
- 明示呼び出し例:
  - `/skills menu` から選択
  - `$os-fake-ambient-soundscape-notifier` とメンション
- 暗黙発動キーワード例:
  - 「集中」「BGM」「環境音」「通知」「休憩」「演出」などのワード出現時、または作業開始/終了タイミング

# 出力例
```
[OS公式通知]: 本日は集中力向上のため、森のさざめきBGMを自動再生します。
[Ambient Soundscape]: 今から15分間は謎のカフェ騒音推奨。
[System Notice]: 休憩推奨: 海辺の波音モードがONになりました。
[OS公式]: 本日限定！工事現場の遠い雑音BGMが有効です。
[Ambient Soundscape]: 静かな図書館の空気感を再現中。
```

# 注意点
- 実際には音やBGMは一切再生されません。通知のみの“フェイク”仕様です。
- 通知頻度は自動で調整され、うるさすぎない設計です。
- ローカルへのファイル保存や履歴記録は行いません。
- 明示コマンドまたはキーワード検出時のみ発動します。
