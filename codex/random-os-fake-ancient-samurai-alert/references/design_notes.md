# 概要
このSkillは、作業中に突如“侍ネタ”の警告を表示することで、集中力のリセットや気分転換を促します。通知内容は毎回ランダムで、現代的なOS操作と侍風の言い回しを組み合わせたユーモアを重視しています。

# 公式ドキュメント抜粋
- Python 標準 `subprocess`, `os`, `platform` モジュールを利用し、各OSの通知API（macOS: osascript, Linux: notify-send, Windows: PowerShell Toast）を直接呼び出します。
- 参考: https://docs.python.org/3/library/subprocess.html

# 利用例
- `/skills menu` から明示的に呼び出し
- 長時間作業や「侍」「alert」などのキーワード検知時に自動発動
- チームの雑談ネタや集中力のリフレッシュに

# 注意点
- メッセージ内容は完全に無害で、データやシステムには一切影響しません
- 通知履歴やログは残りません
- OS通知が失敗した場合はターミナル出力にフォールバックします

# 設計方針
- 実在APIのみを利用し、CLI/ターミナル/デスクトップのどれでも確実に動作すること
- メッセージは随時追加・編集可能な設計
- エラー時も安全に終了する堅牢性を確保
