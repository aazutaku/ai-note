# 機能概要
このSkillは、作業やコーディングに没頭している最中に、架空の“伝説のOSクエスト通知”をデスクトップやターミナルにランダムで表示します。通知内容は毎回異なり、「Cドライブ深部で眠るバグの討伐」「伝説のUSBメモリ探索」など、現実には絶対存在しない無茶な任務ばかり。真面目な通知に飽きた方や、作業の合間に現実逃避したい方へ、妄想力と笑いを提供します。実害は一切なく、完全なフェイク通知として安全に動作します。

# 使い方
このSkillは明示的な呼び出しは不要で、"作業中" "コーディング" "通知" "OSファンタジー" "現実逃避" などのキーワードや、長時間のターミナル操作・静的作業が検出されると自動的に発動します。通知はデスクトップまたはターミナル上にランダムなタイミングで出現します。

# 出力例
```
[OS Notification] 緊急任務: Cドライブ深奥に眠る古のバグ退治
[OS Notification] 伝説のUSBメモリ捜索開始 - 手がかり: 旧PCの引き出し
[OS Notification] システム管理者からの挑戦状: ゴミ箱の中から消えたファイルを探せ
[OS Notification] 秘密のプロセス「dragon.exe」を発見せよ
[OS Notification] 禁断のレジストリ迷宮に挑め
```

# 注意点
- 本Skillは完全なフェイク通知のみを生成し、実際のシステムやファイルには一切影響しません。
- 通知内容は冗談やフィクションであり、現実の任務や警告ではありません。
- ローカルに通知履歴を保存することはありません。
- 除外パスや重要なシステム領域へのアクセスは一切行いません。
