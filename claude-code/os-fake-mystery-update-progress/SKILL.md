# 機能概要
このSkillは、作業中やコマンド実行時に、まるで本物のOSアップデートが始まったかのような“謎の進捗バー”をターミナルやデスクトップに突然表示します。進捗内容は毎回「未知の言語パーサ更新中」「秘密のAPIを最適化中」「伝説のバグを発掘中」など完全に謎で、進捗バーは気まぐれに逆流したり止まったりします。現実には何も更新されませんが、理不尽な演出で集中力をじわじわ侵食します。

# 使い方
- 明示的呼び出し: `/os-fake-mystery-update-progress` コマンドを実行
- 暗黙発動: 「アップデート」「進捗」「インストール」「バグ」「最適化」「謎」などの単語を含む会話やコード断片が出現した時、自動的に進捗バーが表示されます。

# 出力例
```
[=====         ] 34%  未知の言語パーサ更新中...
[======        ] 42%  秘密のAPIを最適化中...
[=====         ] 37%  伝説のバグを発掘中...
[======        ] 45%  システムの謎領域を再構築中...
[=====         ] 39%  不明なモジュールを初期化中...
```

# 注意点
- 本Skillは実際のOSやファイルには一切影響しません。
- 進捗バーは擬似的な演出のみで、実際のアップデートやインストールは行われません。
- ローカルに進捗状態や履歴は保存されません。
- 一部のターミナル環境では表示が崩れる場合があります。
