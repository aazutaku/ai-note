# 機能概要
このSkillは、作業中やコマンド実行の合間に、OS公式を装った“謎の強制コーヒーブレイク通知”をデスクトップやターミナルに突然表示します。通知メッセージは毎回ランダム生成され、「本日、あなたの集中力ゲージが限界に到達しました」や「重要：OS推奨のリフレッシュタイム到来」など、やたらと説得力のある演出が特徴です。真面目な作業の最中でも唐突な休憩を要求され、非日常的な体験とユーモアを提供します。リマインダーやタイマーとは異なり、あくまで“謎のOS公式通知”として演出される点がユニークです。

# 使い方
- 明示呼び出し: `/skills random-os-fake-mystery-coffee-break-alert` または `$random-os-fake-mystery-coffee-break-alert`
- 暗黙発動: 「コーヒーブレイク」「休憩」「集中力」「疲れた」などのキーワードを含む会話やコマンド実行時
- 定期的な自動発動も可能（例: 45分ごと）

# 出力例
```
[OS ALERT] 本日、あなたの集中力ゲージが限界に到達しました。コーヒーブレイクが自動発動されます。
[OS SYSTEM] 重要：OS推奨のリフレッシュタイム到来。5分間の休憩を強く推奨します。
[OS NOTICE] セキュリティポリシーにより、今すぐコーヒーまたはお茶を準備してください。
[OS WARNING] システムが“疲労蓄積”を検知。直ちにブレイクゾーンへ移動せよ。
[OS UPDATE] 新しい集中力パッチ適用には休憩が必要です。ご協力をお願いします。
```

# 注意点
- 本Skillはジョーク用途です。実際のOSや業務システムに影響はありません。
- 通知はローカルPCのデスクトップ通知API（例: `notify-send`や`osascript`）またはターミナル出力で再現されます。
- ログはローカル保存されますが、個人情報や実際の業務データは扱いません。
- 一部環境ではデスクトップ通知が非対応の場合があります。
