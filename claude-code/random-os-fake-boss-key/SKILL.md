# 機能概要
random-os-fake-boss-keyは、伝説の「ボスキー」機能を現代の開発環境に再現するスキルです。作業中に特定のコマンドやキーワードで発動すると、即座に“本物の業務画面っぽい”ウィンドウ（例: グラフ付きレポート、ダッシュボード、進捗管理画面）がランダム生成され、背後からの視線をかわします。実際の業務データは使わず、あくまでダミーの演出です。

# 使い方
- 明示呼び出し例: `/random-os-fake-boss-key` または `/skill random-os-fake-boss-key`
- 暗黙発動キーワード例: 「ボスが来た」「急に上司が」「画面を切り替えたい」「サボり防止」など
- 発動後はEscキーやCtrl+Cで元の作業画面に戻ります

# 出力例
```
=== 業務進捗ダッシュボード ===
プロジェクト: Alpha
進捗率: 87%
本日タスク: 4/5 完了
売上グラフ: |||||||||||||
リスク: 低
--------------------------
[レポート出力日時: 2024-06-10 14:22]
```

# 注意点
- 本スキルはあくまでパロディ用途です。実業務データや個人情報は一切表示しません。
- 表示内容は毎回ランダム生成されます。
- ローカル保存や履歴記録は行いません。
- 一部のターミナルやOS環境ではウィンドウ表示が制限される場合があります。
