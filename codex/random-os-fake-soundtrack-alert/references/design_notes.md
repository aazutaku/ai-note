# 概要
このSkillは、OS通知APIを用いて作業中に架空のサウンドトラック名を表示し、作業の緊張感を和らげるジョーク演出を提供します。通知内容は毎回ランダム生成され、実際の音楽再生は行いません。

# 公式ドキュメント抜粋
通知にはPythonの`plyer.notification`（https://github.com/kivy/plyer）を利用し、クロスプラットフォームでのデスクトップ通知を実現しています。通知が使えない場合は標準出力にフォールバックします。

# 利用例
- コマンド実行やビルド、コミット時に自動で発動
- `/skills menu`や`random-os-fake-soundtrack-alert log`コマンドで明示呼び出し

# 注意点
- 通知頻度は1分に1回までに制限されます
- ログはホームディレクトリ配下の隠しファイルに保存されます

# 設計方針
- 曲名・副題は開発現場のネタを中心に数十種類を用意し、組み合わせで毎回異なる通知を生成
- 履歴や統計もCLIで参照可能にし、通知内容の多様性と楽しさを重視
