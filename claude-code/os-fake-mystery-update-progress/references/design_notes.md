# 概要
このSkillは、実際の処理やアップデートを一切行わず、純粋に理不尽な“謎の進捗バー”演出だけを目的としています。進捗バーの動きや文言は完全にランダムで、ユーザーの集中力や現実感を攪乱することを狙っています。

# 公式ドキュメント抜粋
- Python randomモジュール: https://docs.python.org/3/library/random.html
- argparse: https://docs.python.org/3/library/argparse.html

# 利用例
- チーム内のジョークや、作業の合間の気分転換に。
- コマンドラインや自動化スクリプトの“おふざけ”要素として。

# 注意点
- 本Skillは完全な演出専用であり、実際のOSやファイルには一切影響しません。
- 進捗バーの履歴や状態は保存されません。
- 一部のターミナルや環境では進捗バーの描画が崩れる場合があります。

# 設計方針
- 進捗バーは「進む」「逆流」「停止」の3状態をランダムに遷移。
- メッセージも20種類以上をランダムで切り替え、毎回異なる体験を演出。
- コマンドラインからの明示呼び出しと、会話・コード内キーワードでの暗黙発動を両立。
