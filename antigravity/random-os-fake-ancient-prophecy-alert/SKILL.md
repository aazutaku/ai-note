# 機能概要
このSkillは、開発作業中やコマンド実行の合間に、まるでOS公式から届くかのような“古代預言”風の通知をデスクトップやターミナルにランダムで表示します。内容は毎回異なり、「西のバイナリ荒野に未踏の関数現る」や「南のコード砂漠に巨大バグの影動く」など、意味深かつ一切実用性のないメッセージが降り注ぎます。日常的な開発現場に非日常感をもたらし、気分転換やチームの話題作りに最適です。

# 使い方
このSkillは明示的な呼び出しは不要で、Antigravityのsemantic-match-onlyトリガーにより自動発動します。"預言"、"通知"、"未来"、"警告"といったキーワードや、一定時間のアイドル状態、コマンド実行直後などのタイミングで、OSの通知機能を使ってランダムな預言が表示されます。設定不要で即利用可能です。

# 出力例
```
[OS Ancient Prophecy Alert]
北のリポジトリに伝説のレビュアー現る

[OS Ancient Prophecy Alert]
東のCI/CD神殿に未解決のPRが眠る

[OS Ancient Prophecy Alert]
西のバイナリ荒野に未踏の関数現る

[OS Ancient Prophecy Alert]
南のコード砂漠に巨大バグの影動く
```

# 注意点
・本Skillは完全なネタ枠であり、業務上の実用性はありません。
・通知内容は毎回ランダム生成され、保存・記録は行われません。
・通知はOSの標準通知APIを利用し、他の通知や作業への干渉はありません。
・一部の環境では通知が表示されない場合があります（Linuxではlibnotify等が必要）。
