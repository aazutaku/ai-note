# 概要
このSkillは、現代の作業環境に突如“侍”の世界観を持ち込むことで、ユーザーの集中力をリフレッシュし、単調な作業に遊び心と刺激を与えることを目的としています。実害ゼロ、完全ランダムな通知演出が特徴です。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonの`plyer`ライブラリを利用。`plyer`はクロスプラットフォームでOS標準の通知APIをラップしており、Windows/macOS/Linuxで動作します。

# 利用例
- 明示的に`python samurai_alert.py alert`で通知を発動
- `python samurai_alert.py alert --count 3`で3連続通知
- `python samurai_alert.py list`で全メッセージ確認

# 注意点
- plyerが未インストールの場合は、OSごとのネイティブコマンドまたはターミナル出力に自動フォールバック
- 通知内容はローカル保存されません
- システム設定やファイルへの影響はありません

# 設計方針
- ユーザー体験の安全性と遊び心を重視
- メッセージは都度ランダム生成、飽きさせない
- CLI/スクリプト両対応で柔軟な導入が可能
