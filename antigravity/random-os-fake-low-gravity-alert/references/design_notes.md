# 概要
本Skillは、ユーザーの作業空間に非日常的な「低重力モード」通知をランダムに表示し、集中力のリセットや気分転換を促す演出を目的としています。通知内容は完全ランダム生成で、実際のOSやファイル操作には一切影響を与えません。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonのnotify2ライブラリを利用しています。詳細は https://pypi.org/project/notify2/ を参照してください。

# 利用例
- 長時間作業時に自動で低重力通知を表示し、ユーザーにリフレッシュを促す
- ターミナルから `python low_gravity_alert.py alert` で手動発動も可能

# 注意点
- 通知は演出目的のみで、システム挙動やデータには影響なし
- 一部環境ではnotify2が動作しない場合、ターミナル出力にフォールバック
- ログはホームディレクトリの `.low_gravity_alert_history` に保存

# 設計方針
ユーザーの作業を妨げず、適度な頻度で非日常感を演出することを重視。通知内容の多様性と安全性を確保し、実データやシステムに一切副作用を与えない設計としています。
