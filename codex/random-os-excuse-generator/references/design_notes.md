# 概要
random-os-excuse-generatorは、開発現場のストレス緩和やチームの雰囲気改善を目的としたジョーク系Skillです。エラーやバグ発生時に、科学的根拠のないユーモラスな言い訳を自動生成し、通知またはターミナルに出力します。

# 公式ドキュメント抜粋
デスクトップ通知はPythonのplyerライブラリ（https://github.com/kivy/plyer）を利用。plyerが未インストールの場合は標準出力にフォールバックします。ログはユーザーディレクトリ配下にテキストで記録されます。

# 利用例
- バグ報告時の緊張緩和
- チームの朝会や進捗報告でのアイスブレイク
- 開発現場の雑談ネタ

# 注意点
Skillは通知・表示のみで、ファイルやシステム設定への変更は一切行いません。本番データや業務フローへの影響はありません。

# 設計方針
- OS/環境依存を最小化し、通知非対応時は必ず標準出力に切り替え
- 言い訳パターンは今後も拡張可能
- ログや集計機能で利用状況を可視化
