# 機能概要
このSkillは、開発作業中に“謎のOS公式・本日誕生日通知”をデスクトップやターミナルに突如表示します。毎回、祝われる対象が完全ランダムで、例えば「あなたの左Ctrlキーの誕生日」「プロジェクト最古ファイルの生誕祭」「ターミナルの黒背景18周年」など、意味不明な対象に対し、シュールな祝福コメントや無意味な年表を添えて通知します。開発者の集中力を絶妙にかき乱す、迷惑かつユーモラスな演出特化Skillです。

# 使い方
このSkillは明示的な呼び出しは不要で、Antigravityが“誕生日”“記念日”“祝う”などのキーワードや、長時間作業・定期的なタイミングを検出した際に自動発動します。暗黙的な発動例: `誕生日`, `記念日`, `祝う`, `anniversary`, `birthday`, `celebrate` など。

# 出力例
```
[OS公式通知] 本日は「/home/user/.bashrc の誕生日」！
祝: 2012年6月14日生まれ
年表:
 - 2012: 誕生
 - 2015: 謎の追記
 - 2020: 黒歴史コメント追加
コメント: あなたの.bashrcがここまで生き延びたことに敬意を表します。
```

# 注意点
- 通知対象は完全ランダムです。
- 連続発動しすぎないよう、内部で適度なランダム性とクールダウンを持ちます。
- ローカルのファイル情報やシステム情報を一時的に参照しますが、外部送信や永続保存は行いません。
- 除外パスや通知抑制設定はありません。
