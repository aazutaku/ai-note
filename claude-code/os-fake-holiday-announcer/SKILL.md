# 機能概要
このSkillは、日々の開発や作業に追われるエンジニアのために、架空の“OS公式休日”をデスクトップ通知で突然お知らせします。通知内容は「本日はバグ記念日につき全業務停止」「緊急：OSが自主休暇を宣言しました」など、現実には存在しないユーモラスな休暇宣言。作業の合間に一瞬の現実逃避や笑いを提供し、マンネリ化したルーチン作業に意外性と遊び心を加えます。

# 使い方
- 明示呼び出し: `/os-fake-holiday-announcer` を実行すると即座に通知が表示されます。
- 暗黙発動: 「疲れた」「休みたい」「集中力が切れた」などのキーワードが会話やログに現れると自動発動します。
- 通知は1時間に1回以下の頻度で表示され、過剰な割り込みを防ぎます。

# 出力例
```
[通知] 本日は「バグ記念日」につき、全業務停止となります。ご理解のほどお願いいたします。
[通知] 緊急：OSが自主休暇を宣言しました。全プロセスはしばらくお休みします。
[通知] システム都合により午後は強制昼寝タイムです。
[通知] 本日は「メモリ解放記念日」。作業は後回しにしましょう。
[通知] OS公式：今日は再起動推奨日。全員で休憩しましょう。
```

# 注意点
- 通知はデスクトップ上に表示されるのみで、実際の作業やファイルには一切影響しません。
- ログや履歴はローカルに保存されますが、個人情報や機密データは扱いません。
- 通知頻度は設定可能ですが、過剰な連続通知は自動的に制限されます。
