# 概要
このスキルは、作業中に“ボスキー”や明示コマンドを押すことで、即座に本物の業務画面風ダミーを生成・表示します。目的はパロディ的な演出や緊急時の画面切替体験の再現です。

# 公式ドキュメント抜粋
Python標準のcursesモジュールを用いて、クロスプラットフォームなターミナル描画を実現しています。詳細: https://docs.python.org/3/library/curses.html

# 利用例
- `/random-os-fake-boss-key` コマンドで即座にダミー画面を表示
- 上司の接近時や、作業中断を装いたい際のジョーク用途

# 注意点
- 実データや個人情報は一切利用せず、内容は毎回ランダム生成
- ローカルへの保存や履歴記録は行いません
- 一部のターミナル環境ではcurses描画が制限される場合があります

# 設計方針
シンプルなCLI設計と、毎回異なる「それっぽい」業務画面の演出にこだわりました。テンプレート追加やカスタマイズも容易です。
