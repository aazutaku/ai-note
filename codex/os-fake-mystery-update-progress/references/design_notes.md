# 概要
このSkillは、実際には何も起こらない『謎のOSアップデート進捗バー』をターミナルに表示し、ユーザーの集中力や現実感を理不尽に侵食する演出を目的としています。進捗バーの挙動や文言は毎回ランダム生成され、逆流や停止など現実のアップデートでありがちな理不尽さも再現しています。

# 公式ドキュメント抜粋
- Python random: https://docs.python.org/3/library/random.html
- Python time: https://docs.python.org/3/library/time.html

# 利用例
- 作業の息抜きやジョークコマンドとして
- チーム内の小ネタやハッカソンの演出用

# 注意点
- 実際のシステムやファイルには一切影響しません。
- ターミナルの種類によっては進捗バーの描画が崩れる場合があります。

# 設計方針
- 進捗バーの進行・停止・逆流・文言変更をすべてランダムで制御
- CLIサブコマンド(run/list/summary)で柔軟な利用が可能
- コードは100行超で可読性と拡張性を重視
