# 概要
このSkillは、実際に音を鳴らさず、テキスト通知で“架空の伝説的OS起動音”を演出することに特化しています。集中力を損なわず、作業開始時のちょっとした話題やリフレッシュに活用できます。

# 公式ドキュメント抜粋
Pythonのrandomモジュール（https://docs.python.org/ja/3/library/random.html）を利用し、毎回異なるタイトルを選出しています。

# 利用例
- チーム朝会やペアプロ開始時のアイスブレイク
- 日々の作業開始時の気分転換
- 「/skills random-os-fake-legendary-boot-sound-notifier」コマンドで明示呼び出し

# 注意点
- 実在するOS名や製品名は含まず、フィクション性を重視しています。
- ログや履歴保存はありません。
- 通知はターミナルやチャット上のテキストのみで、外部連携や実際のサウンド再生は行いません。

# 設計方針
Skill本体は100行超のPythonで構成し、CLIサブコマンド（notify/list/summary）とエラーハンドリングを備えています。
