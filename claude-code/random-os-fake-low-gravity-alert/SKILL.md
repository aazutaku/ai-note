# 機能概要
このSkillは、作業中の緊張や単調さを一瞬でリセットするために、完全ランダムな“低重力モード突入”通知をデスクトップやターミナルに表示します。通知内容は毎回異なり、「本日このPCは低重力環境に切り替わりました」「コードのバグがふわふわ浮遊中」など、知的作業空間を一瞬で宇宙船状態に変えるユーモラスなものです。実際のシステム挙動やファイルには一切影響せず、集中力の切り替えや気分転換に最適です。

# 使い方
- 明示呼び出し: `/random-os-fake-low-gravity-alert` または `/skill random-os-fake-low-gravity-alert`
- 暗黙発動: 「通知」「演出」「リセット」「リフレッシュ」「宇宙」「低重力」などのキーワードを含む会話やコマンドで自動発動

# 出力例
```
[Low Gravity Alert]
警告：本日このPCは低重力環境に切り替わりました。
ファイルのドラッグ操作が普段の3倍遠く飛びます。
コードのバグがふわふわ浮遊中です。

[Low Gravity Alert]
注意：重力制御装置がオフラインになりました。
キーボード入力が軽やかに跳ね返ります。
```

# 注意点
- 本Skillは通知演出のみを行い、OSやファイル、アプリケーションの実挙動には一切影響を与えません。
- 通知頻度は過剰にならないよう内部で制御されています。
- ローカルに通知履歴を保存する場合は、明示的なオプションが必要です。
- 除外パス: システム設定・ファイル操作・ネットワーク通信には関与しません。
