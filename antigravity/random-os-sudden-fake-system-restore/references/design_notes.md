# 概要
このSkillは、OSのシステム復元進捗バーをリアルに模倣しつつ、完全に無害な演出として実装されています。進捗率やメッセージは毎回ランダム生成され、ユーザーの作業フローに突然現れることでカオスな体験を提供します。

# 公式ドキュメント抜粋
進捗バーや通知UIの設計は、Apple HIGやWindows Dev Centerのガイドラインを参考にしています。特に進捗の「自然な遷移」や「ユーザー誤認を誘う本物感」を重視しました。

# 利用例
- チームの雑談や開発現場でのアイスブレイク
- 技術系イベントやハッカソンでのネタ演出
- 「OSトラブル」や「復元」話題の文脈で自動発動

# 注意点
本Skillは純粋な演出目的です。実際のシステムやファイルには一切影響を与えません。誤って本番環境で発動しないよう除外パスを設けています。

# 設計方針
- 進捗率・メッセージともに十分なランダム性を確保
- 本物のOS通知に近い表示レイアウト
- CLIサブコマンドでローカルテストやカスタマイズも可能
- エラーハンドリング・中断処理も実装
