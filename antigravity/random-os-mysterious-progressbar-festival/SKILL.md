# 機能概要
このSkillは、あなたの作業中に突如として“謎のOS進捗バー祭り”を発生させます。進捗バーは「バグ撲滅進捗」「コーヒー摂取量」「脳内会議進行度」など意味不明なテーマで、進捗内容も毎回ランダム。複数バーが同時に現れ、何の進捗なのか全く分からないカオスな演出が特徴です。作業の緊張感を一瞬で和らげ、チームの雰囲気を和ませるために設計されています。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「進捗」「バグ」「会議」「進行」「完了」などのキーワードを含むコマンド実行やファイル保存イベントを検知すると、自動的に発動します。例えば `git commit` や `make build`、またはエディタでの保存操作などが該当します。

# 出力例
```
[バグ撲滅進捗]      [███████████-----] 73%
[コーヒー摂取量]    [█████--------] 42%
[脳内会議進行度]    [█████████-----] 65%
[謎のOS再起動率]    [███-----------] 18%
[タスク消滅確率]    [███████████---] 81%
```

# 注意点
- 進捗バーのテーマ・進捗値は完全ランダムです。
- ローカル端末のみに描画され、外部には保存されません。
- 進捗バーは一定時間(約10秒)で自動消去されます。
- 本Skillは通知・演出用途であり、実際のOSやプロジェクト進捗とは無関係です。
