# 概要
本Skillは、作業中に実用警告風の“コーヒーあふれ”通知をランダム発火し、集中空間にユーモアを提供することを目的としています。通知内容は完全に架空で、実際のシステム状態やコーヒー消費量とは無関係です。

# 公式ドキュメント抜粋
- notify2: https://pypi.org/project/notify2/
- win10toast: https://pypi.org/project/win10toast/
- osascript: https://ss64.com/osx/osascript.html

# 利用例
- チームの朝会や集中タイムに突如ネタ通知を発火し、和やかな雰囲気を演出
- 長時間作業時のリフレッシュや“コーヒーブレイク”のきっかけ作り

# 注意点
- 通知はローカル端末でのみ表示され、リモートやWeb経由では動作しません
- ネタ通知のため、混乱を招く重要作業中での利用は控えてください

# 設計方針
- OSごとに標準的な通知APIを使用し、追加依存ライブラリは最小限
- メッセージは毎回ランダム化し、実用警告っぽさとネタ性の両立を重視
- 履歴やログは保持せず、軽快な動作を優先
