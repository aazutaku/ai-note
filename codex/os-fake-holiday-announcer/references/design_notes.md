# 概要
os-fake-holiday-announcerは、開発者の作業中に突如“架空のOS公式休日”を通知することで、気分転換やユーモアを提供するSkillです。通知内容は完全にジョークで、業務やシステムには一切影響しません。

# 公式ドキュメント抜粋
本SkillはPythonのplyer.notification APIを利用し、クロスプラットフォームでローカル通知を実現しています。通知履歴はユーザーのホームディレクトリ直下にJSONとして保存され、外部送信はありません。

# 利用例
- 長時間のコーディングで集中力が切れた時に明示呼び出し
- 「休みたい」「サボりたい」などの発言やコメントで自動発動
- チームの雑談やリモートワークの息抜き用にも

# 注意点
- 通知頻度は1時間に1回まで自動制御
- 実際のファイルやプロセスには一切影響なし
- plyer未インストール時はpip install plyerが必要

# 設計方針
- シンプルで堅牢な構成とし、誤作動や過剰通知を防ぐ
- ユーザー体験を損なわず、純粋な演出・気分転換に特化
