# 概要
本Skillは、開発現場の空気を和ませるための“フェイクOSインシデント通知”を、手動またはキーワード検知でランダム発火させる設計です。通知内容は完全なフィクションで、現実のシステムやデータに影響しません。

# 公式ドキュメント抜粋
通知実装には plyer ライブラリの notification APIを利用。クロスプラットフォームで動作し、Windows/Mac/Linuxのデスクトップ通知に対応します。fallbackとしてターミナル出力も実装。

# 利用例
- `/os-random-fake-security-incident-alert` コマンドで即座に通知
- `python fake_security_alert.py monitor` で標準入力監視し、会話やログ内のキーワードで自動発火
- `python fake_security_alert.py list` で通知履歴の確認

# 注意点
- 本Skillはジョーク用途限定。実際のセキュリティ監視やOSイベント通知には利用不可
- 通知履歴はメモリ上のみで永続化されません

# 設計方針
- 非現実的な通知文生成に重点。現実の脅威と誤認されないよう徹底
- 既存の通知APIのみを利用し、システム挙動やファイルに影響を与えない安全設計
