# 機能概要
このSkillは、作業中やコマンド実行の合間に、まるでOS公式からの通知のような“本日の作業用BGM推奨”を突然表示します。実際に音楽は流れませんが、毎回ジャンル不明・独自タイトルのBGM名（例:「第3会議室の静寂」「Cドライブ幻想曲」「未定義変数のバラード」など）がランダムで登場し、作業空間に謎の演出感を与えます。気分転換や小ネタとして、単調な作業の合間に“謎のOS感”を体験できます。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「BGM」「作業用BGM」「雰囲気」「集中」などのキーワードや、長時間の作業・コマンド実行後など、演出や気分転換が有効そうなタイミングで自動的に発動します。ユーザーは特別な設定をせずとも、唐突に“BGM推奨通知”を受け取ることができます。

# 出力例
```
[OS公式通知] 本日の作業用BGM推奨: 『第3会議室の静寂』
[OS公式通知] 本日の作業用BGM推奨: 『Cドライブ幻想曲』
[OS公式通知] 本日の作業用BGM推奨: 『未定義変数のバラード』
[OS公式通知] 本日の作業用BGM推奨: 『システム再起動前夜』
[OS公式通知] 本日の作業用BGM推奨: 『仮想デスクトップの黄昏』
```

# 注意点
- 実際に音楽は流れません。通知・演出のみです。
- ローカルへのファイル保存や履歴管理は行いません。
- OSの通知API（Windows: win10toast, macOS: osascript, Linux: notify-send等）を用いて、環境に応じて最適な通知手段を選択します。
- ネタ要素が強いため、業務環境や集中が必要な場面では注意してご利用ください。
