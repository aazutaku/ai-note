# 機能概要
このSkillは、日々の単調なPC作業やコーディングに没頭しているときに、突如“伝説のOS公式クエスト”をランダム通知として生成します。内容は「Cドライブ深部の古代バグ討伐」「伝説のUSBメモリ探索」など、実在しない奇天烈なミッションばかり。現実の業務や通知に疲れた方へ、妄想力と笑いを刺激し、作業の合間にちょっとした非日常感を提供します。実害ゼロの完全フェイク通知なので、安心してご利用いただけます。

# 使い方
- 明示呼び出し: `/skills menu` でSkill一覧から選択、または `$random-os-fake-legendary-quest-notification` メンションで即時発動。
- 暗黙発動: 長時間の無操作やコマンド連続入力時など、集中作業中に自動でランダム発動。キーワード例: "疲れた", "現実逃避", "通知飽きた" など。

# 出力例
```
[OS公式伝説クエスト通知]
緊急任務: Cドライブ深奥に眠る古のバグを討伐せよ！
報酬: システムの安寧と謎の称号

[OS公式伝説クエスト通知]
新ミッション: 伝説のUSBメモリを社内のどこかで発見せよ
報酬: 未知のファイル群
```

# 注意点
- 通知は完全なフェイクで、実際のファイル操作やシステム変更は一切行いません。
- ローカルに履歴や個人情報は保存されません。
- 業務中の誤解や混乱を避けるため、実際のシステム通知と混同しないようご注意ください。
