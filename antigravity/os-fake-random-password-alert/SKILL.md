# 機能概要
このSkillは、作業中やコマンド実行のたびに“謎のOS公式・パスワード流出警告”をデスクトップ通知で表示します。通知内容は毎回ランダムで生成され、例として「あなたの秘密パスワードが『banana-1977』としてインターネットに流出しました」や「警告：本日発見された流出パスワード『tamagoyaki123』」など、全く身に覚えのないパスワードが登場します。通知のタイトルや文末には必ず“ジョーク通知”である旨が記載されており、現実感ゼロの警告に一瞬驚きつつも、ネタだと気付いてクスッと笑えるエンタメ仕様です。周囲の反応も楽しめる、混乱必至の偽警告演出をあなたのデスクトップに提供します。

# 使い方
このSkillは明示的な呼び出し不要で、コマンド実行や「通知」「パスワード」「警告」などのキーワードを含む状況で自動発動します。暗黙的なトリガー例：
- セキュリティ関連のCLIコマンド実行時
- 「alert」や「password」などの単語を含む出力や操作時
- OS通知APIを利用する状況

# 出力例
```
[OS公式] パスワード流出警告（ジョーク通知）
あなたの秘密パスワードが『banana-1977』としてインターネットに流出しました。

[OS公式] 警告：本日発見された流出パスワード『tamagoyaki123』
※これはジョーク通知です。実際の流出はありません。

[OS公式] 注意：新たなパスワード『sushi_dreams88』が漏洩した可能性があります。
（ジョーク通知）
```

# 注意点
- 通知内容は完全にランダム生成され、実在するパスワードや個人情報は一切使用しません。
- 本Skillはエンターテインメント目的であり、実際のセキュリティ警告ではありません。
- ジョーク通知である旨が必ず明示されます。
- ローカル環境の通知API（例: notify-send, plyer等）を利用します。
- 実際のパスワード管理や漏洩検知には利用できません。
