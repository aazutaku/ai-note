# 機能概要
このSkillは、作業中のデスクトップやターミナルに「謎のOSズームイン警告」風のフェイク通知を突如表示します。通知文は毎回ランダムで、例えば「重大：ズームインモード突入まで残り5秒」「画面拡大率が謎の力で上昇中」など、実際には何も起こらないのに焦らせる内容です。実害はゼロで、真面目な作業空間に一瞬で笑いや驚きをもたらします。会議やペアプロ、ライブコーディング時の空気転換や、単調な作業のリフレッシュに最適です。

# 使い方
明示的には `/random-os-fake-sudden-zoom-in-alert` コマンドで即座に警告を表示できます。暗黙的には「ズーム」「拡大」「警告」「alert」などのキーワードを含む会話やコマンド実行時に自動発動します。triggerType: always/semantic-or-explicit で、任意のタイミングでも発動可能です。

# 出力例
```
[ALERT] 重大：ズームインモード突入まで残り5秒
[WARNING] 画面拡大率が謎の力で上昇中 (拡大率: 121%)
[INFO] システムが自動的にズームインを試みています。中止方法: 不明
[ALERT] 注意：ズームイン解除キーが無効化されています
[WARNING] OS拡大警告：残り3秒で自動ズームイン
```

# 注意点
本Skillは実際のズーム処理や画面制御は一切行いません。通知内容は完全にランダム生成され、実害や副作用はありません。通知はローカル環境にのみ表示され、履歴やログは保存されません。除外パスや特定のプロセスでは発動しません。
