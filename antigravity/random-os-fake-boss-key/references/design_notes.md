# 概要
random-os-fake-boss-keyは、伝統的な“ボスキー”文化を現代のCLI/AIエージェント環境で再現するために設計されました。ユーザーが“サボり”“上司”などのキーワードやコマンドで即座にフェイク業務画面を表示し、視線対策や気まずい状況を回避できます。

# 公式ドキュメント抜粋
本Skillはローカル端末上で動作し、実在の業務データやAPIには一切アクセスしません。画面は毎回ランダム生成され、プライバシーやセキュリティ上のリスクはありません。

# 利用例
- 在宅勤務中、急に家族や同僚が背後に現れた際に即座に“業務中っぽい”画面を演出
- オンライン会議やスクリーン共有時の緊急フェイク画面切替

# 注意点
本Skillは演出目的のパロディ機能であり、実際の業務記録や証跡としては利用できません。画面内容は保存されません。

# 設計方針
CLIサブコマンドでの明示操作と、AIエージェントによる暗黙発動の両方に対応。フェイク画面はテンプレート＋ランダム生成で毎回異なる内容となるよう工夫しています。
