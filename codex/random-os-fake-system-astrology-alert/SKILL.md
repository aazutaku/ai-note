# 機能概要
このSkillは、開発作業中に突如「OS公式・システム占星術通知」をデスクトップやターミナルにランダムで表示します。通知内容は毎回異なり、「今日のラッキーコマンドはls」「水星逆行中につきバグ注意」など、システムや作業内容とは全く関係のない、占星術風のメッセージが届きます。真面目な開発の合間に、宇宙規模のどうでもいいアドバイスを受け取り、非日常感を楽しむことができます。

# 使い方
- 明示呼び出し例: `/skills random-os-fake-system-astrology-alert` またはスキルメニューから選択
- 暗黙発動キーワード例: 「占星術」「ラッキーコマンド」「運勢」「星座」「バグ注意」などが含まれる文脈で自動発動

# 出力例
```
[OS Astrology Alert] 2024-06-28 14:03:12
今日のラッキーコマンドは: grep
金星がネットワーク層を通過中。通信エラーに要注意。
このマシンの守護惑星は火星です。
---
[OS Astrology Alert] 2024-06-28 16:22:01
水星逆行中につき、バグの再発に気をつけてください。
今日の運勢: システムアップデートは控えめに。
```

# 注意点
- 本Skillは通知の表示のみを行い、システムやファイルには一切変更を加えません。
- ローカルへのデータ保存や履歴記録は行いません。
- 通知内容は完全にランダムで、実際の占星術や運勢とは無関係です。
- データ損失や副作用はありません。
