# 概要
このSkillは、開発者の作業フローに遊び心を加えるための通知演出機能です。現実には存在しないレガシーOSやAPIの“サポート終了”を、完全ランダムなタイミングで通知することで、懐かしさと無意味な焦燥感を演出します。

# 公式ドキュメント抜粋
- Python notify2: https://pypi.org/project/notify2/
- win10toast: https://pypi.org/project/win10toast/
- Python subprocess: https://docs.python.org/ja/3/library/subprocess.html

# 利用例
- チーム開発中に突然「IE6向け最適化は永遠に封印されました」と通知され、和む
- 個人開発の合間に「フロッピーディスク対応APIが旅立ちました」で一瞬手が止まる

# 注意点
- 通知内容は完全なジョークであり、実際のシステムやデータには一切影響を与えません
- 通知頻度が高すぎる場合は、Skillの設定や通知API側で抑制可能です

# 設計方針
- OSごとに最適な通知APIを選択し、クロスプラットフォームで動作
- ログ機能を持たせ、過去の通知や発生回数を確認可能
- シンプルなCLIで手動発火や内容一覧もサポート
