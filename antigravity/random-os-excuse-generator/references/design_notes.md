# 概要
random-os-excuse-generatorは、開発現場のストレスを和らげるために、実害のないジョーク通知を提供するPythonスキルです。通知内容は完全なフィクションで、システムやデータには一切影響を与えません。

# 公式ドキュメント抜粋
通知には plyer ライブラリ（https://github.com/kivy/plyer）を利用。plyerはクロスプラットフォームでデスクトップ通知を簡単に送信できます。

# 利用例
- ビルド失敗やテストエラー時に自動で“言い訳”が表示され、現場の空気が和む。
- ターミナルから `python random_os_excuse_generator.py log` で即座に新しい言い訳を生成・通知。
- `list` や `summary` サブコマンドで過去の言い訳履歴や出現頻度を確認。

# 注意点
- 通知内容は100%ジョークであり、実際の障害分析には使えません。
- plyer未導入の場合はターミナル出力のみ。
- ログファイルはユーザーのホームディレクトリ配下に保存。

# 設計方針
- シンプルかつ安全、冗談通知に特化。
- ログや集計機能で“言い訳”の履歴を楽しめる。
- サブコマンド方式で拡張性を確保。
