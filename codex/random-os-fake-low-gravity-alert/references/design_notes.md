# 概要
このSkillは、作業空間に非日常的な「低重力」演出をランダムかつ安全に提供することを目的としています。通知内容は毎回異なり、ユーザーの集中力リセットや気分転換を促進します。

# 公式ドキュメント抜粋
- Python公式 random, argparse, datetime, os, subprocess: https://docs.python.org/3/library/
- notify-send (Linux), osascript (macOS), win10toast (Windows) など実在APIのみ使用

# 利用例
- 長時間のコーディングや単調作業時に、/skills menu から明示的に発動
- チーム内で「低重力」や「宇宙」などのワードが出た際に自動発動

# 注意点
- システムやファイルには一切影響しません
- 通知履歴はホームディレクトリの隠しファイルとして管理
- 過剰な通知を避けるため、1時間に1回以下の頻度で自動発動

# 設計方針
- ランダム性と安全性を重視
- クロスプラットフォームな通知APIを採用
- 履歴や集計機能でユーザーの演出体験を可視化
