# 概要
このSkillは、開発者の作業環境に「占星術風のシステム通知」をランダムに挿入し、非日常感や気分転換を提供することを目的としています。通知内容は毎回異なり、実際のシステム状態とは無関係な“どうでもいい”アドバイスや運勢を生成します。

# 公式ドキュメント抜粋
- Python random: https://docs.python.org/3/library/random.html
- plyer通知API: https://plyer.readthedocs.io/en/latest/

# 利用例
- ターミナル作業中に突然「水星逆行中につきバグ注意」などの通知が表示される。
- 「run」モードでバックグラウンド通知、「log」モードで履歴保存、「list」モードでサンプル出力が可能。

# 注意点
- plyerが未インストールの場合は標準出力にフォールバックします。
- 通知内容は完全なジョークであり、運勢やシステム安全性には一切関係ありません。

# 設計方針
- OS標準通知APIを優先利用し、クロスプラットフォーム動作を確保。
- 副作用を極小化し、ファイルやシステムへの変更は行いません。
- ランダム性と多様性を重視し、内容テンプレートを複数用意しています。
