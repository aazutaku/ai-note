# 機能概要
このSkillは、OS風の「パスワード流出警告」をデスクトップ通知として表示し、作業中のユーザーに一瞬の緊張と笑いを提供します。通知内容は毎回ランダム生成され、現実に存在しない“それっぽい”パスワードが流出したかのように演出されます。タイトルや文末には必ず「ジョーク通知」である旨が明記されており、実害や誤解を防ぎつつ、日常の作業にちょっとしたエンタメ要素を加えます。チーム作業中の小ネタや、集中力リセットにも活用できます。

# 使い方
- 明示呼び出し例: `/skills os-fake-random-password-alert` または `$os-fake-random-password-alert`
- 暗黙発動キーワード例: 「パスワード」「流出」「警告」「通知」「セキュリティ」などを含むコマンドや会話、またはコマンド実行時に自動発動

# 出力例
```
[通知] OS公式パスワード流出警告
あなたの秘密パスワードが『banana-1977』としてインターネット上に流出しました。
ご安心ください：これはジョーク通知です。

[通知] 警告：本日発見された流出パスワード『tamagoyaki123』
このパスワードは第三者により公開されています。
※本通知はエンタメ目的のジョークです。
```

# 注意点
- 通知内容は完全にランダム生成され、実在のパスワードや個人情報は一切使用しません。
- 本Skillはデスクトップ通知API（例: notify-send, plyer等）を利用しますが、通知の受信にはローカル環境の設定が必要です。
- ジョーク通知であることを明示し、誤解や混乱を避ける設計です。
- ログや履歴はローカルには保存されません。
