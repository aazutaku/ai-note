# 機能概要
このSkillは、作業中に突如として「謎のOS公式・怪しすぎるパッチノート通知」を生成・表示します。毎回、実在しない新機能や不可解なバグ修正が混在した内容が自動生成され、現実と虚構の境界を曖昧にします。開発者の作業フローに一瞬の混乱や笑いをもたらし、集中しすぎた頭をリフレッシュする効果を狙っています。

# 使い方
- 明示呼び出し: `/random-os-fake-mysterious-patch-notes`
- 暗黙発動: "パッチノート", "OSアップデート", "バージョンアップ", "新機能", "リリースノート" などのキーワードを含む会話やコミットメッセージ、または定期的なタイミングで自動発動します。

# 出力例
```
[OS Patch Notes 4.2.7]
新機能: Altキーで未来の天気が予測可能になりました
改善: スペースキーの跳躍力を微増
既知の問題: たまに幸運が訪れることがあります
修正: シャットダウン時にまれに哲学的質問が表示されるバグを修正
---
[OS Patch Notes 5.0.1]
新機能: ターミナルが詩を詠むことがあります
改善: CapsLockの押下感を向上
既知の問題: 一部環境で現実逃避が加速する場合があります
```

# 注意点
- 本Skillは実際のシステムやアプリには一切影響しません。
- 通知内容は毎回異なり、完全に架空です。
- ローカルへの自動保存や履歴管理は行いません。
- 業務用途や正式なリリースノートには絶対に使用しないでください。
