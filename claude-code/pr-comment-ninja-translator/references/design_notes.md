# 概要
このSkillは、Pull Requestのコメントを日本語忍者口調に自動変換することで、開発現場にユーモアを加えることを目的としています。ジョーク枠として、堅苦しいレビューの雰囲気を和らげる設計です。

# 公式ドキュメント抜粋
- GitHub Issues/PR Comments API: https://docs.github.com/en/rest/issues/comments
- 日本語形態素解析: https://github.com/megagonlabs/ginza

# 利用例
- PRコメント「テストが落ちています」→「ござる…テスト、落ちてしまったでござる。」
- 「変数名をもっと分かりやすくしてください」→「拙者思うに、この変数名、影の如く分かりにくき候。分かりやすき名へと変えるのが良きと存ずる。」

# 注意点
- 原文の意味が極端に失われないよう、単語単位での置換＋テンプレート挿入を採用。
- 機密性の高い内容や公式記録には適用しないよう注意。
- 変換ログや元文のバックアップは自動で保存されません。

# 設計方針
- 既存の自然言語処理ライブラリを活用せず、シンプルな正規表現とテンプレートで高速実装。
- コマンドライン引数やファイル入力にも対応し、ローカルテストやバッチ変換も可能。
- エンタメ性重視のため、多少の意味変化や語感の遊びを許容しています。
