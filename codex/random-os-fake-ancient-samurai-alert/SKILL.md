# 機能概要
このSkillは、あなたの作業環境に突如「古のOS侍」からの達しをランダムに通知します。内容は毎回異なり、「Altキーの抜刀訓練状況を監視しておる」「油断大敵、マウスの居合切りに注意せよ」など、時代錯誤かつ意味不明な侍的警句が炸裂。通知はデスクトップ（Windows/macOS/Linux）またはターミナル上に出現し、マンネリ化した作業に突如“侍ワールド”を挿入。集中力のリフレッシュや雑談のきっかけ、チーム内の話題作りにも活用できます。システムやファイルへの実害は一切ありません。

# 使い方
- 明示呼び出し例: `/skills menu` でSkill一覧から選択、または `$ random-os-fake-ancient-samurai-alert` で直接発動
- 暗黙発動: 長時間のコマンド実行や「侍」「alert」「集中」などのキーワード検知時に自動発動

# 出力例
```
[OS侍警告] 拙者、あなたのAltキーの抜刀訓練状況を監視しておる。
[OS侍警告] 油断大敵、マウスの居合切りに注意せよ。
[OS侍警告] このターミナル、既に斬撃済み。
[OS侍警告] ファイル保存、まるで刀の鞘納めの如し。
[OS侍警告] スクロールは風の如く、急ぐべからず。
```

# 注意点
- 通知内容は毎回ランダムで変化しますが、実際のデータやシステムには一切影響しません
- ローカル保存や履歴記録は行いません
- 通知は標準出力またはOS通知APIを利用
- 侍ネタが苦手な方はご注意ください
