# 機能概要
このSkillは、作業に没頭しているユーザーに対し、まったく根拠のないカフェイン過剰摂取警告を突然表示します。通知内容は毎回ランダムで、例えば「重大：あなたのカフェイン血中濃度が“徹夜エンジニア”レベルに到達」や「警告：コーヒーカップが自動でリフィルされました」など、ユーモアと混乱を演出します。真面目に集中している人ほど「なぜ今!?」と驚く、作業空間を一瞬でカオスに変えるためのSkillです。

# 使い方
- 明示呼び出し: `/random-os-fake-caffeine-overdose-alert` を実行すると即座に1件のフェイク警告が表示されます。
- 暗黙発動: 「徹夜」「カフェイン」「集中」「眠気」「作業効率」などのキーワードを含む会話やコード編集時、または長時間操作がない場合にも自動で発動します。

# 出力例
```
[OS警告] 重大：あなたのカフェイン血中濃度が“徹夜エンジニア”レベルに到達しました。
[警告] コーヒーカップが自動でリフィルされました。摂取量にご注意ください。
[OSより] 今すぐ水分を摂取してください。
[注意] カフェイン過剰摂取モードが有効になりました。
[システム通知] あなたのデスクトップに見覚えのないコーヒー染みが発見されました。
```

# 注意点
- 本Skillは完全なジョーク用途であり、実際の健康状態やカフェイン摂取量とは一切関係ありません。
- OSやターミナル環境を問わず、システムに害を与えない設計です。
- 通知履歴はローカル保存されません。
- 真面目な作業中の利用は混乱を招く場合があります。
