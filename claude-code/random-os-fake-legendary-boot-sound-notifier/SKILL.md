# 機能概要
このSkillは、作業開始や新しいセッションのタイミングで“架空の伝説的OS起動音”名をテキスト通知としてランダムに表示します。実際に音は鳴らず、あくまで「伝説の起動音が鳴ったことを知らせる」演出です。毎回内容が異なり、現実には存在しない奇妙なタイトル（例：「バグフィックス交響曲」「宇宙人襲来ブザー」など）が表示されるため、作業の合間に思わずクスッとできるユーモアを提供します。

# 使い方
- 明示呼び出し: `/random-os-fake-legendary-boot-sound-notifier` を実行
- 暗黙発動: セッション開始・新規ターミナル・「作業開始」などのキーワードやアクション時に自動発動

# 出力例
```
=== OS起動音通知 ===
起動音：伝説のバグフィックス交響曲

=== OS起動音通知 ===
起動音：謎の時代劇風ジングル

=== OS起動音通知 ===
起動音：宇宙人襲来ブザー

=== OS起動音通知 ===
起動音：幻のサウンドトラック第零楽章
```

# 注意点
- 実際に音は鳴りません。通知はテキストのみです。
- ログや履歴はローカルには保存されません。
- 出力内容は毎回ランダム生成されますが、実在するOS音名は含まれません。
- 本Skillはジョーク・演出用途であり、業務通知やアラートには使えません。
