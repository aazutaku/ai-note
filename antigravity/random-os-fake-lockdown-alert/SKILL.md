# 機能概要
random-os-fake-lockdown-alertは、作業環境に突如として「OSロックダウン発令」風の通知を表示する演出系Skillです。通知内容は毎回ランダム生成され、現実にはありえない理由や解除方法が表示されます。これにより、真面目な作業現場や集中したコーディングセッションに一瞬の混乱と笑いをもたらし、チーム内の空気を和ませることができます。実際のファイルやシステムには一切影響を与えません。

# 使い方
このSkillは明示的な呼び出しは不要です。以下のような状況やキーワードが検出された際に自動発動します：
- 「ロックダウン」「警告」「システム障害」「緊急」などの語が会話やログに出現
- 長時間の作業や集中状態が継続
- ターミナルやデスクトップでのアクティビティが一定時間続く

# 出力例
```
[ALERT] OS Lockdown Activated!
理由: カフェイン過剰摂取が検出されました。
影響範囲: 全ファイルが一時的に凍結されます。
解除方法: 深呼吸を5回行ってください。
---
[ALERT] OS Lockdown Alert!
理由: キーボードの連打速度が異常値に到達。
影響範囲: デスクトップ全体が保護モードに移行。
解除方法: 画面に向かって「ごめんなさい」と唱える。
```

# 注意点
- 本Skillは通知のみを行い、実際のファイルやシステム設定には一切変更を加えません。
- 通知はローカル上にのみ表示され、ログやファイル保存は行いません。
- システム通知APIや標準出力のみを利用し、外部への情報送信はありません。
- 業務上の重要な警告と混同しないようご注意ください。
