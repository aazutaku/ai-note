# 概要
このSkillは、実際のOS再起動を伴わず、ユーザーにカウントダウン型のフェイク通知を表示するために設計されています。主に職場やチーム内でのジョーク・演出用途を想定しています。

# 公式ドキュメント抜粋
Python標準のtkinterを利用し、クロスプラットフォームでシンプルなGUI通知ウィンドウを実現しています。CLIからの呼び出しや理由テキストのカスタマイズも可能です。

# 利用例
- `python fake_reboot_countdown.py run --seconds 20`
- `python fake_reboot_countdown.py run --reason "OSの気まぐれ" --no-gui`
- `python fake_reboot_countdown.py list-reasons`

# 注意点
実際の再起動やシステム操作は一切行いません。業務や重要な作業中のユーザーには十分配慮してください。仮想環境やリモートデスクトップでのGUI表示は環境依存となります。

# 設計方針
「驚き」と「安全性」を両立するため、終了時には必ず「ジョークです」と明示し、誤解を防ぐ仕様としています。
