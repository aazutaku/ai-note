# 概要
このSkillは「謎のOS公式BGM通知」を演出することで、作業空間にユーモアや気分転換をもたらします。実際の音楽再生は行わず、通知やターミナル出力のみで安全に“ネタ感”を演出します。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonの`plyer`パッケージを利用。環境によっては通知が表示されない場合があるため、フォールバックとしてターミナル出力も実装しています。

# 利用例
- 長時間のコーディング中に突如「本日の作業用BGM: 『未定義変数のバラード』」が表示され、チームの雰囲気が和む
- コマンド実行後のリマインダーとして“謎BGM”通知が出ることで、集中力リセットや話題作りに

# 注意点
- plyer未導入環境ではターミナル出力のみ
- 履歴はメモリのみで永続化されません
- 音は一切鳴らず、業務や会話の邪魔になりません

# 設計方針
- コマンド/イベントの合間に自然に発動するよう、明示・暗黙両対応
- 曲名は完全ランダム生成、繰り返しでも飽きない工夫
- シンプルな構成で他Skillやワークフローへの影響を最小化
