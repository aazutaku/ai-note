# 概要
このSkillは、ユーザーの作業中に現実味のない偽パスワード流出警告をランダム生成し、デスクトップ通知として表示するエンタメ系演出ツールです。実在しないパスワードと明示的なジョーク表記により、混乱を避けつつ一瞬の驚きと笑いを提供します。

# 公式ドキュメント抜粋
- [Python random](https://docs.python.org/ja/3/library/random.html): パスワード生成に利用
- [plyer notification](https://plyer.readthedocs.io/en/latest/): クロスプラットフォームな通知API

# 利用例
- チーム内のリラックスタイムやイベント時のネタ演出
- セキュリティ教育のアイスブレイク
- CLI作業の合間の息抜き

# 注意点
- 実在のパスワードや個人情報を一切扱わない設計
- 通知内容には必ず“ジョーク通知”である旨を明記
- ログはローカル保存のみ。外部送信は行わない

# 設計方針
- OS依存を極力排除し、plyerやnotify-send等で幅広い環境に対応
- CLIサブコマンドで履歴管理やサマリ表示もサポート
- 本物の警告と誤認されない演出バランスを重視
