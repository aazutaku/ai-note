# 概要
このSkillは、作業中に突然現れる「OS公式デスクトップペット」を模した通知・演出を実現します。ペットの種類やメッセージは毎回ランダムで、実際の作業に影響を与えないよう設計されています。

# 公式ドキュメント抜粋
Pythonの通知APIとしてnotify2（Linux）、plyer（Windows/Mac）を利用し、クロスプラットフォームな通知表示を実現しています。出現頻度や演出内容はスクリプト内で自動制御されます。

# 利用例
長時間のコーディングや単調な作業時に、ペットが現れて一瞬だけ集中を崩すことで、気分転換や癒しを提供します。通知領域やターミナルでの演出により、ユーザーに非日常的な体験を与えます。

# 注意点
実害はありませんが、通知が不要な場合はSkillを無効化してください。明示的な呼び出しやカスタマイズはサポートされていません。出力は一時的なもので、履歴は残りません。

# 設計方針
ユーザーの作業を物理的に妨害しすぎないよう、出現頻度は15分以上の間隔で自動調整されています。キャラクターやメッセージは拡張可能な設計です。
