# 機能概要
このSkillは、コーディングや作業の合間に、まるでOSの公式通知のような“404エラー”メッセージをデスクトップやターミナルにランダム表示します。通知内容は「あなたのやる気が見つかりません」や「404: 今日の集中力が迷子です」など、完全に役に立たず、しかし妙に心に刺さるものばかり。実用性はゼロですが、作業の合間の気分転換や、思わず笑ってしまう非日常体験を提供します。

# 使い方
- 明示呼び出し: `/random-os-fake-404-notification` を実行することで即座に通知を表示できます。
- 暗黙発動: 「集中力」「やる気」「進捗」「404」「エラー」などのキーワードが含まれる状況や、一定時間作業が続いたときに自動発動します。

# 出力例
```
[OS Notification] 404: あなたのやる気が見つかりません
[OS Notification] 404: 今日の集中力が迷子です
[OS Notification] 404: 予定されていた進捗が行方不明です
[OS Notification] 404: 休憩予定が未検出です
[OS Notification] 404: 本日の生産性が応答しません
[OS Notification] 404: コーヒーの補給が必要です
```

# 注意点
- 通知は本物のエラーと誤解されないよう、明らかにジョークと分かる文言のみを使用しています。
- 通知の頻度は1時間あたり1～3回程度に自動調整され、作業の妨げになりすぎないよう配慮しています。
- ローカル環境に通知履歴などのデータは保存されません。
- 一部のLinux環境では通知表示に `notify-send` コマンドが必要です。
