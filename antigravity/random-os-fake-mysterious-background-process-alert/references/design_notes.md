# 概要
このSkillは、実際のシステムやデータには一切影響を与えない“演出・通知”系スキルです。ユーザーの作業中に、OS風の謎めいたバックグラウンド通知をランダムなタイミング・内容で出力し、都市伝説的な不安感や遊び心を提供します。

# 公式ドキュメント抜粋
Pythonのrandom, time, argparseモジュールのみを使用し、外部依存はありません。標準出力のみを利用し、OSの通知APIや実プロセス操作は行いません。

# 利用例
- IT系イベントや勉強会でのネタ演出
- 長時間作業時の気分転換や“正気度”チェック
- チーム内のジョークやコミュニケーションのきっかけ

# 注意点
- 実際のプロセスやファイルには一切触れません
- 通知内容は完全にランダム生成され、実害はありません

# 設計方針
「意味不明・無害・都市伝説感」に特化し、ユーザーの作業環境を壊さず、あくまで演出のみを追求しています。
