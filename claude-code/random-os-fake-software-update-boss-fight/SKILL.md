# 機能概要
このSkillは、作業中のOS環境に突如「謎のソフトウェアアップデート vs バグ魔王」のバトル実況をRPG風に演出します。進捗バーや通知が勇者と魔王の攻防を表現し、毎回異なる展開やセリフで開発現場に一瞬の非日常をもたらします。バトルは進捗に応じて進み、勝敗もランダムで決定。真面目な現場に遊び心を加え、リフレッシュやチームの雰囲気改善に役立ちます。

# 使い方
- 明示的呼び出し: `/random-os-fake-software-update-boss-fight`
- 暗黙発動: 「アップデート」「バグ」「パッチ」「進捗」などのキーワード検出時に自動発動

# 出力例
```
[通知] OSアップデート勇者が伝説のバグ魔王に挑む！
[進捗] 勇者「パッチの剣」を抜いた！(20%)
[進捗] バグ魔王「例外の嵐」反撃！(35%)
[進捗] 勇者「デバッグ魔法」発動！(60%)
[進捗] バグ魔王「無限ループの呪い」！(80%)
[通知] 勇者の勝利！アップデート完了！
```

# 注意点
- 実際のソフトウェア更新やシステムには一切影響を与えません
- ローカル通知・標準出力のみ対応。OSの通知APIはPython標準・cross-platformのものを使用
- 出力内容や進行は毎回ランダム生成されます
- 除外パスや特定ディレクトリでの発動制御はありません
