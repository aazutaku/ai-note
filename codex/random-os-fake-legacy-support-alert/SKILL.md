# 機能概要
このSkillは、コマンド実行やエディタ操作のたびに、現代では考えられないレガシーOSやソフトウェアの“サポート終了通知”を完全ランダムにデスクトップへ表示します。例として「Windows 98互換モードのサポート終了」「IE6向け最適化封印」など、開発者の心に一瞬の懐かしさと無意味な焦りを与える演出を提供します。実害は一切なく、実際の環境やデータを変更することもありません。

# 使い方
- 明示呼び出し: `/skills menu` でSkill一覧から選択、または `random-os-fake-legacy-support-alert` を直接指定
- 暗黙発動: ターミナルでコマンド実行時、または「通知」「警告」「レガシー」「サポート終了」などのキーワードを含む操作時に自動発火

# 出力例
```
[サポート終了通知]
Windows 98互換モードのサポートは本日をもって終了しました。
今後はY2K非対応環境での動作保証はありません。
---
[サポート終了通知]
IE6向け最適化は永遠に封印されました。
レガシーCSSハックの時代は終わりました。
---
[サポート終了通知]
フロッピー対応APIが静かに旅立ちました。
FDドライブの回転音はもう聞こえません。
```

# 注意点
- このSkillは通知のみを行い、ファイルやシステム設定には一切影響しません。
- ローカルに通知履歴を保存しません。
- 実際のOSやアプリのサポート状況には関与しません。
- 通知は現行環境に依存せず、完全ランダムに生成されます。
