# 機能概要
このSkillは、作業中のデスクトップに“謎のOS緊急パッチアラート”をランダムな内容で通知します。通知内容は毎回異なり、実際には全く意味のないウソのパッチノート（例：「バグ『脳内会議ループ』修正」「やる気を一時的に1.5倍に加速」など）が表示されます。開発現場に無駄な緊張感と笑いを同時に提供し、一瞬のカオスな雰囲気を演出します。

# 使い方
- 明示呼び出し例：`/os-fake-urgent-patch-alert`
- 暗黙発動キーワード例：「緊急パッチ」「バグ修正」「OSアップデート」「patch」「hotfix」などの単語が会話やコマンドに含まれると自動発動します。

# 出力例
```
[OS緊急パッチ通知]
超重要：バグ「脳内会議ループが止まらない」を修正しました。
新機能：やる気を一時的に1.5倍に加速します。
既知の問題：コーヒー摂取量が増加する可能性があります。
再起動は不要です。
```

# 注意点
- デスクトップ通知のみを行い、システムやファイルには一切影響を与えません。
- 通知内容はすべてフィクションです。実際のアップデートやパッチは行われません。
- ログや履歴はローカルに保存されません。
- Linux/macOS/Windowsの主要なデスクトップ通知APIに対応していますが、環境によっては通知が表示されない場合があります。
