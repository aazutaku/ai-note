# 機能概要
このSkillは、作業やコマンド実行のたびに「本日のテーマソング：『バグ修羅場行進曲』」など、OS公式風の架空サウンドトラック通知をデスクトップに表示します。通知内容は完全オリジナルで、開発現場ネタや意味不明な曲名が毎回ランダム生成され、実際に音は流れません。作業中の緊張感や沈黙をシュールに打ち破る、ジョーク系の通知Skillです。

# 使い方
- 明示呼び出し例: `/skills menu` で選択、または `$random-os-fake-soundtrack-alert` メンション
- 暗黙発動キーワード例: コマンド実行、`build`/`commit`/`push`/`debug`/`run` などの操作時に自動発動

# 出力例
```
[通知] 本日のテーマソング：『バグ修羅場行進曲』
[通知] 今こそ流せ！『納期デッドヒート』
[通知] 公式推奨BGM：『深夜残業エチュード』
[通知] 今日の気分は『マージ地獄協奏曲』
[通知] システムより：『仕様変更ラプソディ』
```

# 注意点
- 通知は毎回異なる内容を生成しますが、実際に音楽やBGMは再生されません。
- 通知頻度は1分に1回までに制限され、過度な連続表示は抑制されます。
- ローカルに通知履歴や曲リストは保存されません。
- Linux/macOS/Windowsの標準通知APIを利用しますが、環境依存で通知が表示されない場合があります。
