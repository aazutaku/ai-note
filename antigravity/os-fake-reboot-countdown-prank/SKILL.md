# 機能概要
このSkillは、PC作業中に突然“OS再起動カウントダウン”ウィンドウを表示し、ユーザーや周囲を驚かせるためのジョーク演出を提供します。カウントダウンには毎回異なる「謎の理由」（例：「RAMの気分転換」「OS自己啓発モード」など）が表示され、数字が0になると「ジョークです」とだけ表示されます。実際に再起動やシャットダウンは一切行われません。オフィスやチーム内でのちょっとした混乱や笑いを誘うための攻めた通知演出Skillです。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「再起動」「アップデート」「OS」「カウントダウン」などのキーワードや、システム関連の会話を検知した際に自動的に発動します。手動でスクリプトを実行する場合は、コマンドラインから `python fake_reboot_countdown.py` を実行してください。カウントダウン秒数や理由をカスタマイズしたい場合は、`--seconds` や `--reason` オプションを利用できます。

# 出力例
```
[OS通知] システム再起動まで: 30秒
理由: RAMの気分転換
...
[OS通知] システム再起動まで: 0秒
ジョークです
```

# 注意点
- このSkillは実際の再起動やシステム操作は一切行いません。
- 表示はローカル端末上のみに限定されます。
- 業務や重要な作業中のユーザーには十分配慮してください。
- 画面上にウィンドウ/通知が表示されるため、仮想環境やリモートデスクトップでは挙動が異なる場合があります。
