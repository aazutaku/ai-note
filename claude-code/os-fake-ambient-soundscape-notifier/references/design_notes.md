# 概要
このSkillは、実際に音を鳴らさずに“環境音通知”の体験だけを提供することで、作業環境にユーモアや非日常感をもたらします。通知内容は完全ランダム生成で、ユーザーの集中力向上や気分転換をサポートします。

# 公式ドキュメント抜粋
通知APIには plyer.notification を利用し、クロスプラットフォームで実際のOS通知風の演出が可能です。plyer: https://plyer.readthedocs.io/en/latest/#plyer.notification.notification

# 利用例
- 長時間作業時の気分転換用
- チーム内での雑談ネタやリモートワークのアイスブレイク
- 実際のBGM再生ができない静かな職場での“気分だけ演出”

# 注意点
- 音声再生は一切行いません
- 通知内容は毎回ランダム生成されるため、同一テーマが続く場合もあります
- 通知履歴はメモリ上のみで永続保存されません

# 設計方針
- 通知頻度やタイミングはうるさすぎず、作業を妨げない範囲に自動調整
- OS通知APIが使えない場合は標準出力にフォールバック
- 再現性よりも“なぜ？”と思わせる演出を重視
