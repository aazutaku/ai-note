# 概要
本Skillは、作業中にOS公式風の理不尽なスリープ通知をランダムに出すことで、ユーザーにユーモアとリフレッシュを提供する演出ツールです。実際のスリープ動作は一切伴いません。

# 公式ドキュメント抜粋
- [Plyer](https://pypi.org/project/plyer/): クロスプラットフォームなPython通知ライブラリ
- [notify-send](https://specifications.freedesktop.org/notification-spec/latest/): Linuxデスクトップ通知
- [win10toast](https://pypi.org/project/win10toast/): Windows 10向けトースト通知

# 利用例
- 長時間作業時の気分転換や雑談のきっかけに
- チームの朝会やリモートワークのアイスブレイク用
- OS通知演出のデモやテストに

# 注意点
- 本Skillはジョーク用途のため、業務システムや重要な通知と混同しないよう注意してください。
- 通知内容は毎回ランダム生成され、実際のOS管理機能とは無関係です。

# 設計方針
- OSごとの通知APIを自動判別し、最大限ネイティブな演出を優先
- ログ・履歴機能は将来的拡張用にCLIサブコマンドでプレースホルダ実装済
- 外部依存は極力最小限とし、標準出力でも動作保証
