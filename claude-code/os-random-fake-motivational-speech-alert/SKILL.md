# 機能概要
このSkillは、コーディングやコマンド実行などの作業時に、毎回異なる“OS公式”風のやる気爆上げスピーチ通知をデスクトップや端末画面に表示します。通知内容は「あなたのcommitが宇宙を救う」「今こそコード界の伝説になるときです」など、どこかズレた本気の激励ばかり。作業の合間にエンタメ要素を注入し、日常のコーディング体験をユーモラスに彩ります。

# 使い方
- 明示呼び出し: `/os-random-fake-motivational-speech-alert`
- 暗黙発動: 任意のコマンド実行・ファイル保存・ビルド等のタイミングで自動発火
- オプション: `--count 3` で複数回連続通知、`--list` で過去の通知履歴を表示

# 出力例
```
[OS公式通知] あなたのキーボードの叩き方に情熱を感じます。
[OS公式通知] 今こそコード界の伝説になるときです。
[OS公式通知] あなたのcommitは宇宙を救う。
[OS公式通知] その一行が未来を変える。
[OS公式通知] シンタックスエラーすら、あなたの成長の証です。
```

# 注意点
- 通知内容は毎回ランダム生成されますが、実害は一切ありません。
- システムやデータには影響せず、通知履歴はローカルファイルにのみ保存されます。
- 一部OSではGUI通知がサポートされない場合、端末出力のみとなります。
