# 概要
このSkillは、日常の作業中に“伝説のOSクエスト通知”をランダムで生成し、ユーザーの現実逃避や気分転換を支援します。完全なフェイク通知で安全性を重視し、実際のシステムやデータには一切影響しません。

# 公式ドキュメント抜粋
- Linux: [notify2](https://pypi.org/project/notify2/)
- Windows: [win10toast](https://pypi.org/project/win10toast/)
- macOS: [osascript](https://ss64.com/osx/osascript.html)

# 利用例
- 長時間のコーディングや単調作業の合間に、突如“伝説のクエスト”が通知され、チーム内で笑いが生まれる。
- `/skills menu`やコマンドラインから即時発動し、現実逃避のきっかけを得られる。

# 注意点
- 通知内容は完全なフィクションであり、実際の業務やシステム運用に混乱を生じさせない設計です。
- 履歴ファイルはユーザーのホームディレクトリにのみ保存し、個人情報や業務データは一切扱いません。

# 設計方針
- OSごとに実在する通知APIのみを使用し、CLIからも明示的に操作可能。
- 通知履歴やサマリー機能を実装し、ユーザーの利用状況を可視化。
- ランダム発動と明示呼び出しの両対応で、柔軟な運用を実現。
