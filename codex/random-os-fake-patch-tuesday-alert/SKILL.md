# 機能概要
このSkillは、作業中やコマンド実行の合間に、まるで本物のOS公式アップデート通知のように見える“ありえないパッチノート”をランダム生成し、ターミナルやデスクトップ通知で表示します。内容は毎回異なり、現実には絶対に存在しない奇妙な新機能や修正が並ぶため、真面目な作業の緊張感を一瞬で和らげます。集中力をハッキングするユーモア演出として、開発現場や勉強中のリフレッシュに最適です。

# 使い方
- 明示呼び出し: `/skills random-os-fake-patch-tuesday-alert` または Skill メニューから選択
- 暗黙発動: 「パッチチューズデー」「アップデート」「パッチノート」「OS通知」などの単語を含む会話やコマンド実行時に自動発動

# 出力例
```
[Patch Tuesday Alert] 本日適用: OSがCapsLockキーの連打回数を自動でツイートする機能を追加しました。
[Patch Tuesday Alert] 緊急修正: Altキー長押しでデスクトップ壁紙がランダムな俳句に変わる不具合を修正。
[Patch Tuesday Alert] 新機能: Ctrlキーを3秒間押し続けるとOSが自己紹介を開始します。
[Patch Tuesday Alert] 重要: マウスカーソルが一定時間停止すると、画面上でダンスを始めます。
[Patch Tuesday Alert] アップデート: ターミナルでlsコマンド実行時、ディレクトリ名がすべて回文に変換されます。
```

# 注意点
- 実際のシステムアップデートやセキュリティ通知とは無関係です。
- 通知内容は完全ランダム生成で、現実のOS挙動には影響しません。
- ローカルに通知履歴は保存されません。
- デスクトップ通知はLinux/macOS/Windowsでサポートされますが、環境によってはターミナル出力のみになる場合があります。
