# 概要
このSkillは、ユーザーの無操作（idle）状態を検出し、30秒以上操作がない場合にOSの通知機能やターミナル出力で“お昼寝検出”メッセージを表示します。主に職場や作業現場でのネタ用途を想定しています。

# 公式ドキュメント抜粋
- Linux: `notify-send` コマンド (freedesktop.org notification spec)
- macOS: `osascript` 経由でネイティブ通知
- Windows: `win10toast` ライブラリ

# 利用例
- ターミナルで `python random_os_nap_detection_alert.py start` を実行し、作業中に30秒以上キー入力がなければ通知が出ます。
- `watch` モードはパイプや標準入力監視用途に便利です。
- `demo` モードは通知内容のランダム性を確認したい場合に使います。

# 注意点
- 全てのアプリケーション操作を監視するものではありません。ターミナルや標準入力の監視が中心です。
- 通知内容や履歴はローカルに保存されません。
- Windowsの場合、`pip install win10toast` が必要です。

# 設計方針
- OSごとに最適な通知手段を自動選択します。
- データ損失や環境破壊を一切起こさない安全設計です。
- メッセージは毎回ランダムで、ユーザーの気まずさ・笑いを誘発することを重視しています。
