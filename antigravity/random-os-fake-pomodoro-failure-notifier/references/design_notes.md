# 概要
本Skillは、ポモドーロや集中タイマーの操作イベントを検知し、毎回異なる“フェイク失敗通知”をランダム生成します。通知内容は完全なジョークで、作業の緊張をほぐしたり、チームの雰囲気作りを目的としています。

# 公式ドキュメント抜粋
- Python random: https://docs.python.org/3/library/random.html
- plyer通知: https://plyer.readthedocs.io/en/latest/

# 利用例
- ターミナルで `python fake_pomodoro_notifier.py listen` を起動し、"タイマー開始"や"ポモドーロ"などのキーワードを入力すると、毎回異なるフェイク通知が出力されます。
- `log` サブコマンドで通知履歴を確認可能。
- `summary` サブコマンドで通知回数や頻出ネタを集計。

# 注意点
- 本Skillは実際のタイマーや作業進行には影響しません。
- 通知内容は毎回ランダムで、実用性はありません。
- plyer未導入の場合はターミナル通知のみ。

# 設計方針
- 依存ライブラリは標準+plyerのみ。
- ログはローカルファイルに限定。
- 10分以内で動作確認可能なシンプル設計。
