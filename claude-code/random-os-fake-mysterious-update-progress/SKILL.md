# 機能概要
このSkillは、作業中や開発環境で突如「謎のOSアップデート進行中」風の進捗バーを表示するエンタメ系演出ツールです。進捗内容は毎回「未知の言語パッチ適用中」「レガシーキーボード最適化中」など意味不明なものばかり。進捗バーは途中で逆戻りしたり、99%で止まったまま一向に終わらなかったりと、理不尽な挙動も再現。普段の作業に謎の非日常感や脱力感を与え、緊張感をほぐしたいときや、チームの雰囲気を和ませたい場面で活用できます。

# 使い方
- 明示呼び出し: `/random-os-fake-mysterious-update-progress` で即時発動
- 暗黙発動: 「謎のアップデート」「進捗バー」「OS更新」などのキーワードを含む会話やコマンドで自動発動
- ターミナルまたはPython環境でスクリプトを直接実行可能

# 出力例
```
[謎のOSアップデート進行中]
進捗: 13% |■■■         | 未知の言語パッチ適用中...
進捗: 26% |■■■■■       | レガシーキーボード最適化中...
進捗: 21% |■■■         | 謎のカーネル再構築中...
進捗: 47% |■■■■■■■    | 不明なプロトコル同期化中...
進捗: 99% |■■■■■■■■■ | 仮想RAMの無限拡張中...
進捗: 99% |■■■■■■■■■ | 仮想RAMの無限拡張中...
進捗: 98% |■■■■■■■■  | 逆流するアップデート...
```

# 注意点
- 本Skillは純粋な演出目的であり、実際のOSやシステムには一切影響を与えません
- 進捗バーは標準出力のみ。ファイル保存や通知機能はありません
- 長時間の99%停滞や逆戻りは仕様です
- 本番環境や重要な作業の妨げにならないようご注意ください
