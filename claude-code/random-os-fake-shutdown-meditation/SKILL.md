# 機能概要
このSkillは、開発作業やコーディングに熱中している際に、突如として“謎のOSシャットダウン瞑想タイム”を演出する通知・タイマー・進捗バーをランダムに発動します。意味不明なメッセージや瞑想度バー、静寂タイマーが現れ、ユーザーの集中を一時的にリセットし、強制的に“無”の時間を提供します。開発者の気分転換やユーモア、意図的な撹乱を目的として設計されています。

# 使い方
- 明示呼び出し: `/random-os-fake-shutdown-meditation` を実行すると即時発動します。
- 暗黙発動: 「shutdown」「meditation」「再起動」「無の境地」「悟り」などの単語が会話やコマンドに含まれると、ランダムタイミングで自動発動します。
- OSのデスクトップ通知、端末出力、進捗バーが表示されます。

# 出力例
```
[通知] システムは5分間、無の境地に入ります。
[進捗バー] 瞑想度: [====      ] 40%
[タイマー] 残り 04:12
[通知] 強制メンテ：心の再起動モード
[進捗バー] 瞑想度: [========  ] 80%
[終了通知] 悟りタイムが完了しました。作業に戻れます。
```

# 注意点
- このSkillは実際のOSシャットダウンや再起動は行いません。
- 通知・タイマーはローカル環境でのみ動作します（Linux/macOS/Windows対応）。
- 長時間の強制タイマーはありません。集中を妨げすぎないよう設計されています。
- ログや履歴は保存されません。
