# 機能概要
このSkillは、作業中のCLIやデスクトップ環境に、幕末日本をモチーフにしたフェイクカウントダウンアラートを突如表示します。通知内容は毎回ランダム生成され、例えば「緊急：システムはあと13分で明治維新されます」「本日は黒船再来。本能寺リブートまで残り8分」など、歴史パロディ満載。実際のシステムには一切影響せず、作業空間にシュールな演出を加えます。歴史好きはもちろん、気分転換やネタ枠としても活用可能です。

# 使い方
- 明示呼び出し例: `/os-fake-bakumatsu-countdown-alert`
- 暗黙発動キーワード例: 「カウントダウン」「アラート」「幕末」「歴史パロ」「タイムリミット」「黒船」「明治維新」などを含む会話やスクリプト実行時。

# 出力例
```terminal
[幕末カウントダウン] 緊急：システムはあと13分で明治維新されます
残り時間: 00:12:59

[幕末カウントダウン] 本日は黒船再来。本能寺リブートまで残り8分
残り時間: 00:07:59

[幕末カウントダウン] 土佐藩アップデートまで残り5分
残り時間: 00:04:59
```

# 注意点
- 実際のシステムやファイルには一切影響を与えません。
- 通知内容・残り時間は完全ランダムです。
- ローカル保存や履歴記録は行いません。
- 一部環境では通知表示に制限がある場合があります。
