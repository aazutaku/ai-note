# 機能概要
random-os-fake-disk-space-crisisは、作業中に突如として現れるフェイクな「OSディスク残量危機」通知を生成・表示するSkillです。実際のディスク容量とは一切関係なく、毎回ランダムで「警告: あなたの残ディスク容量は“カブトムシ2匹分”です」や「緊急: SSDの空きが“ギャラクシー級に不足”」など、意味不明な単位や例えを用いた通知を端末やデスクトップに表示します。これにより、作業の合間に笑いや混乱を提供し、気分転換やチーム内のコミュニケーション活性化を狙います。

# 使い方
本Skillは明示的な呼び出し不要で、会話や作業ログに「ディスク容量」「ストレージ不足」「空き容量」「容量警告」等のキーワードが含まれると自動的に発動します。手動で実行したい場合は、スクリプトを直接CLIから呼び出すことも可能です。

## 暗黙発動キーワード例
- ディスク容量が心配
- ストレージ足りるかな？
- 空き容量ってどれくらい？
- 容量警告が出た

# 出力例
```
[ALERT] 警告: あなたの残ディスク容量は“カブトムシ2匹分”です。
[CRITICAL] 緊急: SSDの空きが“ギャラクシー級に不足”しています。
[WARNING] 残り容量: “カセットテープ1巻分”しかありません。
[NOTICE] あなたのディスク空きは“宇宙の塵”レベルです。
[ALERT] 残容量: “マグロ1匹分”に到達しました。
```

# 注意点
- 実際のシステムディスク容量には一切アクセスせず、現実のストレージ状況には影響しません。
- 通知内容は完全にランダム生成され、意味や単位は実在しません。
- ローカルファイルやシステム設定を変更することはありません。
- 業務システムや本番環境での混乱を避けるため、利用場所に注意してください。
