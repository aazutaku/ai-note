# 概要
このSkillは、OS風の偽パスワード流出通知をランダム生成し、ユーザーにエンタメ体験を提供するものです。実際のパスワードや個人情報は一切使用せず、通知内容も毎回異なるため、現実感とジョーク感のバランスを重視しています。

# 公式ドキュメント抜粋
- [plyer通知API公式](https://plyer.readthedocs.io/en/latest/)
- notify-send (Linux), osascript (macOS) の公式通知機能を活用

# 利用例
- チーム作業中の小ネタ演出
- セキュリティ教育のアイスブレイク
- 長時間作業のリフレッシュ

# 注意点
- 通知内容は完全にフィクションです。
- ログ保存は任意で、デフォルトでは履歴は残りません。
- 本Skillは実害や誤解を避けるため、必ず「ジョーク通知」である旨を明記しています。

# 設計方針
- 毎回異なる現実感のある“それっぽい”パスワードを生成
- 通知APIのクロスプラットフォーム対応
- 誤解や混乱を防ぐ明示的なジョーク表記を徹底
