# 機能概要
このスキルは、PC作業中に突然「OS再起動までのカウントダウン」ウィンドウを表示し、ユーモラスな理由（例：「RAMの気分転換」「OS自己啓発モード突入」など）を添えて、ユーザーを驚かせるジョーク演出ツールです。実際にシステムを再起動することはなく、カウントダウン終了後には「ジョークです」とだけ静かに表示されます。職場や友人とのちょっとした混乱や話題作り、ドキッとしたいときに最適です。

# 使い方
- 明示呼び出し例: `/os-fake-reboot-countdown-prank`
- 暗黙発動キーワード例: 「再起動」「アップデート」「カウントダウン」「RAM」「自己啓発」などが会話やコード内に現れた場合、自動でフェイク通知が表示されます。

# 出力例
```
[ウィンドウ表示]
-----------------------------
OS再起動まで: 30秒
理由: RAMの気分転換
-----------------------------
(カウントダウン表示...)
-----------------------------
ジョークです。
-----------------------------
```

# 注意点
- 本スキルは実際の再起動やシステム操作は一切行いません。
- 通知ウィンドウはローカルPCでのみ表示され、リモート環境やCLI専用端末では動作しません。
- ウィンドウ表示にはPythonの標準GUIライブラリ（tkinter）を使用しています。
- ログや履歴は保存されません。
