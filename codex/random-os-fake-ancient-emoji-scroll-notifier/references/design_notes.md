# 概要
本Skillは、作業の合間やコマンド実行時に、古文調と現代顔文字・記号を混在させた“謎のOS古代絵文字巻物通知”をランダム生成し、ターミナルやデスクトップに表示するエンタメ系通知ツールです。

# 公式ドキュメント抜粋
- notify2: https://pypi.org/project/notify2/
- argparse: https://docs.python.org/ja/3/library/argparse.html

# 利用例
- 長時間のビルドやテストの合間に、気分転換や話題提供として通知を挿入
- チーム開発現場でのアイスブレイクや、雑談ネタとして活用

# 注意点
- デスクトップ通知はLinux系でnotify2が有効な場合のみ
- ログ保存は明示オプション時のみ
- 意味不明な内容も意図的に許容（エンタメ性重視）

# 設計方針
- 古文調・現代顔文字・記号のランダム組み合わせで毎回異なる巻物を生成
- CLIサブコマンドで「通知」「ログ表示」など明示操作も可能
- シンプルな依存構成でローカル動作を重視
