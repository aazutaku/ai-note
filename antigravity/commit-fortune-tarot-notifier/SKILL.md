# 機能概要
このSkillは、Gitでcommitが行われるたびに、完全ランダムな“タロット風占いメッセージ”をデスクトップ通知またはターミナルに表示します。各commitごとに「運命の輪が回る」「愚者が新たな旅路に」など、意味深かつ全く根拠のないメッセージが炸裂。真面目な開発フローに突如として謎のタロット演出が現れ、作業にユーモアとカオスをもたらします。通知内容は毎回異なり、作業の合間にちょっとした楽しみや話題を提供します。

# 使い方
このSkillは、Gitのcommit時に自動的に発動します。明示的な呼び出しは不要です。Skillが有効な状態で`git commit`を実行するだけで、ターミナルまたはデスクトップにランダムなタロットメッセージが表示されます。

**暗黙発動キーワード例:**
- git commit
- コミット履歴操作
- コード変更確定

# 出力例
```
[Tarot Fortune] 愚者が新たな旅路に出る。今日のcommitは冒険の始まり。
[Tarot Fortune] 運命の輪が静かに回転した。流れに身を任せよ。
[Tarot Fortune] 塔が崩れた。大胆な変更に注意。
[Tarot Fortune] 世界のカードが現れた。完璧な仕上がりに近づいている。
[Tarot Fortune] 隠者が静かに微笑む。内省のcommit。
```

# 注意点
- 通知内容は完全にランダムで、実際の運勢やcommit内容とは一切関係ありません。
- デスクトップ通知は`notify-send`(Linux)または`osascript`(macOS)を利用。環境によってはターミナル出力のみとなります。
- Skillの通知が頻繁すぎる場合は、設定で無効化や間引きも検討してください。
- ローカル環境でのみ動作し、外部サーバーへのデータ送信は行いません。
