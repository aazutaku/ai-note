# 機能概要
このSkill「os-fake-random-password-alert」は、あなたの作業中やコマンド実行時に“謎のOS公式・パスワード流出警告”をデスクトップ通知として表示します。通知内容は毎回ランダムに生成され、実在しないパスワード（例：「banana-1977」「tamagoyaki123」）が流出した旨の警告が現れます。現実感がありつつも、必ず「これはジョーク通知です」と明記されるため、混乱を避けつつエンタメとして楽しめます。周囲の反応や自分の気分転換・ネタ用途に最適です。

# 使い方
- 明示的呼び出し例: `/os-fake-random-password-alert`
- 暗黙発動キーワード例: 「コマンド実行」「警告」「パスワード流出」「通知」「ジョーク」などを含む操作や会話時に自動発動します。
- CLIから直接スクリプトを実行することも可能です。

# 出力例
```
[通知] あなたの秘密パスワードが「banana-1977」としてインターネットに流出しました。
警告：本日発見された流出パスワード「tamagoyaki123」
重要：あなたのアカウント情報「penguin_2020」が外部に公開されました。
注意：システムが新たな流出パスワード「misoSoup88」を検出しました。
※これはジョーク通知です。実際の流出ではありません。
```

# 注意点
- 通知内容は毎回ランダム生成され、現実に存在しないパスワードのみを使用します。
- 本Skillはユーザーのローカル環境に通知を表示しますが、情報の保存や外部送信は一切行いません。
- 本物の警告と誤認されないよう、必ず「ジョーク通知」と明記されます。
- 一部のOSや通知環境によっては表示形式が異なる場合があります。
