# 概要
本Skillは、作業中にユーザーの集中を一瞬だけ和らげるための『偽OS休憩通知』をランダムに表示します。実際の業務やデータには一切影響を与えず、ユーモアとリフレッシュ効果を狙っています。

# 公式ドキュメント抜粋
- Python subprocess: https://docs.python.org/3/library/subprocess.html
- win10toast: https://github.com/jithurjacob/Windows-10-Toast-Notifications

# 利用例
- 長時間作業時に自動で休憩通知を表示したい場合
- チームの雰囲気を和ませたい時
- ランダムなタイミングでリフレッシュを促したい場合

# 注意点
- 通知はローカル端末の通知APIを利用するため、環境依存性があります。
- 通知履歴はユーザーホーム以下の .fake_breaktime_alert_history に保存されますが、セキュリティやプライバシーへの影響はありません。

# 設計方針
- OSごとに最適な通知APIを選択し、クロスプラットフォーム動作を重視。
- ユーザー操作なしで自然発動する設計。
- メッセージ内容は完全ランダム生成で、毎回異なる体験を提供。
