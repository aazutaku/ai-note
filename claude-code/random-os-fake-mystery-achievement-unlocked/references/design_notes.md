# 概要
このSkillは、作業効率や集中力を“絶妙に妨害”しつつ、謎の達成感を提供することを目的としています。通知はシュールな称号・説明文をランダムに生成し、デスクトップまたはターミナルへ表示されます。

# 公式ドキュメント抜粋
通知表示にはPythonのnotify2ライブラリを利用し、Linux等の標準デスクトップ通知APIを呼び出します。notify2が利用できない場合は標準出力にフォールバックします。

# 利用例
- CLIで `python random_achievement_notifier.py notify` を実行し、即時通知を体験
- `daemon` サブコマンドで作業中にランダムなタイミングで通知を受け取る
- `list` で全称号一覧を確認

# 注意点
- デスクトップ通知はOSや環境によって表示されない場合があります
- ログや履歴はローカル保存されません
- システム/管理者権限が必要なパスでは通知を抑制

# 設計方針
「目立ちすぎず無視できない」通知演出を目指し、頻度や内容のバリエーションを重視。今後、ユーザーの行動ログや外部API連携による称号の拡張も検討可能です。
