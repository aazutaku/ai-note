# 概要
本Skillは、オフィスや開発現場での雰囲気を和ませるためのエンターテインメント用途に設計されています。実際のセキュリティやOS挙動には一切影響を与えません。

# 公式ドキュメント抜粋
通知表示にはPythonの[plyer](https://plyer.readthedocs.io/en/latest/)ライブラリを利用し、クロスプラットフォームでデスクトップ通知を実現しています。plyerはWindows/Mac/Linuxで動作します。

# 利用例
- `/skills menu`で明示的に選択し、会議中に爆笑フェイク通知を発火
- 「セキュリティ」や「ウイルス」などの単語が会話中に出た際、自動で通知を表示
- CLIから `python fake_security_incident_alert.py log --notify` で即時通知

# 注意点
- 本Skillはシステムやファイルに一切の変更を加えません。
- plyerによる通知はOSごとに見え方が異なります。
- 本物のインシデント通知と混同しないよう、運用ルールを定めてください。

# 設計方針
純粋なエンタメ用途に特化し、ジョーク性・安全性・ランダム性を重視。通知内容は毎回異なり、現実では絶対に起こりえない内容のみを採用しています。
