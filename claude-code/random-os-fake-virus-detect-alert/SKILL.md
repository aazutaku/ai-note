# 機能概要
このSkillは、作業現場に突如「謎のOSウイルス検出アラート」をデスクトップ通知で表示します。通知内容は毎回ランダムで、例えば「怠惰ウイルス」「残業無限増殖型バグウイルス」「コーヒー依存症ウイルス」など、実害ゼロ・緊張ゼロの完全ジョーク仕様です。退屈な作業現場に不条理な刺激を与え、気分転換やチームの笑いを誘発します。実際のシステムやデータには一切影響しません。

# 使い方
- 明示呼び出し例: `/random-os-fake-virus-detect-alert` を実行することで即座にジョーク通知が表示されます。
- 暗黙発動: 「退屈」「集中力が切れた」「気分転換したい」「ジョーク」「通知」などのキーワードや、一定時間作業が継続した際に自動発動します。

# 出力例
```
[通知] OSウイルス検出アラート
脅威名: 怠惰ウイルス (Lazivirus)
詳細: 作業効率を著しく低下させる恐れがあります。
対策: 5分間のストレッチ推奨。

[通知] OSウイルス検出アラート
脅威名: 残業無限増殖型バグウイルス
詳細: 残業時間が永久に増殖する危険性あり。
対策: 早めの帰宅を強く推奨。
```

# 注意点
- 本Skillは完全なジョーク用途であり、システムやファイルへの変更・保存は一切行いません。
- 通知内容は100%フィクションで、実際のウイルスやセキュリティ問題とは無関係です。
- 通知頻度や内容は設定可能ですが、過度な通知にはご注意ください。
