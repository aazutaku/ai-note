# 概要
本Skillは、現実味ゼロの“偽システムメンテナンス通知”をランダム生成し、作業現場や会議中の空気を和ませるための演出系ツールです。通知内容は全てジョークであり、実際のシステムやファイルに一切影響を与えません。

# 公式ドキュメント抜粋
通知文のランダム生成にはPython標準のrandomモジュールを利用し、テンプレート内の時刻や日付もランダムに埋め込みます。通知テンプレートは40種以上を収録。

# 利用例
- `/skills random-os-fake-system-maintenance-alert alert -n 3` で3件のカオス通知を即時出力
- 会議やペアプロで突然“謎通知”を流して場を和ませる

# 注意点
- 出力内容は全てジョークであり、実際のシステムやファイル操作は行いません
- ログや履歴の自動保存機能はありません
- 本Skillの通知を本物と誤解しないよう、利用シーンにご注意ください

# 設計方針
- 実害ゼロ・誤動作リスクゼロを最優先
- カオスかつ現実離れした通知文を厳選
- 10分以内に即体験できるシンプル設計
- CLIサブコマンドで用途別に柔軟に呼び出し可能
