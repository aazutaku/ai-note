# 概要
本Skillは、作業現場に突如として現れる架空のウイルス検出アラートを通じて、気分転換やチームの笑いを提供することを目的としています。実際のウイルスやセキュリティ問題とは一切関係ありません。

# 公式ドキュメント抜粋
通知APIには plyer (https://github.com/kivy/plyer) を利用。クロスプラットフォームでWindows/Mac/Linuxのデスクトップ通知に対応しています。

# 利用例
- 退屈な作業中に自動でジョーク通知を表示し、集中力の回復や場の雰囲気を和らげます。
- チームの朝会や雑談タイムの小ネタとしても活用可能です。

# 注意点
- 通知内容は100%フィクションであり、ユーザーやシステムへの実害はありません。
- plyerの仕様上、通知が出ない場合はOSの通知設定をご確認ください。

# 設計方針
- 実在しないウイルス名・内容であることを徹底し、誤解や混乱を避ける。
- 通知頻度や内容はカスタマイズ可能にし、過度な通知によるストレスを防止。
