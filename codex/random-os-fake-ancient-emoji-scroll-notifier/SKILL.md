# 機能概要
このSkillは、作業中やコマンド実行の合間に、突如として“OS古代絵文字巻物通知”をターミナルまたはデスクトップに表示します。内容は毎回ランダムで生成され、和製古文調の文言と現代的な顔文字・記号が入り混じった、時代錯誤かつシュールなテキストとなっています。これにより、真面目な作業の空気を一瞬で崩し、ユーザーの脳を揺さぶるエンタメ体験を提供します。

# 使い方
- 明示呼び出し: `/skills menu` から本Skillを選択、または `$random-os-fake-ancient-emoji-scroll-notifier` をターミナルで直接実行
- 暗黙発動: ビルド・テスト・デプロイ・長時間コマンドの合間や「通知」「演出」「巻物」などのキーワードを含む文脈で自動発動

# 注意点
- 通知内容は完全ランダム生成のため、意味不明・無関係な場合があります
- ローカル端末の通知機能（notify-send等）やターミナル出力に依存します
- 履歴やログはデフォルトで保存されません
- システム通知が無効な環境ではターミナル出力のみとなります
