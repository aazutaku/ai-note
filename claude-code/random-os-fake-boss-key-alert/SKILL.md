# 機能概要
random-os-fake-boss-key-alertは、作業中のターミナルやデスクトップ環境に突如として“OS公式”を装ったボスキー（緊急画面隠し）警告を表示する演出系スキルです。通知内容は「上司接近！5秒以内にウィンドウを隠してください」や「ボス検知センサーが反応：現在の画面は安全ですか？」など完全ランダムで、実際のウィンドウ制御や画面隠蔽機能は一切ありません。真面目な作業空間に理不尽な緊張感と笑いをもたらし、日常の単調さを打破します。

# 使い方
- 明示的な呼び出し例:
  `/random-os-fake-boss-key-alert`
- 暗黙発動キーワード例:
  `通知`, `警告`, `演出`, `ボスキー`, `OS警告`, `緊急`, `alert`, `boss key`
- スキルは、semantic triggerまたは明示コマンドで発動します。

# 出力例
```
[OS ALERT] 上司接近！5秒以内にウィンドウを隠してください。
[OS WARNING] ボス検知センサーが反応：現在の画面は安全ですか？
[OS NOTICE] 不審な視線を検知。作業内容の見直しを推奨します。
[OS ALERT] 緊急ボスキー発動準備完了。指示があるまで待機してください。
[OS WARNING] 画面の明るさが高すぎます。目立たない作業を推奨。
[OS ALERT] 上司の足音を検出。即座に作業内容を切り替えてください。
```

# 注意点
- 実際のウィンドウ制御や画面隠し機能はありません。
- 通知は完全にランダムで、ユーザーの作業内容や環境には依存しません。
- ローカル保存や履歴記録は行いません。
- 本Skillの出力は演出目的であり、業務用途やセキュリティ対策には利用できません。
