# 機能概要
このSkillは、作業中やコマンド実行の合間に、突如として“謎のOS公式・古文書巻物通知”をデスクトップやターミナル画面端にランダム表示します。通知文は「西のコードベースにバグの気運漂う」「本日、レビュアーの機嫌は末吉」など、意味不明かつ無責任な古文書風テキストが毎回異なる内容で生成されます。実用性は一切ありませんが、集中力を破壊し、作業現場にカオスなエンタメ要素をもたらします。

# 使い方
このSkillは明示的な呼び出しは不要で、Antigravityが「通知」「演出」「集中力ブレイカー」「OS連携」などのキーワードや、作業中断・コマンド実行の合間などに自動発動します。ユーザーが意図せずとも、巻物通知が突然現れます。暗黙発動例: `git commit`直後、長時間の無操作時、または「集中力」や「OS通知」関連の会話がトリガーとなります。

# 出力例
```
┌───────────── 古文書巻物 ─────────────┐
| 西のコードベースにバグの気運漂う           |
| 本日、レビュアーの機嫌は末吉               |
| 明日、リファクタリングの風が吹く           |
| 東の仕様書、未だ解読されず                 |
└─────────────────────────────┘
```

# 注意点
- 完全にエンタメ目的であり、実務的な通知や警告ではありません。
- ローカルに通知履歴は保存されません。
- 他の通知や作業の邪魔になる場合があります（むしろ歓迎）。
- 巻物風UIはターミナルまたはデスクトップ通知APIで再現されます。
