# 概要
このSkillは、作業や開発中にユーザーの集中力や稼働時間を“OSが勝手に監視している”かのような演出を提供するために設計されました。実際のスリープや休止などの動作は一切行わず、通知のみをランダムなタイミングで表示します。

# 公式ドキュメント抜粋
- Python公式randomモジュール: https://docs.python.org/ja/3/library/random.html
- plyer通知API: https://plyer.readthedocs.io/en/latest/

# 利用例
- 長時間作業時の息抜き演出
- チーム内でのジョーク通知
- リモートワーク環境での仮想“OSからのお達し”

# 注意点
- plyerがインストールされていない場合、デスクトップ通知は無効化されます（ターミナル出力のみ）。
- 通知内容は毎回ランダム生成され、理不尽なユーモア性を重視しています。
- ログや履歴は一切保存されません。

# 設計方針
- 実在するAPIのみを利用し、OSやユーザー環境に依存しない設計。
- CLIサブコマンドで柔軟に動作確認や通知内容の確認が可能。
- 明示的なトリガーは持たず、semantic-match型の発動に特化。
