# 機能概要
このSkillは、作業中やコマンド実行後などのタイミングで、架空の“OS公式・本日の作業用BGM推奨通知”をデスクトップ通知またはターミナルに表示します。毎回異なる“ジャンル不明・独自タイトル”の曲名（例:「第3会議室の静寂」「Cドライブ幻想曲」など）がランダムに生成され、実際に音は鳴りませんが、作業空間に一瞬の“謎の演出感”を提供します。気分転換やチーム内の小ネタ、集中力リセットなどに活用できます。

# 使い方
- 明示呼び出し: `/random-os-fake-mysterious-soundtrack-alert`
- 暗黙発動: 「BGM」「作業用BGM」「集中」「気分転換」「OS通知」「謎の演出」などのキーワードを含むコマンドや会話の直後に自動発動します。

# 出力例
```
[OS公式通知] 本日の作業用BGM: 『未定義変数のバラード』
[OS公式通知] 本日の作業用BGM: 『第3会議室の静寂』
[OS公式通知] 本日の作業用BGM: 『Cドライブ幻想曲』
[OS公式通知] 本日の作業用BGM: 『リファクタリングの夜明け』
[OS公式通知] 本日の作業用BGM: 『エラーコードのワルツ』
```

# 注意点
- 実際に音楽は流れません。通知やターミナル出力のみです。
- ローカル環境での通知には `plyer` パッケージが必要です（なければターミナル出力のみ）。
- 出力内容はランダム生成されますが、内容は一時的でファイル保存等は行いません。
- 一部環境ではデスクトップ通知が表示されない場合があります。
