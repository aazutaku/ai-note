# 機能概要
このSkillは、ターミナルやデスクトップに突如として“謎のOS古代絵文字巻物通知”を発生させるエンタメ系演出ツールです。内容は毎回ランダム生成され、和製古文調の謎めいた文章に現代的な顔文字や記号が混ざることで、意味不明かつ時代錯誤な雰囲気を醸し出します。作業中の緊張感や単調な空気を一瞬で崩し、気分転換や話題作りに最適です。

# 使い方
- 明示呼び出し: `/random-os-fake-ancient-emoji-scroll-notifier`
- 暗黙発動: 「バグ」「エラー」「巻物」「通知」「古文」「顔文字」などのキーワードを含むコマンド実行時、または長時間無操作時に自動発動します。
- ターミナル上に直接出力、またはデスクトップ通知（macOS/Linux: notify-send/osascript）で表示されます。

# 出力例
```
【巻物】
東のコード谷にバグの風ぞ吹きぬる…(；´Д｀)
時は令和、されど記号の宴は止まず。
-- (ﾟ∀ﾟ) --

【巻物】
古きOSの夢にて、エラーの影ほの見ゆる。
#(・_・;)# されど我、再起動を恐れず。

【巻物】
バグぞ鳴く、夜半のメモリに。
（￣ー￣）ﾆﾔﾘ
```

# 注意点
- 出力内容は完全にランダム生成され、意味不明な場合があります。
- ローカル通知API（notify-send/osascript）を使用するため、環境によってはデスクトップ通知が表示されない場合があります。
- ログや履歴はローカル保存されません。
- 除外パス: システム/管理系ディレクトリでは自動発動しません。
