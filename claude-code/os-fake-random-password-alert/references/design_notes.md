# 概要
本Skillは、作業やコマンド実行時に毎回異なる“偽パスワード流出警告”をデスクトップ通知で表示し、ユーザーや周囲を一瞬驚かせつつ、必ず「ジョーク通知」である旨を明示するエンタメ系演出ツールです。

# 設計方針
- 通知内容は完全にランダム生成し、実在しないパスワードのみを使用。
- 通知テンプレートやパスワード生成ロジックは拡張性を持たせています。
- plyerライブラリによるクロスプラットフォームな通知実装。
- 本物の流出警告と誤認されないよう、文末に必ず「ジョーク通知」明記。

# 利用例
- チームの休憩時間やイベントでのネタ演出。
- セキュリティ啓発のきっかけや、作業の気分転換。
- ターミナルやスクリプトから直接実行し、複数回通知も可能。

# 注意点
- plyer未導入環境ではprint出力となります。
- ログや履歴は一切保存されません。
- 実際のパスワードや個人情報は一切使用しません。
