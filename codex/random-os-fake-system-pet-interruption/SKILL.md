# 機能概要
このSkillは、作業中のユーザーに対して完全ランダムなタイミングで“OSペット乱入イベント”を発生させる演出ツールです。ペットは仮想的な猫や犬、鳥などがデスクトップ上を横切ったり、ファイルの上で寝たり、マウスカーソルを追いかけたりします。通知や端末出力を通じて、何の役にも立たない癒しと混乱を提供し、集中しすぎた状態を一瞬リセットします。OSがペットを飼い始めたような不思議な体験が得られます。

# 使い方
- 明示呼び出し例: `/skills menu` から `random-os-fake-system-pet-interruption` を選択、または `$random-os-fake-system-pet-interruption` への直接言及。
- 暗黙発動: 作業が一定時間継続している、または「疲れ」「集中しすぎ」「癒し」などのキーワードが会話やログに現れた場合に自動発動します。

# 出力例
```
[OSペット通知] デジタル柴犬がファイル「report.docx」の上で昼寝を始めました。
[OSペット通知] 仮想猫がマウスカーソルを追いかけています！
[OSペット通知] OS公式ペンギンが画面を横切りました。
[OSペット通知] デジタルインコがウィンドウの隅で羽を休めています。
[OSペット通知] バーチャルハムスターがタスクバーでおやつを探しています。
```

# 注意点
- このSkillは実用的な機能はありません。通知内容は完全に架空です。
- ローカルファイルの変更や実際のデスクトップ操作は行いません。
- 出力は端末または通知API経由のみ。実際のペット画像やアニメーションは含みません。
- 連続発動を避けるため、一定のクールタイムを設けています。
