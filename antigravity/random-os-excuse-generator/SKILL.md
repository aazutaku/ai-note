# 機能概要
random-os-excuse-generatorは、開発や作業中に発生するエラーやバグ、ビルド失敗時などに、まったく根拠のない“OS風ジョーク言い訳”を自動で生成し、デスクトップ通知やターミナルに表示するスキルです。深刻なエラーも思わず笑って流せるユーモラスな演出で、開発現場の緊張を和らげます。通知内容は毎回ランダムかつクリエイティブで、作業効率には影響せず安全です。

# 使い方
このSkillは明示的な呼び出し操作は不要です。Antigravityが「バグ」「エラー」「失敗」「クラッシュ」「動かない」などのキーワードやエラーイベントを検知した際に自動発動します。ターミナルやデスクトップ通知に“謎のOS言い訳”が表示されます。

# 出力例
```
[OS Excuse]: 今回のバグは、地球の自転が速すぎたせいです。
[OS Excuse]: コードが恥ずかしがっているため、動作を拒否しました。
[OS Excuse]: 太陽フレアの影響で、処理が一時的に停止しました。
[OS Excuse]: メモリ内の妖精が昼寝中です。しばらくお待ちください。
[OS Excuse]: 水星逆行のため、予期せぬ挙動が発生しました。
```

# 注意点
- 本Skillは通知・演出のみを目的としており、実データやシステムに変更を加えません。
- ローカル環境でのみ動作し、本番環境や重要なデータには影響しません。
- 出力内容はすべてジョークであり、実際の障害原因とは無関係です。
