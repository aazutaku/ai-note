# 概要
本Skillは、作業中に完全ランダムなタイミングで“OS公式風”の理不尽な警告を表示することで、緊張感とユーモアを演出します。実用性はありませんが、作業空間の雰囲気を一変させる演出系Skillです。

# 公式ドキュメント抜粋
- osascript (macOS通知)
- notify-send (Linux通知)
- win10toast (Windows通知)

# 利用例
- 長時間の単調な作業中に突如警告が表示され、場の空気が和む
- オンライン勉強会やリモートワークでネタとして活用

# 注意点
- 本Skillは実際の画面隠しやセキュリティ機能は一切ありません
- 通知のタイミングや文面は完全ランダムで制御できません

# 設計方針
- OS標準APIのみを利用し、追加の外部依存を最小限に
- ログや履歴は一時メモリのみで永続化しない設計
- ユーザーの操作や作業内容に依存せず、純粋なランダム性を重視
