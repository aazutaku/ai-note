# 概要
本Skillは、知的作業空間に“非日常”を演出するための通知スキルです。システムやファイルに一切影響を与えず、完全に演出専用のランダム通知を生成します。

# 公式ドキュメント抜粋
通知実装には plyer ライブラリ (https://pypi.org/project/plyer/) を利用し、クロスプラットフォームなデスクトップ通知を実現しています。plyerが未導入の場合はターミナル出力に自動フォールバックします。

# 利用例
- 長時間作業のリフレッシュ
- チーム内の雑談やアイスブレイク演出
- コーディングセッションの合間の気分転換

# 注意点
本Skillは、通知内容が完全に架空であり、実際のOSやファイル操作には影響しません。履歴保存はユーザー明示オプションのみで行われます。

# 設計方針
- 毎回異なる通知内容
- 過剰通知防止
- システム安全性・副作用ゼロ
- ログ保存は opt-in 方式
