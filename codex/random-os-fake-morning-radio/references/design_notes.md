# 概要
このSkillは、作業開始時などに“謎のOSラジオ”風の無駄なメッセージを通知・ターミナルに出し、開発現場の朝を盛り上げるために設計されました。内容は完全に架空で、実際のシステムには影響しません。

# 公式ドキュメント抜粋
- Linux: `notify-send` コマンドはFreedesktop.orgの通知仕様に基づき、デスクトップ環境に短いメッセージを表示します。
- macOS: `osascript` でAppleScriptを実行し、通知センターにメッセージを出せます。

# 利用例
- ターミナルで `python os_fake_morning_radio.py --notify` を実行すると、日替わりでラジオ風メッセージが表示されます。
- `/skills random-os-fake-morning-radio` で明示呼び出しも可能。

# 注意点
- Windowsではデスクトップ通知をサポートしていません（ターミナル出力のみ）。
- ログや履歴はローカルに保存されません。
- 本Skillは業務効率化を目的としません。

# 設計方針
- 日替わりでメッセージが変化するよう、日付シードを利用。
- 実在のAPI/コマンドのみを利用し、追加インストール不要で動作。
- 無駄な情報で現場に笑いと活気を提供することを重視。
