# 機能概要
このSkillは、作業中や集中タイムに“謎のOS環境音通知”を突如表示することで、日常の作業空間に非日常感を演出します。実際には何も再生されませんが、「森のさざめきBGMを自動再生します」「今から15分間は謎のカフェ騒音推奨」など、意味不明な通知がランダムに現れ、仕事場を一瞬だけ異世界に変えます。通知内容は完全ランダムで、ユーザー自身も「なぜ？」と思うような不可解さを楽しめます。

# 使い方
このSkillは明示的な呼び出しは不要です。`BGM`, `環境音`, `集中`, `作業効率`, `OS通知`, `気分転換`, `演出`, `フェイク`などのキーワードや、作業中のタイミングで自動的に発動します。通知はターミナルやデスクトップに表示されますが、実際の音は一切鳴りません。

# 出力例
```
[OS公式通知] 本日は集中力向上のため、森のさざめきBGMを自動再生します（実際の再生はありません）
[通知] 今から15分間は謎のカフェ騒音推奨。気分転換にどうぞ。
[OS環境音] 深夜のサーバールームホワイトノイズを流します（フェイクです）
[システム] 本日は雨音BGM推奨日です。リラックスして作業を続けてください。
[通知] 本日限定：謎の宇宙船内環境音を自動適用中。
```

# 注意点
- 実際の音声やBGMは一切再生されません。
- 通知頻度は自動調整され、うるさすぎない設計です。
- ローカルファイルや履歴は保存されません。
- 明示呼び出しやカスタム設定はありません。
