# 概要
本Skillは、作業中のユーザーに対して、実際には存在しない“コーヒー関連OS警告”をデスクトップ通知で表示するジョーク系演出ツールです。真面目な作業環境に遊び心を加え、チームの雰囲気を和らげることを目的としています。

# 公式ドキュメント抜粋
通知には plyer の notification API を利用しています。plyerはクロスプラットフォームで、Windows/macOS/LinuxのOS通知に対応しています。

# 利用例
- 長時間のコーディングや会議中に、定期的にコーヒー警告を発火させてリフレッシュを促す。
- チーム内のSlackやチャットで「コーヒー」などの単語が出た際に自動発火。
- CLIから明示的にジョーク通知を送り、場を和ませる。

# 注意点
- 通知は実用的な警告ではありません。業務フローや監視用途には使用しないでください。
- plyerの通知は一部Linux環境で追加パッケージが必要な場合があります。

# 設計方針
- 実在するAPIのみを使用し、依存関係を最小限に抑えています。
- キーワード監視・定期発火・明示呼び出しの3パターンで柔軟に利用可能です。
