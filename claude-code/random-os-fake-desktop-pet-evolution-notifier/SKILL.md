# 機能概要
このSkillは、あなたの作業環境に突如“謎のOS公式・デスクトップペット進化通知”を炸裂させます。内容は毎回ランダムで、実際には存在しないペットが勝手に進化・誕生したことを、愉快かつ唐突に告げます。例えば「あなたのマウスポインタは“幻のカメレオン形態”に進化しました」や「本日よりキーボードは“サボテン系ペット”が宿ります」など、現実のOSやファイルには一切影響を与えない安全設計です。作業の合間にちょっとした笑いと謎の“育成感”を強制付与し、集中しすぎによる疲労感の緩和や、チーム内のアイスブレイクにも活用できます。

# 使い方
- 明示呼び出し例: `/random-os-fake-desktop-pet-evolution-notifier`
- 暗黙発動キーワード例: 「ペット」「進化」「通知」「デスクトップ」「育成」などを含む会話やコマンド時に自動発動

# 出力例
```
[OS公式通知] あなたのマウスポインタは本日“幻のカメレオン形態”に進化しました。
[OS公式通知] 本日よりキーボードは“サボテン系ペット”が宿ります。
[OS公式通知] デスクトップに“空飛ぶクラゲ型ペット”が誕生しました。
[OS公式通知] あなたのウィンドウ枠は“忍者リス形態”へ進化しました。
[OS公式通知] 本日限定で“光るカタツムリ型ペット”が出現中です。
```

# 注意点
- 通知は毎回ランダム生成され、実在のOS・ファイル・設定には一切影響を与えません。
- ローカルファイルやシステムに保存・変更は行いません。
- 出力はターミナルまたはAIの応答のみで、実際のデスクトップに通知が表示されることはありません。
- 業務環境や公共の場での利用時は、内容がジョークであることにご留意ください。
