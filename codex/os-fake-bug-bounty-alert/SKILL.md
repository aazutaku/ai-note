# 機能概要
このSkillは、あなたの開発現場や作業中に突如として“謎のOSバグバウンティ発表通知”を生成・表示します。通知内容は毎回ランダムで、現実離れしたバグ（例：『CapsLockキーが月曜だけ逆転するバグ』）と、ユーモラスな報酬（例：『賞金：2バグポイント＋伝説の称号』）が組み合わされます。真面目な空間に予測不能な笑いを提供し、場の緊張を一瞬でほぐします。

# 使い方
- 明示呼び出し例:
  - ターミナルで`python os_fake_bug_bounty_alert.py`を実行
  - /skillsメニューや`os-fake-bug-bounty-alert`へのメンション
- 暗黙発動例:
  - 「バグ」「報酬」「バウンティ」「OS通知」などのキーワードを含む会話やコマンド実行時

# 出力例
```
[OS Bug Bounty Alert]
発見: 本日限定“昼寝検出バグ”を修正した方に謎の称号『睡魔征服者』を授与。
報酬: 1.5バグポイント＋謎のトロフィー

[OS Bug Bounty Alert]
重大: キーボードのJキー過剰使用バグ発生中。修正者には“Jの守護者”称号進呈。
報酬: 3バグポイント
```

# 注意点
- 通知内容は完全にフィクションであり、実害やデータ損失は一切ありません。
- ローカルファイルやシステムに影響を与えず、通知は一時的にのみ表示されます。
- 業務用端末や共有環境での利用時は、場の雰囲気に配慮してください。
