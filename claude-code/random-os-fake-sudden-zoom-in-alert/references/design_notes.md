# 概要
このSkillは、ユーザーの作業中に「ズームイン警告」風のフェイク通知をランダムに表示し、空気を和ませたり驚かせたりすることを目的としています。実際のズーム処理や画面制御は一切行わず、通知内容も毎回ランダム生成されます。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonの`plyer`ライブラリを利用しています。plyerはクロスプラットフォーム対応で、Windows/Mac/Linuxで同一コードが動作します。
- plyer公式: https://github.com/kivy/plyer

# 利用例
- 会議やライブコーディング時の空気転換
- 単調な作業のリフレッシュ
- チーム内でのジョーク演出

# 注意点
- 通知はローカル環境でのみ表示され、ログや履歴は残りません。
- 除外パス配下や一部プロセスでは発動しません。
- plyer未インストール環境では標準出力のみ対応します。

# 設計方針
Skill本体は100行以上のPythonコードで、明示/暗黙発動・CLIサブコマンド・エラー処理などを実装。通知内容の多様性と安全性（実害ゼロ）を最重視しています。
