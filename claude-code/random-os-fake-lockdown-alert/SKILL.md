# 機能概要
このSkillは、作業中に突如として「謎のOSロックダウン発令通知」をデスクトップやターミナルに表示します。通知内容は完全ランダムで、例えば「全ファイル凍結」「理由：カフェイン過剰摂取検知」「解除方法：深呼吸5回」など、現実にはあり得ない非日常的なメッセージが炸裂。真面目な作業現場に突如カオスと笑いをもたらし、チームの雰囲気を一瞬だけ和ませます。実ファイルや環境への影響は一切なく、演出専用です。

# 使い方
- 明示呼び出し例：`/random-os-fake-lockdown-alert` または `/skill random-os-fake-lockdown-alert`
- 暗黙発動例：会話やコード内に「集中」「眠い」「退屈」「生産性」などのキーワードが含まれる場合、自動で通知が発動します。

# 出力例
```
=== 緊急OSロックダウン発令 ===
発令時刻: 2024-06-01 14:23:11
理由: カフェイン過剰摂取検知
影響範囲: 全ユーザーディレクトリ
解除方法: 深呼吸5回 + 机の上を片付ける
=============================
```
```
=== 謎のシステム凍結警告 ===
発令時刻: 2024-06-01 15:02:44
理由: キーボード連打による過熱
影響範囲: /tmp, /home, /dev/null
解除方法: 画面を3秒間見つめる
=============================
```

# 注意点
- 実際のファイルやシステムには一切影響を与えません。
- 通知は標準出力またはデスクトップ通知APIでのみ表示されます。
- ローカルに履歴や記録は残しません。
- 業務環境での使用はジョーク目的に限定し、誤解を招かないよう注意してください。
