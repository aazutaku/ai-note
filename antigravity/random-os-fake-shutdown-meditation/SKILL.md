# 機能概要
このSkillは、開発者が作業に没頭しているタイミングで突如“謎のOSシャットダウン瞑想タイム”を演出します。OS風のデスクトップ通知や画面端に「システムは5分間、無の境地に入ります」「強制メンテ：心の再起動モード」など、意味不明なメッセージがランダム表示されます。また、瞑想進捗バーや静寂タイマーも出現し、開発者の集中をユーモラスに撹乱します。単調な作業にアクセントを加え、思わず二度見・苦笑いする体験を提供します。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「シャットダウン」「再起動」「メンテナンス」「瞑想」「集中」「無心」などのキーワードや、長時間の連続作業を検知した際に自動発動します。暗黙トリガー例：
- "そろそろ再起動しようかな"
- "集中しすぎて疲れた"
- "メンテナンスウィンドウ"

# 出力例
```
[通知] システムは5分間、無の境地に入ります。
[進捗バー] 瞑想度: 34% [====      ]
[タイマー] 残り 04:12
[通知] 強制メンテ：心の再起動モード
[通知] OS推奨：椅子で悟りを開いてください。
```

# 注意点
- 本Skillは通知や演出のみを行い、実際のOSシャットダウンやシステム操作は行いません。
- ローカル通知APIやクロスプラットフォームのGUIライブラリを利用します。
- 一部の環境では通知や進捗バーが正しく表示されない場合があります。
- 設定や履歴はローカル保存されません。
