# 概要
このSkillは、現実のOSやファイルに影響を与えず、ユーザーの作業環境に“謎のペット進化通知”という遊び心を提供するために設計されています。通知は完全に架空であり、実際のシステム動作や設定を変更することはありません。

# 公式ドキュメント抜粋
通知にはPythonの`plyer.notification` APIを利用しています。plyerはクロスプラットフォームでデスクトップ通知をサポートし、インストールされていない場合は標準出力にフォールバックします。

# 利用例
- 業務中の気分転換やチーム内の話題作り
- ジョーク用途やハッカソンでの演出
- ターミナル/デスクトップの遊び心追加

# 注意点
- plyerが未インストールの場合はprint出力のみ
- ログはユーザーディレクトリに保存されますが、履歴管理以外の目的で利用されません
- 実在のペットやOS設定には一切影響なし

# 設計方針
安全性と無害性を最優先し、通知内容は毎回ランダム生成されるよう工夫しています。通知履歴や集計機能も付加し、ユーザーの利用状況を可視化できます。
