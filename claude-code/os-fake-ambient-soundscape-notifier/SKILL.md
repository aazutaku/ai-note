# 機能概要
このSkillは、作業中やコーディング時に突如“謎のOS環境音通知”を表示し、デスクトップやターミナルに非日常的な演出を加えます。通知内容は完全ランダムで、「森のさざめきBGMを自動再生します」や「今から15分間はカフェ騒音推奨」など、実際には何も再生されない“フェイク通知”です。これにより、ユーザーは音が鳴っているような気分を味わいながら、作業場に新鮮な刺激やユーモアをもたらします。集中力向上や気分転換、雑談のきっかけにも最適です。

# 使い方
- 明示呼び出し: `/os-fake-ambient-soundscape-notifier` で即時通知
- 暗黙発動: 「環境音」「BGM」「集中」「休憩」などのキーワードを含むプロンプトや、長時間作業中のタイミングで自動発動
- 通知頻度やタイミングは自動調整され、うるさすぎない設計です

# 出力例
```
[OS通知] 本日は集中力向上のため、森のさざめきBGMを自動再生します（実際には再生されません）
[OS公式] 今から15分間は謎のカフェ騒音推奨。耳を澄ませてみましょう。
[通知] システム推奨: 砂浜の波音モードに切り替えます。ごゆっくりお過ごしください。
[OS通知] 本日は“宇宙船エンジン音”BGMが選ばれました。静かな宇宙をお楽しみください。
[通知] ご注意: 本通知は演出のみで、実際の音は鳴りません。
```

# 注意点
- 実際の音声やBGMは一切再生されません（完全なフェイク通知）
- 通知内容は毎回ランダム生成されますが、同じテーマが重複する場合があります
- ローカルファイルや履歴は保存されません
- 過度な頻度にならないよう自動制御されています
