# 概要
このスキルは、OS再起動を模したフェイク通知でユーザーに驚きや笑いを提供する演出ツールです。再起動やシステム操作は一切行わず、ウィンドウ表示のみを行います。

# 公式ドキュメント抜粋
- tkinter: https://docs.python.org/3/library/tkinter.html
- argparse: https://docs.python.org/3/library/argparse.html

# 利用例
- オフィスやイベントでのドッキリ演出
- チームの朝会や雑談時のアイスブレイク
- 「アップデート」や「再起動」ワードが出た際の自動演出

# 注意点
- 実際の再起動やファイル操作は一切発生しません。
- ウィンドウはローカルPC上でのみ表示されます。リモートやSSH環境では動作しません。

# 設計方針
- シンプルなPython標準GUI (tkinter) のみで完結
- 理由テキストはランダムまたは指定可能
- CLIサブコマンドで柔軟に利用可能
