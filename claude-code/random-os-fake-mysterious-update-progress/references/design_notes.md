# 概要
本Skillは、作業中に非日常感や脱力感を与えるための演出系ツールです。実際のOSやシステムには一切影響を及ぼさない設計となっています。

# 公式ドキュメント抜粋
- Python random: https://docs.python.org/ja/3/library/random.html
- Python time: https://docs.python.org/ja/3/library/time.html

# 利用例
- チームのアイスブレイクや休憩タイムの話題作り
- 長時間作業の合間の気分転換
- プレゼンや配信でのネタ演出

# 注意点
- 進捗バーは標準出力のみで、システムやファイルには一切変更を加えません
- 実行中に99%で止まる、逆戻りするなど理不尽な挙動は仕様です
- 本番環境や重要な作業の妨げにならないようにしてください

# 設計方針
- 進捗内容・逆戻り・99%停滞など、すべてランダム性を持たせて毎回異なる演出を実現
- CLIサブコマンドで履歴表示や内容一覧もサポート
- シンプルな依存（標準Pythonのみ）でどこでも実行可能
