# 機能概要
このSkillは、作業中やコマンド実行時に完全ランダムな“偽OSエラーハイク”をデスクトップ通知またはターミナル出力として表示します。エラー内容は五・七・五の俳句形式で、毎回異なる内容が生成されます。例えば「メモリ消ゆ　春まだ遠き　バグの夜」や「404　道に迷いて　春霞」など、技術的な用語と詩的な表現が融合した、実用性ゼロなのに心に残る通知体験を提供します。作業の合間に思わずクスリとする摩訶不思議な演出が欲しい方に最適です。

# 使い方
- 明示呼び出し: `/random-os-fake-error-haiku-notifier` を実行すると即座にランダムな偽エラーハイクが表示されます。
- 暗黙発動: ターミナルやコード内で「error」「fail」「not found」「exception」などのキーワードが出現した際にも自動発動します。
- 通知頻度はデフォルトで5分に1回程度、`--interval` オプションで変更可能です。

# 出力例
```
[OS Error Haiku]
メモリ消ゆ
春まだ遠き
バグの夜

[OS Error Haiku]
404
道に迷いて
春霞

[OS Error Haiku]
セグフォ落ち
眠れぬ夜の
カーネルパニック
```

# 注意点
- 実際のエラー通知ではなく、完全なジョーク通知です。
- 通知内容や頻度が作業の妨げにならないよう調整可能です。
- ローカル環境のみに通知され、外部送信や情報保存は行いません。
- 除外パスや特定ディレクトリでの発動抑制も設定可能です。
