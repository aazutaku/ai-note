# 機能概要
このSkillは、作業や開発の合間に「解読不能な横文字や謎の呪文」で構成された“OS古代バグ巻物”風のエラー通知を、ターミナルやデスクトップにランダムに表示します。内容は完全に意味不明で、最後に「解読者求ム」「解決不能」などの無情な一言がスクロールアウト。バグ報告すら理解不能な状況をあえて演出し、チームにカオスと笑いを提供します。通知・演出・OS連携カテゴリに属し、開発現場の緊張を和らげるネタ系Skillです。

# 使い方
- 明示呼び出し例: `/skills menu` から選択、または `$random-os-fake-unreadable-error-scroll` で直接発動
- 暗黙発動キーワード例: error, crash, バグ, unknown failure, OS, panic, exception などの出現時に自動発動

# 出力例
```
╭──────────────────────────────╮
│  ERROR: 0x8F2A3B - UNREADABLE │
│  Xqv!#%&*zplmn$@!~            │
│  0x9A2B: FATAL: GxvZk!@#      │
│  SYST: ∑ΩΔΞΨΦΛΣ∏∫             │
│  [解読者求ム]                  │
╰──────────────────────────────╯
```

# 注意点
- 出力はローカル端末のターミナル/シェル上のみ。ファイル保存や外部送信は行いません。
- 実害はありませんが、頻繁すぎる通知は作業の妨げになるため、発動頻度を調整可能です。
- 本Skillは実際のエラー検知や修復は行いません。完全なジョーク用途です。
