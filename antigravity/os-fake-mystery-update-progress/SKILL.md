# 機能概要
このSkillは、作業中に突如として『謎のOSアップデート進行中』を装った進捗バーをターミナルやデスクトップに表示します。進行内容は「未知の言語パーサ更新中」「秘密のAPIを最適化中」「伝説のバグを発掘中」など毎回ランダムで、進捗バーは時に止まり、逆流し、理不尽な挙動を見せます。実際には何も更新されず、意味も実害もありません。集中力や現実感をじわじわ侵食する、理不尽な演出を提供します。

# 使い方
このSkillは明示的な呼び出しは不要です。Antigravityが「進捗」「アップデート」「OS」「アップグレード」「更新」「バー」「進行状況」などのキーワードを検知すると、自動的に進捗バーが表示されます。手動で `python os_fake_mystery_update_progress.py` を実行することで、ローカル端末でも同様の演出を体験できます。

# 出力例
```terminal
[■■■■■■■---------] 37% 未知の言語パーサ更新中...
[■■■■■■■■■■-----] 62% 秘密のAPIを最適化中...
[■■■■■■■■■■■■■--] 85% 伝説のバグを発掘中...
[■■■■■■■■■■■----] 70% 仕様書を暗号化中...
[■■■■■■■■--------] 50% メモリの謎領域を再構成中...
```

# 注意点
- 実際のシステムやファイルには一切影響しません。
- 進捗バーの内容や挙動は完全に架空です。
- ログや履歴は保存されません。
- 本Skillは通知・演出用途限定で、実務的な意味はありません。
