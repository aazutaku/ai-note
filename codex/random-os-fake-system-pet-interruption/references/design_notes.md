# 概要
本Skillは、ユーザーの作業中に完全ランダムなタイミングで“OSペット乱入”という非生産的な癒しイベントを発生させるものです。現実のデスクトップやファイルには一切影響を与えず、通知APIや端末出力のみを利用します。

# 公式ドキュメント抜粋
- Python通知API: https://docs.python.org/ja/3/library/notify2.html
- Linux通知仕様: https://developer.gnome.org/notification-spec/

# 利用例
- 長時間作業中に「trigger」コマンドで強制乱入
- 「auto」モードで20分〜30分毎に自動発動
- 履歴やペット別回数の集計も可能

# 注意点
- 実際のペット画像やアニメーション表示は行いません
- ログはホームディレクトリ配下に保存
- クールタイム制御あり

# 設計方針
- 完全ランダム性と多様なメッセージで飽きさせない
- 実在APIのみ使用し、環境依存を最小化
- ログや履歴で“癒しイベント”の振り返りも可能に
