# 機能概要
このSkillは、作業中に突如「謎のOSシステムメンテナンス予告通知」をランダム表示します。通知内容は「本日21:00より全システムを逆さまにします」「緊急：マウス左クリック機能が右クリックに統合されます」など、現実味ゼロのカオスな内容ばかり。真面目な現場やペアプロ、会議の空気を一変させ、集中力や現実感覚を華麗に攪乱します。通知は毎回ランダム生成されるため、同じものが表示されることはほぼありません。

# 使い方
- 明示呼び出し例: `/random-os-fake-system-maintenance-alert` を実行すると即座に偽通知が表示されます。
- 暗黙発動キーワード例: 「メンテナンス」「保守」「OS」「通知」「システム」などが会話やコードに現れると自動発動します。

# 出力例
```terminal
[OSメンテナンス通知] 重要：本日23:30より全端末の画面表示を縦書きに切り替えます。
[OSメンテナンス通知] 緊急：明日午前2時から全ユーザーのパスワードが「password」にリセットされます。
[OSメンテナンス通知] ご案内：本日深夜、マウスカーソルが常に逃げ続けるモードに移行します。
[OSメンテナンス通知] 重要：全ファイル名がランダムな絵文字に変換されます。
[OSメンテナンス通知] 緊急：全システムで「Ctrl+Z」が「シャットダウン」に割り当てられます。
```

# 注意点
- 実際のシステムには一切影響しません。通知は完全なジョークです。
- データ損失や誤動作リスクはゼロです。
- 通知内容は毎回ランダム生成され、ローカルに保存されません。
- 業務や重要な会議でのご利用は空気を読んでください。
