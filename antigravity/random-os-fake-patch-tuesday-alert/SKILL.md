# 機能概要
このSkillは、あなたの作業やコマンド実行の合間に、まるで本物のOS公式アップデート通知のような“ありえないパッチノート”を突如表示します。内容は毎回完全ランダムで、「CapsLockキーの押下回数が閾値を超えたため、緊急再起動が必要です」や「新機能: Shiftキーを2秒長押しするとOSが詩を朗読」など、現実には絶対存在しない珍妙なアップデート情報を生成。通知はデスクトップとターミナルの両方に対応し、日常の作業にユーモアと混乱をもたらします。

# 使い方
このSkillは明示的な呼び出しコマンドは不要です。Antigravityエージェントが「パッチ」「アップデート」「OS通知」などのキーワードや、長時間の作業・コマンド連打を検知した際に自動で発動します。設定により、デスクトップ通知またはターミナル表示を選択可能です。

# 出力例
```
[Fake Patch Tuesday Alert]
本日、Ctrlキーの押下速度が基準値未満のため、緊急アップデートが適用されます。
- 新機能: Altキー長押しでOSが詩を朗読
- 既知の問題: エスケープキーの連打で画面が逆立ちします
- 重要: 次回再起動時にCapsLockが自動解除されます
```

# 注意点
本Skillは完全にジョーク目的であり、実際のシステムアップデートやセキュリティ通知とは一切関係ありません。通知内容はランダム生成のため、予期せぬ文言や混乱を招く場合があります。ローカルに通知履歴は保存されません。業務用端末での利用は推奨されません。
