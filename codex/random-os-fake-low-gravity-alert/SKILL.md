# 機能概要
このSkillは、作業中に突如「OS低重力モード突入通知」をデスクトップやターミナルに発生させる演出ツールです。通知内容は「警告：本日このPCは低重力環境に切り替わりました」「コードのバグがふわふわ浮遊中」など、毎回完全ランダム。仕事や学習の緊張感を一瞬で宇宙遊泳気分に切り替え、知的作業空間に非日常体験をもたらします。システム挙動やファイルには一切影響を与えません。

# 使い方
- 明示呼び出し: `/skills menu` から本Skillを選択、または `$random-os-fake-low-gravity-alert` をターミナル等で実行
- 暗黙発動: 「低重力」「宇宙」「浮遊」などのキーワードを含む作業ログや会話を検知した際、自動でランダム通知を表示

# 出力例
```
[低重力アラート] 警告：本日このPCは低重力モードに切り替わりました。
[低重力アラート] コードのバグがふわふわ浮遊中。捕まえてください！
[低重力アラート] ファイルのドラッグ操作が普段の3倍遠く飛びます。
[低重力アラート] OSの重力制御装置が一時的にオフラインです。
[低重力アラート] ターミナルの出力が無重力で流れます。
```

# 注意点
- 通知は完全ランダムで毎回異なります
- システムやファイル操作には一切影響しません
- 通知頻度は1時間に1回以下、または明示呼び出し時のみ
- ローカル保存や履歴機能はありません
