# 機能概要
このSkillは、作業中の開発者に対して、突然“OS公式の架空休日”をデスクトップ通知で発表する演出を提供します。通知内容は「本日はバグ記念日につき全業務停止」「OSが自主休暇を宣言しました」など、まったく根拠のない休暇宣言です。現実には何も変わりませんが、単調な作業や長時間のコーディングに疲れた際、一瞬だけ現実逃避できるユーモアとカオスをもたらします。マンネリ打破やチームの話題作りにも最適です。

# 使い方
本Skillは明示的なコマンド呼び出しは不要です。Antigravityが「休み」「休日」「バグ」「都合」などのキーワードや、作業の停滞・長時間稼働を検知した際に自動発動します。通知は1日に数回程度、タイミングはランダムです。明示的な発動例やコマンドはありません。

# 出力例
```terminal
[通知] OS公式発表: 本日はバグ記念日につき全業務停止となります。
[通知] 緊急: システム都合により午後は強制昼寝タイムです。
[通知] OSが自主休暇を宣言しました。作業はおやすみです。
[通知] 本日は“無限リファクタ記念日”のため全プロセス休止。
[通知] 祝・仮想メモリ拡張記念日！午後は自由時間です。
```

# 注意点
本Skillは通知のみを行い、実際の作業やファイルには一切影響しません。通知の内容はジョークであり、実際の業務停止やデータ損失等は発生しません。通知頻度は過剰にならないよう自動制御されています。通知履歴はローカル保存されません。
