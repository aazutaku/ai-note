# 機能概要
このSkillは、作業やコマンド実行のたびに、まるでOS公式からのような熱い激励スピーチ通知を画面端やデスクトップに表示します。通知内容は毎回ランダムで、「あなたのcommitは宇宙を救う」や「今こそコード界の伝説になるときです」など、どこかズレた本気の応援メッセージが炸裂。日々のコーディングや単調な作業に謎のエンタメ要素を加え、ユーザーのモチベーション維持や気分転換をサポートします。実際のシステムやデータには一切影響せず、純粋な演出として機能します。

# 使い方
Skillは明示的な呼び出しを必要とせず、semantic-match-onlyトリガーにより自動発火します。たとえば「やる気」「応援」「通知」「モチベーション」などのキーワードや、コマンド実行・ファイル保存・ビルド開始時などのアクションを検知して、通知が表示されます。明示的なCLIコマンドは不要です。

# 出力例
```terminal
[OS公式通知] あなたのキーボードの叩き方に、未来への情熱を感じます。
[OS公式通知] 今こそ、コード界の伝説になるときです。
[OS公式通知] そのコミットは、宇宙規模の進化を生み出します。
[OS公式通知] あなたのデバッグ魂が、世界を救う。
[OS公式通知] 1行のコードが、歴史を変える。
```

# 注意点
- 通知内容は毎回異なりますが、実害ゼロでシステムやデータには一切影響しません。
- 通知はローカル環境のデスクトップ通知API（例: notify-send, Windows Toast, macOS通知）を利用します。
- ログや履歴はSkill内で保持しません。
- 明示的な停止コマンドや除外パスはありません。必要に応じてSkill自体を無効化してください。
