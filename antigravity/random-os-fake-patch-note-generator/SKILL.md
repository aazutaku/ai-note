# 機能概要
random-os-fake-patch-note-generatorは、日常の開発作業をユーモラスに演出するためのSkillです。ターミナルやエディタでコマンド実行やファイル保存などのアクションを検知すると、まるで本物のOSアップデートのような“謎のパッチノート”を毎回ランダム生成して通知またはターミナルに表示します。内容は「バグ修正」「新機能追加」「既知の問題」など、現実とは無関係なカオスな文章で、作業の緊張感を和らげます。

# 使い方
このSkillは明示的な呼び出し不要で、Antigravityがコマンド実行・ファイル保存・ビルド・実行などのアクションを検知したときに自動発動します。暗黙発動キーワード例: `update`, `patch`, `build`, `save`, `run`, `deploy` など。

# 出力例
```
[FakeOS Patch Note v3.1.42]
- バグ修正: 机の上の書類が自動で増殖する問題を解消しました。
- 新機能: 集中力が一瞬だけ上昇するアルゴリズムを追加。
- 既知の問題: おやつの消費が止まらない現象が継続中です。

[FakeOS Patch Note v2.9.17]
- 機能追加: マウスカーソルが時々踊る機能を実装。
- バグ修正: コーヒーカップの残量が誤表示される不具合を修正。
```

# 注意点
- 本Skillは実際のOSやソフトウェアには一切影響しません。
- 出力はローカル通知またはターミナル表示のみで、ファイル保存等は行いません。
- 頻度制御により、作業の邪魔にならないよう配慮されています。
- 除外パスや特定プロセスでは発動しません。
