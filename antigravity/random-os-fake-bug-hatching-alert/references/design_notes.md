# 概要
このSkillは、OS風の“バグ孵化警告”を完全ランダムなタイミングでユーザーに通知する演出用スクリプトです。実害はなく、気分転換やチームの話題作りを主目的としています。

# 公式ドキュメント抜粋
デスクトップ通知にはPythonの[plyer](https://plyer.readthedocs.io/en/latest/)を利用しています。plyerが未導入の場合は自動的にターミナル出力にフォールバックします。

# 利用例
- 長時間のビルドやテスト中に、突然“バグ孵化”警告が表示されて緊張感と笑いを演出
- チームのペアプロやリモート会議中に、話題作りとして活用
- 本物のエラー通知と混同しないよう、ジョーク感を前面に出した文面

# 注意点
- 実際のバグやエラーには一切影響しません
- ログはユーザーのホームディレクトリに保存されます
- plyer未導入時はpip install plyerで導入可能

# 設計方針
通知タイミングは180秒〜900秒の範囲で完全ランダムに設定。CLIサブコマンドでログ閲覧や累計表示も可能にし、演出の透明性と操作性を両立しています。
