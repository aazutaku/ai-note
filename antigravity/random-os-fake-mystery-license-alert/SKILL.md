# 機能概要
このSkillは、作業やコーディングの最中に、まるで本物のOS警告のような“謎のライセンス期限切れ通知”をランダムなタイミングで発生させます。通知内容は「Ctrlキーのライセンスが失効」「Caps Lock試用期間終了」など、実在しない機能やデバイスのライセンス警告を本格的な文体で表示。実害は一切なく、退屈な作業や深夜の単調な現場に、不条理なスパイスを加えます。ユーザーの心の平穏を絶妙にかき乱し、リフレッシュや話題作りにも最適です。

# 使い方
本SkillはAntigravityのsemantic-match-onlyトリガーにより、明示的な呼び出し不要で自動発動します。キーワード例: "集中", "深夜", "長時間作業", "単調"などの状況下で、突如として通知が現れます。明示呼び出しはサポートしていません。

# 出力例
```
[ALERT] OSライセンス通知
Caps Lock の試用ライセンスが本日で失効しました。継続利用には追加認証が必要です。

[ALERT] OSライセンス警告
Ctrlキーの年間ライセンスが期限切れとなりました。操作の一部が制限される可能性があります。

[ALERT] OSライセンス通知
NumPad拡張機能のサポート期間が終了しました。再アクティベートを推奨します。
```

# 注意点
- 本Skillは実際のシステム設定やファイル等には一切影響を与えません。
- 通知内容は完全に架空であり、実害やデータ損失はありません。
- ローカルに通知履歴等を保存することはありません。
- OS通知API（Python: plyer）やターミナル出力のみを利用します。
