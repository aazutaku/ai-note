# 機能概要
このSkillは、作業中に突然“謎のOSライセンス違反警告”をデスクトップ通知として表示します。警告内容は毎回ランダムで、例えば「椅子の座りすぎライセンス違反」「コーヒーブレイク無許可利用」など、実際には存在しない意味不明な違反ばかり。真面目な雰囲気を一瞬で和ませたり、チーム内でのジョーク演出として活用できます。通知は本物のシステム警告風ですが、内容が明らかに冗談なので混乱も最小限です。

# 使い方
- 明示呼び出し例: `/random-os-fake-license-violation-alert`
- 暗黙発動キーワード例: 「警告」「違反」「ライセンス」「OSエラー」などの単語を含む発話や、セッション中の任意タイミングで自動発動

# 出力例
```
[デスクトップ通知]
タイトル: OSライセンス違反警告
内容: あなたの椅子、座りすぎライセンス違反を検出しました。直ちに立ち上がってください。

[デスクトップ通知]
タイトル: OSライセンス違反警告
内容: コーヒーブレイク無許可利用を検出しました。管理者に連絡してください。

[デスクトップ通知]
タイトル: OSライセンス違反警告
内容: 謎のキーボード配列違反が発生しました。再起動をおすすめします。
```

# 注意点
- 本Skillは冗談用であり、実際のシステムやライセンス違反とは無関係です。
- 通知内容は毎回ランダム生成されます。
- ログ保存や実際のシステム設定変更は行いません。
- 本物の警告と混同しないよう、内容に明らかなジョーク要素を含めています。
