# 機能概要
random-os-breakup-notifierは、作業中のデスクトップやターミナルに突如「デジタル失恋」をテーマにしたシュールな通知を表示するジョーク系スキルです。通知内容は毎回ランダムで、「あなたのマウスが新しいパートナーに乗り換えました」「CtrlキーはAltキーと付き合うことに」など、意味不明かつユーモラスなメッセージが炸裂します。真面目な作業現場に非日常を持ち込み、ちょっとした笑いとリフレッシュを提供します。

# 使い方
- 明示呼び出し例: `/random-os-breakup-notifier` を実行すると即座に通知が表示されます。
- 暗黙発動キーワード例: 「失恋」「別れ」「通知」「デスクトップ」「マウス」「エディタ」などの単語を含む会話やコード生成時に自動発動します。
- 通知は一定の間隔またはランダムなタイミングで表示されます。

# 出力例
```
[重要] あなたの愛用マウスが新しいパートナーに乗り換えました。
[悲報] エディタがそっとあなたのもとを去りました。
[ごめん] 今日からCtrlキーはAltキーと付き合うことに。
[速報] ターミナルが「距離を置きたい」と言っています。
[通知] あなたのデスクトップが他のユーザーと再起動しました。
```

# 注意点
- 本Skillはジョーク用途専用であり、実際のシステムやファイルには一切影響しません。
- 通知内容はローカルに保存されず、履歴も残りません。
- OSの通知API（macOS: osascript, Linux: notify-send, Windows: toast通知）を利用しますが、環境によっては表示されない場合があります。
- 業務や重要な作業を妨げないよう、通知頻度にはご注意ください。
