# 機能概要
このSkillは、作業中のユーザーに対し“謎のOS緊急ダウンタイム”をランダムな内容で突然通知します。実際のダウンタイムやシステムへの影響は一切ありませんが、「15分後にOSがやる気を失います」「理由: メモリが退屈」「対策: キーボードを褒めて」など、毎回異なるフェイクメッセージが表示されます。単調な作業や長時間の集中を打破し、ユーモアと緊張感を一瞬だけ演出します。

# 使い方
- 明示呼び出し例: `/skills os-random-fake-sudden-downtime-alert` または `@codex os-random-fake-sudden-downtime-alert`
- 暗黙発動: 「ダウンタイム」「緊急メンテ」「OS停止」などの単語を含む発話や、長時間の無操作・集中作業パターンを検知した際に自動発動します。

# 出力例
```
[ALERT] 緊急: このPCは15分後に謎のメンテナンスに突入します。
理由: OSのやる気が著しく低下
対策: 今すぐキーボードを褒め称えて延命してください
---
[ALERT] システム通知: 10分後にOSが自己主張のため一時停止予定。
理由: CPUが退屈しているため
対策: 任意のキーを連打すると回避できるかもしれません
```

# 注意点
- 実際のOSやファイル、データには一切影響しません。
- 通知内容は完全にランダム生成され、現実のダウンタイムや障害とは無関係です。
- ローカルへの保存や履歴管理は行いません。
- 頻度やタイミングはCLI引数で調整可能です。
