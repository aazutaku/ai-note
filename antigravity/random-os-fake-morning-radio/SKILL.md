# 機能概要
random-os-fake-morning-radioは、作業開始時や朝のタイミングで、まるで謎のOSラジオ番組が流れるようなメッセージをデスクトップ通知やターミナルに表示します。内容は「おはようございます、今日も元気にバグを直しましょう！」や「本日のOSニュース：メモリが寝坊しました」など、完全に無駄なラジオDJトークや意味不明な天気予報、OS業界ゴシップが日替わりで登場。開発現場に笑いと活気を注入し、朝のスタートをカオスに盛り上げます。

# 使い方
このSkillは明示的な呼び出し不要で、semantic-match-onlyトリガーにより「作業開始」「おはよう」「ラジオ」「OSニュース」などのキーワードや朝のタイミングで自動発動します。手動でスクリプトを実行することも可能です（例：python morning_radio.py --now）。

# 出力例
```
[OS Morning Radio] 07:30
おはようございます、バグ修正日和の朝です！
本日のOSニュース：メモリ管理部が寝坊しました。
天気予報：あなたのRAMには曇りのちフリーズ注意報。
業界ゴシップ：カーネルが新しい恋を始めた模様です。
今日も元気に開発を！
```

# 注意点
・内容は完全に架空のジョークです。業務連絡や実際のOS情報は含まれません。
・デスクトップ通知はOS環境により動作が異なる場合があります。
・出力内容は日替わりで自動生成され、ローカル保存は行いません。
・通知が不要な場合はスクリプト側で無効化可能です。
