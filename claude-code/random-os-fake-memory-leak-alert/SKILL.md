# 機能概要
このSkillは、作業中のあなたに突然「謎のOSメモリリークアラート」を表示することで、日常にちょっとしたスリルと遊び心を加えます。通知内容は毎回ランダムで、深刻そうなものからユーモラスなものまで多彩。実際のシステムやメモリには一切影響を与えず、あくまでフェイク警告として動作します。集中しすぎて疲れた心に、ちょっとした息抜きや話題のきっかけを提供します。

# 使い方
- 明示呼び出し: `/random-os-fake-memory-leak-alert` を実行すると即座にフェイク通知が表示されます。
- 暗黙発動: 「メモリ」「リーク」「OSエラー」などのキーワードが会話やコマンドに含まれると、自動的にランダム通知が発動します。

# 出力例
```
[ALERT] 重大：メモリがどこかに消えました
[WARNING] OS公式：記憶領域流出中
[INFO] 注意：あなたのやる気メモリもリークしています
[CRITICAL] システムリソースが想定外の方向に流出しています
[NOTICE] メモリリーク検出ツールがバグっています（たぶん）
```

# 注意点
- 通知はすべてフェイクであり、実際のシステムやファイルには影響しません。
- ローカル保存やログ出力は行いません。
- 重要な作業中に驚かないよう、必要に応じてSkillを無効化できます。
- OSの通知機能を利用するため、環境によっては通知が表示されない場合があります。
