# 概要
このSkillは、ユーザーの作業体験にユーモアやリフレッシュ効果をもたらすことを目的とし、完全にフェイクなOS通知をランダム生成します。通知内容は実際のOSやアプリの挙動に一切干渉せず、ユーザーの現実感覚を軽く揺さぶる演出に徹しています。

# 公式ドキュメント抜粋
Python標準のrandom・argparse・datetimeモジュールのみを利用し、外部依存を排除しています。

# 利用例
- コーディング中に「省エネ」や「遅い」といった話題が出た際に自動発動
- 明示的にCLIから `python fake_power_saving_mode.py log -n 3` で複数通知を生成
- 履歴やサマリー表示で過去のフェイク通知を振り返る

# 注意点
本Skillは完全なジョーク用途であり、実際のシステムや業務フローには影響を与えません。通知内容はすべてフィクションです。

# 設計方針
- 実在APIのみを利用し、OSやファイルへの副作用を最小化
- 履歴管理・サマリー機能で演出のバリエーションを強化
- スクリプト本体は100行以上でCLIサブコマンドに対応
