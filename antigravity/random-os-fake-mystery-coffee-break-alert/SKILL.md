# 機能概要
このSkillは、作業中に突如「OS公式」風の強制コーヒーブレイク通知を発生させることで、ユーザーの集中や疲労をリセットし、意図しない休憩を促します。通知メッセージは毎回ランダム生成され、まるで本物のOSや管理者からの指示のような説得力と謎演出を楽しめます。通常のリマインダーや休憩ツールとは異なり、唐突さやユーモアを重視し、作業の合間に非日常的な体験を提供します。

# 使い方
このSkillは明示的な呼び出しは不要で、Antigravityのセマンティックマッチによって自動発動します。たとえば「集中」「休憩」「timer」「break」「coffee」などの単語が会話やコマンド履歴に現れると、Skillが作動し、ターミナルやデスクトップに謎の通知が表示されます。明示的に `python coffee_break_alert.py` を実行しても動作します。

# 出力例
```
[OS SYSTEM ALERT] 本日、あなたの集中力ゲージが限界に到達しました。コーヒーブレイクが自動発動されます。
[OS NOTICE] 重要：OS推奨のリフレッシュタイム到来。今すぐ席を立ち、コーヒーを準備してください。
[OS OFFICIAL] システム管理者より：あなたの作業効率を維持するため、強制的に5分間のコーヒーブレイクを開始します。
[OS ALERT] 休憩プロトコル #42 発動中。理由：集中度が閾値を下回りました。
[OS SYSTEM] 重大：自動休憩タイマーが作動しました。作業を一時中断してください。
```

# 注意点
本Skillはジョーク的な通知演出を主目的とし、実際のOS管理や生産性管理ツールとは異なります。通知はローカル環境でのみ表示され、外部サーバーやネットワークには一切データを送信しません。既存のリマインダーやアラートとの併用時は、通知が重複する場合があります。
