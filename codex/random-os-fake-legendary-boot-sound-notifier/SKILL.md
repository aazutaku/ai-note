# 機能概要
このSkillは、作業開始時や明示的な呼び出し時に、まるで架空のOS公式“伝説の起動音”が鳴ったかのようなテキスト通知を表示します。毎回内容はランダムで、「バグフィックス交響曲」「宇宙人襲来ブザー」「未承認アップデートファンファーレ」など、絶対に実在しない怪しすぎる起動音タイトルが炸裂。実際に音は鳴らず、集中を妨げることなく、ちょっとした演出や気分転換、チームのアイスブレイクなどに活用できます。

# 使い方
- 明示呼び出し例:
  - `/skills random-os-fake-legendary-boot-sound-notifier`
  - スキルメニューから選択
- 暗黙発動:
  - 作業開始時や新規セッション開始時
  - 「起動」「スタート」「run」などのキーワードを含む初回発話

# 出力例
```
[OS通知] 起動音：伝説のバグフィックス交響曲
[OS通知] 起動音：宇宙人襲来ブザー
[OS通知] 起動音：未承認アップデートファンファーレ
[OS通知] 起動音：時代劇風ジングル - 幕開けの章
[OS通知] 起動音：謎のセキュリティ警告マーチ
```

# 注意点
- 実際に音は鳴りません。すべてテキスト通知のみです。
- 通知内容は毎回ランダム生成され、実在するOSや製品名は含まれません。
- ローカル保存や履歴管理は行いません。
- 出力はターミナルやチャット画面上のみ。外部通知やシステム連携はありません。
