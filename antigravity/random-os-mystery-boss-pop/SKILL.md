# 機能概要
このSkillは、作業中のユーザーに突如として“謎のOSボスキャラ”が出現し、カオスな命令や警告を発することで、集中力や気分転換を促す演出を提供します。ボスキャラやセリフは毎回ランダム生成され、通知は画面端やデスクトップに意外性をもって表示されます。業務の合間にユーモラスな体験を挟むことで、過度な集中やストレスの緩和、作業リズムのリセットをサポートします。

# 使い方
このSkillは明示的な呼び出しコマンドはありません。Antigravityが「ストレッチ」「休憩」「警告」「ボス」「通知」などのキーワードや、長時間の作業継続を検出した場合に自動発動します。暗黙的な発動例:
- 例: 「そろそろ休憩したほうがいいかな？」
- 例: 連続作業が1時間を超えた場合

# 出力例
```
[OS BOSS POP]
ボス名: メモリ喰いのガベージ伯爵
任務: 今すぐ椅子から立ち上がり、3回ジャンプせよ！
警告: 本日は残業魔王が降臨中。全プロセスが監視されているぞ。
画面表示位置: 左下

[OS BOSS POP]
ボス名: タスク破壊のクラッシュ女王
任務: コーヒーを淹れて深呼吸せよ！
警告: あなたの集中力ゲージが危険域です。
画面表示位置: 右上
```

# 注意点
- このSkillは通知演出のみで、ファイルやプロセスへの影響はありません。
- ローカル保存や記録は行いません。
- 実行環境によっては通知がOSのネイティブ通知機能に依存する場合があります。
- 業務環境や集中が必要な場面では、意図しないタイミングで表示されることがあります。
