# 機能概要
このSkillは、開発者の作業中に突如として「謎のOSシャットダウン瞑想タイム」を演出する通知・演出ツールです。デスクトップ通知や画面端に、毎回ランダムな意味不明メッセージ（例：「システムは5分間、無の境地に入ります」「強制メンテ：心の再起動モード」など）が表示され、進捗バーで“瞑想度”を測ったり、静寂を強制するタイマーも現れます。集中を撹乱しつつ、開発者に一瞬の悟り体験を提供します。

# 使い方
- 明示呼び出し例: `/skills random-os-fake-shutdown-meditation` または Skill メニューから選択
- 暗黙発動キーワード例: 「シャットダウン」「再起動」「メンテ」「瞑想」「進捗バー」などを含む会話やコマンドで自動発動

# 出力例
```
[通知] OS推奨：椅子で悟りを開いてください
[進捗バー] 瞑想度: [██████    ] 60%
[タイマー] 残り 03:12
[通知] 強制メンテ：心の再起動モード
[進捗バー] 瞑想度: [████████  ] 80%
[通知] システムは5分間、無の境地に入ります
```

# 注意点
- 本Skillは実際のOSシャットダウンやシステム操作は行いません。
- 通知・進捗バーはPythonの標準/主要GUIライブラリでローカル表示されます。
- ログや進捗は自動保存されません。実行中のみ演出が現れます。
- 一部環境（Linux/Windows/Mac）で通知表示方法が異なります。
