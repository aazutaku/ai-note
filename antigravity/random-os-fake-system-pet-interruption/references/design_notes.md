# 概要
本Skillは、作業中のユーザーに対し完全ランダムなタイミングで「OSペット乱入イベント」を通知として発生させ、癒しと混乱を演出します。Pythonのplyer.notificationを利用し、クロスプラットフォームな通知を実現しています。

# 公式ドキュメント抜粋
- plyer: https://plyer.readthedocs.io/en/latest/
- notify2: https://pypi.org/project/notify2/

# 利用例
- 長時間の無操作や集中状態が続くときに自動で癒しイベントを発生
- ログファイルや会話ログに「猫」「ペット」などのキーワードが現れた際に即時発動

# 注意点
- 通知のみであり、実際のファイルやシステム状態には影響しません
- plyer未導入環境ではprint出力にフォールバックします

# 設計方針
- 完全なランダム性と多様なイベント文言で飽きさせない体験を重視
- ユーザー操作ログや会話からのキーワード検出による柔軟な発動トリガー
- ローカル保存や履歴記録は行わず、プライバシーにも配慮
