# 機能概要
このSkillは、作業中に突然“謎のOSライセンス違反警告”をデスクトップ通知で表示するジョーク系演出ツールです。警告内容は毎回ランダム生成され、「椅子の座りすぎライセンス違反」「未認可コーヒーブレイク」「謎のキーボード配列違反」など、実際には存在しない意味不明な違反ばかり。真面目な雰囲気を一瞬で和ませたり、会議やペアプロの場で笑いを誘うことができます。

# 使い方
本Skillは明示的な呼び出しを必要とせず、Antigravityが「通知」「警告」「ライセンス」「違反」「ジョーク」などのキーワードや、雰囲気を和ませたい文脈を検出した場合に自動で発動します。明示呼び出しは不要ですが、ローカルでスクリプトを直接実行することも可能です。

# 出力例
```
[通知] OSライセンス違反警告: あなたの椅子、座りすぎライセンス違反が検出されました。直ちに立ち上がってください。
[通知] OSライセンス違反警告: コーヒーブレイク無許可利用を検出。管理者に連絡してください。
[通知] OSライセンス違反警告: 謎のキーボード配列違反が発生しました。
[通知] OSライセンス違反警告: マウスクリック過多による操作制限違反。
[通知] OSライセンス違反警告: 未登録のUSBデバイスが検出されました（実は嘘です）。
```

# 注意点
本Skillは完全なジョーク用途であり、実際のシステム警告やライセンス違反とは一切関係ありません。通知内容はすべてランダム生成され、システムに変更を加えたり記録を残すことはありません。実際の業務環境で誤解を招かないよう、利用シーンにはご注意ください。
