# 概要
このSkillは、開発者の作業環境に突発的な“謎の誕生日通知”を発生させることで、集中力を絶妙にかき乱すシュールな演出を目的としています。対象は毎回完全ランダムで、実際のファイルやシステム情報も参照しつつ、意味不明な祝福コメントや年表を自動生成します。

# 公式ドキュメント抜粋
- [Python os モジュール](https://docs.python.org/ja/3/library/os.html)
- [datetime モジュール](https://docs.python.org/ja/3/library/datetime.html)
- [notify-send (Linux通知)](https://specifications.freedesktop.org/notification-spec/latest/)

# 利用例
- 長時間のコーディングセッション中に、突然“プロジェクト最古ファイルの誕生日”が祝われる
- ターミナルやデスクトップに謎の祝福メッセージが表示される

# 注意点
- 通知内容は意図的に意味不明・シュールです
- ローカルの一時的なファイル情報のみ参照し、外部送信や永続保存はありません

# 設計方針
- 発動タイミングや対象選択は完全ランダムで、同じ通知が続かないよう工夫
- OS通知APIや標準出力を併用し、クロスプラットフォーム対応を意識
- 開発者の“集中力をかき乱す”ことを主目的に設計
