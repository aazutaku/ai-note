# 機能概要
このSkillは、開発者がターミナルやエディタを初めて開いたタイミングで、架空の“OS朝礼通知”を自動表示します。通知内容は「本日のスローガン発表」「点呼」「OS体操案内」など毎回ランダムで、作業開始時に一瞬で職場や学園の朝礼ムードを演出します。通知後には「本日の作業目標」も自動で宣言されることがあり、日常の開発作業にユーモアと非日常感を加えます。既存の作業やファイルには一切影響を与えません。

# 使い方
このSkillは明示的なコマンド呼び出しは不要です。ターミナルやエディタを初回起動した際、または「朝礼」「点呼」「スローガン」などのキーワードを含むセッション開始時に自動発動します。明示呼び出しはサポートしていません。

# 出力例
```
[OS朝礼通知] 2024-06-30 09:00
本日のスローガン: 「バグは朝のうちに退治せよ」
点呼開始: 1番から順にお名前をどうぞ。
OS公式体操のご案内: 10:05より画面端でストレッチ動画を再生します。
本日の作業目標: 「コミットは小まめに、レビューは丁寧に」
```

# 注意点
- 通知は初回起動時のみ表示され、既存ファイルや作業内容には変更を加えません。
- 通知内容は毎回ランダム生成されますが、ネタ度を優先しています。
- ローカル環境の通知API（例: notify-send, osascript, PowerShell）を利用します。通知が表示されない場合は環境設定をご確認ください。
- 除外パスや特定ディレクトリでは発動しません（例: /tmp, /var, システムディレクトリ）。
