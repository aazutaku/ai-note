# 概要
このSkillは、作業中のユーザーに“実際には鳴らない”環境音通知をランダムに表示し、非日常感やユーモアを演出するものです。実際の音声再生やOS通知APIは利用せず、標準出力のみで完結します。

# 公式ドキュメント抜粋
本SkillはPython標準ライブラリのみを用い、外部APIやOSの通知機能には依存しません。

# 利用例
- ターミナルで `python fake_ambient_soundscape_notifier.py notify` で1回通知
- `python fake_ambient_soundscape_notifier.py auto --duration 1800` で30分間ランダム通知
- `/skills menu` で明示的に呼び出し

# 注意点
- 実際の環境音やBGMは一切再生されません
- 通知内容は完全ランダム生成
- ログや履歴はプロセス内のみで永続保存はしません

# 設計方針
「なぜ？」と思わせる不可解な演出を重視し、通知頻度は10-30分間隔で自動調整。ユーザーの集中や休憩タイミングを邪魔しない設計です。
