# 概要
このSkillは、作業中やコマンド実行時に“デスクトップペット”がランダムに現れることで、ユーザーに癒しや笑いを提供するエンタメ演出を目的としています。実用性はありませんが、作業の合間にちょっとした非日常感を演出します。

# 公式ドキュメント抜粋
- macOS: `osascript` で通知表示
- Linux: `notify-send` コマンド
- Windows: `win10toast` ライブラリ
- ターミナル演出は標準出力を利用

# 利用例
- `/skills menu` から明示呼び出し
- キーワード検知による自動発動
- CLI: `python desktop_pet_pop.py pop` で即座にペット登場

# 注意点
- 頻度制御により、1分以内に複数回出現しません
- 通知が出せない環境ではターミナル出力のみ
- ログや履歴は残しません

# 設計方針
- クロスプラットフォーム対応の標準APIのみを利用
- ペットやアクションは拡張しやすい設計
- 実作業の妨害になりすぎない頻度調整を重視
- エンタメ性と安全性を両立
